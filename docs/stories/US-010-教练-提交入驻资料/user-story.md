- **触发方**：教练

## 3. 前置条件

- [x] 教练已完成微信授权登录
- [x] 系统未存在该教练的入驻记录（或记录状态为已驳回/已离职可重新申请）
- [x] 保存草稿或提交审核后，`coach.status` 均写入 0（待审核），不新增独立草稿态
- [x] 系统已配置入驻所需资料字段

---

## 4. 业务流程

### 4.1 主路径

1. 教练进入教练端，点击「申请入驻」
2. 系统展示入驻资料填写页
3. 教练上传证书照片、填写任教年限、总学员数、总课时数、个人简介
4. 教练设置参考单价
5. 教练点击「提交审核」或「保存草稿」
6. 系统校验资料完整性与图片大小（仅提交审核时校验完整性）
7. 系统创建/更新 coach 记录，`coach.status = 0`（待审核）
   - 点击「保存草稿」时：`submitted_at` 为 NULL，资料持久化但不进入审核队列
   - 点击「提交审核」时：`submitted_at` 写入当前时间，进入 US-011 审核队列
8. 系统返回提交成功或草稿保存成功；仅正式提交时提示等待审核

### 4.2 异常分支

- **分支 1**：必填项缺失 → 前端阻止提交并提示
- **分支 2**：证书图片过大/格式错误 → 提示「请上传小于 5MB 的 JPG/PNG 图片」
- **分支 3**：参考单价超出范围 → 提示「参考单价需在 50-2000 元之间」
- **分支 4**：已存在待审核/已通过记录 → 提示「您已提交入驻申请，请勿重复提交」（已驳回记录可重新提交）

## 6. 验收标准（业务级 Gherkin）

> L2（1 人天）：2 正常 + 3 异常 = 5 个场景

### 6.1 场景 1：正常提交入驻资料

```gherkin
Given 教练已完成登录且未提交过入驻申请
When  教练填写任教年限 5 年、总学员数 100、总课时数 500、个人简介
And   教练上传证书照片并设置参考单价 300 元
And   教练点击「提交审核」
Then  coach 记录创建成功
And   coach.status = 0（待审核）
And   系统返回"提交成功，等待审核"
```

### 6.2 场景 2：保存入驻资料草稿

```gherkin
Given 教练正在填写入驻资料
When  教练填写部分资料后点击「保存草稿」
Then  coach 记录创建成功
And   coach.status = 0（待审核）
And   已填字段被保存，下次进入可继续编辑
And   不新增独立草稿状态
```

### 6.3 场景 3：必填项缺失

```gherkin
Given 教练进入入驻资料页
When  教练未上传证书且未填写任教年限即点击「提交审核」
Then  前端阻止提交
And   缺失字段下方提示"此项为必填"
And   后端未收到提交请求
```

### 6.4 场景 4：重复提交入驻申请

```gherkin
Given 教练已存在 status = 0 的入驻申请
When  教练再次点击「提交审核」
Then  返回错误码 COACH_APPLICATION_PENDING
And   前端提示"您已提交入驻申请，请勿重复提交"
```

### 6.5 场景 5：证书图片过大

```gherkin
Given 教练正在上传证书照片
When  教练选择一张 8MB 的 PNG 图片
Then  前端/后端校验拒绝
And   前端提示"请上传小于 5MB 的 JPG/PNG 图片"
```

### 6.6 场景 6：已驳回教练重新提交入驻资料

```gherkin
Given 教练已存在 status = 2 的驳回记录
And   驳回原因已查看
When  教练修改证书照片与任教年限后点击「提交审核」
Then  系统更新 coach 记录
And   coach.status 重置为 0（待审核）
And   coach.rejection_reason 清空
And   coach.submitted_at 更新为当前时间
And   系统返回"提交成功，等待审核"
```

## 8. 边界场景

### 8.1 边界场景 1：已离职教练重新申请

- **触发条件**：status = 3（已离职）的教练重新申请入驻
- **预期行为**：允许重新提交，创建新的待审核记录或重置状态为 0
- **用户可见反馈**："请重新提交入驻资料，等待审核"

### 8.2 边界场景 2：网络中断导致图片上传失败

- **触发条件**：提交过程中网络中断
- **预期行为**：前端提示上传失败，已填字段保留
- **用户可见反馈**："网络异常，请检查网络后重试"

### 8.3 边界场景 3：并发提交

- **触发条件**：教练快速点击两次「提交审核」
- **预期行为**：幂等处理，只创建一条待审核记录
- **用户可见反馈**：正常提示提交成功

## 12. 备注

- **图片限制**：单张 ≤ 5MB，格式 JPG/PNG
- **参考单价范围**：50-2000 元/节，后台可配置
- **幂等键**：`coach_apply:{user_id}:{timestamp}`
- **草稿状态**：MVP 不新增独立草稿状态；保存草稿与提交审核均写入 `coach.status=0`，通过 `submitted_at IS NOT NULL` 区分正式提交与草稿。US-011 审核列表必须过滤 `submitted_at IS NOT NULL` 的记录，避免草稿进入审核队列
- **驳回后重新提交**：status=2 的教练可修改资料后重新提交，复用原 coach 记录，清空 `rejection_reason`，`status` 重置为 0，`submitted_at` 更新为当前时间

## 14. 页面级设计决策

### 14.1 入驻资料是否分步填写

- **背景**：入驻字段较多，考虑分步或单页
- **选项**：A. 单页长表单；B. 分步骤向导
- **结论**：选择 A，MVP 先做单页长表单，降低复杂度
- **影响范围**：入驻资料页 UI

### 14.2 参考单价输入方式

- **背景**：教练需设置一节课的参考单价
- **结论**：数字输入框，单位「元/节」，带范围提示
- **影响范围**：入驻资料页表单

### 14.3 页面级交互说明

| 交互 | 触发 | 反馈 | 备注 |
|------|------|------|------|
| 上传证书 | 点击上传区 | 图片预览 + 大小校验 | 超出限制提示错误 |
| 保存草稿 | 点击按钮 | 提示"草稿已保存" | 不进入审核队列 |
| 提交审核 | 点击按钮 | 加载态 + 成功/失败提示 | 需防重复点击 |
