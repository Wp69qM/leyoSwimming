## 4. 业务流程

### 4.1 主路径

1. 管理员进入「数据看板」模块
2. 系统默认展示今日/本周/本月关键指标与 5 项基础看板
3. 管理员选择时间范围或筛选条件
4. 系统返回对应图表数据
5. 管理员切换至「客服工单」模块
6. 系统展示工单列表（待处理 / 处理中 / 待反馈 / 已关闭）
7. 管理员查看工单详情，分配处理人，填写处理回复
8. 系统更新工单状态并通知提交者

### 4.2 异常分支

- **分支 1**：时间范围不合法（开始 > 结束）→ 返回 `INVALID_DATE_RANGE`
- **分支 2**：工单不存在 → 返回 HTTP 404
- **分支 3**：管理员无权限 → 返回 HTTP 403

## 6. 验收标准（业务级 Gherkin）

> 本 US 为 L2（1.5 人天），场景数 = 2 正常 + 3 异常 = 5。

### 6.1 场景 1：管理员查看数据看板

```gherkin
Given 管理员已登录且具有数据看板权限
And   系统已存在体验课预约记录 120 条，正价课预约记录 300 条
When  管理员选择时间范围 2026-07-01 至 2026-07-31 查看"游泳高峰期"看板
Then  系统返回 HTTP 200
And   返回 24 个时段的体验课预约分布数据，每个时段 count ≥ 0
And   响应时间 < 500ms
And   页面展示折线图
```

### 6.2 场景 2：管理员处理客服工单

```gherkin
Given 管理员已登录且具有客服工单处理权限
And   存在工单 T-001，status='pending'，类型="换教练申请"
When  管理员将工单 T-001 分配给客服 A
And   管理员提交回复："已为您安排新教练，请查看短信通知"
And   管理员将工单状态更新为"closed"
Then  系统返回 HTTP 200
And   support_ticket 表 T-001 的 handler_id=客服 A ID，status='closed'
And   ticket_reply 表新增 1 条记录
And   提交者收到工单处理结果通知
```

### 6.3 场景 3：时间范围不合法

```gherkin
Given 管理员已登录且具有数据看板权限
When  管理员查询"每月总课时"看板，start_month="2026-08"，end_month="2026-07"
Then  系统返回 HTTP 400
And   返回错误码 INVALID_DATE_RANGE
And   不执行 SQL 查询
```

### 6.4 场景 4：工单不存在

```gherkin
Given 管理员已登录且具有客服工单处理权限
When  管理员查看 id=99999 的工单详情
Then  系统返回 HTTP 404
And   返回错误码 TICKET_NOT_FOUND
```

### 6.5 场景 5：无权限管理员访问看板接口

```gherkin
Given 管理员已登录但角色无"数据看板"权限
When  管理员调用 GET /api/admin/dashboard/peak-hours
Then  系统返回 HTTP 403
And   返回错误码 FORBIDDEN
And   不返回任何看板数据
```

## 8. 边界场景

### 8.1 边界场景 1：看板数据为空

- **触发条件**：所选时间范围内无任何业务数据
- **预期行为**：返回空数组或零值，图表展示空状态
- **用户可见反馈**：提示"所选时间段暂无数据"

### 8.2 边界场景 2：工单已被其他客服处理

- **触发条件**：客服 A 正在回复工单时，客服 B 已将其关闭
- **预期行为**：后提交者收到冲突提示，状态以最新为准
- **用户可见反馈**：提示"该工单状态已变更，请刷新后重试"

### 8.3 边界场景 3：工单关闭后仍尝试回复

- **触发条件**：工单已 closed，管理员再次提交回复
- **预期行为**：系统拒绝并提示工单已关闭
- **用户可见反馈**：提示"工单已关闭，无法继续回复"

## 14. 页面级设计决策

### 14.1 看板与工单分模块

- 「数据看板」与「客服工单」作为两个独立菜单
- 看板默认展示本周数据，支持自定义时间范围

### 14.2 工单状态标签

- pending（待处理）、processing（处理中）、awaiting_feedback（待反馈）、closed（已关闭）
- 列表支持按状态筛选与排序

### 14.3 页面级交互说明

| 交互 | 触发 | 反馈 | 备注 |
|------|------|------|------|
| 切换时间范围 | 选择日期 | 图表重新加载 | 限制最大 90 天 |
| 分配工单 | 选择处理人 | 工单状态变 processing | 通知处理人 |
| 提交回复 | 点击发送 | 状态变 awaiting_feedback 或 closed | 通知提交者 |
