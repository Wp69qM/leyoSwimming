## 2. 触发条件

> 什么事件/操作触发该故事

- **触发方**：用户
- **触发动作**：首次使用微信授权登录（US-004）后，系统检测到资料缺失，进入资料补充页
- **触发时机**：登录成功后立即触发，或用户主动进入「我的 → 个人资料」完善信息

- [x] 用户已完成微信授权登录（依赖 US-004）
- [x] 当前用户资料状态为不完整（手机号/用户名/密码/邮箱未填写）
- [x] 系统未存在相同手机号的已注册用户

## 4. 业务流程

> 步骤列表（带异常分支），用户视角描述

### 4.1 主路径

1. 用户微信授权登录成功，系统判断为首次登录且资料缺失
2. 系统展示资料补充页，默认带入微信头像与昵称
3. 用户填写手机号、用户名、密码、邮箱（手机号必填，其余按需）
4. 系统校验手机号格式、用户名唯一性、密码强度
5. 用户点击「完成注册」
6. 系统保存资料，`user.status = '注册用户'`
7. 系统返回首页，身份切换为注册用户

### 4.2 异常分支

- **分支 1**：手机号已注册 → 提示「该手机号已绑定其他账号，请更换或登录」
- **分支 2**：手机号格式非法 → 前端实时提示「请输入正确的手机号」
- **分支 3**：用户名已存在 → 提示「用户名已被占用」
- **分支 4**：密码强度不足 → 提示「密码需包含 8-20 位字母与数字」

## 6. 验收标准（业务级 Gherkin）

> **业务级 Gherkin**：聚焦"用户能观察到的结果"，不绑死实现细节。

### 6.1 场景 1：正常补充注册资料

```gherkin
Given 用户已完成微信授权登录且资料缺失
And   系统未存在手机号 13800138000 的注册用户
When  用户填写手机号 13800138000、用户名 swimmer01、密码 Abcd1234、邮箱 a@b.com
And   用户点击「完成注册」
Then  系统保存成功
And   user.status = '注册用户'
And   页面跳转至首页，顶部显示用户名 swimmer01
```

### 6.2 场景 2：手机号已被注册

```gherkin
Given 系统中已存在手机号 13800138000 的注册用户
When  用户填写手机号 13800138000 并提交
Then  返回错误码 PHONE_ALREADY_BOUND
And   前端提示"该手机号已绑定其他账号，请更换或登录"
And   用户资料未被保存
```

### 6.3 场景 3：必填项缺失

```gherkin
Given 用户已完成微信授权登录
When  用户未填写手机号直接点击「完成注册」
Then  前端阻止提交
And   手机号输入框下方提示"手机号不能为空"
And   后端未收到请求
```

## 8. 边界场景

> 至少 3 个异常边界场景

### 8.1 边界场景 1：快速重复提交

- **触发条件**：用户连续点击「完成注册」按钮两次
- **预期行为**：幂等处理，第二次请求返回与第一次一致的结果，不创建重复用户
- **用户可见反馈**：页面正常跳转，无重复提示

### 8.2 边界场景 2：网络中断

- **触发条件**：提交过程中网络断开
- **预期行为**：前端展示重试机制，失败后提示用户重新提交
- **用户可见反馈**："网络异常，请检查网络后重试"

### 8.3 边界场景 3：用户名含有敏感词

- **触发条件**：用户输入包含敏感词的用户名
- **预期行为**：后端校验拒绝，前端提示修改
- **用户可见反馈**："用户名包含敏感内容，请重新输入"

## 14. 页面级设计决策

> 本节是**本故事特殊**的设计选择，**全局规范**中没有定义的设计决策记录在这里。

### 14.1 资料补充的入口策略

- **背景**：首次微信登录后必须补充资料才能使用核心功能
- **选项**：A. 强制弹窗拦截；B. 首页顶部提示条引导
- **结论**：选择 A，登录后直接跳转资料补充页，未填写手机号无法进入首页
- **影响范围**：登录回调页、资料补充页、首页路由守卫

### 14.2 用户名是否必填

- **背景**：微信昵称已存在，是否还需独立用户名
- **选项**：A. 必填；B. 选填，默认用微信昵称
- **结论**：用户名必填，避免微信昵称重复/敏感词问题
- **影响范围**：资料补充页表单、user.username 唯一索引

### 14.3 页面级交互说明

| 交互 | 触发 | 反馈 | 备注 |
|------|------|------|------|
| 手机号输入 | 输入 11 位数字 | 实时校验格式 | 非 11 位禁用提交 |
| 完成注册 | 点击按钮 | 加载态 + 成功跳转/错误提示 | 需防重复点击 |
