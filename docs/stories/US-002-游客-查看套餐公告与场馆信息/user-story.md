## 2. 触发条件

- **触发方**：游客
- **触发动作**：在首页点击「套餐」「公告」「场馆」任一入口，或滚动首页公告栏
- **触发时机**：用户主动操作；首页公告栏在页面加载时自动拉取并轮播

## 3. 前置条件

- [x] 游客已打开小程序（无需登录）
- [x] 管理员已在后台配置场馆信息（依赖 US-047）
- [x] 管理员已配置至少 1 个标准套餐模板（依赖 US-045）
- [x] 公告/通知栏由管理员在后台维护（依赖 US-047/US-048）

---

## 4. 业务流程

### 4.1 主路径

1. 游客进入小程序首页
2. 首页通知栏自动展示当前生效公告（按 priority 排序，最多 5 条）
3. 游客点击「查看全部套餐」进入套餐列表页
4. 系统按「体验套餐 → 正式套餐」顺序展示套餐模板
5. 游客点击「场馆信息」入口查看场馆名称、地址、开业年限、泳池状态
6. 游客点击「导航」唤起微信地图导航至场馆

### 4.2 异常分支

- **分支 1**：无任何已上架套餐 → 套餐列表展示空状态文案"暂无可选套餐，敬请期待"
- **分支 2**：无生效中公告 → 通知栏隐藏，不展示空状态
- **分支 3**：场馆信息未配置 → 场馆信息页提示"场馆信息配置中"
- **分支 4**：网络异常 → 提示"网络异常，请重试"

## 6. 验收标准（业务级 Gherkin）

> 业务级 Gherkin：聚焦"用户能观察到的结果"，不绑死实现细节。

### 6.1 场景 1：正常浏览套餐、公告与场馆信息

```gherkin
Given 系统已配置 1 个体验套餐 + 3 个标准套餐（1/6/8 节）
And   有 2 条生效中的公告（priority=2 紧急、priority=0 普通）
And   场馆信息已配置（名称="乐游游泳馆"，地址="北京市朝阳区..."）
When  游客进入小程序首页
Then  通知栏按 priority 降序展示 2 条公告
And   通知栏滚动展示公告（轮播时长见 §14.1）
When  游客点击「查看全部套餐」
Then  套餐列表按「体验套餐 → 正式套餐」顺序展示 4 个套餐
And   每个套餐展示名称、课时数、价格、有效期
When  游客点击「场馆信息」入口
Then  场馆信息页展示名称、地址、开业年限、泳池状态
And   页面底部展示「导航」按钮
```

### 6.2 场景 2：无套餐可展示（异常）

```gherkin
Given 管理员未配置任何套餐模板（或所有套餐模板 status=下架）
When  游客进入套餐列表页
Then  列表返回空数组 + HTTP 200
And   页面展示空状态插画 + 文案"暂无可选套餐，敬请期待"
And   不展示"立即购买"按钮（未注册用户无法购买，统一在 US-017/US-020 处理）
```

### 6.3 场景 3：公告维护中 / 无生效公告（异常）

```gherkin
Given 系统无任何生效中公告（所有公告 start_at/end_at 不在当前时间区间）
When  游客进入首页
Then  通知栏区域整体隐藏（不展示空状态，避免视觉噪音）
And   套餐入口与场馆入口正常展示
```

### 6.4 场景 4：场馆信息未配置（异常）

```gherkin
Given 管理员尚未配置场馆信息（venue 表为空）
When  游客点击「场馆信息」入口
Then  场馆信息页展示占位文案"场馆信息配置中"
And   不展示「导航」按钮（无可导航坐标）
```

### 6.5 场景 5：自定义套餐不返回

```gherkin
Given 系统已配置 1 个体验套餐、1 个标准套餐和 1 个 package_type=2 的自定义套餐，且均为上架状态
When  游客进入套餐列表页
Then  列表返回 2 个套餐（仅体验套餐和标准套餐）
And   返回的 items 数组中不包含自定义套餐模板
```

### 6.6 场景 6：闭馆换水时间窗命中

```gherkin
Given venue_closure 表存在一条记录，start_at <= NOW() < end_at，closure_type=1（换水）
And   场馆信息已配置
When  游客请求场馆信息
Then  场馆信息接口返回 200
And   返回的 closureNotice 字段填充 type="换水"、reason、startAt、endAt
And   前端场馆信息页置顶红色提示条展示换水信息
```

## 7. 数据/API/状态机影响

> 本节为摘要级概述，完整技术设计见 [./tech-design.md](./tech-design.md)。

| 维度 | 影响 |
|------|------|
| **数据表** | 读取 `notice`（公告，PRD §9.2.13）、`venue`（场馆）、`venue_closure`（闭馆换水）、`package_template`（套餐模板，PRD 未明确字段，待 US-045 补充） |
| **API** | 新增 `GET /api/v1/packages`（套餐列表）、`GET /api/v1/announcements`（公告列表）、`GET /api/v1/venue`（场馆信息） |
| **状态机** | 只读 US，不修改任何实体状态；读取依赖 `notice.start_at/end_at` 时间窗、`venue` 配置存在性、`package_template.status` 上架状态 |
| **缓存** | Redis 缓存：套餐列表 TTL 300s、公告 TTL 60s、场馆信息 TTL 3600s |

> **配套文档**：[技术设计](./tech-design.md)　·　[测试计划](./test-plan.md)　·　Figma 见 §13-15

## 8. 边界场景

| # | 场景 | 处理方式 |
|---|------|---------|
| 1 | 无任何已上架套餐模板 | 套餐列表返回空数组 + 200，前端展示空状态文案"暂无可选套餐，敬请期待" |
| 2 | 无生效中公告（公告时间窗不命中） | 通知栏区域隐藏，不展示空状态，不报错 |
| 3 | 场馆信息未配置（venue 表无记录） | 场馆信息页展示"场馆信息配置中"占位文案，不展示「导航」按钮 |
| 4 | 公告 `visible_scope` 不含游客（如配置为 student/coach） | 该公告不出现在游客的通知栏，按 type/priority 过滤后再按时间窗过滤 |
| 5 | 网络异常 / 接口超时 | 提示"网络异常，请重试"，首页其他模块（教练入口、套餐入口）仍可用 |
| 6 | 套餐模板价格为 0（赠送类模板被错误上架） | 列表过滤掉 `price = 0` 的赠送类模板，仅展示 `package_type ∈ {体验, 正式}` 且 `status = 上架` 的模板 |

## 14. 页面级设计决策

> 本节是**本故事特殊**的设计选择，**全局规范**中没有定义的设计决策记录在这里。

### 14.1 通知栏的展示规则

- **位置**：首页顶部，Logo 下方
- **展示数量**：最多 5 条，超出按 priority 降序截断
- **滚动方式**：垂直轮播，每条 4 秒，循环播放
- **type 颜色映射**：
  - type=0 开放 → 主色（蓝）
  - type=1 换水 → 警告色（橙）
  - type=2 释放 → 成功色（绿）
  - type=3 紧急 → 危险色（红）
- **空状态**：通知栏区域整体隐藏，不展示空插画（避免首页视觉噪音）

### 14.2 套餐卡片的展示顺序

按业务优先级展示，引导用户先体验后正价：
1. 体验套餐（如有）— 顶部，带"推荐"标签
2. 标准套餐 1 节
3. 标准套餐 6 节
4. 标准套餐 8 节
5. 标准套餐 10 节
6. 自定义套餐入口（跳转 US-020）

**取舍说明**：体验套餐置顶是因为它是新用户转化的最低门槛入口；自定义套餐不直接展示价格（按教练单价动态计算），仅展示入口卡片。

### 14.3 套餐卡片字段密度

每个套餐卡片展示（按视觉权重排序）：
1. 套餐名称（16pt 加粗）
2. 课时数（14pt，"X 节课"）
3. 价格（20pt 主色加粗，"¥XXX"）
4. 有效期（12pt 灰色，"X 天有效"）
5. 标签（如"推荐""热门"，最多 1 个）

**不展示**：教练信息（套餐未绑定教练，购买时才选）、购买按钮（游客未登录，点击后引导注册）

### 14.4 场馆信息页布局

- 场馆名称（页头大标题）
- 场馆图片（顶部 banner，可选，无图时占位灰色块）
- 地址行（带定位图标）
- 「导航」按钮（底部固定，唤起微信地图）
- 开业年限 + 泳池状态（次级信息行）
- 当前闭馆/换水提示（如有 venue_closure 记录命中当前时间，置顶红色提示条）

### 14.5 页面级交互说明

| 交互 | 触发 | 反馈 | 备注 |
|------|------|------|------|
| 通知栏点击 | tap 某条公告 | 跳转公告详情页（不在本 US 范围，P2） | MVP 仅展示，不可点 |
| 套餐卡片点击 | tap 套餐卡片 | 跳转套餐详情页 / 引导注册 | 需触发 US-017/US-020 |
| 「导航」按钮 | tap | 唤起微信内置地图导航 | 使用 `wx.openLocation` |
| 下拉刷新 | 下拉手势 | 重新拉取公告 + 套餐 + 场馆 | 首页/列表页均支持 |
