## 4. 业务流程

### 4.1 主路径

1. 用户进入账号安全设置页
2. 系统展示当前手机号、密码强度、登录设备列表
3. 用户可选择：换绑手机号、修改密码、管理登录设备
4. 用户完成敏感操作需二次验证：换绑手机号需原手机号短信验证码或当前密码验证，修改密码需原密码
5. 系统保存变更并发送通知

### 4.2 异常分支

- **分支 1**：新手机号已注册 → 提示「该手机号已被其他账号绑定」
- **分支 2**：原密码错误 → 提示「原密码错误」
- **分支 3**：新密码与旧密码相同 → 提示「新密码不能与旧密码相同」
- **分支 4**：设备下线失败 → 提示「操作失败，请重试」

## 6. 验收标准（业务级 Gherkin）

> L2（1 人天）：3 正常 + 3 异常 = 6 个场景

### 6.1 场景 1：正常换绑手机号

```gherkin
Given 用户已登录且当前手机号为 13800138000
And   新手机号 13900139000 未注册
When  用户输入新手机号及验证码
And   用户完成二次验证
Then  user.phone 更新为 13900139000
And   旧手机号 13800138000 可重新注册
And   系统发送换绑通知短信
```

### 6.2 场景 2：正常修改密码

```gherkin
Given 用户已登录且原密码为 Abcd1234
When  用户输入原密码 Abcd1234 和新密码 NewPass123
And   用户点击「确认修改」
Then  password_hash 更新
And   仅当前设备保留登录态，其他设备 token 立即失效
And   系统发送密码修改通知
```

### 6.3 场景 3：新手机号已被绑定

```gherkin
Given 用户已登录
And   手机号 13900139000 已绑定其他账号
When  用户尝试换绑到 13900139000
Then  返回错误码 PHONE_ALREADY_BOUND
And   前端提示"该手机号已被其他账号绑定"
```

### 6.4 场景 4：原密码错误

```gherkin
Given 用户已登录且原密码为 Abcd1234
When  用户输入原密码 WrongPass 和新密码 NewPass123
And   用户点击「确认修改」
Then  返回错误码 INVALID_OLD_PASSWORD
And   前端提示"原密码错误"
And   password_hash 保持不变
```

### 6.5 场景 5：下线登录设备

```gherkin
Given 用户已登录且存在 2 个登录设备
When  用户在设备列表中点击「下线」其中一个设备
Then  被下线设备的 token 立即失效
And   设备列表刷新，显示 1 个在线设备
And   被下线设备再次访问时返回 401
```

### 6.6 场景 6：微信登录用户首次设置密码

```gherkin
Given 用户仅通过微信授权登录，password_hash 为空
When  用户进入账号安全设置页并输入新密码 NewPass123
And   用户点击「确认设置」
Then  password_hash 更新为 NewPass123 的 bcrypt 哈希
And   系统发送密码设置通知
And   当前设备会话保留
```

## 8. 边界场景

### 8.1 边界场景 1：换绑手机号 24 小时内再次换绑

- **触发条件**：用户 24 小时内第二次换绑手机号
- **预期行为**：系统限制频繁换绑，24 小时内仅允许 1 次
- **用户可见反馈**："手机号换绑过于频繁，请 24 小时后再试"

### 8.2 边界场景 2：新密码强度不足

- **触发条件**：用户输入弱密码如 123456
- **预期行为**：前端+后端双重校验拒绝
- **用户可见反馈**："密码需包含 8-20 位字母与数字"

### 8.3 边界场景 3：异地登录后强制修改密码

- **触发条件**：系统检测到异常异地登录
- **预期行为**：提示用户检查账号安全，建议修改密码
- **用户可见反馈**："检测到异常登录，请确认是否为本人操作"

## 14. 页面级设计决策

### 14.1 敏感操作二次验证方式

- **背景**：换绑手机号、修改密码等操作风险较高
- **选项**：A. 统一用原密码；B. 根据操作类型选择验证码/密码
- **结论**：选择 B，换绑手机号用短信验证码，修改密码用原密码
- **影响范围**：各设置项的验证流程

### 14.2 设备列表信息展示

- **背景**：用户需要识别自己的登录设备
- **结论**：展示设备名称、登录时间、地点、是否当前设备
- **影响范围**：设备管理页 UI

### 14.3 页面级交互说明

| 交互 | 触发 | 反馈 | 备注 |
|------|------|------|------|
| 点击换绑手机号 | 点击入口 | 进入验证+换绑流程 | 需短信验证码 |
| 点击修改密码 | 点击入口 | 弹出原密码输入框 | 需原密码校验 |
| 点击下线设备 | 点击按钮 | 二次确认弹窗 | 确认后删除 token |
