- [x] 后台可读取当前生效配置

---

## 4. 业务流程

### 4.1 主路径

1. 管理员进入 [预约释放规则配置] 页面
2. 系统展示当前配置：释放时间、释放范围、候补开关、候补有效期、关注提醒提前时间
3. 管理员修改配置并点击「保存」
4. 系统校验字段格式与业务规则
5. 系统写入 `release_rule` 表并记录变更日志
6. 系统返回保存成功，并提示「新规则将于下次释放时生效」

### 4.2 异常分支

- **分支 1**：释放时间格式非法 → 返回错误 `INVALID_RELEASE_TIME`，前端高亮字段
- **分支 2**：关注提醒时间大于释放周期 → 返回错误 `REMINDER_TOO_LONG`
- **分支 3**：管理员无权限 → 返回 HTTP 403 `FORBIDDEN`

## 6. 验收标准（业务级 Gherkin）

### 6.1 场景 1：正常配置默认释放规则

```gherkin
Given 管理员已登录并拥有排班配置权限
And   当前系统使用默认规则（每周三 10:00 释放下周整周）
When  管理员将释放时间改为周五 14:00 并保存
Then  release_rule 表记录更新为 release_time = "14:00"、release_weekday = 5
And   release_scope = "NEXT_WEEK"
And   系统返回 HTTP 200
And   前端提示"保存成功，新规则将于下次释放时生效"
```

### 6.2 场景 2：配置节假日提前释放

```gherkin
Given 管理员已登录并拥有排班配置权限
And   下周一为法定节假日且场馆闭馆
And   当前默认释放日为周三 10:00
When  管理员勾选"节假日提前释放"并将释放日期提前至本周二 10:00
Then  release_rule.holiday_release_enabled = true
And   release_rule.holiday_release_offset_days = -1
And   系统生成首页公告草稿"下周预约将提前至本周二 10:00 开放"
```

### 6.3 场景 3：释放时间格式非法

```gherkin
Given 管理员已登录并拥有排班配置权限
When  管理员输入释放时间为 "25:70" 并保存
Then  系统返回 HTTP 400，错误码 INVALID_RELEASE_TIME
And   release_rule 表数据不被修改
And   前端高亮"释放时间"输入框
```

### 6.4 场景 4：关注提醒时间超过释放周期

```gherkin
Given 管理员已登录并拥有排班配置权限
And   当前释放周期为 7 天
When  管理员将"关注提醒提前时间"设为 10080 分钟以上并保存
Then  系统返回 HTTP 400，错误码 REMINDER_TOO_LONG
And   前端提示"提醒时间不能晚于下次释放前"
```

### 6.5 场景 5：无权限管理员尝试保存

```gherkin
Given 管理员已登录但无 SCHEDULE_RELEASE_CONFIG 权限
When  该管理员调用保存释放规则接口
Then  系统返回 HTTP 403，错误码 FORBIDDEN
And   release_rule 表数据不被修改
```

## 8. 边界场景

### 8.1 边界场景 1：并发保存导致覆盖

- **触发条件**：两名管理员同时编辑并保存
- **预期行为**：后保存者覆盖前者，系统记录两次操作日志
- **用户可见反馈**：最后一次保存的内容生效，历史可在操作日志中追溯

### 8.2 边界场景 2：规则字段部分缺失

- **触发条件**：前端异常只提交了部分字段
- **预期行为**：未提交字段保持原值，不做清空处理
- **用户可见反馈**：保存成功，未修改字段维持原配置

### 8.3 边界场景 3：规则保存后立即查看首页倒计时

- **触发条件**：保存后游客进入首页
- **预期行为**：倒计时按最新规则重新计算
- **用户可见反馈**：倒计时文案与释放时间一致

## 12. 备注

- **幂等键**：`PUT /api/admin/release-rule` 使用 `Idempotency-Key` 防止重复提交
- **事务边界**：单表更新，无需跨表事务
- **性能要求**：配置查询 QPS 较低，可接受 < 100ms
- **生效时机**：规则保存后立即影响倒计时计算；下次释放任务按新规则执行

## 14. 页面级设计决策

### 14.1 释放时间选择器

- 使用「星期 + 时间」组合选择器，避免纯 CRON 表达式对运营不友好
- 默认值为周三 10:00

### 14.2 规则生效提示

- 保存成功后弹窗提示「新规则将于下次释放时生效」，不提示「立即生效」
- 倒计时首页需在 5 秒内感知新规则（通过缓存失效或短 TTL）

### 14.3 页面级交互说明

| 交互 | 触发 | 反馈 | 备注 |
|------|------|------|------|
| 切换释放范围 | 点击下拉框 | 下方说明文案联动更新 | 选项：下周整周 / 未来 7 天 |
| 开启候补开关 | 点击 toggle | 候补有效期输入框启用 | 关闭时隐藏有效期 |
