## 2. 触发条件

- **触发方**：游客
- **触发动作**：
  - 打开小程序首页，在「推荐教练」区浏览后点击「更多」进入教练列表页；
  - 在首页横向滚动的教练卡片上直接点击，进入教练详情页；

## 4. 业务流程

### 4.1 主路径

1. 游客通过以下任一方式进入：
   - 打开小程序首页，在「推荐教练」区看到最多 5 位评分最高的教练；卡片横向滚动，展示个人形象照、姓名、擅长泳姿、教龄、实时状态
   - 点击首页「推荐教练」区的「更多」按钮，进入教练列表页
   - 点击底部 TabBar「教练」，进入教练列表页
2. 在教练列表页，系统按默认排序（综合评分从高到低）展示教练列表；列表卡片展示：个人形象照、姓名、性别、实时状态标签、综合评分、教龄、擅长泳姿
3. 游客选择某教练，点击卡片进入详情页
4. 游客看到教练详情：个人形象照、姓名、年龄、性别、评分、教龄、擅长泳姿、学员总数、总课时数、证书、简介、参考单价、联系方式（手机号、微信二维码）、可选套餐、学员评价、可约时间预览、实时状态
5. 可选套餐区默认最多展示 3 个套餐卡片：若用户具备购买体验课资格，则首张卡片必须为体验课套餐，其余为标准套餐；否则 3 个均为标准套餐。点击「更多」进入完整套餐列表；点击单个套餐卡片进入套餐详情页并支持购买
6. 可约时间预览区展示本周每天的可约时段，点击「查看全部」进入教练预约页面

### 4.2 异常分支

- **分支 1**：系统无任何公开教练（status IN (1, 4)） → 列表展示空状态文案"暂无教练入驻，敬请期待"
- **分支 2**：网络异常 → 提示"网络异常，请重试"
- **分支 3**：教练请假中 → 详情页正常展示，但不展示"立即预约"按钮

### 6.1 场景 1：正常浏览

```gherkin
Given 系统有 5 名已通过（status=1）教练
When  游客进入"找教练"页面
Then  列表按综合评分从高到低展示 5 名教练
And   每张卡片展示个人形象照、姓名、性别、实时状态标签、综合评分、教龄、擅长泳姿
When  游客点击其中某位教练
Then  跳转到教练详情页
And   详情页展示该教练的个人形象照、姓名、年龄、性别、评分、教龄、擅长泳姿、学员总数、总课时数、证书、简介、参考单价、联系方式、可选套餐、学员评价、可约时间预览、实时状态
And   实时状态为"空闲中"时展示"立即预约"按钮
```

### 6.2 场景 2：空状态

```gherkin
Given 系统内无任何公开教练（status IN (1, 4)）
When  游客进入"找教练"页面
Then  列表展示空状态插画
And   展示文案"暂无教练入驻，敬请期待"
```

### 6.3 场景 3：教练请假中

```gherkin
Given 某教练实时状态为"请假中"
When  游客进入该教练详情页
Then  详情页正常展示教练资料
And   实时状态徽标显示"请假中"
And   不展示"立即预约"按钮
And   展示文案"教练当前请假中，可查看其可约时间"
```

### 6.4 场景 4：教练待审核或驳回不出现

```gherkin
Given 某教练状态为"待审核"（status=0）或"驳回"（status=2）
When  游客浏览教练列表或直接访问该教练详情 URL
Then  该教练不出现在公开列表
```

### 6.5 场景 5：教练已离职不出现


### 6.6 场景 6：教练申请离职中仍可见且无标签

```gherkin
Given 某教练状态为"申请离职中"（status=4）且实时状态为"空闲中"
When  游客浏览教练列表
Then  该教练正常出现在列表中
And   教练卡片不展示"申请离职中"等任何状态标签
When  游客进入该教练详情页
Then  详情页正常展示教练资料
And   不展示"申请离职中"等任何状态标签
```

### 6.7 场景 7：点击套餐进入套餐详情

```gherkin
Given 某教练有 5 个在售套餐
And   游客具备购买体验课资格

And   第 2、3 个卡片为标准套餐

When  游客点击第 2 个套餐卡片

```

### 6.8 场景 8：点击可约时间预览进入预约页

```gherkin

And   展示「查看全部」入口
```

## 14. 页面级设计决策

> 本节是**本故事特殊**的设计选择，**全局规范**中没有定义的设计决策记录在这里。

### 14.1 教练卡片信息密度

教练卡片需展示的字段（按视觉权重排序）：
1. 个人形象照（圆形，48×48）
2. 姓名（16pt 加粗）
3. 性别（12pt 灰色，"男"/"女"）
4. 实时状态徽标（12pt，引用全局规范）
5. 综合评分（14pt，⭐ + 数字）
6. 任教年限（12pt 灰色，"X 年教龄"）
7. 擅长泳姿（Neutral Tag，最多 2 项 + "..."省略）

**取舍说明**：形象照 + 评分 + 状态 是 3 个核心视觉锚点，名字紧随其后；擅长泳姿帮助用户快速匹配需求。证书在详情页展示，列表不展示。

### 14.2 评分可视化

- 评分 ≥ 4.5：实心 5 星 + 数字
- 评分 4.0~4.5：实心 4 星 + 半星 + 数字
- 评分 < 4.0：实心 4 星 + 空 1 星 + 数字
- 评分 < 3.0：4 星 + "评价较少" 标签

**为什么不直接显示精确小数？** 小数会让卡片视觉噪音增加，星级更直观。

### 14.3 列表排序的可视化

默认按综合评分 DESC。**当前不在 UI 上显示排序依据**（避免视觉负担）。
如未来需要支持多维度排序（评分 / 价格 / 距离），顶部增加下拉筛选器。

### 14.4 详情页"立即预约"按钮

- **位置**：固定在底部（fixed bottom），不随滚动
- **样式**：高亮主色，高度 48px，全宽

### 14.5 列表 → 详情 跳转交互

- 整张卡片可点击
- 跳转动画：右滑入（forward）
- 返回：左滑出（back）
- 不使用模态弹窗（保持导航清晰）

### 14.6 页面级交互说明

| 交互 | 触发 | 反馈 | 备注 |
|------|------|------|------|
| 列表分页 | 滚动到底部 | 自动加载下一页（loading skeleton） | size=10 |
| 列表下拉刷新 | 下拉手势 | 顶部 spinner + 重新拉取 |  |
| 卡片点击 | tap | 右滑入详情页 |  |
| 详情页返回 | tap 返回按钮 | 左滑出回列表 |  |
| "立即预约"按钮显隐 | 进入详情页 / 实时状态变化 | 见下方"立即预约"按钮状态显隐决策 | 依据 §6.3 场景 3 |
| "立即预约"按钮 | tap | 跳转预约页（不在本 US 范围） | 需触发 US-029 |

#### 14.6.1 "立即预约"按钮状态显隐决策

依据 §6.3 场景 3（教练请假中），详情页"立即预约"按钮的显隐由教练实时状态驱动：

| 实时状态 | 按钮显隐 | 附加反馈 |
|---------|---------|---------|
| 空闲中 | 显示 | — |
| 上课中 / 休息中 / 已下班 | 隐藏 | — |
| 请假中 | 隐藏 | 顶部展示提示条（背景色淡黄，文案"教练当前请假中，可查看其可约时间"） |

**取舍说明**：将"状态显隐"决策放在 §14.6 交互说明区，与按钮 tap 交互同源维护，避免按钮样式（§14.4）与显隐规则分散在两处。
