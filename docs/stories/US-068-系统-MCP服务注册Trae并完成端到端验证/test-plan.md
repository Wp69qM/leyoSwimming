# Test Plan: US-068 系统-MCP服务注册Trae并完成端到端验证

## 1. 测试范围

- Trae MCP 注册与连接状态
- 4 个工具真实调用验证
- 错误 token / 服务未启动的失败行为
- token 轮换与服务重启恢复

## 2. 测试用例

### 2.1 手动验证（Trae）

| 用例 | 步骤 | 预期 | 对应场景 |
|------|------|------|---------|
| 注册连接 | 写入 .trae MCP 配置 → 重载 | 连接状态正常，4 工具可见 | 场景 1 |
| 知识工具 | 会话中触发 query_knowledge("野泳的注意事项") | 返回带来源片段 | 场景 1 |
| 推荐工具 | 依次触发 query_coaches / query_packages / get_hot_recommendations | 返回业务数据 | 场景 1 |
| 错误 token | 配置改为错误 token → 重载 | 连接失败（401） | 场景 2 |
| 服务未启动 | 停 ai-service → 连接 | 连接拒绝，提示明确 | 场景 3 |

### 2.2 自动化辅助（SDK 脚本）

| 用例 | 输入 | 预期 |
|------|------|------|
| 全工具巡检 | 脚本依次调用 4 工具 | 全部成功，输出结果摘要表 |
| token 失效巡检 | 错误 token 运行脚本 | 全部 401 |

### 2.3 恢复性验证

| 用例 | 步骤 | 预期 |
|------|------|------|
| token 轮换 | 更新 token → Trae 旧配置调用失败 → 更新配置 | 恢复可用（边界 1） |
| 服务重启 | 重启 ai-service → Trae 重连 | 恢复可用，无残留会话问题（边界 2） |
| backend 降级 | 停 backend → 调推荐工具 | 结构化错误提示；知识工具正常（边界 3） |

## 3. 验收检查清单

- [ ] Trae 连接状态正常，4 工具 description 完整
- [ ] 4 工具真实调用各 ≥1 次成功，结果记录归档到 US §15
- [ ] 错误 token 与服务未启动的失败行为符合预期
- [ ] token 轮换、服务重启、backend 降级三个恢复场景通过
- [ ] `.env.example` 与部署文档已更新 MCP_API_TOKEN 说明
