## 4. 业务流程

### 4.1 主路径

1. 学员进入「我的订单」页面
2. 系统按时间倒序展示订单列表
3. 列表卡片按订单状态区分展示：
   - **已完成**：包含「已支付」和「已退款」两类，展示订单号、金额、状态标签、套餐模式标签（正价/体验课）；已退款订单额外展示退款原因
   - **待支付**：展示订单号、金额、状态标签、套餐模式标签、剩余支付倒计时；卡片提供「取消支付」和「去支付」两个操作按钮；点击卡片或「去支付」进入订单详情
   - **退款中**：展示订单号、金额、状态标签、套餐模式标签；卡片提供「取消退款」操作按钮；点击卡片查看详情并展示关联套餐信息
4. 学员点击已完成/退款中卡片进入详情
5. 系统展示订单金额、支付状态、创建时间、支付时间、退款/驳回原因（如有），以及购买时快照的套餐信息

### 4.2 异常分支

- **分支 1**：用户无订单 → 展示空状态
- **分支 2**：订单被删除或不存在 → 返回 404

## 6. 验收标准（业务级 Gherkin）

### 6.1 场景 1：正常查看订单列表

```gherkin
Given 学员已登录且名下有多笔订单
And   订单 A 的 package_mode = "standard"，status = 已支付
And   订单 B 的 package_mode = "experience"，status = 已退款，refund_reason = "个人原因"
And   订单 C 的 package_mode = "standard"，status = 待支付，剩余有效期 23 小时 30 分
And   订单 D 的 package_mode = "standard"，status = 退款中
When  学员进入「我的订单」页面
Then  列表按 created_at 倒序展示所有订单
And   每笔订单展示订单号、金额、状态标签
And   每笔订单展示套餐模式标签："standard" 显示"正价"，"experience" 显示"体验课"
And   已完成卡片（已支付/已退款）展示退款原因（仅已退款）
And   待支付卡片展示剩余支付倒计时，并提供「取消支付」「去支付」按钮
And   退款中卡片提供「取消退款」按钮
And   状态标签支持 9 种：0-无 / 1-待支付(橙色) / 2-已支付(绿色) / 3-已取消(灰色) / 4-退款审批中(蓝色) / 5-争议退款处理中(紫色) / 6-已退款(深灰) / 7-退款被拒(红色) / 8-退款处理中(蓝色脉冲)
```

### 6.2 场景 2：无订单空状态

```gherkin
Given 学员已登录但名下无任何订单
When  学员进入「我的订单」页面
Then  页面展示空状态插画
And   展示文案"暂无订单"
```

### 6.3 场景 3：查看订单详情

```gherkin
Given 学员已登录且存在 order.status = 已支付的订单
And   该订单快照字段：package_name = "蛙泳基础 10 节", package_mode = "standard", coach_name = "王教练", teaching_type = "1v1", total_hours = 10, duration_minutes = 60, valid_days = 90, original_price = 2000, paid_amount = 1800, refund_enabled = true, refund_ratio = 0.8, refund_valid_days = 30
And   对应 package_template 后续已被管理员修改为其他内容
When  学员点击该订单进入详情
Then  详情页展示订单号、金额、支付时间、状态标签"已完成-已支付"
And   套餐信息区展示购买时快照：套餐名称"蛙泳基础 10 节"、套餐模式"正价"、教练"王教练"、教学类型"1v1"、课时数 10、每节课时长 60 分钟、有效期 90 天、原价 2000 元、实付价 1800 元、退款规则"支付后 30 天内可退，退款比例 80%"
And   套餐信息不受 package_template 后续变更影响
```

Given 学员已登录且存在 order.status = 待支付的订单

## 7. 数据/API/状态机影响

### 7.1 数据表影响

| # | 表名 | 操作 | 说明 |
|---|------|------|------|
| 1 | `order` | 读取 | 查询当前用户的订单列表与详情；列表与详情中的套餐信息均取自 order 中保存的模板快照字段 |
| 2 | `package` | 读取 | 详情页展示关联课时包状态（如剩余课时），不用于展示购买时套餐内容 |
| 3 | `coach` | 读取 | 仅当订单快照中未保存教练姓名时兜底读取；原则上详情页直接展示 order.coach_name 快照 |
| 4 | `payment` | 读取 | 详情页展示支付流水与支付时间 |
| 5 | `refund` | 读取 | 详情页/列表卡片展示退款原因、驳回原因、退款状态 |
| 6 | `package_template` | 不读取 | 订单详情中的套餐信息不依赖 package_template 当前状态，避免模板后续变更影响历史订单展示 |

### 7.2 API 影响

| # | API | 方法 | 操作 | 说明 |
|---|-----|------|------|------|
| 1 | `/api/order/list` | POST | 新增 | 当前用户订单列表（分页）；JSON body 传入 `page`、`pageSize`、`status` |
| 2 | `/api/order/detail` | POST | 新增 | 订单详情；JSON body 传入 `orderId` |

## 8. 边界场景

### 8.1 边界场景 1：越权访问他人订单

- **触发条件**：用户直接请求其他用户的 order_id
- **预期行为**：返回 403 FORBIDDEN
- **用户可见反馈**：提示"无权查看该订单"

### 8.2 边界场景 2：分页超出范围

- **触发条件**：用户请求页码超出实际数据页数
- **预期行为**：返回空数组 + HTTP 200
- **用户可见反馈**：列表底部显示"没有更多订单"

### 8.3 边界场景 3：订单详情中订单被退款

- **触发条件**：订单状态为已退款
- **预期行为**：详情页/列表卡片展示退款金额、退款时间与退款原因
- **用户可见反馈**：状态标签显示"已完成-已退款"

### 8.4 边界场景 4：退款被驳回

- **触发条件**：学员发起退款后，管理员在 US-028 中驳回退款
- **预期行为**：订单详情页展示驳回原因，状态标签显示"已完成-退款被拒"
- **用户可见反馈**：用户可查看具体驳回原因并重新申请或联系客服

### 8.5 边界场景 5：购买后套餐模板被修改/下架

- **触发条件**：用户购买套餐后，管理员修改或下架了对应的 package_template
- **预期行为**：订单详情中的套餐信息仍展示购买时快照字段，不受 package_template 后续变更影响
- **用户可见反馈**：用户看到的套餐名称、课时、价格、有效期与下单时一致

## 12. 备注

- **性能要求**：订单列表查询 P99 < 200ms，详情查询 P99 < 100ms
- **缓存策略**：列表页使用 Redis 缓存 60s，详情页缓存 300s；缓存 key 以 order 快照字段版本号为后缀，避免模板变更后缓存污染
- **分页**：默认 page=1，pageSize=10
- **快照字段**：订单列表与详情中的套餐信息必须取自 order 快照字段（package_name, package_mode, coach_name, teaching_type, total_hours, duration_minutes, valid_days, original_price, paid_amount, refund_enabled, refund_ratio, refund_valid_days），禁止实时查询 package_template

## 14. 页面级设计决策

### 14.1 订单状态标签

> 对齐 PRD §6.2.1/§6.2.2 订单状态机（9 状态）。v3 评审 P0 修复：原仅 4 状态，现补全为 9 状态。

| 状态码 | 状态名 | 标签色 | 说明 |
|--------|--------|--------|------|
| 0 | 无 | — | 初始态，不展示 |
| 1 | 待支付 | 橙色 #FA8C16 | 等待用户支付 |
| 2 | 已支付 | 绿色 #52C41A | 支付成功 |
| 3 | 已取消 | 灰色 #BFBFBF | 用户/系统取消 |
| 4 | 退款审批中 | 蓝色 #1890FF | 管理员审核中 |
| 5 | 争议退款处理中 | 紫色 #722ED1 | 争议处理 |
| 6 | 已退款 | 深灰 #595959 | 终态 |
| 7 | 退款被拒 | 红色 #F5222D | 终态 |

- 默认按创建时间倒序
- 支持按状态筛选（全部/待支付/已支付/已退款/退款处理中）
