- **触发方**：注册用户/学员
- **触发动作**：在套餐页或教练详情页点击「购买正价套餐」并提交订单

- [x] 用户已登录（依赖 US-004 / US-005）

- [x] 用户已阅读并同意最新版《用户须知》、健康承诺书、免责协议（§6.9）
- [x] 系统已配置标准套餐或允许自定义课时（依赖 US-019 / US-045）

## 4. 业务流程

### 4.1 主路径

1. 用户进入套餐详情页或教练详情页，选择正价套餐（标准套餐或自定义课时数）
2. 系统展示/确认绑定教练
3. 系统展示《用户须知》、健康承诺书、免责协议；用户勾选同意
4. 系统校验：教练 status=1、用户无其他教练的 active 套餐、协议版本正确
5. 系统生成待支付订单（order.status=待支付，course_type=1）
6. 系统记录协议签署（agreement_sign）
7. 系统返回订单信息，前端跳转支付页（US-025）

### 4.2 异常分支

- **分支 1**：用户未同意协议 → 返回错误码 `AGREEMENT_REQUIRED`
- **分支 2**：用户已持有其他教练的 active 套餐 → 返回错误码 `COACH_CONFLICT`，引导先更换教练（US-022）
- **分支 3**：教练 status ≠ 1 → 返回错误码 `COACH_UNAVAILABLE`
- **分支 4**：同一教练存在未支付订单 → 返回现有待支付订单（幂等）

## 6. 验收标准（业务级 Gherkin）

### 6.1 场景 1：正常提交标准套餐

```gherkin
Given 注册用户已登录且同意最新版协议
And   教练 A 状态为已通过（status=1）
And   用户名下无其他教练的 active 套餐
And   系统已配置 10 节标准套餐
When  用户选择教练 A 的 10 节标准套餐并提交订单
Then  系统创建 order.status = 待支付，course_type = 1
And   系统记录 agreement_sign 版本号与签署时间
And   接口返回 HTTP 201 与订单 ID
And   前端跳转支付页（US-025）
```

### 6.2 场景 2：正常提交自定义课时

```gherkin
Given 注册用户已登录且同意最新版协议
And   教练 A 已设置参考单价
And   用户选择自定义 12 课时
When  用户提交自定义课时订单
Then  系统按参考单价计算订单金额
And   order.status = 待支付，course_type = 1
And   接口返回 HTTP 201 与订单 ID
```

### 6.3 场景 3：未同意协议

```gherkin
Given 注册用户已登录
And   用户未勾选《用户须知》
When  用户提交正价套餐订单
Then  系统返回 HTTP 400，错误码 AGREEMENT_REQUIRED
And   不创建订单
```

### 6.4 场景 4：已持有其他教练 active 套餐

```gherkin
Given 用户已持有教练 B 的 active 套餐
When  用户尝试购买教练 A 的正价套餐
Then  系统返回 HTTP 400，错误码 COACH_CONFLICT
And   文案提示"您已持有其他教练的有效套餐，需先更换教练"
And   不创建订单
```

### 6.5 场景 5：教练状态不可用

```gherkin
Given 教练 C 状态为待审核（status=0）
When  用户购买教练 C 的正价套餐
Then  系统返回 HTTP 400，错误码 COACH_UNAVAILABLE
And   不创建订单
```

## 8. 边界场景

### 8.1 边界场景 1：重复提交幂等

- **触发条件**：用户 5 秒内连续两次点击提交
- **预期行为**：第二次返回同一待支付订单，不重复创建
- **用户可见反馈**：继续进入支付页

### 8.2 边界场景 2：自定义课时越界

- **触发条件**：用户提交自定义课时数为 0 或超过后台最大限制
- **预期行为**：拒绝提交，提示有效课时范围
- **用户可见反馈**："课时数需在 1-50 之间"

### 8.3 边界场景 3：协议版本过期

- **触发条件**：《用户须知》在订单提交前刚更新，用户未重新同意
- **预期行为**：校验失败，返回 AGREEMENT_REQUIRED 并引导重新阅读
- **用户可见反馈**：弹窗提示"《用户须知》已更新，请阅读后购买"

## 14. 页面级设计决策

### 14.1 协议确认交互

- 购买页底部固定「我已阅读并同意」勾选区，点击可展开协议全文
- 若用户未勾选即提交，弹窗提示并定位到勾选区

- 默认展示教练参考单价 × 课时数 = 订单金额
- 超出后台配置的最大课时数时，输入框实时变红并禁用提交
