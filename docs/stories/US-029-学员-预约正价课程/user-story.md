## 2. 触发条件

- **触发方**：学员
- **触发动作**：在「预约网格页」选择某个可约时段并提交预约
- **触发时机**：用户主动约课时

**入口说明**：
- 首页「立即预约」：仅当学员持有 active 套餐时进入对应绑定教练的预约网格页；无套餐时引导购买套餐。
- 教练详情页「预约」：始终可进入该教练的预约网格页；无套餐时可查看时段，提交时提示购买。

## 4. 业务流程

### 4.1 主路径（有 active 套餐）

1. 学员通过首页「立即预约」或教练详情页「预约」进入预约网格页
2. 系统展示目标教练未来 7 天的可约时段
3. 学员选择日期与时段
4. 系统校验：套餐 active、available_count > 0、时段有效且空闲、无冲突预约
5. 系统按 FIFO 选择最早 active 套餐，预占 1 课时：available_count -1，reserved_count +1
6. 系统创建 booking 记录，status = 已预约
7. 系统返回预约成功详情，并发送提醒

### 4.2 主路径（无 active 套餐，仅查看）

1. 学员从教练详情页进入预约网格页
2. 系统展示该教练未来 7 天的可约时段（已约满置灰，空闲可查看）
3. 页面顶部展示提示条「您还没有可用套餐，购买后即可预约」
4. 学员点击时段时，系统拦截并引导购买套餐
5. 学员无法提交预约

### 4.3 异常分支

- **分支 1**：时段已被他人预约 → 返回错误码 `SLOT_TAKEN`
- **分支 2**：套餐无可用课时 → 返回错误码 `NO_QUOTA`
- **分支 3**：目标时段不在可约范围内（>7 天或已过期）→ 返回错误码 `SLOT_NOT_AVAILABLE`
- **分支 4**：套餐处于退款审批中 / 冻结 → 返回错误码 `PACKAGE_NOT_BOOKABLE`
- **分支 5**：提交预约时无 active 正价套餐 → 返回错误码 `NO_ACTIVE_PACKAGE`，并引导购买

## 6. 验收标准（业务级 Gherkin）

### 6.1 场景 1：正常预约已绑定教练时段

```gherkin
Given 学员已登录
And   存在 active 套餐，available_count = 5，coach_id = 100
And   已绑定教练 100 在明日 10:00 有可约时段
When  学员从首页点击「立即预约」并选择明日 10:00 提交
Then  booking 创建成功，status = 已预约
And   package.reserved_count = 1，available_count = 4
And   返回预约详情
And   HTTP 状态码 = 201
```

### 6.2 场景 2：无 active 套餐时查看教练可约时段

```gherkin
Given 学员已登录
And   学员名下无 active 正价套餐
When  学员从教练详情页点击「预约」
Then  系统展示该教练未来 7 天的可约时段
And   页面顶部显示提示「您还没有可用套餐，购买后即可预约」
And   已约满时段置灰展示
And   HTTP 状态码 = 200
```

### 6.3 场景 3：无 active 套餐时尝试提交预约

```gherkin
Given 学员已登录
And   学员名下无 active 正价套餐
And   学员在预约网格页选择了明日 10:00
When  学员点击「确认预约」
Then  系统返回 HTTP 400，错误码 NO_ACTIVE_PACKAGE
And   提示「您还没有可用套餐，请先购买套餐」
And   不创建 booking
```

### 6.4 场景 4：时段已被预约

```gherkin
Given 学员已登录
And   明日 10:00 时段已被其他学员预约
When  学员尝试预约明日 10:00
Then  系统返回 HTTP 400，错误码 SLOT_TAKEN
And   package 课时不变
```

### 6.5 场景 5：套餐可用课时不足

```gherkin
Given 学员已登录
And   active 套餐 available_count = 0
When  学员尝试预约
Then  系统返回 HTTP 400，错误码 NO_QUOTA
And   不创建 booking
```

## 8. 边界场景

### 8.1 边界场景 1：多人并发预约同一时段

- **触发条件**：两名学员同时提交同一时段预约
- **预期行为**：数据库唯一索引 / 分布式锁保证仅第一个成功，其余返回 SLOT_TAKEN
- **用户可见反馈**："该时段已被他人预约，请选择其他时段"

### 8.2 边界场景 2：教练请假导致时段关闭

- **触发条件**：提交瞬间教练请假审批通过，schedule_slot.status = closed
- **预期行为**：预约接口拒绝，返回 SLOT_NOT_AVAILABLE
- **用户可见反馈**："该时段已不可用"

### 8.3 边界场景 3：网络抖动导致重复提交

- **触发条件**：前端重试导致同一请求多次到达
- **预期行为**：幂等键去重，返回已有 booking
- **用户可见反馈**：预约成功页

## 14. 页面级设计决策

### 14.1 预约网格页入口

- **首页「立即预约」**：
  - 有 active 套餐：跳转至套餐绑定教练的预约网格页
  - 无 active 套餐：弹窗或页面提示「您还没有可用套餐，请先购买套餐」，并提供购买入口
- **教练详情页「预约」**：
  - 始终进入该教练的预约网格页
  - 无套餐时顶部提示「您还没有可用套餐，购买后即可预约」
- **tabbar「我的预约」页**：
  - 无套餐时展示空状态，提示「暂无预约，请先购买套餐」
  - 不展示「立即预约」按钮，避免无法确定教练

### 14.2 无套餐时的预约网格页

- 可正常查看教练未来 7 天可约时段
- 已约满时段置灰显示"已满"
- 空闲时段可点击查看，但点击后弹窗引导购买套餐
- 底部「确认预约」按钮禁用或点击后引导购买套餐

### 14.3 时段状态展示

- 已约满 / 被锁定的时段置灰并显示"已满"
- 用户已预约的时段高亮显示
- 当前选中时段高亮边框
