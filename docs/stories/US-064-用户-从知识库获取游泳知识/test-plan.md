# Test Plan: US-064 用户-从知识库获取游泳知识

## 1. 测试范围

- 知识类问题调用 query_knowledge
- 推荐类问题不调用 query_knowledge
- 相似度阈值过滤
- 禁用文档不返回

## 2. 测试用例

### 2.1 单元测试

| 用例 | 输入 | 预期 |
|------|------|------|
| 向量检索 | query="野泳注意事项" | 返回相关知识片段 |
| 阈值过滤 | 最高 score=0.5 | 返回空列表 |
| 意图判断 | "推荐教练" | 不调用 query_knowledge |

| 禁用不返回 | 禁用文档 → 用户提问 | 不返回该文档 |

### 2.3 E2E 测试

|------|------|------|

## 3. 验收检查清单
