# Test Plan: US-062 管理员-上传知识库文档

## 1. 测试范围

- 手动输入上传
- 文件上传
- 标题唯一性校验
- ai-service 失败回滚
- 权限控制

## 2. 测试用例

### 2.1 单元测试

| 用例 | 输入 | 预期 |
|------|------|------|
| 解析 Markdown | `# 标题\n内容` | 返回 "标题 内容" |
| 分块 | 1500 字文本 | 返回多个 chunk，每个 <= 500 字 |
| 标题重复校验 | 已存在标题 | 抛出 BusinessException |

### 2.2 集成测试

| 用例 | 步骤 | 预期 |
|------|------|------|
| 完整入库 | 上传 → backend → ai-service → Chroma | MySQL 和 Chroma 都有数据 |
| 索引失败回滚 | ai-service 返回 500 | MySQL 无记录 |

### 2.3 E2E 测试

| 用例 | 步骤 | 预期 |
|------|------|------|
| web-admin 手动上传 | 填写表单保存 | 列表出现新文档 |
| web-admin 文件上传 | 选择 .md 文件 | 列表出现新文档 |

## 3. 验收检查清单

- [ ] 手动输入上传成功
- [ ] 文件上传成功
- [ ] 标题重复被拒绝
- [ ] ai-service 失败时 MySQL 回滚
- [ ] 非 ADMIN 用户无法上传
