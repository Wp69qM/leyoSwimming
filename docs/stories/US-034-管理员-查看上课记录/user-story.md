## 4. 业务流程

### 4.1 主路径

1. 管理员登录管理后台，进入「上课记录」页面
2. 系统默认展示最近 30 天的上课记录列表（分页）
3. 管理员可按教练、学员、课程状态、时间范围等条件筛选
4. 系统返回匹配的上课记录列表，包含：课程时间、教练、学员、状态、消耗课时、课程内容简介
5. 管理员点击单条记录，查看详情：教练记录、学员课后总结（如有）、课时变动日志
6. 管理员可导出当前筛选结果（CSV/Excel）用于对账

### 4.2 异常分支

- **分支 1**：无查看权限 → 返回 403 `ADMIN_PERMISSION_DENIED`
- **分支 2**：筛选条件无匹配记录 → 返回空列表 200，展示空状态
- **分支 3**：时间范围超过系统限制（如 > 1 年）→ 返回 400 `DATE_RANGE_TOO_LARGE`

## 6. 验收标准（业务级 Gherkin）

### 6.1 场景 1：管理员正常查看上课记录列表

```gherkin
Given 管理员已登录且有查看权限
And   系统中存在 10 条已完成上课记录
When  管理员进入「上课记录」页面
Then  系统默认返回最近 30 天的记录列表
And   每条记录展示课程时间、教练姓名、学员姓名、状态、消耗课时
And   HTTP 状态码 = 200
```

### 6.2 场景 2：管理员按条件筛选上课记录

```gherkin
Given 管理员已登录
And   系统中存在教练 100 的 3 条上课记录和教练 200 的 5 条上课记录
When  管理员选择教练 100 并点击筛选
Then  系统返回 3 条教练 100 的记录
And   返回 HTTP 200
```

### 6.3 场景 3：管理员查看单条上课记录详情

```gherkin
Given 管理员已登录
And   存在 booking.status = 已完成，对应 course_record.content = "自由泳打腿"
When  管理员点击该记录详情
Then  系统返回课程时间、教练、学员、状态、消耗课时、课程内容、学员课后总结
And   HTTP 状态码 = 200
```

### 6.4 场景 4：无权限管理员访问

```gherkin
Given 管理员已登录但无上课记录查看权限
When  管理员请求上课记录列表
Then  系统返回 HTTP 403，错误码 ADMIN_PERMISSION_DENIED
And   不返回任何记录
```

### 6.5 场景 5：筛选时间范围过大

```gherkin
Given 管理员已登录
When  管理员选择时间范围超过 1 年
Then  系统返回 HTTP 400，错误码 DATE_RANGE_TOO_LARGE
And   提示"时间范围不能超过 1 年"
```

## 8. 边界场景

### 8.1 边界场景 1：数据量极大时的分页

- **触发条件**：系统中存在上万条上课记录
- **预期行为**：分页查询单次返回 20 条，翻页响应 P99 < 300ms
- **用户可见反馈**：列表正常加载，翻页无卡顿

### 8.2 边界场景 2：课程记录关联的学员已注销

- **触发条件**：学员账号已软删除
- **预期行为**：列表仍展示记录，学员姓名显示为「已注销用户」或保留脱敏姓名
- **用户可见反馈**：记录可正常查看，不可再跳转学员详情

### 8.3 边界场景 3：并发导出与数据更新

- **触发条件**：管理员导出时，教练正在确认新的上课记录
- **预期行为**：导出基于导出请求时间点的快照，不阻塞新数据写入
- **用户可见反馈**：导出文件包含发起导出前的数据
