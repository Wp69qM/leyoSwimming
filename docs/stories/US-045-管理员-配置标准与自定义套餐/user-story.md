## 4. 业务流程

### 4.1 标准套餐配置

1. 管理员进入「套餐配置」页面
2. 系统展示标准套餐列表（含状态：上架/下架）
3. 管理员点击「新增标准套餐」
4. 系统弹出表单：名称、套餐模式（正价套餐/体验课）、适用教练（可多选）、教学类型、泳姿、课时数、每节课时长、有效期（天）、原价、售价、是否支持退款、退款比例、退款有效期限制、标签、套餐描述、套餐展示图片、上下架状态
5. 管理员填写并提交
6. 系统校验字段合法后写入 `package_template` 表及 `package_template_coach` 关联表，`status='inactive'`（新增套餐默认未上架）
7. 返回列表并刷新

### 4.2 自定义套餐配置

1. 管理员在「套餐配置」页切换至「自定义套餐规则」Tab
2. 系统展示当前自定义套餐全局规则：允许课时范围（min_hours / max_hours）、有效期默认值（default_valid_days）
3. 管理员修改规则：最小/最大课时数、默认有效期
4. 系统校验：0 < min_hours ≤ max_hours ≤ 100，default_valid_days > 0
5. 系统将规则写入 `custom_package_config` 表（全局仅保留一条生效配置）
6. 返回保存成功提示

### 4.3 异常分支

- **分支 1**：课时数 ≤ 0、售价 < 0、原价 < 0、或原价 < 售价 → 前端/后端返回 `INVALID_PACKAGE_PARAM`
- **分支 2**：套餐名称重复 → 返回 `DUPLICATE_PACKAGE_NAME`
- **分支 3**：管理员无权限 → 返回 HTTP 403
- **分支 4**：退款比例不在 0~100 之间，或退款有效期限制 < 0 → 返回 `INVALID_PACKAGE_PARAM`
- **分支 5**：适用教练为空数组或未选择任何教练 → 返回 `INVALID_PACKAGE_PARAM`
- **分支 6**：上传图片格式非法或大小超限 → 返回 `INVALID_IMAGE_FILE`
- **分支 7**：自定义标签长度超限或包含非法字符 → 返回 `INVALID_TAG_FORMAT`

## 8. 边界场景

### 8.1 边界场景 1：管理员并发编辑同一套餐

- **触发条件**：两名管理员同时编辑同一标准套餐
- **预期行为**：后提交者收到乐观锁冲突提示，需刷新后重试
- **用户可见反馈**：提示"该套餐信息已被他人修改，请刷新页面重试"

### 8.2 边界场景 2：删除已关联订单的标准套餐模板

- **触发条件**：模板已被历史订单引用，管理员尝试删除
- **预期行为**：系统拒绝物理删除，标记为 inactive 并保留历史数据
- **用户可见反馈**：提示"该套餐已产生订单，仅可下架不可删除"

### 8.3 边界场景 3：自定义套餐课时数超出范围

- **触发条件**：学员购买自定义套餐时课时数不在后台配置范围内
- **预期行为**：购买接口拒绝并提示允许范围
- **用户可见反馈**：提示"自定义课时数需在 1~50 节之间"

### 8.4 边界场景 4：退款配置冲突

- **触发条件**：管理员设置"支持退款=true"但退款比例=0
- **预期行为**：系统允许保存（技术上支持退款但比例为 0，可理解为不可退），前端提示文案需明确
- **用户可见反馈**：提示"退款比例为 0 时，学员实际不可退款"

### 8.5 边界场景 5：套餐已上架时编辑限制

- **触发条件**：套餐处于 `active` 状态，管理员尝试编辑
- **预期行为**：系统禁止直接编辑；必须先执行下架操作，待状态变为 `inactive` 后才允许编辑
- **用户可见反馈**：编辑按钮置灰或点击后提示"已上架套餐需先下架才能编辑"

### 8.6 边界场景 6：已购套餐不受模板修改影响

- **触发条件**：学员已购买套餐 A 后，管理员修改或下架套餐 A 的模板
- **预期行为**：`package` 实例保存购买时快照，学员在"我的套餐"中看到的名称、课时数、价格、有效期等保持不变
- **用户可见反馈**：学员端套餐详情与购买时一致

### 8.7 边界场景 7：套餐图片上传失败

- **触发条件**：网络异常或图片服务不可用
- **预期行为**：表单提交前图片应已上传完成；上传失败时不允许提交
- **用户可见反馈**：图片区域显示"上传失败，请重试"

## 14. 页面级设计决策

### 14.1 标准套餐与自定义套餐分 Tab 展示

- 标准套餐以表格形式展示，含描述、图片、标签、退款等完整配置
- 自定义套餐配置区仅展示「允许课时范围」和「有效期默认值」，不需要描述、图片、标签等营销字段

### 14.2 上下架与编辑规则

- 新增套餐默认状态为 `inactive`，不直接上架
- **未上架套餐**：操作列显示「查看」「编辑」「上架」
- **已上架套餐**：操作列显示「查看」「下架」，不显示「编辑」
- 上架/下架按钮点击后二次确认
- 已上架套餐必须先下架，才能编辑；编辑保存后仍保持 `inactive`，需手动重新上架
- 生效后立即影响游客端/学员端套餐列表

### 14.3 表单字段说明

| 字段 | 类型 | 必填 | 默认值 | 校验规则 |
|------|------|------|--------|----------|
| 名称 | 文本 | 是 | — | 唯一，长度 1~50 |
| 套餐模式 | 单选 | 是 | 正价套餐 | 可选：正价套餐 / 体验课；影响学员端购买流程与退款规则 |
| 适用教练 | 多选 | 是 | — | 至少选 1 项；关联 `coach` 表；绑定多名教练时，学员购买该套餐可在其中任选一名 |
| 教学类型 | 单选 | 是 | 一对一 | 可选：一对一 / 一对二 / 一对三 |
| 泳姿 | 多选 | 否 | 全部泳姿 | 不选时默认全部泳姿可用 |
| 课时数 | 整数 | 是 | — | > 0 |
| 每节课时长 | 单选 | 是 | 60 分钟 | 可选：45 / 60 / 90 分钟 |
| 有效期 | 整数 | 是 | — | > 0 天 |
| 原价 | 金额 | 是 | — | ≥ 0，且 ≥ 售价 |
| 售价 | 金额 | 是 | — | ≥ 0 |
| 是否支持退款 | 开关 | 是 | 否 | — |

### 14.5 适用教练多选绑定

- **背景**：标准套餐原本设计为一个模板绑定一名教练，运营上不够灵活
- **决策**：标准套餐模板支持绑定多名教练，通过 `package_template_coach` 关联表维护
- **约束**：
  - 每个模板至少绑定 1 名教练
  - 保存时同步写入/更新关联表
  - 学员购买该套餐时，可在绑定的教练列表中选择其中一名
- **影响范围**：
  - US-045：新增/编辑表单、数据表、API 参数、校验规则
  - US-019 / US-020：学员端套餐列表/详情需展示可选教练，购买流程需选择教练
