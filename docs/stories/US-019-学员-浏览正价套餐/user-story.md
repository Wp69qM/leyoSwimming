## 4. 业务流程

### 4.1 主路径

1. 用户在教练详情页点击「查看套餐」
2. 系统按以下过滤条件查询并展示该教练的正价套餐选项：
   - 教练状态：`coach.status = 1`（已通过）
   - 标准套餐模板状态：`package_template.status = active`（启用）
   - 当前教练可约（未离职、未冻结）
3. 展示内容：
   - **标准套餐列表**：1 节 / 6 节 / 8 节 / 10 节（由管理员预设，§5.5.3）
   - **自定义课时入口**：用户可选择任意课时数，金额 = 参考单价 × 课时数
4. 每个套餐展示：课时数、价格、单价、有效期说明
5. 用户点击「购买」跳转 US-020（学员购买正价套餐）

### 4.2 异常分支

- **分支 1**：教练未设置参考单价 → 自定义课时入口置灰，提示「教练尚未开放自定义课时」
- **分支 2**：管理员未配置标准套餐 → 仅展示自定义课时入口
- **分支 3**：教练 status ≠ 1 → 返回 404，提示「教练不可约」

## 6. 验收标准（业务级 Gherkin）

### 6.1 场景 1：正常浏览正价套餐

```gherkin
Given 教练 A 状态为已通过（status=1）
And   管理员已配置 4 个标准套餐（1/6/8/10 节）
And   教练 A 已设置参考单价 = 200 元/节
When  用户在教练 A 详情页点击「查看套餐」
Then  系统返回 4 个标准套餐列表
And   每个套餐包含课时数、价格、单价、有效期
And   展示自定义课时入口（最低 1 节，最高 50 节）
And   接口返回 HTTP 200
```

### 6.2 场景 2：教练未设置参考单价

```gherkin
Given 教练 B 状态为已通过（status=1）
And   管理员已配置标准套餐
And   教练 B 未设置参考单价
When  用户浏览教练 B 的正价套餐
Then  系统展示标准套餐列表
And   自定义课时入口置灰，提示"教练尚未开放自定义课时"
And   接口返回 HTTP 200
```

### 6.3 场景 3：教练不可约

```gherkin
Given 教练 C 状态为待审核（status=0）
When  用户尝试浏览教练 C 的正价套餐
Then  系统返回 HTTP 404，错误码 COACH_NOT_FOUND
And   前端提示"教练信息不存在"
```

## 8. 边界场景

### 8.1 边界场景 1：标准套餐配置为空

- **触发条件**：管理员尚未配置任何标准套餐
- **预期行为**：仅展示自定义课时入口，标准套餐区域显示空状态
- **用户可见反馈**：「暂无标准套餐，可选择自定义课时」

### 8.2 边界场景 2：自定义课时超出范围

- **触发条件**：用户输入自定义课时为 0 或超过 50
- **预期行为**：前端校验阻止提交，提示「课时数需在 1-50 之间」
- **用户可见反馈**：输入框红色提示

### 8.3 边界场景 3：教练已离职但数据未清理

- **触发条件**：教练 status=3（已离职）但用户通过旧链接访问
- **预期行为**：返回 404，提示「教练已不可约」
- **用户可见反馈**：错误页引导返回列表

## 14. 页面级设计决策

### 14.1 标准套餐 vs 自定义课时展示

- **背景**：需同时展示固定套餐与自定义入口
- **选项**：A. 上下分栏；B. Tab 切换
- **结论**：选择 A（上下分栏），标准套餐在上，自定义入口在下，降低操作成本
- **影响范围**：套餐浏览页

### 14.2 页面级交互说明

| 交互 | 触发 | 反馈 | 备注 |
|------|------|------|------|
| 点击套餐卡片 | 点击「购买」 | 跳转 US-020 下单页 | 携带套餐参数 |
| 输入自定义课时 | 输入数字 | 实时计算金额 | 金额 = 参考单价 × 课时 |
