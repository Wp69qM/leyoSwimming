## 4. 业务流程

### 4.1 主路径

#### 路径 A：首页全局入口

1. 用户在首页点击「购买正价套餐」或「全部套餐」
2. 系统进入全局套餐列表页（未绑定教练），按 `package_template.status = 'active'` 查询所有已上架套餐
3. 列表按套餐模式分组/标注：
   - **体验课**：`package_mode = 'experience'`
   - **标准正价课**：`package_mode = 'standard'`（1/6/8/10 节等）
   - **自定义套餐**：`package_mode = 'custom'`（或无固定模板，由学员自由输入课时）
4. 每个套餐展示：课时数、标签、原价、售价、教学类型、每节课时长、有效期说明、退款规则概要
5. 用户点击套餐卡片进入详情页；点击「购买」跳转 US-020（学员购买正价套餐）或 US-017（体验课购买）

#### 路径 B：教练详情页入口

1. 用户在教练详情页点击「查看套餐」
2. 系统按以下过滤条件查询并展示该教练支持的套餐选项：
   - 教练状态：`coach.status = 1`（已通过）
   - 当前教练可约（未离职、未冻结）
   - 标准套餐模板：`package_template.package_mode = 'standard'` 且 `status = 'active'`，并适配当前教练（部分标准套餐可能仅特定教练支持）
   - 体验课套餐：`package_template.package_mode = 'experience'` 且 `status = 'active'`，当前教练支持
   - 自定义课时入口：基于教练参考单价计算
3. 展示内容：
   - **标准套餐列表**：适配当前教练的 1/6/8/10 节等标准套餐
   - **体验课套餐**：当前教练的体验课卡片（若用户具备购买体验课资格）
   - **自定义课时入口**：用户可选择任意课时数，金额 = 参考单价 × 课时数
4. 每个套餐展示字段同路径 A
5. 用户点击套餐卡片进入详情页；若模板已下架（`status ≠ 'active'`），系统提示"套餐不存在或已下架"
6. 用户在详情页点击「购买」跳转对应购买流程（US-017 体验课 / US-020 正价套餐）

### 4.2 异常分支

#### 路径 A（首页全局入口）

- **分支 A1**：系统中无任何已上架套餐（`package_template.status ≠ 'active'`） → 列表返回空数组 + 200，前端展示空状态「暂无可用套餐」

#### 路径 B（教练详情页入口）

- **分支 B1**：教练未设置参考单价 → 自定义课时入口置灰，提示「教练尚未开放自定义课时」
- **分支 B2**：管理员未配置标准套餐 → 仅展示自定义课时入口（若教练已设置参考单价）
- **分支 B3**：教练 status ≠ 1 或教练不可约 → 返回 404，提示「教练不可约」
- **分支 B4**：标准/体验套餐模板已下架或不存在（`package_mode` 不匹配或 `status ≠ 'active'`） → 不在列表中展示；从详情页进入时返回 404，提示"套餐不存在或已下架"

## 6. 验收标准（业务级 Gherkin）

### 6.1 场景 1：从教练详情页浏览套餐

```gherkin
Given 教练 A 状态为已通过（status=1）
And   管理员已配置 4 个标准套餐（1/6/8/10 节），package_mode='standard' 且 status='active'，并适配教练 A
And   教练 A 已设置参考单价 = 200 元/节
When  用户在教练 A 详情页点击「查看套餐」
Then  系统返回适配教练 A 的 4 个标准套餐列表
And   每个套餐包含课时数、标签、original_price、price、teaching_type、duration_minutes、有效期、退款规则概要
And   展示自定义课时入口（最低 1 节，最高 50 节）
And   接口返回 HTTP 200
```

### 6.2 场景 1a：从首页浏览全局套餐列表

```gherkin
Given 管理员已配置多个套餐：
  | 套餐名称 | package_mode | status | 适配教练 |
  | 体验课 | experience | active | 教练 A、教练 B |
  | 标准 6 节 | standard | active | 教练 A |
  | 标准 10 节 | standard | active | 教练 B |
  | 自定义 | custom | active | （不绑定教练） |
When  用户在首页点击「全部套餐」
Then  系统进入全局套餐列表页
And   列表展示所有 status='active' 的套餐
And   套餐按 package_mode 分组/标注为：体验课、标准正价课、自定义套餐
And   接口返回 HTTP 200
```

### 6.3 场景 2：教练未设置参考单价

```gherkin
Given 教练 B 状态为已通过（status=1）
And   管理员已配置标准套餐
And   教练 B 未设置参考单价
When  用户浏览教练 B 的正价套餐
Then  系统展示标准套餐列表
And   自定义课时入口置灰，提示"教练尚未开放自定义课时"
And   接口返回 HTTP 200
```

### 6.4 场景 3：教练不可约

```gherkin
Given 教练 C 状态为待审核（status=0）
When  用户尝试浏览教练 C 的正价套餐
Then  系统返回 HTTP 404，错误码 COACH_NOT_FOUND
And   前端提示"教练信息不存在"
```

### 6.5 场景 4：已下架套餐不展示且详情不可进入

```gherkin
Given 教练 A 状态为已通过（status=1）
And   管理员已配置标准套餐 S，package_mode='standard' 且 status='inactive'
When  用户浏览教练 A 的正价套餐列表
Then  系统不返回套餐 S
And   接口返回 HTTP 200
When  用户直接访问套餐 S 的详情页
Then  系统返回 HTTP 404，错误码 PACKAGE_NOT_FOUND
And   前端提示"套餐不存在或已下架"
```

### 6.6 场景 5：首页全局套餐列表空状态

```gherkin
Given 系统中无任何 status='active' 的套餐模板
When  用户在首页点击「全部套餐」
Then  系统返回空数组
And   前端展示空状态「暂无可用套餐」
And   接口返回 HTTP 200
```

## 7. 数据/API/状态机影响

### 7.1 数据表影响

| # | 表名 | 操作 | 说明 |
|---|------|------|------|
| 1 | `coach` | 读 | 入口 B 校验教练状态 |
| 2 | `package_template` | 读 | 读取管理员配置的套餐模板，按 `status='active'` 过滤；入口 B 额外按教练适配与 `package_mode` 过滤 |
| 3 | `coach` | 读 | 入口 B 读取参考单价 |
| 4 | `coach_package_template`（或关联表） | 读 | 入口 B 校验标准套餐是否适配当前教练 |

### 7.2 API 影响

| # | API | 方法 | 操作 | 说明 |
|---|-----|------|------|------|
| 1 | `/api/packages/list` | POST | 新增 | 首页全局套餐列表：查询所有已上架套餐，按 `package_mode` 区分 |
| 2 | `/api/coach/packages/list` | POST | 新增 | 教练详情页套餐列表：JSON body 传入 `coach_id`，查询当前教练支持的正价套餐、体验课、自定义入口 |
| 3 | `/api/packages/detail` | POST | 新增 | 查询单个套餐模板详情：JSON body 传入 `package_id`，可选 `coach_id`；返回套餐详情、适配教练列表（未传 coach_id 时）/ 当前教练信息（传入 coach_id 时），模板下架时返回 404 |

### 7.3 状态机影响

US-019 是只读 US，不修改任何实体状态。

## 8. 边界场景

### 8.1 边界场景 1：标准套餐配置为空

- **触发条件**：管理员尚未配置任何标准套餐
- **预期行为**：仅展示自定义课时入口，标准套餐区域显示空状态
- **用户可见反馈**：「暂无标准套餐，可选择自定义课时」

### 8.2 边界场景 2：自定义课时超出范围

- **触发条件**：用户输入自定义课时为 0 或超过 50
- **预期行为**：前端校验阻止提交，提示「课时数需在 1-50 之间」
- **用户可见反馈**：输入框红色提示

### 8.3 边界场景 3：教练已离职但数据未清理

- **触发条件**：教练 status=3（已离职）但用户通过旧链接访问
- **预期行为**：返回 404，提示「教练已不可约」
- **用户可见反馈**：错误页引导返回列表

### 8.4 边界场景 4：首页全局入口无任何上架套餐

- **触发条件**：系统中无任何 status='active' 的套餐模板
- **预期行为**：返回空数组 + 200
- **用户可见反馈**：全局套餐列表页展示「暂无可用套餐」

## 14. 页面级设计决策

### 14.1 标准套餐 vs 自定义课时展示

- **背景**：需同时展示固定套餐与自定义入口
- **选项**：A. 上下分栏；B. Tab 切换
- **结论**：选择 A（上下分栏），标准套餐在上，自定义入口在下，降低操作成本
- **影响范围**：套餐浏览页

### 14.2 页面级交互说明

| 交互 | 触发 | 反馈 | 备注 |
|------|------|------|------|
| 点击套餐卡片 | 点击「购买」 | 跳转 US-020 下单页 | 携带套餐参数 |
| 输入自定义课时 | 输入数字 | 实时计算金额 | 金额 = 参考单价 × 课时 |
