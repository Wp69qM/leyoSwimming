## 2. 触发条件

- **触发方**：学员
- **触发动作**：在「预约网格页」选择体验课时段并提交预约；或在预约详情页取消预约
- **触发时机**：学员主动操作

**入口说明**：
- 体验课预约与正价课预约共用同一个「预约网格页」。
- 教练详情页「预约」：始终可进入该教练的预约网格页；无体验套餐时可查看时段，提交时提示购买。
- tabbar「我的预约」页：无套餐时提示购买，不展示「立即预约」按钮。

## 3. 前置条件

### 3.1 查看预约网格页

- [x] 学员已登录
- [x] 目标教练已生成可约时段（依赖 US-016）

### 3.2 提交体验课预约

- [x] 学员持有 active 体验套餐（依赖 US-017）
- [x] 套餐可用课时 available_count > 0
- [x] 目标时段已被释放且未被预约
- [x] 课程开始时间在未来 7 天内

### 3.3 取消体验课预约

- [x] 存在 status = 已预约 的体验课 booking
- [x] 当前距开课时间 ≥ 24h

## 4. 业务流程

### 4.1 主路径（有体验套餐，预约）

1. 学员从教练详情页「预约」或我的预约页入口进入预约网格页
2. 系统展示该教练未来 7 天的可约时段
3. 学员选择时段并提交预约
4. 系统校验体验套餐可用且时段未被占
5. 系统预占课时（package.reserved +1, available -1）
6. 系统创建 booking 记录（status='已预约'，course_type=0）
7. 系统返回预约成功

### 4.2 主路径（无体验套餐，仅查看）

1. 学员从教练详情页进入预约网格页
2. 系统展示该教练未来 7 天的可约时段（已约满置灰，空闲可查看）
3. 页面顶部展示提示条「您还没有体验课套餐，购买后即可预约」
4. 学员点击时段时，系统拦截并引导购买体验课套餐
5. 学员无法提交预约

### 4.3 主路径（取消）

1. 学员在「我的预约」中选择已预约体验课
2. 系统判断距开课时间 ≥ 24h
3. 学员确认取消
4. 系统释放预占课时（package.reserved -1, available +1）
5. 系统更新 booking.status = '已取消'
6. 系统返回取消成功

### 4.4 异常分支

- **分支 1**：无可用体验套餐 → 返回 `NO_TRIAL_PACKAGE`，并引导购买
- **分支 2**：时段已被预约 → 返回 `SLOT_TAKEN`
- **分支 3**：开课 < 24h 内取消 → 不允许取消，提示"开课 24 小时内不可取消"
- **分支 4**：目标时段不在可约范围内（>7 天或已过期）→ 返回 `SLOT_NOT_AVAILABLE`

## 6. 验收标准（业务级 Gherkin）

### 6.1 场景 1：正常预约体验课

```gherkin
Given 学员持有 active 体验套餐且 available = 1
And   教练 A 明日 10:00 时段未被预约
When  学员从教练详情页点击「预约」并选择明日 10:00 提交
Then  booking.status = 已预约
And   course_type = 0
And   package.reserved = 1, package.available = 0
And   接口返回 HTTP 201
```

### 6.2 场景 2：开课前 24 小时外取消

```gherkin
Given 学员已预约后天 10:00 体验课
And   当前距开课 48 小时
When  学员取消预约
Then  booking.status = 已取消
And   package.reserved = 0, package.available = 1
And   接口返回 HTTP 200
```

### 6.3 场景 3：无体验套餐时查看教练可约时段

```gherkin
Given 学员已登录
And   学员名下无 active 体验套餐
When  学员从教练详情页点击「预约」
Then  系统展示该教练未来 7 天的可约时段
And   页面顶部显示提示「您还没有体验课套餐，购买后即可预约」
And   已约满时段置灰展示
And   HTTP 状态码 = 200
```

### 6.4 场景 4：无体验套餐时尝试提交预约

```gherkin
Given 学员已登录
And   学员名下无 active 体验套餐
And   学员在预约网格页选择了明日 10:00
When  学员点击「确认预约」
Then  系统返回 HTTP 400，错误码 NO_TRIAL_PACKAGE
And   提示「您还没有体验课套餐，请先购买体验课套餐」
And   不创建 booking
```

### 6.5 场景 5：时段已被预约

```gherkin
Given 教练 A 明日 10:00 已被其他学员预约
When  学员尝试预约该时段
Then  系统返回 HTTP 400，错误码 SLOT_TAKEN
And   package 课时不变
```

### 6.6 场景 6：开课前 24 小时内取消

```gherkin
Given 学员已预约明日 10:00 体验课
And   当前距开课 12 小时
When  学员尝试取消
Then  系统拒绝取消
And   提示"开课 24 小时内不可取消"
And   booking.status 保持已预约
And   package 课时不变
```

## 8. 边界场景

### 8.1 边界场景 1：快速重复提交

- **触发条件**：学员快速点击预约按钮两次
- **预期行为**：幂等，第二次返回已有 booking
- **用户可见反馈**：预约成功页

### 8.2 边界场景 2：预约同时体验套餐过期

- **触发条件**：提交瞬间套餐 expire_at 到达
- **预期行为**：拒绝预约，提示套餐已过期
- **用户可见反馈**：引导购买正价套餐或重新购买体验课（如允许）

### 8.3 边界场景 3：教练请假导致时段关闭

- **触发条件**：预约后教练请假，slot 被关闭
- **预期行为**：系统自动取消 booking 并释放课时，通知学员
- **用户可见反馈**：收到取消通知，课时已恢复

## 14. 页面级设计决策

### 14.1 共用预约网格页

- 体验课预约与正价课预约共用同一个「预约网格页」。
- 页面不区分体验课/正价课时段，所有教练时段统一展示。
- 提交预约时根据学员持有的 active 套餐类型（体验课或正价课）调用对应接口。

### 14.2 无体验套餐时的预约网格页

- 可正常查看教练未来 7 天可约时段
- 顶部提示「您还没有体验课套餐，购买后即可预约」
- 空闲时段点击后弹窗引导购买体验课套餐
- 底部「确认预约」按钮禁用或点击后引导购买

### 14.3 取消按钮时间窗提示

- ≥ 24h：直接显示「取消预约」
- < 24h：不显示「取消预约」按钮，或置灰并提示"开课 24 小时内不可取消"
