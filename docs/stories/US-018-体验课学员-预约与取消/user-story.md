## 4. 业务流程

### 4.1 主路径（预约）

1. 学员进入教练详情页或预约页
2. 系统展示该教练未来可约的体验课时段
3. 学员选择时段并提交预约
4. 系统校验体验套餐可用且时段未被占
5. 系统预占课时（package.reserved +1, available -1）
6. 系统创建 booking 记录（status='已预约'，course_type=0）
7. 系统返回预约成功

### 4.2 主路径（取消）

1. 学员在「我的预约」中选择已预约体验课
2. 系统判断距开课时间 ≥ 24h
3. 学员确认取消
4. 系统释放预占课时（package.reserved -1, available +1）
5. 系统更新 booking.status = '已取消'
6. 系统返回取消成功

### 4.3 异常分支

- **分支 1**：无可用体验套餐 → 返回 `NO_TRIAL_PACKAGE`
- **分支 2**：时段已被预约 → 返回 `SLOT_TAKEN`
- **分支 3**：开课 < 24h 内取消 → 进入教练审批流程

## 6. 验收标准（业务级 Gherkin）

### 6.1 场景 1：正常预约体验课

```gherkin
Given 学员持有 active 体验套餐且 available = 1
And   教练 A 明日 9:00 时段未被预约
When  学员预约该时段
Then  booking.status = 已预约
And   course_type = 0
And   package.reserved = 1, package.available = 0
And   接口返回 HTTP 201
```

### 6.2 场景 2：开课前 24 小时外取消

```gherkin
Given 学员已预约后天 9:00 体验课
And   当前距开课 48 小时
When  学员取消预约
Then  booking.status = 已取消
And   package.reserved = 0, package.available = 1
And   接口返回 HTTP 200
```

### 6.3 场景 3：无可用体验套餐

```gherkin
Given 学员名下无 active 体验套餐
When  学员尝试预约体验课
Then  系统返回 HTTP 400，错误码 NO_TRIAL_PACKAGE
And   不创建 booking
```

### 6.4 场景 4：时段已被预约

```gherkin
Given 教练 A 明日 9:00 已被其他学员预约
When  学员尝试预约该时段
Then  系统返回 HTTP 409，错误码 SLOT_TAKEN
And   package 课时不变
```

### 6.5 场景 5：开课前 24 小时内取消需审批

```gherkin
Given 学员已预约明日 9:00 体验课
And   当前距开课 12 小时
When  学员申请取消
Then  系统创建取消审批单
And   booking.status 保持已预约
And   提示"已提交教练审批，24 小时内未处理视为拒绝"
```

## 8. 边界场景

### 8.1 边界场景 1：快速重复提交

- **触发条件**：学员快速点击预约按钮两次
- **预期行为**：幂等，第二次返回已有 booking
- **用户可见反馈**：预约成功页

### 8.2 边界场景 2：预约同时体验套餐过期

- **触发条件**：提交瞬间套餐 expire_at 到达
- **预期行为**：拒绝预约，提示套餐已过期
- **用户可见反馈**：引导购买正价套餐或重新购买体验课（如允许）

### 8.3 边界场景 3：教练请假导致时段关闭

- **触发条件**：预约后教练请假，slot 被关闭
- **预期行为**：系统自动取消 booking 并释放课时，通知学员
- **用户可见反馈**：收到取消通知，课时已恢复
