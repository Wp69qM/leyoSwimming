## 2. 触发条件

- **触发方**：教练

## 3. 前置条件

- [x] 教练已登录且 `coach.status = 1`（已通过入驻审核，依赖 US-011 / US-012）
- [x] 教练个人主页资料已完善（姓名、证书、任教年限、参考单价等）
- [x] 小程序已配置分享海报/卡片模板

---

## 4. 业务流程

### 4.1 主路径

1. 教练进入个人主页或排班页
2. 点击「分享主页」或「分享可约时段」按钮
3. 系统生成带 scene 参数的小程序分享卡片/海报，包含教练头像、姓名、任教年限、评分、最近可约时段
4. 教练选择分享到微信好友或朋友圈（海报）
5. 游客/注册用户点击分享卡片进入小程序落地页
6. 系统解析 scene 参数，展示教练资料与可约时段
7. 游客可直接点击「预约体验课」或「购买套餐」（触发 US-004 / US-017 / US-020）

### 4.2 异常分支

- **分支 1**：教练状态非已通过 → 隐藏分享入口或提示「暂不可分享」
- **分支 2**：当前无可约时段 → 卡片/落地页显示「暂无近期可约时段，可关注后等待释放」
- **分支 3**：分享链接过期或 scene 解析失败 → 落地页提示「链接已失效，返回首页」

## 6. 验收标准（业务级 Gherkin）

> 本 US 为 L2（1 人天），包含 2 个正常场景 + 3 个异常场景 = 5 个场景。

### 6.1 场景 1：教练成功生成分享卡片

```gherkin
Given 教练 C 已登录且状态为已通过
And   教练 C 有个人主页资料且未来 7 天有可约时段
When  教练 C 点击「分享主页」
Then  系统生成分享卡片 scene="coach=123&ts=1753879200"
And   卡片包含教练头像、姓名、任教年限、评分、最近 3 个可约时段
And   调用 wx.showShareImageMenu 或返回海报图片 URL
```

### 6.2 场景 2：游客通过分享链接查看教练主页与可约时段

```gherkin
Given 游客 V 未登录
And   教练 C 的分享 scene 合法且未过期
When  游客 V 点击分享卡片进入小程序
Then  落地页展示教练 C 的姓名、证书、任教年限、评分、参考单价
And   展示未来 7 天可约时段
And   隐藏教练手机号与微信二维码
And   提供「预约体验课」和「购买套餐」按钮
```

### 6.3 场景 3：教练状态非已通过时无法分享

```gherkin
Given 教练 C 的 coach.status = 0（待审核）
When  教练 C 进入个人主页
Then  「分享主页」按钮隐藏或置灰
And   点击时提示「入驻审核通过后可分享"
```

### 6.4 场景 4：当前无可约时段的兜底展示

```gherkin
Given 教练 C 已登录且状态为已通过
And   教练 C 未来 7 天无可约时段
When  教练 C 点击「分享主页」
Then  系统仍允许生成分享卡片
And   卡片/落地页展示「暂无近期可约时段，可关注后等待释放"
And   不展示空时段列表
```

### 6.5 场景 5：分享链接过期或非法

```gherkin
Given 游客 V 点击一条已过期或被篡改的分享链接
When  小程序解析 scene 失败
Then  落地页提示「链接已失效，返回首页"
And   提供返回首页按钮
```

## 8. 边界场景

### 8.1 边界场景 1：分享后可约时段发生变化

- **触发条件**：教练生成分享卡片后，其可约时段被预约或新增
- **预期行为**：落地页实时读取最新可约时段，不缓存旧数据（或缓存 TTL ≤ 1 分钟）
- **用户可见反馈**：游客看到的时段与教练当前实际可约时段一致

### 8.2 边界场景 2：游客未授权登录即点击购买

- **触发条件**：游客点击「购买套餐」
- **预期行为**：跳转微信授权登录页（US-004），授权后进入套餐购买流程
- **用户可见反馈**：先弹出登录提示，完成后回到购买页

### 8.3 边界场景 3：并发生成分享卡片

- **触发条件**：教练快速多次点击分享
- **预期行为**：使用相同 scene 参数，避免重复写入 share_log
- **用户可见反馈**：仅弹出一次分享菜单/生成一张海报

## 12. 备注

- **幂等键**：分享生成接口使用 `coach:{coach_id}:share:profile:{date}` 防止同一天重复生成不同 scene
- **scene 有效期**：落地页解析 scene 时不强制过期，但海报二维码建议 30 天有效
- **性能要求**：分享数据生成 P99 < 300ms，落地页加载 P99 < 500ms
- **隐私**：游客落地页不展示 coach.phone 与 wechat_qr

## 14. 页面级设计决策

### 14.1 分享内容范围

- **背景**：需要平衡引流效果与教练隐私
- **选项**：A. 分享完整主页含联系方式；B. 分享精简资料+可约时段，联系方式隐藏
- **结论**：选择 B，游客落地页隐藏手机号与微信二维码，需登录/购买后才可查看
- **影响范围**：分享卡片、落地页、教练主页

### 14.2 落地页入口

- **背景**：游客点击卡片后应直接进入转化路径
- **选项**：A. 进入教练详情页；B. 进入专用分享落地页
- **结论**：选择 B，落地页突出「预约体验课」与「购买套餐」CTA
- **影响范围**：小程序路由 /pages/coach-share/index

### 14.3 页面级交互说明

| 交互 | 触发 | 反馈 | 备注 |
|------|------|------|------|
| 点击分享 | 主页/排班页按钮 | 底部弹出分享菜单或生成海报 | |
| 生成海报 | 选择海报分享 | 显示加载 → 展示海报图片 | 失败时提示重试 |
| 游客点击卡片 | 微信消息卡片 | 打开小程序落地页 | scene 解析失败进错误页 |
| 点击购买套餐 | 落地页 CTA | 未登录跳转授权，已登录跳转套餐列表 | |
