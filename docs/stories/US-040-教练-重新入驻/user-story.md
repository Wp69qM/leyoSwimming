## 2. 触发条件

- **触发方**：教练
- **触发动作**：在教练端登录后点击「重新入驻」，提交新的入驻资料
- **触发时机**：用户主动操作

---

## 3. 前置条件

- [x] 教练当前 `coach.status = 3`（已离职，依赖 US-039 / US-041）
- [x] 教练账号未被注销或封禁
- [x] 系统允许已离职教练发起重新入驻（MVP 无冷却期限制）

---

## 4. 业务流程

### 4.1 主路径

1. 已离职教练登录教练端
2. 系统在「我的」页面展示「重新入驻」入口
3. 教练点击「重新入驻」
4. 系统将 `coach.status` 从 3 更新为 0（待审核）
5. 教练填写/确认入驻资料（证书、任教年限、参考单价等）
6. 教练提交入驻申请
7. 系统生成新的入驻审核记录，进入管理员审核队列
8. 管理员审核通过后，`coach.status` 从 0 更新为 1（已通过）

### 4.2 异常分支

- **分支 1**：教练状态非 3 → 隐藏「重新入驻」入口，点击时提示「当前状态不可重新入驻」
- **分支 2**：教练已处于 status=0（待审核） → 提示「入驻申请审核中，请勿重复提交」
- **分支 3**：重新入驻审核被拒绝 → `coach.status` 保持 3，可再次发起重新入驻

## 6. 验收标准（业务级 Gherkin）

> 本 US 为 L2（1 人天），包含 2 个正常场景 + 3 个异常场景 = 5 个场景。

### 6.1 场景 1：已离职教练成功发起重新入驻

```gherkin
Given 教练 C 当前 coach.status = 3（已离职）
And   教练 C 的账号状态正常
When  教练 C 点击「重新入驻」并确认
Then  coach.status 更新为 0（待审核）
And   系统生成新的入驻审核记录 application.status = "pending"
And   返回 HTTP 200 与提示"入驻申请已提交，请等待审核"
```

### 6.2 场景 2：管理员通过重新入驻审核

```gherkin
Given 教练 C 的 coach.status = 0（待审核）
And   已提交重新入驻资料
When  管理员在后台点击「通过审核」
Then  coach.status 更新为 1（已通过）
And   application.status 更新为 "approved"
And   老学员仍可在历史记录中查看该教练过往评分
And   新学员查看教练主页时不展示历史评分
```

### 6.3 场景 3：非已离职教练无法重新入驻

```gherkin
Given 教练 C 的 coach.status = 1（已通过）
When  教练 C 访问「重新入驻」入口
Then  入口隐藏或按钮置灰
And   提示"当前状态不可重新入驻"
```

### 6.4 场景 4：重复发起重新入驻

```gherkin
Given 教练 C 的 coach.status = 0（待审核）
When  教练 C 再次调用重新入驻接口
Then  返回错误码 REAPPLY_ALREADY_PENDING
And   HTTP 状态码 409
And   coach.status 保持 0，不生成新的审核记录
```

### 6.5 场景 5：重新入驻审核被拒绝

```gherkin
Given 教练 C 的 coach.status = 0（待审核）
When  管理员点击「拒绝审核」并填写原因="资料不完整"
Then  coach.status 更新为 3（已离职）
And   application.status 更新为 "rejected"
And   教练端提示"审核未通过，原因：资料不完整，可再次申请"
```

## 8. 边界场景

### 8.1 边界场景 1：并发发起重新入驻

- **触发条件**：教练快速多次点击「重新入驻」
- **预期行为**：使用幂等键去重，仅生成 1 条入驻审核记录
- **用户可见反馈**：仅一次成功提示

### 8.2 边界场景 2：已 frozen 的老学员套餐不变

- **触发条件**：教练重新入驻成功后，老学员查看之前因教练离职而被 frozen 的套餐
- **预期行为**：package.status 保持 frozen，不自动恢复为 active
- **用户可见反馈**：学员端显示「套餐已冻结，可换回原教练或申请退款」

### 8.3 边界场景 3：历史评价对新学员不可见

- **触发条件**：新学员（未与该教练有过 package/booking 关联）浏览重新入驻教练的主页
- **预期行为**：系统不返回该教练历史评分与评价
- **用户可见反馈**：主页评分区域显示「暂无评价」

## 14. 页面级设计决策

### 14.1 重新入驻入口可见性

- **背景**：只有已离职教练需要重新入驻入口
- **选项**：A. 所有状态教练均可见；B. 仅 status=3 可见
- **结论**：选择 B，避免已通过教练误操作
- **影响范围**：教练端「我的」页面

### 14.2 历史评分可见性

- **背景**：重新入驻后若直接展示旧评分，可能误导新学员
- **选项**：A. 完全删除历史评分；B. 保留但仅老学员可见
- **结论**：选择 B，既保留数据又保护新学员决策
- **影响范围**：教练主页、列表评分展示

### 14.3 页面级交互说明

| 交互 | 触发 | 反馈 | 备注 |
|------|------|------|------|
| 点击重新入驻 | 我的页面按钮 | 弹出确认/进入资料页 | status=3 时才可触发 |
| 提交资料 | 资料页按钮 | 跳转审核状态页 | status 变为 0 |
| 审核通过 | 管理员操作 | 教练端收到通知 | status 变为 1 |
| 审核拒绝 | 管理员操作 | 教练端显示原因 | status 恢复 3 |
