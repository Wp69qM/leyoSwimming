## 2. 触发条件

- **触发方**：教练
- **触发动作**：在教练端进入「我的 → 排班管理」添加/删除/修改可约时段
- **触发时机**：教练通过审核后主动维护，或每周固定释放时段时

## 4. 业务流程

### 4.1 主路径

1. 教练进入排班管理页
2. 系统展示当前已设置的可约时段日历/列表
3. 教练选择日期并添加新的可约时段（如明日 9:00-10:00）
4. 系统校验时段不冲突
5. 教练点击「发布」
6. 系统保存 schedule_slot 记录，`status = available`
7. 学员端该教练详情页展示新的可约时段

### 4.2 异常分支

- **分支 1**：添加时段与已有时段冲突 → 提示「该时段与已有可约时段冲突」
- **分支 2**：删除已有学员预约的时段 → 提示「该时段已有预约，无法删除」
- **分支 3**：批量复制上周排班时部分日期闭馆 → 提示「X 月 X 日闭馆，已自动跳过」

## 6. 验收标准（业务级 Gherkin）

> L2（1.5 人天）：2 正常 + 3 异常 = 5 个场景

### 6.1 场景 1：正常添加可约时段

```gherkin
Given 教练已通过审核且 status = 1
And   明日 9:00-10:00 无其他可约时段
When  教练添加明日 9:00-10:00 的可约时段
And   教练点击「发布」
Then  schedule_slot 记录创建成功
And   schedule_slot.status = 'available'
And   学员端教练详情页展示该时段可预约
```

### 6.2 场景 2：批量复制上周排班

```gherkin
Given 教练上周已发布 5 个可约时段
When  教练点击「复制上周排班」
Then  系统按上周模板生成本周 schedule_slot 记录
And   闭馆日期自动跳过
And   与已有 booking 冲突的时段标记为冲突待处理
```

### 6.3 场景 3：添加时段冲突

```gherkin
Given 教练已添加明日 9:00-10:00 的可约时段
When  教练尝试添加明日 9:30-10:30 的可约时段
Then  返回错误码 SLOT_TIME_CONFLICT
And   前端提示"该时段与已有可约时段冲突"
And   未创建新的 schedule_slot 记录
```

### 6.4 场景 4：删除已有预约的时段

```gherkin
Given 教练明日 9:00-10:00 的时段已被学员预约
When  教练尝试删除该时段
Then  返回错误码 SLOT_HAS_BOOKING
And   前端提示"该时段已有预约，无法删除"
And   schedule_slot 记录保持不变
```

### 6.5 场景 5：发布后学员端可见

```gherkin
Given 教练已发布明日 9:00-10:00 的可约时段
When  学员打开该教练详情页
Then  页面展示明日 9:00-10:00 为可预约状态
And   学员点击后可进入预约流程
```

## 8. 边界场景

### 8.1 边界场景 1：添加过去时间的时段

- **触发条件**：教练尝试添加今天之前或当前时间之前的时段
- **预期行为**：前端/后端拒绝
- **用户可见反馈**："不能添加过去时间的可约时段"

### 8.2 边界场景 2：跨天时段

- **触发条件**：教练添加 23:00-次日 1:00 的时段
- **预期行为**：系统支持跨天但拆分为两个日期记录或标记跨天
- **用户可见反馈**：正常展示跨天时段

### 8.3 边界场景 3：管理员后台修改教练排班

- **触发条件**：管理员在后台修改教练可约时段
- **预期行为**：教练端同步更新，已预约时段不可删除
- **用户可见反馈**：教练端展示最新排班

## 14. 页面级设计决策

### 14.1 排班展示方式

- **背景**：教练需要直观管理一周排班
- **选项**：A. 周历视图；B. 列表视图
- **结论**：选择 A，默认周历视图，支持切换到列表
- **影响范围**：排班管理页 UI

### 14.2 时段冲突处理

- **背景**：添加时段时可能与已有预约冲突
- **结论**：添加时仅校验与可约时段冲突，不校验预约；删除时校验是否已有 booking
- **影响范围**：排班 API 校验逻辑

### 14.3 页面级交互说明

| 交互 | 触发 | 反馈 | 备注 |
|------|------|------|------|
| 点击日期格子 | 点击 | 弹出添加时段弹窗 | 默认选中当天 |
| 复制上周排班 | 点击按钮 | 二次确认后生成本周排班 | 展示生成结果 |
| 删除时段 | 左滑/点击删除 | 冲突时提示不可删除 | 已预约不可删 |
