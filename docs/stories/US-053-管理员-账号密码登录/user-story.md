## 2. 触发条件

### 2.1 登录触发

- **触发方**：管理员
- **触发动作**：管理员打开 Web 后台管理系统或当前会话已过期时访问受保护页面
- **触发时机**：未登录态访问后台管理系统任意页面时被拦截进入登录页

### 2.2 退出登录触发

- **触发方**：管理员
- **触发动作**：管理员点击后台管理系统全局导航栏右上角管理员名字，在下拉菜单中点击「退出登录」
- **触发时机**：管理员已登录且主动选择退出当前账号

## 3. 前置条件

### 3.1 登录前置条件

- [x] 管理员账号已在系统预置或创建（`admin_user` 表存在记录）
- [x] 管理员账号状态为启用（`status = 0`）
- [x] 管理员当前处于未登录态或登录态已过期

### 3.2 退出登录前置条件

- [x] 管理员已登录（admin_token 有效）
- [x] 管理员位于任意后台管理系统页面（全局导航栏可见）

## 4. 业务流程

### 4.1 登录主路径

1. 管理员访问 Web 后台管理系统 URL
2. 系统检测到管理员未登录，展示登录页
3. 管理员输入用户名
4. 管理员输入密码
5. 管理员点击「登录」按钮
6. 系统校验用户名、密码正确
7. 系统校验账号状态为启用
8. 系统生成单一管理员会话 token（有效期 24 小时）
9. 系统将 token 和 userInfo 写入前端 localStorage
10. 系统记录登录日志
11. 系统跳转至后台首页（如数据看板或默认首页）

### 4.2 退出登录主路径

1. 管理员登录后进入任意后台管理系统页面
2. 系统在全局导航栏右上角展示当前管理员名字
3. 管理员点击右上角管理员名字
4. 系统展开下拉菜单，展示「退出登录」选项
5. 管理员点击「退出登录」选项
6. 系统调用后端退出登录接口，使当前 admin_session token 失效
7. 系统清除前端 localStorage 中的 admin_token 和 admin_user
8. 系统跳转回管理员登录页

### 4.3 异常分支

- **分支 1**：用户名或密码错误 → 系统提示「用户名或密码错误」，不记录登录成功日志
- **分支 2**：账号已被禁用 → 系统提示「账号已被禁用，请联系超级管理员」
- **分支 3**：token 已过期 → 后端返回 401，前端自动跳转登录页并提示「登录信息已过期，请重新登录」
- **分支 4**：网络异常 → 系统提示「网络异常，请稍后重试」
- **分支 5**：退出登录时网络异常 → 前端仍清除 localStorage 中的 admin_token 和 admin_user，跳转回登录页；服务端 token 按 TTL 自然过期
- **分支 6**：本地 admin_token 已不存在 → 前端直接清除残留 storage，跳转回登录页

## 6. 验收标准（业务级 Gherkin）

> US 等级：L1（0.5d，单一登录接口 + 登录页 + 全局退出菜单；共 5 个场景：3 个登录 + 2 个退出）

### 6.1 场景 1：管理员正常登录

```gherkin
Given 管理员账号 "admin" 已存在且状态为启用
And   管理员当前处于未登录态
When  管理员访问后台管理系统
And   输入正确的用户名 "admin"
And   输入正确的密码 "correct_password"
And   点击「登录」按钮
Then  系统校验通过
And   系统生成单一管理员会话 token（有效期 24 小时）
And   系统将 token 和 userInfo 写入前端 localStorage
And   系统记录登录成功日志
And   页面跳转至后台首页
```

### 6.2 场景 2：用户名或密码错误

```gherkin
Given 管理员当前处于未登录态
When  管理员在登录页输入用户名 "admin"
And   输入错误的密码 "wrong_password"
And   点击「登录」按钮
Then  系统返回 401 ADMIN_CREDENTIALS_INVALID
And   页面提示 "用户名或密码错误"
And   系统不生成 token
And   系统记录登录失败日志
```

### 6.3 场景 3：管理员账号被禁用

```gherkin
Given 管理员账号 "disabled_admin" 存在但状态为禁用（status = 1）
And   管理员当前处于未登录态
When  管理员输入正确的用户名和密码
And   点击「登录」按钮
Then  系统返回 403 ADMIN_DISABLED
And   页面提示 "账号已被禁用，请联系超级管理员"
And   系统不生成 token
```

### 6.4 场景 4：管理员正常退出登录

```gherkin
Given 管理员 M 已登录且 localStorage 中存在有效的 admin_token 和 admin_user
And   管理员 M 位于后台管理系统任意页面
When  管理员 M 点击全局导航栏右上角的管理员名字
And   在下拉菜单中点击「退出登录」
Then  系统调用后端 POST /api/v1/admin/auth/logout 接口
And   后端将当前 admin_session token 标记为失效
And   前端清除 localStorage 中的 admin_token 和 admin_user
And   页面跳转回管理员登录页
```

### 6.5 场景 5：本地 admin_token 已过期或不存在

```gherkin
Given 管理员 M 位于后台管理系统任意页面
And   本地 admin_token 不存在或已过期
When  管理员 M 点击「退出登录」
Then  前端直接清除 localStorage 中残留的 admin_token 和 admin_user
And   页面跳转回管理员登录页
And   后端不执行任何 token 失效操作（无可失效 token）
```

## 7. 数据/API/状态机影响

> 本节为摘要级概述，完整技术设计见 [./tech-design.md](./tech-design.md)。

| 2 | `/api/v1/admin/auth/logout` | POST | 新增 | 管理员退出登录（右上角下拉菜单）|

### 7.3 状态机影响

| # | 实体 | 转换 | 触发条件 | 说明 |

## 8. 边界场景

### 8.1 边界场景 1：密码输入框显示/隐藏

- **触发条件**：管理员点击密码输入框右侧眼睛图标
- **预期行为**：密码在明文与密文之间切换
- **用户可见反馈**：眼睛图标状态变化，密码显示方式变化

### 8.2 边界场景 2：连续多次登录失败

- **触发条件**：管理员连续 5 次输入错误密码
- **预期行为**：系统可临时锁定该账号 15 分钟（可选，MVP 阶段可先记录日志不强制锁定）
- **用户可见反馈**：提示"登录失败次数过多，请 15 分钟后重试"（若启用锁定策略）

### 8.3 边界场景 3：登录态过期后访问受保护页面

- **触发条件**：管理员 token 已过期（超过 24 小时）
- **预期行为**：后端接口返回 401，前端自动跳转登录页
- **用户可见反馈**：页面重定向至登录页，提示"登录信息已过期，请重新登录"

## 12. 备注

- **安全要求**：
  - 密码必须加密存储（bcrypt/scrypt 等），禁止明文存储
  - 登录接口需限流，防止暴力破解
  - token 使用 HTTP-only cookie 或安全 storage
  - 传输层必须使用 HTTPS
- **权限说明**：本 US 仅负责登录认证，管理员权限配置由 US-054（管理员账号管理）负责
- **幂等性**：同一用户名密码重复登录应生成新的 session 记录
- **设计相关**：见 §13-15 Figma 相关章节
- **技术相关**：见 [./tech-design.md](./tech-design.md)

## 14. 页面级设计决策

> 本节是**本故事特殊**的设计选择，**全局规范**中没有定义的设计决策记录在这里。**禁止重复全局规范已定义的内容**。

### 14.1 登录页布局

- **背景**：需要一个简洁的后台管理登录页
- **选项**：A. 左侧品牌图 + 右侧登录表单；B. 居中卡片式登录表单
- **结论**：选择 B，居中卡片式，更简洁，适配各种屏幕尺寸
- **影响范围**：管理员登录页

### 14.2 登录态保持策略

- **背景**：管理员需要一定时间的登录态保持，且后台系统使用复杂度低于小程序
- **选项**：A. access_token + refresh_token 双 token 机制；B. 单一 token，有效期 24 小时，过期后重新登录
- **结论**：选择 B，单一 token 有效期 24 小时，过期后端返回 401，前端自动跳转登录页并提示"登录信息已过期，请重新登录"
- **影响范围**：admin_session 表设计（仅 token_hash，无 refresh_token）、API 鉴权中间件、前端路由守卫与请求拦截器

### 14.3 退出登录入口

- **背景**：管理员需要安全退出后台系统
- **选项**：A. 左侧菜单底部固定退出；B. 右上角管理员名字下拉菜单中显示退出
- **结论**：选择 B，右上角名字下拉菜单，符合主流后台系统交互习惯
- **影响范围**：后台管理系统全局导航栏

### 14.4 页面级交互说明

| 交互 | 触发 | 反馈 | 备注 |
|------|------|------|------|
| 点击「登录」 | click | 按钮 loading，校验成功后跳转后台首页 | 失败时显示错误提示 |
| 点击密码眼睛图标 | click | 密码明文/密文切换 | — |
| 点击右上角管理员名字 | click | 展开下拉菜单，显示退出登录选项 | — |
| 点击「退出登录」 | click | 清除 localStorage 中的 token 和 userInfo，返回登录页 | 可弹窗二次确认（可选） |
