## 4. 业务流程

### 4.1 主路径

1. 教练点击 tabbar「预约」进入教练端预约页
2. 系统默认以列表卡片形式展示教练的学员预约
3. 列表按上课时间正序排列，包含待上课和已上完的课程
4. 每个卡片展示：上课时间、学员姓名、学习泳姿、课程状态
5. 教练可切换视图至「周网格」
6. 周网格横向为日期，纵向为 10:00-20:00 共 11 个时段
7. 已被预约的单元格显示两行内容：学员姓名、学习泳姿
8. 教练点击卡片或单元格进入课程确认/记录页（US-033）

### 4.2 异常分支

- **分支 1**：当前教练无学员预约 → 展示空状态
- **分支 2**：非教练身份访问 → 返回 403
- **分支 3**：周网格中某时段无预约 → 单元格展示为空或「可约」

## 6. 验收标准（业务级 Gherkin）

### 6.1 场景 1：正常查看列表视图

```gherkin
Given 教练已登录
And   教练明日 10:00 有学员 A 的预约，明日 14:00 有学员 B 的预约
When  教练进入 tabbar 预约页
Then  系统按上课时间正序展示 2 个预约卡片
And   每个卡片显示上课时间、学员姓名、学习泳姿、状态
And   HTTP 状态码 = 200
```

### 6.2 场景 2：正常切换周网格视图

```gherkin
Given 教练已登录
And   列表视图已展示学员预约
When  教练点击「周网格」切换按钮
Then  系统展示未来一周的周网格
And   纵向为 10:00 至 20:00 共 11 个时段
And   已被约单元格显示学员姓名与学习泳姿
```

### 6.3 场景 3：无预约时展示空状态

```gherkin
Given 教练已登录
And   当前教练无任何学员预约
When  教练进入预约页
Then  系统展示空状态插画与提示"暂无学员预约"
```

### 6.4 场景 4：点击已结束课程进入确认页

```gherkin
Given 教练已登录
And   存在 booking.status = 已完成，开课时间为今日 10:00
When  教练点击该预约卡片
Then  系统进入课程确认/记录页
And   教练可查看或确认上课记录
```

### 6.5 场景 5：周网格中空闲时段展示

```gherkin
Given 教练已登录
And   明日 10:00 有预约，明日 11:00 无预约
When  教练切换至周网格视图
Then  明日 10:00 单元格展示学员姓名与学习泳姿
And   明日 11:00 单元格展示为空或"可约"
```

## 8. 边界场景

### 8.1 边界场景 1：跨周切换

- **触发条件**：教练查看非当前周的预约
- **预期行为**：周网格支持前后翻周，列表支持按周筛选
- **用户可见反馈**：顶部展示当前周范围，提供翻周按钮

### 8.2 边界场景 2：多个学员同名

- **触发条件**：不同学员姓名相同
- **预期行为**：卡片/单元格通过头像或学员 ID 区分
- **用户可见反馈**：展示学员头像辅助识别

### 8.3 边界场景 3：课程状态变化后刷新

- **触发条件**：教练在确认页确认上课后返回预约页
- **预期行为**：预约列表/网格状态自动刷新
- **用户可见反馈**：课程状态更新为已完成

## 14. 页面级设计决策

### 14.1 默认视图

- 默认进入「列表卡片」视图
- 顶部提供「列表 / 周网格」切换 Tab

### 14.2 列表卡片信息结构

- 上课时间（日期 + 具体时段）
- 学员头像 + 姓名
- 学习泳姿
- 课程状态（已预约 / 待上课 / 上课中 / 已完成 / 旷课 / 已取消）

### 14.3 周网格结构

- 横向：未来 7 天日期
- 纵向：10:00、11:00、12:00、13:00、14:00、15:00、16:00、17:00、18:00、19:00、20:00
- 被约单元格：第一行学员姓名，第二行学习泳姿
- 空闲单元格：空白或显示「可约」

### 14.4 页面级交互说明

| 交互 | 触发 | 反馈 | 备注 |
|------|------|------|------|
| 切换列表/网格 | 点击顶部 Tab | 视图切换 | |
| 点击预约卡片 | 列表视图 | 进入课程确认/记录页 | 跳转 US-033 |
| 点击被约单元格 | 网格视图 | 进入课程确认/记录页 | 跳转 US-033 |
| 翻周 | 点击翻周按钮 | 网格与列表数据更新 | |
