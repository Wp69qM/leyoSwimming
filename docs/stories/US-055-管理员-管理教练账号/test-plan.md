# US-055 管理员管理教练账号 — 测试计划

> 状态：[REVIEW]
> 最后更新：2026-08-07

## 1. 测试范围

- 教练管理列表查询（按创建时间降序、状态筛选、关键词搜索）
- 教练详情查看（完整生效资料、证书、历史记录）
- 管理员编辑教练资料（含实名与资质）
- 管理员新建教练（直接已通过）
- 管理员取消教练入驻
- 权限控制与异常场景

## 2. 测试策略

| 测试类型 | 覆盖内容 | 工具 |
|---------|---------|------|
| 单元测试 | Service 层校验、状态机转换、审计日志写入 | JUnit 5 + Mockito |
| 集成测试 | API 接口端到端、数据库事务 | Spring Boot Test + Testcontainers |
| 接口契约测试 | 请求/响应字段、错误码 | REST Assured |
| 前端组件测试 | 列表页、详情页、编辑弹窗 | React Testing Library |

## 3. 关键测试用例

### 3.1 列表查询

| 用例 ID | 场景 | 预期结果 |
|---------|------|---------|
| TC-001 | 默认查询 | 返回 status 不为过滤条件，按 approved_at 降序 |
| TC-002 | 按状态筛选「已通过」 | 仅返回 coach.status=1 的教练 |
| TC-003 | 关键词搜索姓名 | 返回匹配姓名的教练 |
| TC-004 | 关键词搜索手机号 | 返回匹配手机号的教练 |
| TC-005 | 无权限访问 | 返回 403 ADMIN_PERMISSION_DENIED |

### 3.2 详情查看

| 用例 ID | 场景 | 预期结果 |
|---------|------|---------|
| TC-006 | 查看已通过教练详情 | 返回完整资料、证书列表、历史申请 |
| TC-007 | 查看不存在教练 | 返回 404 COACH_NOT_FOUND |

### 3.3 编辑资料

| 用例 ID | 场景 | 预期结果 |
|---------|------|---------|
| TC-008 | 正常编辑简介 | coach.bio 更新，audit_log 新增记录 |
| TC-009 | 编辑手机号重复 | 返回 409 PHONE_ALREADY_EXISTS |
| TC-010 | 编辑身份证号重复 | 返回 409 ID_CARD_ALREADY_EXISTS |
| TC-011 | 编辑资质证书 | coach_certificate 更新 |

### 3.4 新建教练

| 用例 ID | 场景 | 预期结果 |
|---------|------|---------|
| TC-012 | 正常新建 | coach.status=1，证书写入，audit_log 记录 |
| TC-013 | 手机号已存在 | 返回 409 PHONE_ALREADY_EXISTS |
| TC-014 | 必填项缺失 | 返回字段级校验错误 |

### 3.5 取消入驻

| 用例 ID | 场景 | 预期结果 |
|---------|------|---------|
| TC-015 | 正常取消已通过教练 | coach.status=3，audit_log 记录 |
| TC-016 | 取消非已通过教练 | 返回 400 COACH_STATUS_NOT_APPROVED |
| TC-017 | 未填写原因 | 返回字段级校验错误 |

## 4. 回归测试

- US-011 管理员审核教练入驻资质（审核详情字段与教练管理详情字段一致性）
- US-012 教练管理个人主页与参考单价（教练端编辑范围与管理员编辑范围差异）
- US-041 管理员处理教练离职（取消入驻后触发离职处理）
