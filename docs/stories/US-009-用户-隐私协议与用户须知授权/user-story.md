## 4. 业务流程

### 4.1 登录页协议确认（主路径）

1. 用户/教练进入登录页
2. 页面默认展示「我已阅读并同意《用户须知》和《隐私协议》」勾选区，初始状态为未勾选
3. 用户/教练点击勾选框或「我已阅读并同意」这几个字（不含《用户须知》《隐私协议》两个协议名）→ 仅切换勾选框状态：未勾选变为已勾选，已勾选变为未勾选
4. 用户/教练点击「《用户须知》」或「《隐私协议》」协议名 → 唤起协议浮层弹窗
5. 浮层弹窗默认展示《用户须知》Tab，可切换至《隐私协议》Tab
6. 用户/教练阅读后点击浮层底部「同意」按钮
7. 浮层关闭，登录页勾选框状态变为已勾选
8. 用户/教练点击登录按钮，系统校验勾选框已勾选，允许进入登录流程
9. 登录成功后，系统记录用户/教练同意的《用户须知》版本号和《隐私协议》版本号及同意时间

### 4.2 登录页协议不同意

1. 用户/教练在协议浮层中点击「不同意」按钮
2. 浮层关闭，登录页勾选框状态保持/变为未勾选
3. 用户/教练点击登录按钮时，系统校验勾选框未勾选，阻止登录并提示「请阅读并同意《用户须知》和《隐私协议》」

### 4.3 登录后查看协议（主路径）

1. 用户/教练进入「我的 → 设置 → 用户须知」或「我的 → 设置 → 隐私协议」
2. 系统展示当前生效的协议内容
3. 页面仅支持查看，不提供「撤回授权」按钮

### 4.4 异常分支

- **分支 1**：用户/教练点击浮层外部区域 → 浮层关闭，勾选框状态保持唤起浮层前的状态
- **分支 2**：用户/教练未勾选协议直接点击登录 → 系统阻止登录并提示
- **分支 3**：协议内容加载失败 → 展示默认错误文案并支持重试

## 6. 验收标准（业务级 Gherkin）

### 6.1 场景 1：登录页点击协议名并同意后成功登录

```gherkin
Given 用户进入用户端登录页
And   当前《用户须知》版本为 v2.0，《隐私协议》版本为 v2.0
And   登录页勾选框当前为未勾选
When  用户点击「《用户须知》」协议名
Then  协议浮层弹窗展示《用户须知》Tab
When  用户切换到《隐私协议》Tab 阅读
And   用户点击「同意」按钮
Then  浮层关闭
And   登录页勾选框状态变为已勾选
And   用户完成登录后，系统记录 user_terms_consent.version = 'v2.0'
And   系统记录 user_privacy_consent.version = 'v2.0'
And   两条记录的 agreed_at 均为当前时间
```

### 6.2 场景 2：登录页不同意协议导致无法登录

```gherkin
Given 用户进入用户端登录页

When  用户点击「不同意」按钮
Then  浮层关闭
And   登录页勾选框状态为未勾选
And   用户点击登录按钮时系统阻止登录

```

### 6.3 场景 3：登录后查看用户须知和隐私协议


## 8. 边界场景

### 8.1 边界场景 1：协议版本更新

- **触发条件**：系统更新《用户须知》或《隐私协议》至新版本
- **预期行为**：下次登录时（若会话失效）重新展示协议浮层；已登录态不受影响，但用户可在设置页查看最新版本
- **用户可见反馈**：登录页重新展示「请阅读并同意最新版《用户须知》和《隐私协议》」

### 8.2 边界场景 2：协议内容加载失败

- **触发条件**：网络异常导致协议内容无法加载
- **预期行为**：浮层展示错误提示，提供重试按钮
- **用户可见反馈**："协议内容加载失败，请重试"

### 8.3 边界场景 3：用户从设置页重新进入登录页

- **触发条件**：用户退出登录后再次进入登录页
- **预期行为**：勾选框恢复默认未勾选状态，需重新同意
- **用户可见反馈**：勾选框为空，登录前提示同意

## 14. 页面级设计决策

### 14.1 登录页协议勾选区

- **背景**：登录前需强制同意《用户须知》和《隐私协议》
- **结论**：在登录按钮上方放置勾选区「我已阅读并同意《用户须知》和《隐私协议》」。点击勾选框或「我已阅读并同意」这几个字仅切换勾选状态；点击「《用户须知》」或「《隐私协议》」协议名唤起浮层弹窗
- **影响范围**：用户端/教练端登录页

### 14.2 协议浮层弹窗

- **背景**：在登录页内完整展示两个协议，不打断登录流程
- **选项**：A. 跳转新页面；B. 当前页浮层弹窗
- **结论**：选 B，浮层弹窗内包含《用户须知》和《隐私协议》两个 Tab，底部固定「同意」「不同意」按钮
- **影响范围**：登录页交互

### 14.3 浮层关闭与勾选状态联动

- **背景**：用户可能不同意或误触关闭
- **结论**：
  - 点击「同意」→ 浮层关闭，勾选框变为已勾选
  - 点击「不同意」→ 浮层关闭，勾选框变为未勾选
  - 点击浮层外部 → 浮层关闭，勾选框保持原状态
- **影响范围**：登录页状态管理

### 14.4 设置页协议查看

- **背景**：登录后用户可能需要再次查看协议
- **结论**：「我的 → 设置」中提供「用户须知」「隐私协议」两个入口，进入后仅展示内容，不提供撤回操作
- **影响范围**：设置页
