# Test Plan: US-063 管理员-管理知识库文档

## 1. 测试范围

- 列表查询与分页
- 启用/禁用文档
- 删除文档
- 状态同步到向量库

## 2. 测试用例

### 2.1 单元测试

| 用例 | 输入 | 预期 |
|------|------|------|
| 列表分页 | page=1, pageSize=20 | 返回正确分页数据 |
| 按关键词筛选 | keyword="野泳" | 只返回标题含野泳的文档 |

### 2.2 集成测试

| 用例 | 步骤 | 预期 |
|------|------|------|
| 禁用后检索不到 | 禁用 → 用户提问 | query_knowledge 无结果 |
| 启用后可检索 | 启用 → 用户提问 | query_knowledge 有结果 |
| 删除清理向量 | 删除 → 查询 Chroma | 对应 chunk 不存在 |

### 2.3 E2E 测试

| 用例 | 步骤 | 预期 |
|------|------|------|
| web-admin 禁用 | 点击禁用 | 状态变禁用，用户检索不到 |
| web-admin 删除 | 点击删除确认 | 列表消失，向量清理 |

## 3. 验收检查清单

- [ ] 列表分页正常
- [ ] 禁用后向量库删除
- [ ] 启用后向量库重建
- [ ] 删除后 MySQL 和向量库都清理
- [ ] 非 ADMIN 无法操作
