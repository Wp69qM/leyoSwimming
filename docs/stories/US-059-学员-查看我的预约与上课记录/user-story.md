## 4. 业务流程

### 4.1 主路径

1. 学员点击 tabbar「预约」进入我的预约页
2. 若学员无 active 套餐，展示空状态与「去购买套餐」按钮，流程结束
3. 若学员有 active 套餐但无 booking，展示空状态与「立即预约」按钮
4. 系统按上课时间正序展示学员的待上课 booking 列表
5. 每个卡片展示：上课时间、教练姓名、课程状态、可操作按钮
6. 学员可对符合条件的卡片执行操作：
   - 距开课 ≥24h 的已预约课程：点击「取消预约」
   - 已进入签到窗口的课程：点击「一键签到」
   - 已完成的课程：点击「写课后总结」
7. 学员点击卡片进入预约/上课详情页
8. 详情页展示：课程信息、教练上课记录、学员课后总结（如有）
9. 学员切换到「上课记录」页，查看历史已完成课程列表

### 4.2 异常分支

- **分支 1**：学员无待上课预约 → 展示空状态并提示去预约
- **分支 2**：非本人 booking → 返回 403
- **分支 3**：教练尚未填写上课记录 → 详情页展示占位提示，仍允许学员预填总结

## 6. 验收标准（业务级 Gherkin）

### 6.1 场景 1：正常查看待上课列表

```gherkin
Given 学员已登录
And   学员存在 2 条已预约的 booking，开课时间分别为明日 10:00 和明日 14:00
When  学员进入 tabbar 预约页
Then  系统按开课时间正序展示 2 个预约卡片
And   每个卡片显示上课时间、教练姓名、状态
And   HTTP 状态码 = 200
```

### 6.2 场景 2：正常查看上课详情

```gherkin
Given 学员已登录
And   存在 booking.status = 已完成
And   教练已通过 US-033 创建 course_record
When  学员点击该预约卡片
Then  详情页展示课程信息、教练记录、学员课后总结
And   HTTP 状态码 = 200
```

### 6.3 场景 3：无待上课预约但有套餐

```gherkin
Given 学员已登录
And   学员名下无任何 booking
And   学员持有 active 套餐
When  学员进入 tabbar 预约页
Then  系统展示空状态插画与提示"暂无预约，去预约一节课吧"
And   提供「立即预约」按钮（跳转套餐绑定教练的预约网格页）
```

### 6.4 场景 4：无套餐时展示空状态

```gherkin
Given 学员已登录
And   学员名下无任何 booking
And   学员无 active 套餐
When  学员进入 tabbar 预约页
Then  系统展示空状态插画与提示"暂无可用套餐，请先购买套餐"
And   提供「去购买套餐」按钮
And   不展示「立即预约」按钮
```

### 6.5 场景 5：教练尚未填写上课记录

```gherkin
Given 学员已登录
And   存在 booking.status = 已完成
And   教练尚未创建 course_record
When  学员进入详情页
Then  展示占位提示"教练还未填写本节课记录"
And   仍允许学员点击「写课后总结」
```

### 6.6 场景 6：非本人 booking 越权查看

```gherkin
Given 学员 A 已登录
And   存在 booking 属于学员 B
When  学员 A 尝试查看该 booking 详情
Then  系统返回 HTTP 403
And   不返回任何 booking 详情数据
```

## 8. 边界场景

### 8.1 边界场景 1：列表数据量大

- **触发条件**：学员有大量历史 booking
- **预期行为**：分页加载，避免一次性加载过多数据
- **用户可见反馈**：列表底部展示加载更多提示

### 8.2 边界场景 2：网络中断后恢复

- **触发条件**：进入页面时网络异常，恢复后重新加载
- **预期行为**：自动重试或提供手动刷新按钮
- **用户可见反馈**：展示错误状态与刷新按钮

### 8.3 边界场景 3：操作按钮状态动态变化

- **触发条件**：学员停留在列表页，某课程进入签到窗口
- **预期行为**：页面刷新或重新进入时展示最新操作按钮
- **用户可见反馈**：按钮状态与时间窗一致

## 14. 页面级设计决策

### 14.1 列表卡片信息结构

- 上课时间（日期 + 具体时段）
- 教练头像 + 姓名
- 课程状态（已预约 / 待上课 / 上课中 / 已完成 / 已取消 / 旷课）
- 操作按钮区（根据状态和时间窗动态展示）

### 14.2 空状态按钮规则

| 状态 | 展示按钮 | 跳转目标 |
|---|---|---|
| 无 active 套餐 | 「去购买套餐」 | 套餐购买页 |
| 有 active 套餐但无 booking | 「立即预约」 | 套餐绑定教练的预约网格页 |

### 14.3 操作按钮展示规则

| booking 状态 | 时间条件 | 展示按钮 |
|-------------|---------|---------|
| 已预约 | 距开课 ≥24h | 取消预约 |
| 待上课 / 上课中 | 签到窗口内且未签到 | 一键签到 |
| 已完成 | 学员未写课后总结 | 写课后总结 |
| 已完成 | 学员已写课后总结 | 查看总结 |

### 14.4 详情页内容分组

- 课程信息组：上课时间、教练、课程类型、关联套餐
- 教练记录组：课程内容、重点、掌握程度、作业、媒体
- 学员总结组：身体感受、学习效果、问题反馈

### 14.5 页面级交互说明

| 交互 | 触发 | 反馈 | 备注 |
|------|------|------|------|
| 点击预约卡片 | 列表页 | 进入详情页 | |
| 点击取消预约 | 卡片操作区 | 二次确认弹窗 | 调用 US-030 API |
| 点击一键签到 | 卡片操作区 | Toast 提示签到成功 | 调用 US-032 API |
| 点击写课后总结 | 卡片操作区 | 底部弹出总结表单 | 调用 US-032 API |
| 切换上课记录 | Tab 切换 | 展示历史已完成课程 | |
