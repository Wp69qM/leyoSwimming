## 4. 业务流程

### 4.1 主路径

1. 管理员进入「首页运营」模块
2. 选择子功能：通知栏 / Banner / 运营卡片
3. 系统展示现有配置列表（含生效状态、可见范围、有效期）
4. 管理员新增或编辑条目
5. 管理员设置可见身份（全部 / 仅学员 / 仅游客 / 仅注册用户）、排序、有效期
6. 管理员点击「预览」查看小程序首页效果（预览不影响线上配置）
7. 管理员确认后提交保存
8. 系统校验字段合法性后直接写入对应业务表（`notice` / `homepage_banner` / `homepage_card`），前端配置即时生效（PRD §5.5.5 #6 / D47：预览机制无需审核直接生效）

> **P1-15 修复说明**（v1.2）：原 §4.1 步骤 8-9 含「内容安全审核」流程,违反 PRD §5.5.5 #6「预览机制无需审核直接生效」与 D47「公告无需审核,预览机制直接生效」。现移除审核环节,改为字段校验通过后直接写入并即时生效。

### 4.2 异常分支

- **分支 1**：有效期不合法（结束时间 ≤ 开始时间）→ 返回 `INVALID_TIME_RANGE`
- **分支 2**：可见范围参数非法 → 返回 `INVALID_VISIBLE_SCOPE`
- **分支 3**：管理员无权限 → 返回 HTTP 403

## 6. 验收标准（业务级 Gherkin）

> 本 US 为 L2（1.5 人天），场景数 = 2 正常 + 4 异常 = 6。

### 6.1 场景 1：管理员配置通知栏与 Banner 并即时生效

```gherkin
Given 管理员已登录且具有首页运营权限
And   当前不存在标题为"暑期班招生中"的通知栏
And   当前不存在名称为"清凉一夏"的 Banner
When  管理员提交通知栏：标题="暑期班招生中", 可见范围=全部, 生效时间=2026-07-30 00:00, 失效时间=2026-08-31 23:59
And   管理员提交 Banner：名称="清凉一夏", 图片URL="https://cdn.example.com/banner1.jpg", 排序=1, 可见范围=全部
Then  系统返回 HTTP 200
And   notice 表新增 1 条记录，title="暑期班招生中"，status='published'，visible_scope='all'
And   homepage_banner 表新增 1 条记录，name="清凉一夏"，sort_order=1，status='active'
And   游客端/学员端首页立即展示"暑期班招生中"通知栏与"清凉一夏" Banner
```

### 6.2 场景 2：管理员配置可见范围与预览运营卡片

```gherkin
Given 管理员已登录且具有首页运营权限
When  管理员提交运营卡片：标题="老学员续费入口", 可见范围=student, 排序=2, 生效时间=2026-07-30 00:00, 失效时间=2026-09-30 23:59
And   管理员点击"预览"并选择身份=学员
Then  系统返回预览结果中展示"老学员续费入口"卡片
And   选择身份=游客时预览结果中不展示该卡片
And   homepage_card 表新增 1 条记录，visible_scope='student'，status='active'
```

### 6.3 场景 3：有效期不合法

```gherkin
Given 管理员已登录且具有首页运营权限
When  管理员提交 Banner：生效时间=2026-08-01 00:00, 失效时间=2026-07-30 23:59
Then  系统返回 HTTP 400
And   返回错误码 INVALID_TIME_RANGE
And   提示"失效时间必须晚于生效时间"
And   homepage_banner 表不新增记录
```

### 6.4 场景 4：可见范围参数非法

```gherkin
Given 管理员已登录
When  管理员提交运营卡片：可见范围="vip"
Then  系统返回 HTTP 400
And   返回错误码 INVALID_VISIBLE_SCOPE
And   提示"可见范围只能是 all / visitor / registered / student"
And   homepage_card 表不新增记录
```

### 6.5 场景 5：无权限管理员访问配置接口

```gherkin
Given 管理员已登录但角色无"首页运营"权限
When  管理员调用 POST /api/admin/homepage/notices
Then  系统返回 HTTP 403
And   返回错误码 FORBIDDEN
And   notice 表不新增记录
```

## 8. 边界场景

### 8.1 边界场景 1：首页配置为空

- **触发条件**：小程序首页没有任何生效的通知栏 / Banner / 卡片
- **预期行为**：首页隐藏对应模块，不展示空白占位
- **用户可见反馈**：页面正常加载，无运营位

### 8.2 边界场景 2：多条通知栏同时生效

- **触发条件**：管理员配置了 3 条同时生效的通知栏
- **预期行为**：按 priority 与 sort_order 排序展示前 N 条（默认最多 3 条）
- **用户可见反馈**：首页展示排序最高的通知栏，其余折叠或隐藏

### 8.3 边界场景 3：运营卡片图片上传过大

- **触发条件**：上传图片超过 2MB 或非 jpg/png/webp 格式
- **预期行为**：上传服务拒绝并提示约束
- **用户可见反馈**：提示"图片大小需小于 2MB，格式限 jpg/png/webp"

## 14. 页面级设计决策

### 14.1 首页运营采用 Tab 分组

- Tab：通知栏 / Banner / 运营卡片 / 预览
- 各 Tab 独立保存，预览 Tab 支持按身份切换

### 14.2 可见范围四选一

- `all`：全部身份可见
- `visitor`：仅未登录游客可见
- `registered`：仅已登录但无有效套餐用户可见
- `student`：仅学员可见

### 14.3 页面级交互说明

| 交互 | 触发 | 反馈 | 备注 |
|------|------|------|------|
| 切换身份预览 | 选择身份下拉框 | 预览区实时刷新 | 不影响线上配置 |
| 提交配置 | 点击保存 | 成功：列表刷新；失败：显示错误 | 即时生效 |
| 手动下线 | 点击下线按钮 | 状态变 offline，前端立即隐藏 | — |
