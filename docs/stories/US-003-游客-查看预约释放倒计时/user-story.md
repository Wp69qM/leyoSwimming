## 2. 触发条件

- **触发方**：游客
- **触发动作**：打开小程序首页
- **触发时机**：系统检测到当前时间处于"释放倒计时窗口"（释放前 24 小时内至释放时刻）时，首页顶部展示倒计时组件

---

## 3. 前置条件

- [x] 游客已打开小程序（无需登录）
- [x] 管理员已在后台配置 `release_rule`（释放规则，依赖 US-015）
- [x] `release_rule.status = 1`（规则启用中）
- [x] 当前服务器时间处于倒计时窗口内（释放前 24 小时内，或释放当天 10:00 前）

---

## 4. 业务流程

### 4.1 主路径

1. 游客打开小程序首页
2. 系统读取 `release_rule`，结合当前服务器时间计算倒计时状态
3. 若处于倒计时窗口，首页顶部展示倒计时组件：
   - 释放前 24 小时内（非释放当天）→ 展示「距离下周预约开放还有 XX 小时」
   - 释放当天 10:00 前 → 展示「今日 10:00 开放下周预约」
4. 倒计时每秒/每分钟自动刷新（前端定时器）

### 4.2 异常分支

- **分支 1**：`release_rule` 未配置或被禁用 → 不展示倒计时组件，首页正常加载其他内容
- **分支 2**：当前时间不在倒计时窗口内（如周三 10:01 至下周二 09:59 之间）→ 不展示倒计时组件
- **分支 3**：网络异常 → 倒计时组件隐藏，不影响首页其他模块加载
- **分支 4**：管理员手动覆盖释放时间（提前/延迟）→ 倒计时按手动覆盖后的时间点计算

## 8. 边界场景

> 至少 3 个异常边界场景

| # | 场景 | 处理方式 |
|---|------|---------|
| 1 | `release_rule` 未配置或 `status=0`（禁用） | API 返回 `{ show: false }`，前端隐藏倒计时组件，后端记录 WARN 日志 |
| 2 | 客户端时间与服务器时间不同步（用户改手机时间） | 倒计时**以服务器返回的 `releaseAt` 时间戳为准**，前端用 `setInterval` 递减但每 10s 重新拉取服务器时间校准；不信任客户端 `Date.now()` 单点 |
| 3 | 释放时刻刚过（周三 10:00:01） | 倒计时立即消失，下次显示需等到下周二 10:00（释放前 24 小时）；API 在 10s 缓存过期后返回 `show: false` |
| 4 | 管理员手动覆盖释放时间（提前/延迟） | 倒计时按 `manual_override_at` 字段计算；若覆盖时间已过则按下一个常规释放点计算 |
| 5 | 服务器时间与数据库时间不一致 | 统一以数据库 `NOW()` 为准，API 计算时使用 DB 时间而非应用服务器时间 |

## 14. 页面级设计决策

> 本节是**本故事特殊**的设计选择，**全局规范**中没有定义的设计决策记录在这里。

### 14.1 倒计时显示窗口的两种文案

- **背景**：PRD §5.3.2 第 4 条要求两种文案：「距离下周预约开放还有 XX 小时」（释放前 24 小时）和「今日 10:00 开放下周预约」（释放当天）
- **选项**：
  - A：统一一种文案 + 动态数字
  - B：两种文案按时间段切换（选定）
- **结论**：选 B，严格遵循 PRD 文案。两种文案语义不同：前者强调"还有多久"，后者强调"今天几点"
- **影响范围**：首页倒计时组件

### 14.2 倒计时刷新频率

- **背景**：倒计时需要实时更新，但每秒拉 API 会压垮后端
- **选项**：
  - A：前端每秒 `setInterval` 递减（不拉 API）
  - B：前端每分钟刷新一次
  - C：前端每秒递减 + 每 10s 拉一次 API 校准（选定）
- **结论**：选 C。前端每秒本地递减保证视觉流畅，每 10s 拉 API 校准避免客户端时间漂移。API 有 10s Redis 缓存，10s 校准不会穿透 DB
- **影响范围**：首页倒计时组件 + `GET /release-countdown` API

### 14.3 倒计时组件的位置与视觉权重

- **位置**：首页顶部，通知栏（Notice Bar）下方，轮播图上方
- **样式**：高亮主色背景，高度 56px，全宽
- **动效**：数字变化时有轻微的翻牌动画（参考全局规范动效章节）
- **取舍**：不放在通知栏内（通知栏有时效性内容会冲突），独立组件更醒目

### 14.4 非倒计时窗口的隐藏策略

- **背景**：大部分时间（如周三 10:01 至下周二 09:59）不需要显示倒计时
- **结论**：组件完全隐藏（`display: none`），不占用首页空间。隐藏时首页其他模块上移填补空白
- **影响范围**：首页布局

### 14.5 页面级交互说明

| 交互 | 触发 | 反馈 | 备注 |
|------|------|------|------|
| 倒计时数字更新 | 每 1s | 数字递减 1s，带翻牌动效 | 前端本地递减 |
| 倒计时校准 | 每 10s | 静默拉 API，若偏差 > 30s 则跳变到正确值 | 无视觉反馈 |
| 倒计时消失 | 释放时刻到达 | 组件淡出消失，首页其他模块上移 | 触发 US-016 释放 |
| 倒计时点击 | tap | 跳转「可约时段」页（US-014 范围） | MVP 可选，P2 |
