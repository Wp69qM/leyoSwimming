- [x] 时段未被其他学员预约

---

## 4. 业务流程

### 4.1 主路径

1. 学员在教练详情页点击"选择时段"
2. 系统展示教练未来 7 天的可约时段
3. 学员选择某时段（如"明日 9:00"）
4. 系统校验：package 可用 + 时段未被占
5. 系统锁单：package.reserved +1, available -1
6. 系统创建 booking 记录（status='已预约'）
7. 系统返回预约成功 + 预约详情
8. 学员看到预约成功页

### 4.2 异常分支

- **分支 1**：时段已被预约 → 返回错误 `SLOT_TAKEN`
- **分支 2**：套餐无可用课时 → 返回错误 `NO_QUOTA`
- **分支 3**：套餐状态非 active → 返回错误 `PACKAGE_INACTIVE`

## 6. 验收标准（Gherkin）

### 6.1 场景 1：正常预约

```gherkin
Given 学员有 active 套餐且 available = 5
And   明日 9:00 时段未被预约
When  学员选择"明日 9:00"并提交
Then  booking 记录创建成功
And   booking.status = '已预约'
And   package.reserved = 1
And   package.available = 4
And   返回预约详情给前端
```

### 6.2 场景 2：时段已被预约

```gherkin
Given 明日 9:00 已被其他学员预约
When  学员尝试预约明日 9:00
Then  返回错误码 SLOT_TAKEN
And   前端提示"该时段已被预约，请选择其他时段"
And   package 课时不变
```

### 6.3 场景 3：套餐无可用课时

```gherkin
Given 学员套餐 available = 0
When  学员尝试预约
Then  返回错误码 NO_QUOTA
And   前端提示"请先购买套餐"
```

## 7. 数据 / API / 状态机影响

### 7.1 数据模型

- **新增表/字段**：`booking` 表新增记录
- **修改表/字段**：`package` 表 `reserved` 和 `available` 更新
- **索引**：`booking(schedule_slot_id, status)` 联合唯一索引

### 7.2 API 接口

- **新增接口**：
  - `POST /api/booking/create`：创建预约
  - `GET /api/coach/{id}/available-slots`：获取教练可约时段

### 7.3 状态机

- **状态转换**：
  - `booking.status`：0（无）→ 2（已预约）
  - `package`：available -1, reserved +1
- **涉及状态**：`已预约`（v11 §6.1）

## 8. 边界场景

| # | 场景 | 期望处理 |
|---|------|----------|
| 1 | 学员快速重复点击（网络抖动）| 幂等键防重，第二次请求返回已有预约 |
| 2 | 网络中断 | 前端重试机制（3 次），失败后提示用户 |
| 3 | 教练请假 | 系统检测 schedule_slot.status=closed，预约接口直接拒绝 |
| 4 | 学员同时约多个时段 | 每个时段独立事务，部分成功部分失败需事务补偿 |
| 5 | 套餐 reserved+consumed+available = 0 | 触发 active → exhausted 转换 |
