## 4. 业务流程

> 步骤列表（带异常分支），用户视角描述

### 4.1 主路径（查看学员完整资料）

1. 教练在教练端进入「我的学员」列表，默认展示「活跃学员」Tab
2. 系统将学员分为两类：
   - **活跃学员**：与当前教练存在 `status='active'` 套餐关联的学员
   - **历史学员**：与当前教练有过关联但当前无 `status='active'` 套餐的学员
3. 系统列出当前 Tab 下的学员，卡片展示：头像、姓名、性别、年龄、是否未成年人
4. 对于「活跃学员」卡片，系统额外展示其活跃套餐标签：
   - 若存在 active 体验课套餐：显示「体验课」标签
   - 若存在 active 正价套餐：显示「正价套餐 x N」标签（N 为 active 正价套餐数量）
   - 两种套餐同时存在时，两个标签同时显示
5. 教练可点击 Tab 切换「活跃学员」与「历史学员」
6. 教练点击目标学员进入详情页
7. 系统展示学员**完整资料**：
   - **学员自主档案（US-005，只读）**：头像、姓名、手机号（脱敏）、年龄、性别、是否未成年人、有无游泳基础、会什么泳姿、游泳年限、个人描述
   - **教练视角切片（可编辑）**：学习泳姿、游泳等级、基础情况、沟通备注
   - **关联套餐卡片列表**：该学员与当前教练的所有 package 实例，按购买时间倒序展示
     - 卡片字段：套餐名称、套餐模式（正价/体验）、有效期、状态标签、剩余课时
     - 状态标签：未使用 / 使用中 / 已使用 / 已过期 / 已退款
     - 点击卡片跳转「套餐使用详情页」，由 **US-021 教练视角**统一承接
8. 教练点击「编辑资料」进入编辑模式
9. 教练编辑可写字段并点击保存
10. 系统保存到 `coach_student_profile` 表，仅影响该教练视角；`user` 表中学员自主档案不被修改
11. 返回保存成功提示，并记录操作日志

### 4.2 异常分支

- **分支 1**：学员不是当前教练的关联学员 → 返回错误 `NOT_ASSOCIATED_STUDENT`，前端提示「无权查看该学员」
- **分支 2**：教练尝试修改学员自主档案字段（头像、姓名、手机号、年龄、性别、是否未成年人、监护人信息等）→ 后端忽略或返回错误 `READONLY_USER_PROFILE`，前端仅展示不可编辑

## 8. 边界场景

### 8.1 边界场景 1：并发编辑同一学员资料

- **触发条件**：教练在 A、B 两个设备上同时编辑同一学员并保存
- **预期行为**：后端以 `coach_id + student_id` 为幂等键去重，第二次请求返回与第一次相同结果，不生成重复记录；若字段冲突，以后到请求的完整提交为准并记录审计日志
- **用户可见反馈**：两次均提示「保存成功」

### 8.2 边界场景 2：教练输入 XSS 脚本

- **触发条件**：教练在「沟通备注」中输入 `<script>alert(1)</script>`
- **预期行为**：服务端进行 HTML 转义存储，前端展示时渲染为纯文本，不执行脚本
- **用户可见反馈**：学员详情页正常显示文本，无弹窗

### 8.3 边界场景 3：学员主动注销后教练仍查看历史切片

- **触发条件**：学员账号已注销（user.status = 1），但历史 booking 仍存在
- **预期行为**：教练仍可查看该学员历史信息切片，但姓名/手机号按脱敏规则展示（保留最后 1 位）
- **用户可见反馈**：列表显示"张*（已注销）"

### 8.4 边界场景 4：教练尝试修改学员自主档案字段

- **触发条件**：教练在编辑页尝试提交 US-005 字段（如姓名、年龄、性别、个人描述）
- **预期行为**：后端忽略只读字段或返回 READONLY_USER_PROFILE；`user` 表不被修改；教练切片正常保存
- **用户可见反馈**：只读字段无编辑入口，保存后提示"保存成功"，US-005 字段保持不变

## 14. 页面级设计决策

### 14.1 信息切片与学员本人资料的边界

- **背景**：教练需要查看学员完整档案，但不能覆盖学员自行维护的基础资料
- **选项**：A. 直接修改 user 表；B. 独立 coach_student_profile 表
- **结论**：选择 B，教练修改仅写入 coach_student_profile，user 表只读
- **影响范围**：教练端学员详情页、后端 PUT /api/coach/v1/students/{id}/profile

### 14.2 US-005 字段在教练端只读

- **背景**：US-005 中的头像、姓名、手机号、年龄、性别、游泳基础等属于学员自主档案
- **选项**：A. 教练可编辑；B. 教练仅查看
- **结论**：选择 B，教练端展示 US-005 字段但不可编辑；如需修改，引导学员在「我的 → 个人资料」中自行维护
- **影响范围**：教练端学员详情页、后端 PUT 接口忽略 US-005 字段

### 14.3 未成年人标识入口

- **背景**：需要在学员详情中明确标识未成年人并维护监护人
- **选项**：A. 学员本人填写；B. 教练标记
- **结论**：选择 A，未成年人信息统一由学员在 US-005 中自主维护；教练端仅只读展示，不维护监护人联系方式。如需备注，教练可写在沟通备注或基础情况中
- **影响范围**：教练端详情页只读展示、US-005 编辑入口、package 购买流程（US-020）

### 14.4 页面级交互说明

| 交互 | 触发 | 反馈 | 备注 |
|------|------|------|------|
| 进入我的学员 | 点击底部 Tab | 默认展示「活跃学员」Tab，加载列表骨架屏 | 列表卡片展示头像、姓名、性别、年龄、是否未成年人 |
| 切换 Tab | 点击「活跃学员」/「历史学员」Tab | 切换列表数据源 | 活跃学员卡片额外展示套餐类型标签 |
| 点击学员卡片 | 卡片点击 | 进入详情页，顶部显示学员 US-005 自主档案 | 头像、姓名、性别、年龄 |
| 点击编辑资料 | 点击编辑按钮 | 进入编辑模式，US-005 字段不可编辑 | 教练切片字段可编辑（学习泳姿、游泳等级、基础情况、沟通备注） |
| 点击套餐卡片 | 卡片点击 | 跳转至套餐使用详情页 | 详情页由 US-021 教练视角统一承接 |
| 保存资料 | 点击保存按钮 | 成功提示 + 返回详情 | 校验失败时字段标红 |

### 14.5 套餐使用详情页入口

- **背景**：学员详情页需展示与该教练关联的所有 package 卡片，并支持查看套餐使用详情
- **选项**：
  - A. 点击卡片跳转至独立「教练视角套餐详情页」（复用/扩展 US-021 教练端页面）
  - B. 在学员详情页内以抽屉/折叠面板形式展开套餐使用记录
- **结论**：选择 A，由 **US-021 教练视角**统一承接「套餐使用详情页」。教练视角与学员视角共用相同信息架构（套餐快照、剩余课时、有效期、状态、使用记录列表），仅在入口和权限上区分
- **影响范围**：US-037 仅负责入口与列表卡片；US-021 负责套餐详情页内容及教练视角适配
