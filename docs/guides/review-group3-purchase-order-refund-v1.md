## 3. 组内 MVP 逻辑通顺性检查

### 3.1 主线流程

```
US-017 游客购买体验课套餐
  → US-018 体验课学员预约与取消
US-019 学员浏览正价套餐
  → US-020 学员购买正价套餐
    → US-025 学员支付套餐订单
      → US-021 学员查看我的套餐
        → US-022 学员更换绑定教练 / US-029 学员预约正价课程
        → US-023 学员候补与关注时段
          → US-024 学员候补自动转正
```
