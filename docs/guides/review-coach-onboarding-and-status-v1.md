### 1. 教练状态机覆盖

本组 US 覆盖了以下教练状态转换：

| 转换 | 涉及 US | 状态 |
|------|---------|------|
| 无 → 0（待审核） | US-010 | ✅ |
| 0 → 1（已通过） | US-011 | ✅ |
| 0 → 2（已驳回） | US-011 | ✅，但 **2 → ? 缺失**，被驳回教练无法重新提交 |
| 1 → 4（申请离职中） | US-039 | ✅ |
| 4 → 3（已离职） | US-041（组外） | 待 US-041 验证 |
| 3 → 0（重新入驻） | US-040 | ✅ |

**断裂点**：`status = 2`（已驳回）没有回到 `0` 或 `3` 的路径，导致审核驳回后教练永久退出入驻流程。

1. **US-016 与 PRD §5.4.7 冲突**：US-016 仅对 `status=1` 教练释放时段，但 PRD 要求 `status=4` 期间仍继续生成排班。
