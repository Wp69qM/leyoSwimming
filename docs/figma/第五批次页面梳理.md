## 5. 核心规则摘要

1. **只读白名单**：MVP 仅暴露 4 个只读工具（`query_knowledge` / `query_coaches` / `query_packages` / `get_hot_recommendations`），逐个显式注册，禁止批量导入。
2. **越权面收窄（安全红线）**：`get_user_profile` / `get_user_packages` 依赖 user_hash 身份闭包，**禁止**注册到 MCP；`ingest` / `chat` / `web_search` 不暴露。
3. **独立鉴权**：MCP 端点用独立 `MCP_API_TOKEN`（≥32 位强随机），与 `INTERNAL_API_TOKEN` 分离可独立轮换；`InternalAuthMiddleware` 放行 `/mcp-server/**`，MCP 层自行校验 Bearer header。
4. **限流覆盖**：MCP 路径必须纳入 `RateLimitMiddleware`（IP 维度），防外部 Agent 耗尽 Embedding 配额。
5. **共享 Service 层**：MCP 直调 `KnowledgeService` / `JavaInternalClient`，不包装 LangChain `@tool` 闭包；归一化函数提取 `normalizers.py` 两条协议层共用。
6. **阈值复用**：知识检索阈值复用 `KNOWLEDGE_SIMILARITY_THRESHOLD` 配置（当前值 0.2；注：第四批次文档中 0.7 为历史值，已调优）。
7. **参数防护**：`top_k` 截断至 10、`limit` 截断至 20；中文参数（泳姿/性别/套餐模式）自动归一化，未知值降级为 None 按无过滤查询。
8. **故障隔离**：backend 不可达时推荐工具返回结构化错误（不抛异常、不崩溃），知识工具与既有 REST 链路不受影响。
9. **零回归**：既有 `/api/ai-assistant/*` 与 `/api/internal/ai/*` 链路在 MCP 挂载后行为不变。
10. **验证闭环**：Trae 本地注册（URL + Bearer header），4 个工具真实调用各 ≥1 次成功，验证记录归档 US-068 §15。
