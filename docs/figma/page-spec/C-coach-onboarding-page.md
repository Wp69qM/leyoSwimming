# 页面规格：C-教练端入驻资料填写页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../../docs/prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-010（教练提交入驻资料）/ US-040（教练重新入驻）
> **对应 PRD**：§5.4.1 入驻与资料、§5.5.1 管理员审核
> **版本**：v1.0 | **创建日期**：2026-08-05

## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 业务含义 | 页面表现 |
|------|---------|----------|
| -1 未提交 | 首次入驻 | 显示完整表单，可编辑，按钮为「保存草稿」「提交审核」 |
| 0 待审核 | 已正式提交 | **不可进入本页**；系统自动重定向至 C-等待审核页 |
| 1 已通过 | 已入驻 | **不可进入本页**；从我的-个人主页编辑进入资料编辑（非本 US） |
| 2 已驳回 | 审核未通过 | 顶部显示红色驳回原因条，表单可编辑，提交按钮文案改为「重新提交」 |
| 3 已离职 | 重新入驻 | 标题可改为"重新入驻资料"，表单预填旧资料，按钮同首次入驻 |
| 4 申请离职中 | 功能仍可用 | **不可进入本页**；提示"当前状态不可修改入驻资料" |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| 是否已驳回 | coach.status = 2 | 顶部显示驳回原因条，按钮文案变更 |
| 是否重新入驻 | coach.status = 3 | 标题与提示文案变更，预填旧资料 |
| 是否首次入驻 | coach.status = -1 | 默认空表单，基础信息从微信带入 |

### 3.3 基础信息分组卡片

> **来自字段设计分组 1**：微信登录带入，仅姓名可编辑。

| 字段 | 组件/尺寸 | 规则 |
|------|----------|------|
| 分组标题 | 16px Medium `#262626`，"基础信息" | 固定 |
| 姓名/昵称 | 输入框，高 44px，全宽 | 必填，1-32 字符，为空时错误提示"请输入姓名" |
| 手机号 | 只读文本，14px Regular `#8C8C8C` | 微信解密手机号脱敏展示，不可改 |

### 3.4 实名与资质分组卡片

> **来自字段设计分组 2**：全部必填。

| 字段 | 组件/尺寸 | 规则 |
|------|----------|------|
| 分组标题 | 16px Medium `#262626`，"实名与资质" | 固定 |
| 身份证号 | 输入框，高 44px | 必填，18 位中国大陆身份证；非法时错误提示"请输入 18 位有效身份证号" |
| 身份证正面照 | 上传区 100×100 | 必填 1 张，JPG/PNG，≤5MB；未上传提示"请上传身份证正面照" |
| 身份证反面照 | 上传区 100×100 | 必填 1 张，JPG/PNG，≤5MB |
| 教练资格证 | 上传区 100×100，横向排列 | 必填 ≥1 张，最多 9 张，每张 ≤5MB |
| 健康证 | 上传区 100×100 | 必填 1 张，JPG/PNG，≤5MB |
| 个人形象照 | 上传区 100×100 | 必填 1 张，JPG/PNG，≤5MB；用于教练列表/详情展示 |

### 3.5 教学履历分组卡片

> **来自字段设计分组 3**。

| 字段 | 组件/尺寸 | 规则 |
|------|----------|------|
| 分组标题 | 16px Medium `#262626`，"教学履历" | 固定 |
| 任教年限 | 数字输入框，高 44px | 必填，整数 0-60，单位"年" |
| 总学员数 | 数字输入框，高 44px | 必填，整数 0-99999，单位"人" |
| 总课时数 | 数字输入框，高 44px | 必填，整数 0-99999，单位"节" |
| 擅长泳姿 | 多选标签组 | 可选，选项：蛙泳/自由泳/仰泳/蝶泳；未选时显示"请选择（可选）" |
| 个人简介 | 多行文本域，最小高 96px | 必填，10-500 字符，右下角实时字数统计 "0/500" |

### 3.6 服务设置分组卡片

> **来自字段设计分组 4**。

| 字段 | 组件/尺寸 | 规则 |
|------|----------|------|

| 参考单价 | 数字输入框，高 44px | 必填，DECIMAL(10,2)，50-2000 元/节，保留两位小数；下方提示"参考单价范围 50-2000 元/节" |

## 5. 跳转动线

| 起点 | 行为 | 条件/说明 |
|------|------|----------|
| 提交审核按钮 | → C-教练端入驻提交成功页 | 校验通过并提交成功 |
| 保存草稿按钮 | 停留在本页，Toast "草稿已保存" | 保存后 `status=0`、`submitted_at=NULL` |
| 图片上传区 | 调用微信 chooseImage / 上传接口 | 超出 5MB 或非 JPG/PNG 时提示错误 |
| 进入本页 | → C-教练端等待审核页 | status = 0 时自动重定向 |

## 6. 四态设计

| 状态 | 表现 |
|------|------|
| 空状态 | 各上传区显示默认占位图；表单字段为空；未操作时无错误提示 |
| 加载中 | 页面首次进入显示骨架屏；提交/保存时按钮显示 loading |
| 错误状态 | 字段下方显示红色错误提示；顶部可展示驳回原因条；网络异常时 Toast "网络异常，请检查网络后重试" |
| 成功状态 | 提交成功后跳转 C-教练端入驻提交成功页；草稿保存后 Toast 提示 |

## 7. 业务规则引用

| 规则 | 来源 | 在本页的体现 |
|------|------|-------------|
| 首次入驻需上传证书、任教年限、总学员数、总课时数、个人简介 | PRD §5.4.1 / US-010 §5 | §3.4 / §3.5 表单字段 |
| 入驻资质需管理员审核 | PRD §5.4.1 / US-010 §5 | 提交后进入待审核状态 |

| 身份证正反面/教练资格证/健康证/形象照必须上传，≤5MB，JPG/PNG | 字段设计 / US-010 §5 | §3.4 上传区规则 |
| 参考单价 50-2000 元/节 | 字段设计 / US-010 §5 | §3.6 参考单价输入框 |

| 已驳回可重新提交并清空 rejection_reason | US-010 §4.2 / §6.8 | §2.1 / §3.2 驳回原因条 |
