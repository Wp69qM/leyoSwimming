## 2. 用户身份与业务状态维度

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客（未登录教练） | ✅ | 当前页面目标用户；展示手机号输入、验证码输入、登录按钮 |
| 注册用户（无教练资质） | ✅ | 同游客处理，登录后按无 coach 记录跳转入驻资料页 |
| 已登录教练 | ❌ | 已登录教练不应进入此页；若通过旧链接/分享进入，自动跳转 `C-教练端首页` |
| 学员 | ❌ | 学员使用用户端小程序登录流程 |
| 管理员 | ❌ | 管理端使用 Web 后台登录流程 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| **未发起登录** | 教练刚进入页面，尚未输入手机号 | 展示手机号输入框、清空验证码输入框、获取验证码按钮可点击 |
| **手机号已输入** | 教练已输入合法手机号 | 「获取验证码」按钮高亮可用 |
| **验证码发送中** | 教练点击「获取验证码」，系统请求短信服务 | 按钮进入 loading，显示「发送中…」，防止重复点击 |
| **验证码已发送** | 短信服务返回成功，验证码 5 分钟内有效 | 按钮变为倒计时「60s 后重发」，验证码输入框自动聚焦 |
| **登录中** | 教练点击「登录」，后端校验手机号与验证码 | 登录按钮进入 loading，显示「登录中…」，防止重复提交 |
| **首次登录（无 coach 记录）** | 手机号未注册，验证码正确，系统自动创建教练账号 | 登录成功后跳转 `C-入驻资料页`（US-010） |
| **待审核（coach.status=0）** | 已提交入驻资料，等待管理员审核 | 登录成功后跳转 `C-等待审核页` |
| **已通过（coach.status=1）** | 入驻审核通过 | 登录成功后跳转 `C-教练端首页` |
| **已驳回（coach.status=2）** | 审核被拒绝，需重新提交 | 登录成功后跳转 `C-入驻资料页`（US-040，重新入驻状态），显示驳回原因 |
| **已离职（coach.status=3）** | 离职审批通过 | 登录成功后跳转 `C-入驻资料页`（US-040，重新入驻状态） |
| **申请离职中（coach.status=4）** | 已提交离职申请，待管理员审批 | 登录成功后跳转 `C-教练端首页`；「我的」页面提供「查看离职申请」入口，可主动进入 `C-离职处理中页` |
| **手机号格式错误** | 教练输入的手机号不符合中国大陆手机号格式 | 输入框标红，提示「请输入正确的手机号」，不发送验证码 |
| **验证码错误/过期** | 教练提交的验证码错误或已过期 | 验证码输入框标红，提示「验证码错误或已过期」 |
| **验证码发送限流** | 教练 60 秒内重复点击获取验证码 | 按钮保持倒计时，提示「请 60 秒后再试」 |
| **短信服务失败** | 短信服务不可用或接口异常 | 提示「验证码发送失败，请稍后重试」 |
| **未勾选协议** | 教练点击登录按钮但未勾选隐私协议 | 提示「请阅读并同意《用户须知》和《隐私协议》」，不执行登录 |

| 触发条件 | 目标页面 | 条件/说明 |

| 参数 | 类型 | 来源 | 用途 |
|------|------|------|------|

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 页面首次加载，未输入任何内容 | 表单为空，获取验证码按钮可点击（手机号为空时禁用），登录按钮禁用 |
| **加载中** | 获取验证码中 / 登录提交中 | 对应按钮 loading，其他表单元素不可交互 |
| **错误状态** | 手机号格式错误 / 验证码错误 / 短信服务失败 / 未勾选协议 | 对应输入框标红，错误提示区显示动态文案 |
| **成功状态** | 手机号验证码校验通过 | 登录按钮保持成功态 300ms 后，以淡出动效离开并跳转目标页 |
| **协议未勾选状态** | 教练点击登录按钮但未勾选隐私协议 | 底部登录区上方显示「请阅读并同意协议」提示，按钮不进入 loading |
