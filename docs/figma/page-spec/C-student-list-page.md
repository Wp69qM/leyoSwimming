## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
| ------ | :-------: | --------- |
| 已通过（1） | 是 | 完整功能 |
| 申请离职中（4） | 是 | 列表正常展示 |
| 其他状态 | 否 | 重定向 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
| ------ | ------ | ----------- |
| 有学员 / 无学员 | 是否存在 booking/package 关联 | 列表/空状态切换 |
| 活跃 / 历史 | 当前是否存在 `status='active'` 的 package 关联 | Tab 分类与套餐标签显隐 |
| 成人 / 未成年人 | `user.is_minor`（US-005） | 未成年人卡片显示标识 |

#### 活跃套餐标签规则

| 标签 | 显示条件 |
| ------ | --------- |
| 体验课 | 学员存在 `status='active'` 的体验课套餐 |
| 正价套餐 x N | 学员存在 `status='active'` 的正价套餐，N 为 active 正价套餐数量 |
| 并列显示 | 体验课与正价套餐同时存在时，两个标签同时展示 |

> 历史学员卡片不展示任何套餐标签。

## 6. 四态设计

| 状态 | 表现 |
| ------ | ------ |
| 空状态 | "暂无学员" 插画 |
| 加载中 | 卡片骨架屏 |
| 错误状态 | 网络错误 + 重试 |
| 成功状态 | 默认列表展示 |

> 空状态按当前 Tab 独立触发：活跃学员 Tab 无活跃关联时显示"暂无活跃学员"；历史学员 Tab 无历史关联时显示"暂无历史学员"。文案最终以 Calicat 设计稿为准。

## 7. 业务规则引用

| 规则 | 来源 | 本页应用 |
| ------ | ------ | --------- |
| 列表仅展示与教练存在 booking/package 关联的学员 | US-037 §4.1 / CROSS-BATCH §4.1 | §2.2 / §3.4 |
| 学员分为「活跃学员」与「历史学员」，默认展示活跃学员 | US-037 §4.1 / §5 规则 6 | §2.2 / §3.3 |
| 活跃学员卡片展示活跃套餐类型标签（体验课 / 正价套餐 x N） | US-037 §4.1 / §5 规则 7 | §3.4 |
| 历史学员卡片不展示套餐类型标签 | US-037 §6.4 | §3.4 |
| 未成年人信息由学员在 US-005 自主维护，教练端仅只读展示 | US-037 §5 规则 3 / §14.2 | §2.2 / §3.4 |
| 申请离职中仍可使用功能 | US-039 / CROSS-BATCH §1.2 | §2.1 / §4 |
