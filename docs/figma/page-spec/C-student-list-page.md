# 页面规格：C-我的学员列表页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-037 / US-031
> **对应 PRD**：§5.4.4 学员管理、§5.4.2 预约管理
> **版本**：v1.0 | **创建日期**：2026-08-02

## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 已通过（1） | 是 | 完整功能 |
| 申请离职中（4） | 是 | 列表正常展示，代约入口保留 |
| 其他状态 | 否 | 重定向 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| 有学员 / 无学员 | 是否存在 booking/package 关联 | 列表/空状态切换 |
| 成人 / 未成年人 | coach_student_profile.is_minor | 未成年人卡片显示监护人标识 |
| 有代约需求 | 学员有 active 套餐 | 卡片显示"代约"快捷按钮 |

## 6. 四态设计

| 状态 | 表现 |
|------|------|
| 空状态 | "暂无学员" 插画 + "去排班" 按钮 |
| 加载中 | 卡片骨架屏 |
| 错误状态 | 网络错误 + 重试 |
| 成功状态 | 默认列表展示 |
