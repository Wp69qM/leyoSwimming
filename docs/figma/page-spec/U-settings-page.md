# 页面规格：U-设置页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-009（隐私协议与用户须知授权）/ US-008（用户账号安全设置，设置入口）
> **对应 PRD**：§5.2.2 账号安全、§11.3.3《用户须知》
> **版本**：v1.0 | **创建日期**：2026-08-08

## 2. 用户身份与业务状态维度

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | ❌ | 必须登录后通过「我的 → 设置」进入；若直接进入，跳转登录页 |
| 注册用户 | ✅ | 可进入 |
| 学员 | ✅ | 与注册用户一致 |
| 教练 | ❌ | 教练端使用教练端小程序设置页 |
| 管理员 | ❌ | 管理端使用 Web 后台 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| **默认进入** | 从「我的 → 设置」进入 | 展示设置列表 |
| **加载中** | 请求设置项或跳转中 | 列表项显示骨架屏或 loading |
| **错误状态** | 网络/服务错误 | 展示全局错误提示 |
| **成功状态** | 数据正常 | 完整展示设置列表 |

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 页面首次加载 | 列表为空或展示默认占位 |
| **加载中** | 设置项请求中 | 列表项显示骨架屏 |
| **错误状态** | 网络/服务错误 | 页面中部展示错误插画 + 重试按钮 |
| **成功状态** | 数据正常 | 完整展示设置列表 |
