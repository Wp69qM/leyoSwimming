# 页面规格：U-设置页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-009（隐私协议与用户须知授权）/ US-008（用户账号安全设置，设置入口）
> **对应 PRD**：§5.2.2 账号安全、§11.3.3《用户须知》
> **版本**：v1.0 | **创建日期**：2026-08-08

## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | ❌ | 必须登录后通过「我的 → 设置」进入；若直接进入，跳转登录页 |
| 注册用户 | ✅ | 可进入 |
| 学员 | ✅ | 与注册用户一致 |
| 教练 | ❌ | 教练端使用教练端小程序设置页 |
| 管理员 | ❌ | 管理端使用 Web 后台 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| **默认进入** | 从「我的 → 设置」进入 | 展示设置列表 |
| **加载中** | 请求设置项或跳转中 | 列表项显示骨架屏或 loading |
| **错误状态** | 网络/服务错误 | 展示全局错误提示 |
| **成功状态** | 数据正常 | 完整展示设置列表 |

## 3. 元素清单（自上而下）

> **设计原则**：
> 1. **元素清单只描述「有什么元素」以及「元素之间的交互与状态」，不描述具体样式细节。** 颜色、宽度、高度、边距、背景、圆角、字体、字号、阴影等视觉参数**禁止**出现在 page-spec 中。
> 2. 视觉样式以 Calicat 设计稿为唯一最高优先级来源；page-spec 仅对交互逻辑、业务规则、状态流转负责。
> 3. 每个元素必须说明：名称、作用、显示条件、交互行为、关联业务规则。

### 3.1 状态栏 + NavBar

| 字段 | 值 |
|------|-----|
| 名称 | 状态栏 + NavBar |
| 作用 | 系统状态栏占位与页面导航，标题为「设置」 |
| 显示条件 | 登录用户进入本页时统一显示 |
| 点击行为 | 返回按钮 → 返回「我的」 |
| 关联业务规则 | 全局设计规范 §2.5.6 NavBar |

### 3.2 设置列表

| 字段 | 值 |
|------|-----|
| 名称 | 设置列表 |
| 作用 | 提供账号安全、用户须知、隐私协议等入口 |
| 显示条件 | 登录用户进入本页时始终显示 |
| 列表项 | 左侧图标 + 标题 + 右侧箭头 |
| 点击行为 | 按对应入口跳转 |
| 关联业务规则 | PRD §5.2.2；US-009 §4.3 |

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 页面首次加载 | 列表为空或展示默认占位 |
| **加载中** | 设置项请求中 | 列表项显示骨架屏 |
| **错误状态** | 网络/服务错误 | 页面中部展示错误插画 + 重试按钮 |
| **成功状态** | 数据正常 | 完整展示设置列表 |
