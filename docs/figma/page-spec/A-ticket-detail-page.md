## 2. 状态维度

| 维度 | 状态枚举 | 页面影响 |
|------|---------|---------|
| 工单状态 | 待处理 / 处理中 / 待反馈 / 已关闭 | 底部操作栏显隐 |
| 工单类型 | 投诉 / 建议 / 换教练申请 / 其他 | 详情卡标签 |
| 处理记录 | 无 / 有 | 处理记录区显隐 |
| 关闭原因 | 已解决 / 无效工单 / 重复提交 | 关闭弹窗选择 |

***

## 3. 元素清单（自上而下）

### 3.1 TopBar / 侧边栏 / 面包屑

同 A-客服工单管理页，面包屑当前页为 "工单详情"。

### 3.2 工单信息卡

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 24 px，margin-bottom 16 px |
| 工单号 | 20px Medium #262626 |
| 状态标签 | Tag：工单状态 |
| 类型标签 | Tag：工单类型 |
| 信息行 | 用户（可跳转）、提交时间、处理人、联系方式 |
| 工单标题 | 16px Medium #262626 |
| 工单内容 | 多行文本，最小高度 80 px |

### 3.3 关联订单/套餐卡

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 24 px，margin-bottom 16 px |
| 标题 | "关联信息"，16px Medium #262626 |
| 内容 | 关联订单号（可跳转 A-订单详情页）、关联套餐编号（可跳转 A-套餐详情页）、关联教练（可跳转 A-教练详情页） |

### 3.4 聊天记录/沟通记录卡

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 24 px，margin-bottom 16 px |
| 标题 | "沟通记录"，16px Medium #262626 |
| 内容 | 时间轴形式展示用户留言与客服回复 |
| 回复区 | 多行输入框 + 发送按钮 |

### 3.5 处理记录卡

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 24 px，margin-bottom 80 px |
| 标题 | "处理记录"，16px Medium #262626 |
| 表格 | 时间 / 处理人 / 操作 / 备注 |

### 3.6 底部固定操作栏

| 字段 | 值 |
|------|-----|
| 位置 | 固定页面底部 |
| 背景 | #FFFFFF，顶部阴影 `shadow-float` |
| 左侧 | 返回按钮（默认） |
| 右侧 | 分配给我（待处理）、回复（处理中）、关闭工单（主按钮，处理中/待反馈） |
| 关闭弹窗 | 选择关闭原因 + 处理结果说明 |

## 6. 四态设计

### 6.1 空状态

- 无沟通记录/处理记录时显示 "暂无记录"。

### 6.2 加载中

- 页面级 `el-loading` 遮罩。

### 6.3 错误状态

- 错误占位页：插画 + "工单不存在" + 「返回列表」按钮。

### 6.4 成功状态

- 回复/关闭成功后 Toast "操作成功" 并返回列表。

***

## 7. 业务规则引用

| 规则 | 来源 | 在本页的体现 |

| 工单流转：提交 → 处理 → 反馈 → 关闭 | PRD §5.5.7 | 状态标签与操作按钮 |

| 处理记录需记录处理人与备注 | PRD §5.5.7 | 处理记录卡 |
| 关闭工单需填写处理结果 | PRD §5.5.7 | 关闭弹窗 |
