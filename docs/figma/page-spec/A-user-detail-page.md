## 2. 状态维度

| 维度 | 状态枚举 | 页面影响 |
|------|---------|---------|
| 用户身份 | 游客 / 注册用户 / 学员 | 详情卡身份标签、Tab 显隐 |
| 账号状态 | 正常 / 封禁 | 底部操作栏按钮（封禁/解禁） |
| 当前 Tab | 基本信息 / 订单 / 套餐 / 上课记录 / 操作日志 | 内容区切换 |

## 3. 元素清单（自上而下）

### 3.1 TopBar / 侧边栏 / 面包屑

同 A-用户管理页，面包屑当前页为 "用户详情"。

### 3.2 用户信息卡

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 24 px，margin-bottom 16 px |
| 头像 | 80×80 px 圆形 |
| 昵称 | 20px Medium #262626 |
| 用户 ID | 12px Regular #8C8C8C |

## 6. 四态设计

### 6.1 空状态

- 各 Tab 无数据时显示 `el-empty` "暂无数据"。

### 6.2 加载中

- 页面级 `el-loading` 遮罩或各卡片骨架屏。

### 6.3 错误状态

- 错误占位页：插画 + "用户不存在或已删除" + 「返回列表」按钮。

### 6.4 成功状态

- 用户信息与各 Tab 正常展示。
