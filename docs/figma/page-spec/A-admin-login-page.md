| 触发元素 | 目标页面 | 条件/说明 |
|---------|---------|----------|

## 6. 四态设计

### 6.1 空状态

- 表单初始为空，placeholder 提示输入。
- 用户名、密码输入框均展示默认边框 `#D9D9D9`。
- 登录按钮默认启用（前端不做空值禁用，点击后由后端返回错误提示；也可在空值时前端禁用，两种方案均合理，以视觉稿为准）。

### 6.2 加载中

- 点击登录后按钮显示 `el-loading` / `Spin` Spinner，按钮文案变为 "登录中..."，按钮禁用。
- 用户名、密码输入框禁用，防止重复提交。

### 6.3 错误状态

- **用户名/密码错误**：密码输入框下方红色错误文案 "用户名或密码错误"（US-053 §6.2）。
- **账号被禁用**：密码输入框下方红色错误文案 "账号已被禁用，请联系超级管理员"（US-053 §6.3）。
- **token 过期**：页面顶部或登录卡片顶部显示红色提示 "登录信息已过期，请重新登录"（US-053 §4.2 分支 3）。
- **网络错误**：顶部 `el-message` / `notification` "网络异常，请稍后重试"。

### 6.4 成功状态

- 登录成功：Toast "登录成功"，500ms 后跳转 A-数据看板页（US-053 §4.1 第 11 步）。

## 7. 业务规则引用

| 规则 | 来源 | 在本页的体现 |
|------|------|-------------|
| 管理员通过账号密码登录后台 | PRD §5.6.1 | 登录表单字段为"用户名"+"密码" |
| 管理员为独立角色，不支持自助注册 | PRD §3.1 / US-053 §5 | 无注册入口、无忘记密码入口 |
| 错误登录提示避免泄露账号存在性 | US-053 §6.2 | 统一提示 "用户名或密码错误" |
| 账号禁用不可登录 | US-053 §6.3 | 提示 "账号已被禁用，请联系超级管理员" |
| token 过期自动跳转登录页 | US-053 §4.2 分支 3 | token 过期状态显示对应提示 |
| 单 token 24 小时有效期 | US-053 §14.2 | 技术实现约束，设计无需额外元素 |
