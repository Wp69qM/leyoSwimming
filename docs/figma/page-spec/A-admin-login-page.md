## 6. 四态设计

### 6.1 空状态

- 表单初始为空，placeholder 提示输入。

### 6.2 加载中

- 点击登录后按钮显示 `el-loading` Spinner，按钮文案变为 "登录中..."，输入框禁用。

### 6.3 错误状态

- 用户名/密码错误：输入框下方红色错误文案 "用户名或密码错误"；
- 验证码错误：验证码输入框下方红色提示 "验证码错误，请重新输入"，同步刷新验证码图片；
- 网络错误：顶部 `el-message` "网络异常，请稍后重试"。

### 6.4 成功状态

- 登录成功：Toast "登录成功"，500ms 后跳转 A-数据看板页。
