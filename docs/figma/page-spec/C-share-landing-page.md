# 页面规格：C-游客分享落地页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-038
> **对应 PRD**：§5.4.1 入驻与资料、§5.3.1 教练详情
> **版本**：v1.0 | **创建日期**：2026-08-02

## 2. 用户身份维度

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | 是 | 展示公开资料，CTA 先登录 |
| 注册用户 | 是 | 展示公开资料，CTA 可直接跳转购买 |
| 学员 | 是 | 同注册用户 |
| 教练（自己） | 是 | 显示"这是您自己的主页"提示 |
| 管理员 | 否 | 不通过此页访问 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| scene 合法 | 分享参数有效 | 正常展示 |
| scene 过期/非法 | 参数解析失败 | 显示链接失效空状态 |
| 教练状态非 1 | 教练未通过或已离职 | 显示"教练暂不可约"提示 |
| 有可约时段 | 未来 7 天存在 schedule_slot | 展示时段列表 |
| 无可约时段 | 未来 7 天无时段 | 展示兜底文案 |

## 5. 跳转动线

| 起点 | 游客 | 注册用户/学员 |
|------|------|--------------|
| 预约体验课 | → U-微信授权页 → U-套餐列表页（体验课） | → U-套餐列表页（体验课） |
| 购买套餐 | → U-微信授权页 → U-套餐列表页 | → U-套餐列表页 |
| 查看全部时段 | → 展开完整周视图 | 同左 |
| 返回 | → U-首页 | → U-首页 |
| scene 失效 | → 错误页（链接已失效 + 返回首页） | 同左 |

## 6. 四态设计

| 状态 | 表现 |
|------|------|
| 空状态 | 无可约时段显示兜底文案 |
| 加载中 | 头部与卡片显示骨架屏 |
| 错误状态 | scene 失效显示"链接已失效，返回首页" |
| 成功状态 | 完整教练资料 + 可约时段 + CTA |
