# 页面规格：U-注销账号页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-007（用户账号注销）
> **对应 PRD**：§3.7 数据保留、§5.2.1 注册登录、§9.2.1 用户状态、§11.2 隐私合规
> **版本**：v1.0 | **创建日期**：2026-08-05

## 2. 用户身份与业务状态维度

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | ❌ | 未登录用户不可进入；若直接进入，跳转登录页 |
| 注册用户 | ✅ | 当前页面目标用户 |
| 学员 | ✅ | 与注册用户一致 |
| 教练 | ❌ | 教练端使用教练端小程序 |
| 管理员 | ❌ | 管理端使用 Web 后台 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| **条件满足** | 无 active 套餐、无未完成订单、无进行中预约 | 「确认注销」按钮高亮可点击 |
| **条件不满足** | 存在任一未满足条件 | 对应 checklist 项显示未通过，按钮置灰 |
| **弹窗确认中** | 用户点击「确认注销」后 | 展示二次确认弹窗 |
| **注销中** | 用户点击弹窗「确认」后 | 按钮 loading，执行注销 |
| **注销成功** | 后端返回成功 | 清除登录态，跳转登录页 |
| **取消注销** | 用户点击弹窗「取消」 | 关闭弹窗，停留在本页 |

## 3. 元素清单（自上而下）

### 3.1 状态栏 + NavBar

| 字段 | 值 |
|------|-----|
| 状态栏 | 375×44，`#FFFFFF`，y=0 |
| NavBar 容器 | 375×44，`#FFFFFF`，底部 1px `color-divider` #F0F0F0，y=44 |
| 标题 | 「注销账号」，17px Medium `color-text-primary` #262626，居中 |
| 左侧返回 | 有，返回「我的」 |

### 3.2 风险提示区

| 字段 | 值 |
|------|-----|
| 尺寸 | 343 × 自适应，x=16 |
| 背景 | `#FFF2F0`（`color-error-bg`），`radius-lg` 12px |
| 边框 | 1px `color-error` #FF4D4F 或等效浅红边框 |
| 内边距 | 16px |
| 标题 | 「注销账号前，请确认以下重要信息」，14px Medium `color-error` |
| 风险项 | 每条 12px Regular `color-text-primary`，左侧带警告图标 |
| 风险项内容 | 1. 注销后账号不可找回；2. 原账号数据与新账号隔离；3. 重新登录视为新用户，不绑定原数据；4. 历史订单/交易记录保留 90 天后匿名化 |

### 3.3 条件 checklist 区

| 字段 | 值 |
|------|-----|
| 尺寸 | 343 × 自适应，x=16，位于风险提示区下方 16px |
| 背景 | `#FFFFFF`，`radius-lg` 12px，`shadow-card` |
| 标题 | 「需满足以下条件」，14px Medium `color-text-primary`，内边距 16px |
| checklist 项 | 每条左侧图标 + 文案 |
| 通过状态 | 绿色勾选图标 + 绿色文字 |
| 未通过状态 | 红色感叹号图标 + 红色文字 + 右侧说明 |
| checklist 项内容 | 1. 无活跃中的套餐；2. 无未完成订单；3. 无进行中或待上课的课程预约 |

### 3.4 底部固定提交区

| 字段 | 值 |
|------|-----|
| 尺寸 | 375 × 98 px（含底部安全区 34px），固定底部 |
| 背景 | `#FFFFFF`，顶部 1px `color-divider`，`shadow-float` |

#### 3.4.1 确认注销按钮

| 字段 | 值 |
|------|-----|
| 尺寸 | 343 × 44 px |
| 背景 | `gradient-primary`（#1890FF → #0050B3） |
| 圆角 | `radius-md` 8px |
| 文案 | 「确认注销」 |
| 禁用态 | 条件未满足或注销中时，透明度 0.5 且不可点击 |
| loading 态 | 文案「注销中…」 |

### 3.5 二次确认弹窗

| 字段 | 值 |
|------|-----|
| 类型 | 模态弹窗，居中 |
| 尺寸 | 280 × 自适应 |
| 背景 | `#FFFFFF`，`radius-lg` 12px |
| 标题 | 「确认注销」，16px Medium `color-text-primary`，居中 |
| 内容 | 「注销后账号不可找回，是否确认注销？」，14px Regular `color-text-secondary`，居中 |
| 按钮 | 左右双按钮：「取消」（默认样式）+「确认」（`color-error` 背景或红色文字） |
| 点击取消 | 关闭弹窗，停留在本页 |
| 点击确认 | 执行注销，按钮 loading，成功后跳转登录页 |

## 5. 跳转动线矩阵

| 触发条件 | 目标页面 |
|---------|---------|
| 进入本页 | 从「我的 → 注销账号」进入 |
| 点击返回 | 返回「我的」 |
| 点击「确认注销」 | 弹出二次确认弹窗 |
| 弹窗点击「确认」 | → 登录页（注销成功） |
| 弹窗点击「取消」 | 关闭弹窗，停留在本页 |

---

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 页面刚进入，条件校验中 | checklist 项显示加载/占位，按钮置灰 |
| **加载中** | 提交注销中 | 弹窗按钮 loading，页面不可交互 |
| **错误状态** | 条件不满足/注销过程中条件变化 | 对应 checklist 项显示未通过，按钮置灰；全局错误在按钮上方显示 |
| **成功状态** | 注销成功 | 清除登录态，跳转登录页 |

## 7. 业务规则引用

| 规则 | PRD / US 引用 | 在本页面应用 |
|------|--------------|-------------|
| 账号注销后进入软删除状态 | PRD §5.2.1；US-007 §4.1 | §3.4 提交区 |
| 历史数据保留 90 天后匿名化 | PRD §3.7；US-007 §4.1 | §3.2 风险提示区 |
| 注销前需校验无 active 套餐/未完成订单/进行中预约 | PRD §5.2.1；US-007 §4.1 | §3.3 条件 checklist |
| 注销后重新注册视为新用户 | PRD §5.2.1 第 4 条；US-007 §4.2 | §3.2 风险提示区 |
| 注销需二次确认防止误操作 | PRD §11.2；US-007 §4.1 | §3.5 二次确认弹窗 |
