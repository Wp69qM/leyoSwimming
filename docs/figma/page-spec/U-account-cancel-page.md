## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | ❌ | 未登录用户不可进入；若直接进入，跳转登录页 |
| 注册用户 | ✅ | 当前页面目标用户 |
| 学员 | ✅ | 与注册用户一致 |
| 教练 | ❌ | 教练端使用教练端小程序 |
| 管理员 | ❌ | 管理端使用 Web 后台 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| **条件满足** | 无 active 套餐、无未完成订单、无进行中预约 | 「确认注销」按钮高亮可点击 |
| **条件不满足** | 存在任一未满足条件 | 对应 checklist 项显示未通过，按钮置灰 |
| **弹窗确认中** | 用户点击「确认注销」后 | 展示二次确认弹窗 |
| **注销中** | 用户点击弹窗「确认」后 | 按钮 loading，执行注销 |
| **注销成功** | 后端返回成功 | 清除登录态，跳转登录页 |
| **取消注销** | 用户点击弹窗「取消」 | 关闭弹窗，停留在本页 |

## 3. 元素清单（自上而下）

> **设计原则**：
> 1. **元素清单只描述「有什么元素」以及「元素之间的交互与状态」，不描述具体样式细节。** 颜色、宽度、高度、边距、背景、圆角、字体、字号、阴影等视觉参数**禁止**出现在 page-spec 中。
> 2. 视觉样式以 Calicat 设计稿为唯一最高优先级来源；page-spec 仅对交互逻辑、业务规则、状态流转负责。
> 3. 每个元素必须说明：名称、作用、显示条件、交互行为、关联业务规则。

### 3.1 状态栏 + NavBar

| 字段 | 值 |
|------|-----|
| 名称 | 状态栏 + NavBar |
| 作用 | 系统状态栏占位与页面导航，标题为「注销账号」 |
| 显示条件 | 登录用户进入本页时统一显示 |
| 点击行为 | 返回按钮 → 返回「我的」 |
| 关联业务规则 | 全局设计规范 §2.5.6 NavBar |

### 3.2 风险提示区

| 字段 | 值 |
|------|-----|
| 名称 | 风险提示区 |
| 作用 | 提示注销账号的风险与数据影响 |
| 显示条件 | 登录用户进入本页时始终显示 |
| 内容 | 1. 注销后账号不可找回；2. 原账号数据与新账号隔离；3. 重新登录视为新用户，不绑定原数据；4. 历史订单/交易记录保留 90 天后匿名化 |
| 关联业务规则 | PRD §3.7；US-007 §4.1 |

### 3.3 条件 checklist 区

| 字段 | 值 |
|------|-----|
| 名称 | 条件 checklist 区 |
| 作用 | 逐项展示注销前置条件是否满足 |
| 显示条件 | 登录用户进入本页时始终显示 |
| 内容 | 1. 无活跃中的套餐；2. 无未完成订单；3. 无进行中或待上课的课程预约 |
| 状态展示 | 通过项显示勾选与通过文案；未通过项显示警告图标、未通过文案与右侧说明 |
| 关联业务规则 | PRD §5.2.1；US-007 §4.1 |

### 3.4 底部固定提交区

| 字段 | 值 |
|------|-----|
| 名称 | 底部固定提交区 |
| 作用 | 固定展示「确认注销」按钮 |
| 显示条件 | 登录用户进入本页时始终显示 |
| 点击行为 | 条件满足时点击弹出二次确认弹窗；条件未满足或注销中时按钮禁用 |
| 关联业务规则 | PRD §5.2.1；US-007 §4.1 |

#### 3.4.1 确认注销按钮

| 字段 | 值 |
|------|-----|
| 名称 | 确认注销按钮 |
| 作用 | 触发二次确认弹窗 |
| 显示条件 | 条件满足且未注销中时可用；条件未满足或注销中时禁用 |
| 文案 | 默认「确认注销」；注销中显示「注销中…」 |
| 关联业务规则 | PRD §5.2.1；US-007 §4.1 |

### 3.5 二次确认弹窗

| 字段 | 值 |
|------|-----|
| 名称 | 二次确认弹窗 |
| 作用 | 防止误操作，要求用户再次确认注销 |
| 显示条件 | 点击「确认注销」按钮后显示 |
| 内容 | 标题「确认注销」；正文「注销后账号不可找回，是否确认注销？」 |
| 按钮 | 「取消」+「确认」 |
| 点击取消 | 关闭弹窗，停留在本页 |
| 点击确认 | 执行注销，成功后清除登录态并跳转登录页 |
| 关联业务规则 | PRD §11.2；US-007 §4.1 |

## 5. 跳转动线矩阵

| 触发条件 | 目标页面 |
|---------|---------|
| 进入本页 | 从「我的 → 注销账号」进入 |
| 点击返回 | 返回「我的」 |
| 点击「确认注销」 | 弹出二次确认弹窗 |
| 弹窗点击「确认」 | → 登录页（注销成功） |
| 弹窗点击「取消」 | 关闭弹窗，停留在本页 |

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 页面刚进入，条件校验中 | checklist 项显示加载/占位，按钮置灰 |
| **加载中** | 提交注销中 | 弹窗按钮 loading，页面不可交互 |
| **错误状态** | 条件不满足/注销过程中条件变化 | 对应 checklist 项显示未通过，按钮置灰；全局错误在按钮上方显示 |
| **成功状态** | 注销成功 | 清除登录态，跳转登录页 |

## 7. 业务规则引用

| 规则 | PRD / US 引用 | 在本页面应用 |
|------|--------------|-------------|
| 账号注销后进入软删除状态 | PRD §5.2.1；US-007 §4.1 | §3.4 提交区 |
| 历史数据保留 90 天后匿名化 | PRD §3.7；US-007 §4.1 | §3.2 风险提示区 |
| 注销前需校验无 active 套餐/未完成订单/进行中预约 | PRD §5.2.1；US-007 §4.1 | §3.3 条件 checklist |
| 注销后重新注册视为新用户 | PRD §5.2.1 第 4 条；US-007 §4.2 | §3.2 风险提示区 |
| 注销需二次确认防止误操作 | PRD §11.2；US-007 §4.1 | §3.5 二次确认弹窗 |
