## 3. 元素清单（自上而下）

### 3.1 TopBar / 侧边栏 / 面包屑

同 A-排班管理页，当前菜单为 "预约释放配置"，面包屑为 "首页 / 课程预约 / 预约释放配置"。

### 3.2 基础释放配置卡

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 24 px，margin-bottom 16 px |
| 标题 | "基础释放配置"，16px Medium #262626 |
| 释放时间 | 时间选择器，默认 "每周三 10:00" |
| 释放范围 | 单选：下周整周 / 未来 7 天 / 未来 14 天 |
| 释放开关 | 是否启用自动释放 |

### 3.3 候补配置卡

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 24 px，margin-bottom 16 px |
| 标题 | "候补队列配置"，16px Medium #262626 |
| 候补开关 | 是否启用候补队列 |
| 候补有效期 | 数字输入 + 单位选择（小时/天），默认 24 小时 |
| 关注提醒提前时间 | 数字输入 + 单位选择（分钟/小时），默认 30 分钟 |
| 说明文案 | "候补有效期过期后自动移除候补学员"，12px Regular #8C8C8C |

### 3.4 节假日特殊释放设置卡

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 24 px，margin-bottom 80 px |
| 标题 | "节假日特殊释放设置"，16px Medium #262626 |
| 列表 | 日期 / 是否营业 / 替代释放时间 / 操作 |
| 操作 | 新增 / 编辑 / 删除 |
| 新增弹窗 | 日期选择器 + 是否营业开关 + 释放时间 |

### 3.5 底部固定操作栏

| 字段 | 值 |
|------|-----|
| 位置 | 固定页面底部 |
| 背景 | #FFFFFF，顶部阴影 `shadow-float` |
| 按钮 | 取消（默认）、保存（主按钮） |
| 保存成功后 | Toast "保存成功" |

## 6. 四态设计

### 6.1 空状态

- 节假日列表为空时显示 "暂无特殊设置"。

### 6.2 加载中

- 表单区显示骨架屏，保存按钮显示 Loading。

### 6.3 错误状态

- 保存失败：顶部 `el-message` "保存失败，请稍后重试"。

### 6.4 成功状态

- 保存成功：Toast "保存成功"，表单显示最新配置。
