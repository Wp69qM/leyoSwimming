## 6. 四态设计

### 6.1 空状态

- 表格空：空插画 + "暂无教练数据" + 「重置筛选」按钮。

### 6.2 加载中

- 表格骨架屏 3 行。

### 6.3 错误状态

- 表格区域 `el-empty` "加载失败" + 「重试」按钮。

### 6.4 成功状态

- 列表正常展示，操作后刷新。

## 7. 业务规则引用

| 规则 | 来源 | 在本页的体现 |
|------|------|-------------|
| 管理员查看所有教练 | PRD §5.5.1 | 列表展示 |
| 教练状态机 5 种状态 | 全局原则 §3.2 | 状态筛选与标签 |
| 已通过教练可取消入驻 | PRD §5.5.1 / §5.5.1.1 | 取消入驻按钮 |
| 实时状态徽标 | 全局原则 §3.1 | 实时状态列 |
| 教练在职时长基于 approved_at 计算 | US-055 §6.1 | 在职时长列 |
| 当前学员数为该教练名下 active 套餐去重学员数 | US-055 §6.1 | 当前学员数列 |
