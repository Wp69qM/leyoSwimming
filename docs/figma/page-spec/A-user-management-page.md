## 6. 四态设计

### 6.1 空状态

- 表格空：空插画 + "暂无用户数据" + 「重置筛选」按钮。

### 6.2 加载中

- 表格骨架屏 3 行，表头保留。

### 6.3 错误状态

- 表格区域 `el-empty` "加载失败" + 「重试」按钮。

### 6.4 成功状态

- 列表正常展示，分页可用，操作按钮响应正常。

***

## 7. 业务规则引用

| 规则 | 来源 | 在本页的体现 |
|------|------|-------------|
| 管理员查看所有游客、注册用户 | PRD §5.5.1 | 列表展示与身份筛选 |
| 按身份、注册时间筛选与统计 | PRD §5.5.1 | 筛选区字段 |
| 管理员可封禁账号 | PRD §3.3 | 封禁/解禁按钮 |
| 用户资料完善字段来自 US-005 | US-005 §7.1 / §4.1 | 列表展示头像/姓名/手机号/性别/年龄/资料完善状态 |
| 未成年人需填写监护人信息 | US-005 §4.1 / §6.2 | 在 A-用户详情页展示，列表不展示 |
| 敏感字段脱敏 | 全局原则 §8.2 | 手机号脱敏显示 |
