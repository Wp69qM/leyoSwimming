## 6. 四态设计

### 6.1 空状态

- 表格空：空插画 120×120 + "暂无用户数据" + 「重置筛选」按钮。

### 6.2 加载中

- 表格骨架屏 3 行，表头保留。

### 6.3 错误状态

- 表格区域 `el-empty` "加载失败" + 「重试」按钮。

### 6.4 成功状态

- 列表正常展示，分页可用，操作按钮响应正常。
