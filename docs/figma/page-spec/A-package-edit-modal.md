## 2. 状态维度

| 维度 | 状态枚举 | 弹窗影响 |
|------|---------|---------|
| 弹窗模式 | 新增 / 编辑 | 新增模式所有字段为空且默认 inactive；编辑模式回显当前套餐数据 |
| 套餐状态 | active / inactive | active 状态下弹窗进入只读提示，禁止编辑 |
| 退款开关 | 可退 / 不可退 | 可退时显示退款比例与退款有效天数；不可退时隐藏 |
| 保存状态 | 可保存 / 校验中 / 保存中 | 保存按钮 loading / disabled 状态 |

## 3. 元素清单（自上而下）

### 3.1 标题栏

| 字段 | 值 |
|------|-----|
| 新增模式标题 | "新增标准套餐" |
| 编辑模式标题 | "编辑标准套餐" |
| 关闭按钮 | 右上角 X，点击关闭弹窗 |

### 3.2 基础信息分组

| 字段 | 组件 | 规则 |
|------|------|------|
| 套餐名称 | 文本输入框 | 必填，非空，唯一性校验；重复时提示 DUPLICATE_PACKAGE_NAME |
| 套餐模式 | 单选 / 选择器 | 选项：正价套餐 / 体验课；必填 |
| 适用教练 | 单选选择器 | 必填，选项来自教练列表，显示教练参考单价 |
| 教学类型 | 单选 | 选项：1对1 / 1对2 / 1对3；必填 |
| 泳姿 | 多选框 | 必填，至少选 1 项；选项来自系统泳姿字典 |

### 3.3 课时与有效期分组

| 字段 | 组件 | 规则 |
|------|------|------|
| 课时数 | 数字输入框 | 必填，正整数，> 0 |
| 每节课时长 | 数字输入框 | 必填，分钟，正整数，> 0 |
| 有效期 | 数字输入框 | 必填，天，正整数，> 0 |

### 3.4 价格分组

| 字段 | 组件 | 规则 |
|------|------|------|
| 原价 | 金额输入框 | 必填，单位分，正数 |
| 售价 | 金额输入框 | 必填，单位分，正数，且售价 ≤ 原价 |

### 3.5 退款配置分组

| 字段 | 组件 | 规则 |
|------|------|------|
| 是否可退 | 开关 / 单选 | 必填；关闭时隐藏下方两项 |
| 退款比例 | 数字输入框 | 可退时必填，0-100 整数；比例为 0 时前端提示"学员实际不可退款" |
| 退款有效天数 | 数字输入框 | 可退时必填，正整数，> 0 |

### 3.6 展示与描述分组

| 字段 | 组件 | 规则 |
|------|------|------|
| 标签 | 标签输入器 | 可选，支持多标签；非法格式时提示 INVALID_TAG_FORMAT |
| 套餐描述 | 多行文本框 | 可选，富文本或纯文本 |
| 套餐展示图片 | 图片上传区 | 可选，支持 1-5 张；格式/大小非法时提示 INVALID_IMAGE_FILE |

### 3.7 上下架状态

| 字段 | 组件 | 规则 |
|------|------|------|
| 上下架状态 | 开关 / 单选 | 新增默认 inactive；编辑保持当前状态；保存时可切换 |

### 3.8 底部操作栏

| 字段 | 值 |
|------|-----|
| 取消按钮 | 点击关闭弹窗，返回 A-套餐配置页 |
| 保存按钮 | 表单校验通过且未在保存中时可点击 |

## 6. 四态设计

### 6.1 加载中

- 编辑模式打开时：表单字段显示 skeleton 加载，图片上传区显示 loading 占位。
- 保存中：保存按钮进入 loading 状态，表单字段禁用。

### 6.2 空状态

- 新增模式：所有表单字段为空，图片上传区显示占位文案，上下架状态默认 inactive。

### 6.3 错误状态

- 字段校验失败：对应字段下方显示错误文案（如"套餐名称不能为空"、"售价不能高于原价"等）。
- 名称重复：名称字段下方显示"套餐名称已存在"。
- 已上架编辑限制：弹窗顶部或底部显示"已上架套餐需先下架才能编辑"。
- 接口失败：弹窗顶部显示全局错误提示。

### 6.4 成功状态

- 保存成功后关闭弹窗，A-套餐配置页列表刷新，toast 提示"套餐已创建"/"套餐已更新"。

## 7. 业务规则引用

| 规则 | 来源 | 在本弹窗的体现 |
|------|------|---------------|
| 标准套餐由管理员后台预设固定套餐 | US-045 §5.5.3 | 弹窗用于新增/编辑标准套餐模板 |
| 新增套餐默认未上架 | US-045 §4.1 | 上下架状态新增时默认 inactive |
| 已上架套餐不可编辑 | US-045 §8.5 | active 状态字段禁用并提示先下架 |
| 字段合法性校验 | US-045 §4.1 / §6.5 | 课时数/价格/有效期正数，售价 ≤ 原价 |
| 退款配置规则 | US-045 §4.1 / §8.4 | 退款比例 0-100，退款有效天数 > 0 |
| 名称唯一性 | US-045 §6.4 | 保存时校验并提示 DUPLICATE_PACKAGE_NAME |
