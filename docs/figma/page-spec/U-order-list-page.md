## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。
> 本页为**学员核心页面**，游客访问时统一拦截到登录流程。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | ❌ 不可见 | 整页拦截，跳转 `U-微信授权页`；登录成功后返回本页刷新 |
| 注册用户 | ✅ 可见 | 可查看自己名下的体验课/正价课订单列表；操作权限受订单状态约束 |
| 学员 | ✅ 可见 | 可查看并操作全部历史订单，是主使用身份 |
| 教练 | ❌ 不可见 | 教练端无此页面 |
| 管理员 | ❌ 不可见 | 管理端使用 Web 后台订单管理页 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| `order.status = 1` 待支付 | 订单创建后未支付 | 卡片显示「去支付」按钮，展示支付倒计时 |
| `order.status = 2` 已支付 | 支付成功，套餐生效中 | 卡片显示「查看详情」按钮；**本页不发起退款申请** |
| `order.status = 3` 已取消 | 超时未支付或用户主动取消 | 卡片显示「已取消」灰标，显示「删除记录」 |
| `order.status = 4` 退款审批中 | 用户提交退款，等待管理员审批 | 卡片显示「退款审批中」蓝标；**退款申请从套餐详情页发起** |
| `order.status = 5` 争议退款处理中 | 特殊原因申诉进入争议流程 | 卡片显示「争议处理中」红标，提示 3 工作日反馈 |
| `order.status = 6` 已退款 | 退款流程完成 | 卡片显示「已退款」深灰标，展示退款金额 |
| `order.status = 7` 退款被拒 | 申诉/退款被驳回，套餐恢复 active | 卡片显示「退款被拒」红标，可进入详情查看 |
| `order.status = 8` 退款处理中 | 管理员批准，等待渠道回调 | 卡片显示处理中标识，提示预计 3-7 工作日到账 |
| 支付倒计时 ≤ 0 | 待支付订单超过 24h 未支付 | 订单状态自动变为已取消，卡片刷新 |

## 3. 元素清单（自上而下）

> **设计原则**：
> 1. 每个元素必须说明：名称、作用/功能、显示条件、交互行为、关联业务规则。
> 2. 视觉样式（尺寸、颜色、圆角、字体、间距等）以 Calicat 设计稿与全局设计规范为准，本规格不再赘述具体样式细节。

### 3.1 状态栏 + NavBar

| 元素名称 | 作用 | 显示条件 | 交互行为 | 关联业务规则 |
|----------|------|----------|----------|--------------|
| 状态栏占位 | 为系统状态栏预留区域 | 始终显示 | 无 | 全局设计规范 |
| 导航栏 | 展示页面标题"我的订单"与返回入口 | 登录用户统一显示（游客被拦截，不进入本页） | 点击返回按钮 → 返回上一页（个人中心页 / 首页） | 全局设计规范 §2.5.6；PRD §13.3 |

> **来源**：全局设计规范 §2.5.6 NavBar；PRD §13.3 页面 16「订单列表页」。

### 3.2 顶部状态 Tab 栏

> **来源**：US-026 §14.2 / PRD §6.2 订单状态机。
> **设计决策**：按 US-026 用户可见状态聚合为 5 个 Tab；退款申请入口已迁移至套餐详情页。

| 元素名称 | 作用 | 显示条件 | 交互行为 | 关联业务规则 |
|----------|------|----------|----------|--------------|
| 顶部状态 Tab 栏 | 按订单状态聚合切换，过滤订单列表 | 登录用户始终显示 | 切换 Tab，列表按对应状态过滤重新加载 | US-026 §14.2 / PRD §6.2 |
| Tab 项：全部 | 展示用户全部订单，按创建时间倒序 | 始终显示 | 点击切换 | US-026 §14.2 |
| Tab 项：待支付 | 过滤 `order.status = 1`，含支付倒计时 | 始终显示 | 点击切换 | PRD §6.2.1 |
| Tab 项：已完成 | 过滤 `order.status ∈ {2, 6}` | 始终显示 | 点击切换 | US-026 §14.2 |
| Tab 项：退款中 | 过滤 `order.status ∈ {4, 5, 8}` | 始终显示 | 点击切换 | US-026 §14.2 |
| Tab 项：已取消 | 过滤 `order.status = 3` | 始终显示 | 点击切换 | PRD §6.2.1 |
| 默认选中 | 进入本页时默认展示全部订单 | — | — | US-026 §14.2 |

> **排他说明**：一张订单只归属一个 Tab；已过期套餐的退款申请在 `U-我的套餐页` 处理，不进入本页 Tab。

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 当前 Tab 下无任何订单 | 隐藏列表，居中展示 Empty 组件：插画 + 主文案 + 副文案 + "去购买套餐" 按钮 |
| **加载中** | 首次进入 / 切换 Tab / 下拉刷新 / 分页加载 | 列表区域显示骨架屏卡片；NavBar 与 Tab 栏保持可见 |
| **错误状态** | 网络断开 / 接口 5xx / 业务 4xx | 隐藏骨架屏，中央展示错误插画 + "加载失败，点击重试" + Primary「重新加载」按钮 |
| **成功状态** | 数据正常返回 | 按 §4 显示规则矩阵完整展示 Tab 栏、订单卡片、操作按钮；支付倒计时实时递减 |
