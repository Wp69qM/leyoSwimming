## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。
> 本页为**学员核心页面**，游客访问时统一拦截到登录流程。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | ❌ 不可见 | 整页拦截，跳转 `U-微信授权页`；登录成功后返回本页刷新 |
| 注册用户 | ✅ 可见 | 可查看自己名下的体验课/正价课订单列表；操作权限受订单状态约束 |
| 学员 | ✅ 可见 | 可查看并操作全部历史订单，是主使用身份 |
| 教练 | ❌ 不可见 | 教练端无此页面 |
| 管理员 | ❌ 不可见 | 管理端使用 Web 后台订单管理页 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| `order.status = 1` 待支付 | 订单创建后未支付 | 卡片显示「去支付」按钮，展示支付倒计时 |
| `order.status = 2` 已支付 | 支付成功，套餐生效中 | 卡片显示「申请退款」按钮，可进入详情 |
| `order.status = 3` 已取消 | 超时未支付或用户主动取消 | 卡片显示「已取消」灰标，仅可查看详情 |
| `order.status = 4` 退款审批中 | 用户提交退款，等待教练/管理员审批 | 卡片显示「退款审批中」蓝标，禁用重复退款 |
| `order.status = 5` 争议退款处理中 | 特殊原因申诉进入争议流程 | 卡片显示「争议处理中」红标，提示 3 工作日反馈 |
| `order.status = 6` 已退款 | 退款流程完成 | 卡片显示「已退款」深灰标，展示退款金额 |
| `order.status = 7` 退款被拒 | 申诉/退款被驳回，套餐恢复 active | 卡片显示「退款被拒」红标，可再次申请或联系客服 |
| `order.status = 8` 退款处理中 | 管理员批准，等待渠道回调 | 卡片显示脉冲蓝标，提示预计 3-7 工作日到账 |
| `package.status = expired` | 套餐已过期（订单仍为已支付） | 归入「已过期」Tab，可申请退款 |
| 支付倒计时 ≤ 0 | 待支付订单超过 24h 未支付 | 订单状态自动变为已取消，卡片刷新 |

### 3.2 顶部状态 Tab 栏

> **来源**：US-026 §14.2 / PRD §6.2 订单状态机。
> **设计决策**：按用户可见状态聚合为 5 个 Tab，减少认知负担。

| 字段 | 值 |
|------|-----|
| 容器 | 375×48，y = 88，背景 `#FFFFFF`，底部 1px `#F0F0F0` |
| Tab 项 | 横向等分 5 项："待支付" / "进行中" / "已退款" / "已过期" / "已取消" |
| Tab 项尺寸 | 每项宽 75px，高度 48px，文字居中 |
| 未选中项 | 14px / Regular `color-text-secondary` |
| 选中项 | 14px / Medium `color-primary` #1890FF，底部 2px `#1890FF` 指示条，宽 24px，居中 |
| 默认选中 | 「进行中」，进入本页时默认展示进行中的订单 |
| 显示条件 | 登录用户始终显示 |
| 点击行为 | 切换 Tab，列表按对应状态过滤重新加载 |

#### Tab 与后端状态映射表

| Tab 名称 | 包含订单状态 | 补充说明 |
|---------|-------------|---------|
| 待支付 | `order.status = 1` | 含支付倒计时 |
| 进行中 | `order.status ∈ {2, 4, 5, 7, 8}` | 已支付、退款审批/争议/处理中、退款被拒 |
| 已退款 | `order.status = 6` | 退款终态 |
| 已过期 | `order.status = 2` 且 `package.status = expired` | 套餐过期但订单未退款 |
| 已取消 | `order.status = 3` | 超时未支付或用户主动取消 |

> **排他说明**：一张订单只归属一个 Tab；已进入退款流程的订单不重复显示在「已过期」Tab。

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 当前 Tab 下无任何订单 | 隐藏列表，居中展示 Empty 组件：插画 + 主文案 + 副文案 + "去购买套餐" 按钮 |
| **加载中** | 首次进入 / 切换 Tab / 下拉刷新 / 分页加载 | 列表区域显示骨架屏卡片；NavBar 与 Tab 栏保持可见 |
| **错误状态** | 网络断开 / 接口 5xx / 业务 4xx | 隐藏骨架屏，中央展示错误插画 + "加载失败，点击重试" + Primary「重新加载」按钮 |
| **成功状态** | 数据正常返回 | 按 §4 显示规则矩阵完整展示 Tab 栏、订单卡片、操作按钮；支付倒计时实时递减 |
