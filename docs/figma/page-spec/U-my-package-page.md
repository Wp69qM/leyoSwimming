# 页面规格：U-我的套餐页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-021（学员查看我的套餐）/ US-045（已购套餐保存模板快照）
> **对应 PRD**：§3.4 套餐状态机、§4.2 套餐生命周期、§5.3.3 学员课时汇总、§6.4 退款规则
> **版本**：v1.0 | **创建日期**：2026-08-13

## 2. 用户身份与业务状态维度

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | ❌ | 个人中心点击「我的套餐」后引导登录，不进入本页 |
| 注册用户 | ✅ | 可查看自己名下的所有套餐列表与状态分组 |
| 学员 | ✅ | 与注册用户一致，为本页主使用身份 |
| 教练 | ❌ | 教练端使用教练端小程序 |
| 管理员 | ❌ | 管理端使用 Web 后台 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| **active** | 套餐生效中，仍可约课/退款 | 默认展开，计入顶部课时汇总 |
| **exhausted** | 课时已用完 | 归入「已耗尽」分组，不计入顶部汇总，不展示退款入口 |
| **expired** | 已过有效期 | 归入「已过期」分组，满足退款条件时展示退款入口 |
| **refunded** | 已退款完成 | 归入「已退款」分组，仅展示历史信息 |
| **frozen** | 套餐被冻结 | 归入「已冻结」分组；`frozen_reason='coach_resigned'` 时展示教练离职提示与退款入口 |

## 3. 元素清单（自上而下）

> **设计原则**：
> 1. **元素清单只描述「有什么元素」以及「元素之间的交互与状态」，不描述具体样式细节。** 颜色、宽度、高度、边距、背景、圆角、字体、字号、阴影等视觉参数**禁止**出现在 page-spec 中。
> 2. 视觉样式以 Calicat 设计稿为唯一最高优先级来源；page-spec 仅对交互逻辑、业务规则、状态流转负责。
> 3. 每个元素必须说明：名称、作用、显示条件、交互行为、关联业务规则。

### 3.1 状态栏 + NavBar

| 字段 | 值 |
|------|-----|
| 名称 | 状态栏 + 导航栏 |
| 作用 | 提供系统状态栏占位与页面导航标题 |
| 显示条件 | 登录用户进入本页时统一显示 |
| 点击行为 | 返回按钮点击返回上一页（个人中心页） |
| 关联业务规则 | PRD §13.3 二级页面导航规范 |

### 3.2 顶部课时汇总区

| 字段 | 值 |
|------|-----|
| 名称 | active 套餐课时汇总 |
| 作用 | 展示用户当前可用套餐的课时总览 |
| 显示条件 | 存在 `active` 套餐时显示；无 active 套餐时隐藏 |
| 字段内容 | 总课时 / 已上课时 / 剩余课时，三个数值仅统计 `status='active'` 的套餐 |
| 点击行为 | 无 |
| 关联业务规则 | US-021 §4.1 第 5 步；PRD §5.3.3 |

### 3.3 状态分组折叠面板

| 字段 | 值 |
|------|-----|
| 名称 | 套餐状态分组列表 |
| 作用 | 按业务状态将套餐卡片分组展示，降低多状态混杂的认知负担 |
| 显示条件 | 登录用户且名下存在套餐时显示 |
| 分组顺序 | 可用（active）→ 已耗尽（exhausted）→ 已过期（expired）→ 已退款（refunded）→ 已冻结（frozen） |
| 默认展开 | 仅 `active` 分组默认展开，其余分组默认折叠 |
| 点击行为 | 点击分组标题可展开/折叠该分组；展开后显示该状态全部套餐卡片 |
| 关联业务规则 | US-021 §4.1 第 3 步 / §14.1 |

#### 3.3.1 分组标题

| 字段 | 值 |
|------|-----|
| 名称 | 状态分组标题 |
| 作用 | 标识当前分组的状态名称与该状态下的套餐数量 |
| 显示条件 | 每个非空分组均显示标题 |
| 字段内容 | 状态中文名 + 该状态套餐数量 |
| 点击行为 | 展开/折叠分组内容 |
| 关联业务规则 | US-021 §4.1 第 3 步 |

#### 3.3.2 教练离职冻结提示条

| 字段 | 值 |
|------|-----|
| 名称 | 教练离职冻结提示条 |
| 作用 | 在 `frozen` 分组顶部提示用户冻结原因及可执行动作 |
| 显示条件 | 仅 `frozen` 分组内存在 `frozen_reason='coach_resigned'` 的套餐时显示 |
| 字段内容 | 文案如「教练已离职，请更换教练或申请退款」 |
| 点击行为 | 无（纯提示） |
| 关联业务规则 | US-021 §4.3 分支 2；PRD §3.7 |

### 3.4 套餐卡片

| 字段 | 值 |
|------|-----|
| 名称 | 我的套餐卡片 |
| 作用 | 展示单个已购套餐的核心快照信息 |
| 显示条件 | 各分组展开后显示该状态对应的套餐卡片 |
| 字段内容 | 教练名、套餐模式标签（正价/体验课）、教学类型、每节课时长、有效期、课时数（共/已用/剩余）、购买时价格、状态标签 |
| 点击行为 | 点击整张卡片 → `U-我的套餐详情页`（携带 `package_id`） |
| 关联业务规则 | US-021 §4.1 第 4 步；US-045 快照规则 |

#### 3.4.1 状态标签

| 字段 | 值 |
|------|-----|
| 名称 | 套餐状态标签 |
| 作用 | 明示当前套餐的业务状态 |
| 显示条件 | 每张套餐卡片均显示 |
| 字段内容 | active / exhausted / expired / refunded / frozen 对应中文标签 |
| 点击行为 | 无 |
| 关联业务规则 | PRD §3.4 / §4.2 套餐状态机 |

#### 3.4.2 退款入口（卡片级）

| 字段 | 值 |
|------|-----|
| 名称 | 申请退款入口 |
| 作用 | 允许用户在列表页快速发起退款 |
| 显示条件 | 满足退款条件时显示：`package.status ∈ {active, expired}`，或 `status='frozen' 且 frozen_reason='coach_resigned'`；且 `refund_enabled=true`；且未超过 `refund_valid_days`；`exhausted` 套餐不显示 |
| 点击行为 | 点击 → `U-退款申请页`（携带 `package_id`，退款金额由 US-027 计算） |
| 关联业务规则 | US-021 §4.1 第 7 步 / §5 规则 4；PRD §6.4.1 / §6.4.2 |

### 3.5 空状态占位

| 字段 | 值 |
|------|-----|
| 名称 | 无套餐空状态 |
| 作用 | 用户名下无任何套餐时的引导占位 |
| 显示条件 | 接口返回 items = [] 时显示 |
| 字段内容 | 插画 + 主文案「您还没有套餐，去选购吧」+ 「去购买套餐」CTA |
| 点击行为 | CTA 点击 → `U-套餐列表页` |
| 关联业务规则 | US-021 §4.3 分支 1；US-021 §6.2 |

## 5. 跳转动线矩阵

| 起点元素 | 游客 | 注册用户 | 学员 |
|---------|------|---------|------|
| 整页访问 | → `U-微信授权页` / `U-手机号登录页` | 正常进入本页 | 正常进入本页 |
| 返回按钮 | — | → 上一页（个人中心页） | → 上一页（个人中心页） |
| 状态分组标题 | — | 展开/折叠该分组 | 展开/折叠该分组 |
| 套餐卡片 | — | → `U-我的套餐详情页`（package_id） | → `U-我的套餐详情页`（package_id） |
| 申请退款入口 | — | → `U-退款申请页`（package_id） | → `U-退款申请页`（package_id） |
| 空状态 CTA「去购买套餐」 | — | → `U-套餐列表页` | → `U-套餐列表页` |

> **"引导登录"**：当游客尝试进入本页或点击受登录限制的元素时，优先唤起登录页（`U-微信授权页` 或 `U-手机号登录页`），登录成功后返回本页并刷新数据。

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 用户登录但名下无任何 package 记录 | 隐藏列表与汇总，居中展示 Empty 组件：插画 + 主文案 + 「去购买套餐」CTA |
| **加载中** | 首次进入 / 下拉刷新 / 展开分组加载 | 顶部汇总区与列表区显示骨架屏；NavBar 保持可见 |
| **错误状态** | 网络断开 / 接口 5xx / 业务 4xx | 隐藏骨架屏，中央展示错误插画 + 错误文案 + Primary「重新加载」按钮 |
| **成功状态** | 数据正常返回 | 按 §4 显示规则完整展示汇总区、状态分组、套餐卡片及可操作的退款入口 |

| 规则 | PRD / US 引用 | 在本页面应用 |
