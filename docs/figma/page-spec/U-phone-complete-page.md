# 页面规格：U-完善个人资料页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-005（用户完善个人资料）/ US-009（用户隐私协议授权，前置同意校验）
> **对应 PRD**：§3.2 身份状态机、§5.2.1 注册登录、§5.6.1 手机号登录、§8.1 注册流程、§11.2 隐私合规、§13.3 MVP 页面 5
> **版本**：v3.0 | **创建日期**：2026-08-02 | **重大修订日期**：2026-08-05

## 2. 用户身份与业务状态维度

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | ❌ | 未登录用户不应进入此页；若直接进入，先跳转 `U-微信授权页` 或 `U-手机号登录页` |
| 注册用户 | ✅ | 当前页面目标用户，需满足 `identity_status='注册用户'` 且 `profile_completed=false`（首次完善）或主动编辑资料 |
| 学员 | ✅ | 仅作为「编辑资料」入口可见；若通过旧链接以 `profile_completed=false` 进入，自动跳转 `U-首页` |
| 教练 | ❌ | 教练端使用教练端小程序注册流程 |
| 管理员 | ❌ | 管理端使用 Web 后台注册流程 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| **首次进入** | `profile_completed=false`，表单带入登录时获取的头像与手机号 | 展示预填表单，标题为「完善资料」，无返回按钮 |
| **编辑进入** | `profile_completed=true`，从「我的」进入 | 标题为「编辑资料」，有返回按钮，回显全部已填内容 |
| **填写中** | 用户正在输入/选择字段 | 实时校验必填项与格式 |
| **头像上传中** | 用户选择头像后正在上传 | 头像区域显示上传 loading |
| **提交中** | 用户点击「保存」，后端正在保存 | 按钮 loading，表单不可编辑 |
| **资料校验失败** | 必填项缺失/格式错误/手机号已绑定/姓名敏感词 | 对应字段下方显示红色错误提示，不跳转 |
| **未成年人状态** | 用户选择年龄 < 18 周岁 | 动态展示监护人信息区，监护人姓名/手机号为必填 |
| **成年人状态** | 用户选择年龄 ≥ 18 周岁 | 隐藏监护人信息区，已保存数据保留但不展示 |
| **提交成功** | 后端返回保存成功 | 首次完善跳转 `U-首页`；编辑资料返回「我的」 |
| **网络错误** | 提交过程中网络断开或后端 5xx | 展示全局错误提示「网络异常，请检查网络后重试」 |

## 3. 元素清单（自上而下）

> **设计原则**：
> 1. **元素清单只描述「有什么元素」以及「元素之间的交互与状态」，不描述具体样式细节。** 颜色、宽度、高度、边距、背景、圆角、字体、字号、阴影等视觉参数**禁止**出现在 page-spec 中。
> 2. 视觉样式以 Calicat 设计稿为唯一最高优先级来源；page-spec 仅对交互逻辑、业务规则、状态流转负责。
> 3. 每个元素必须说明：名称、作用、显示条件、交互行为、关联业务规则。

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 首次进入，部分字段未填 | 头像默认微信头像/占位，必填项为空，协议未勾选；未成年人时监护人信息区为空 |
| **加载中** | 头像上传中 / 提交中 | 对应区域 loading，表单置灰 |
| **错误状态** | 字段校验失败 / 网络错误 | 字段级错误在表单项下方显示；未成年人未填监护人信息在监护人区显示错误；全局错误在按钮上方显示 |
| **成功状态** | 后端返回保存成功 | 首次完善跳转首页；编辑资料返回「我的」 |
