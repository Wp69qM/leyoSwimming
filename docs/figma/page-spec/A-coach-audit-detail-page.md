### 3.1 TopBar / 侧边栏 / 面包屑

### 3.2 审核资料卡

| 字段 | 值 |
|------|-----|
| 容器 | 卡片 |
| 个人形象照 | — |
| 姓名 | — |
| 申请 ID | — |
| 状态标签 | Tag：待审核 / 已通过 / 已驳回 |

| 字段 | 值 |

| 标题 | "实名与资质照片" |
| 身份证号 | 完整 18 位文本 |

### 3.4 审核检查清单

| 字段 | 值 |
|------|-----|
| 容器 | 卡片 |
| 标题 | "审核检查清单" |
| 检查项 | checkbox 列表：证件清晰可辨 / 信息一致 / 无不良记录 / 单价在合理区间 |
| 状态 | 已通过 / 待确认 |

### 3.5 申请历史与审核记录

| 字段 | 值 |
|------|-----|
| 容器 | 卡片 |
| 标题 | "申请历史" |
| 说明 | 展示该教练（coach_id）的所有 coach_application 记录，按提交时间倒序 |
| 列表 | 每行：申请 ID / 状态标签 / 提交时间 / 审核时间 / 审核人 / 驳回原因（如有） |
| 当前申请 | 列表顶部高亮显示当前正在查看的申请 |
| 切换 | 点击历史申请 ID 可切换查看对应快照 |
| 时间轴 | 当前申请下方展示审核时间轴：提交申请 / 管理员通过 / 管理员驳回 |
| 驳回节点 | 显示驳回原因 |

### 3.6

| 字段 | 值 |
|------|-----|
| 位置 | — |
| 背景 | — |
| 左侧 | 返回按钮（默认） |
| 右侧 | 审批意见输入框（，选填）+ 驳回按钮（危险）+ 通过按钮（主按钮） |

## 6. 四态设计

### 6.1 空状态

- 资质照片缺失时显示 "未上传" 占位。

### 6.2 加载中

- 页面级 `el-loading` 遮罩。

### 6.3 错误状态

- 错误占位页：插画 + "申请不存在" + 「返回列表」按钮。

### 6.4 成功状态

- 审核通过后 Toast "已通过"，驳回后 Toast "已驳回"，均返回队列页。
