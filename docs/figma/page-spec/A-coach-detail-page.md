## 3. 元素清单（自上而下）

### 3.1 TopBar / 侧边栏 / 面包屑

### 3.2 教练信息卡

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 24 px，margin-bottom 16 px |
| 个人形象照 | 80×80 px 圆形 |
| 姓名 | 20px Medium #262626 |
| 教练 ID | 12px Regular #8C8C8C |
| 状态标签 | Tag：教练状态 |

## 6. 四态设计

### 6.1 空状态

- 各 Tab 无数据时显示 `el-empty` "暂无数据"。

### 6.2 加载中

- 页面级 `el-loading` 遮罩或各卡片骨架屏。

### 6.3 错误状态

- 错误占位页：插画 + "教练不存在" + 「返回列表」按钮。

### 6.4 成功状态

- 教练信息与各 Tab 正常展示。
