## 6. 四态设计

### 6.1 空状态

- 暂无数据时图表显示空状态占位，Top 表格显示 "暂无数据"。

### 6.2 加载中

- 指标卡显示骨架屏（5 个灰色矩形），图表区显示 `el-skeleton`，表格显示 3 行骨架。

### 6.3 错误状态

- 页面顶部 `el-alert` "数据加载失败，请重试"，提供「刷新」按钮。

### 6.4 成功状态

- 全部数据正常渲染，图表可交互，表格可排序。
