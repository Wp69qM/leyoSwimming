## 3. 元素清单（自上而下）

### 3.1 TopBar / 侧边栏 / 面包屑

- 同 Web 后台管理页公共布局，当前菜单为「套餐配置」。
- 面包屑路径：首页 / 套餐订单 / 套餐配置。

### 3.2 Tab 切换

| Tab | 说明 |
|-----|------|
| 标准套餐 | 默认 Tab；维护 `package_template` 标准套餐模板列表 |
| 自定义套餐规则 | 维护全局唯一的 `custom_package_config` 配置 |

### 3.3 标准套餐 Tab

#### 3.3.1 筛选区

| 字段 | 值 |
|------|-----|
| 套餐模式下拉 | 全部 / 正价套餐 / 体验课 |
| 状态下拉 | 全部 / active / inactive |
| 关键词搜索 | 按套餐名称搜索 |
| 查询按钮 | 执行筛选 |
| 重置按钮 | 清空筛选条件 |
| 新增标准套餐按钮 | 打开 `A-套餐编辑弹窗`（新建模式） |

#### 3.3.2 表格区

| 列名 | 说明 |
|------|------|
| 套餐编号 | 标准套餐唯一编号 |
| 名称 | 套餐名称 |
| 套餐模式 | 正价套餐 / 体验课 |
| 适用教练 | 关联教练姓名，可多选或「全部」 |
| 教学类型 | 一对一 / 一对多 等 |
| 课时数 | 套餐包含总课时 |
| 有效期 | 套餐有效天数 |
| 售价 | 套餐售价 |
| 状态 | active / inactive |
| 操作 | 查看/编辑、上架/下架 |

#### 3.3.3 操作按钮

| 字段 | 显示条件 | 说明 |
|------|---------|------|
| 查看/编辑 | 所有状态均显示「查看」；仅 `inactive` 状态可进入编辑 | active 状态点击编辑时提示"已上架套餐需先下架才能编辑" |
| 上架 | `inactive` 状态显示 | 点击后 `status` 变为 `active` |
| 下架 | `active` 状态显示 | 点击后 `status` 变为 `inactive`；若已产生历史订单则仅可下架不可删除 |
| 新增标准套餐 | 始终显示 | 打开 `A-套餐编辑弹窗`（新建模式） |

### 3.4 自定义套餐规则 Tab

#### 3.4.1 配置表单

| 字段 | 说明 |
|------|------|
| 最小课时数（min_hours） | 自定义套餐允许选择的最小课时 |
| 最大课时数（max_hours） | 自定义套餐允许选择的最大课时 |
| 默认有效期（default_valid_days） | 自定义套餐默认有效天数 |
| 保存按钮 | 提交并保存配置 |
| 取消/重置按钮 | 恢复至上一次保存的值 |

> 保存校验：0 < min_hours ≤ max_hours ≤ 100，default_valid_days > 0。

## 6. 四态设计

### 6.1 空状态

- 标准套餐表格空：空插画 + "暂无标准套餐数据" + 「新增标准套餐」按钮。
- 自定义套餐规则首次进入：表单展示默认值占位，无保存记录时提示可配置。

### 6.2 加载中

- 标准套餐 Tab：表格骨架屏。
- 自定义套餐规则 Tab：表单区域骨架屏或整页加载遮罩。

### 6.3 错误状态

- 列表/表单加载失败：错误提示 Message + 「重试」按钮。
- 保存校验失败：表单项级错误提示。

### 6.4 成功状态

- 新增/编辑/上下架成功：Toast「操作成功」，列表自动刷新。
- 自定义规则保存成功：Toast「保存成功」，表单保持当前值。

## 7. 业务规则引用

| 规则 | 来源 | 在本页的体现 |
|------|------|-------------|
| 标准套餐由管理员后台预设固定套餐 | PRD §5.5.3 / US-045 | 标准套餐列表与新增/编辑入口 |
| 自定义套餐配置：学员在购买时可自由选择课时 | PRD §5.5.3 / US-045 | 自定义套餐规则 Tab 与课时范围配置 |
| 教练可设置参考单价，作为套餐定价基准 | PRD §5.5.3 / US-045 | `A-套餐编辑弹窗`中读取教练参考单价 |
| 新增标准套餐默认状态为 `inactive` | US-045 §4.1 | 新增成功后列表展示为未上架 |
| 已上架套餐需先下架才能编辑 | US-045 §8.5 | active 状态编辑按钮置灰/点击提示 |
| 已购套餐需保存模板快照，避免后续模板变更影响历史订单 | US-045 §5 | 列表展示模板当前字段，历史订单不受影响 |
| 自定义套餐课时范围校验 | US-045 §4.2 | 保存时校验 0 < min_hours ≤ max_hours ≤ 100 |
| 自定义套餐默认有效期必须大于 0 | US-045 §4.2 | 保存时校验 default_valid_days > 0 |
