## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
| ------ | :-------: | --------- |
| 待审核（0） | 是 | 仅显示入驻状态提示与入驻资料入口 |
| 已通过（1） | 是 | 完整功能入口 |
| 已驳回（2） | 是 | 显示驳回原因条，入口去入驻资料页 |
| 已离职（3） | 是 | **唯一入口**，仅显示已离职状态与「重新入驻」入口 |
| 申请离职中（4） | 是 | 显示「离职申请中」提示条与「查看离职申请」入口；隐藏「申请离职」入口，其他功能入口仍可用 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
| ------ | ------ | ----------- |
| 资料审核中（0） | 已提交入驻资料 | 隐藏收入/排班等功能入口 |
| 入驻被驳回（2） | 审核未通过 | 显示驳回原因，提供修改入口 |
| 在职（1） | 审核通过 | 展示全部功能入口 |
| 申请离职中（4） | 已提交离职申请 | 隐藏「申请离职」入口，显示「查看离职申请」入口；其他功能仍可用 |
| 已离职（3） | 离职审批通过 | 功能锁定，仅保留重新入驻 |

## 6. 四态设计

| 状态 | 触发 | 表现 |
| ------ | ------ | ------ |
| 空状态 | 教练资料字段为空 | 头图卡片显示默认个人形象照占位 + 「未设置昵称」 |
| 加载中 | 进入页面时拉取 coach 信息 | 头图卡片与功能列表显示骨架屏 |
| 错误状态 | 网络/服务异常 | 中央错误插画 + 「加载失败，点击重试」 |
| 成功状态 | 数据正常返回 | 按 §4 矩阵完整显示 |
