## 6. 四态设计

### 6.1 空状态

- 历史版本为空时显示 "暂无历史版本"。

### 6.2 加载中

- 编辑器与列表显示骨架屏。

### 6.3 错误状态

- 保存失败：顶部 `el-message` "保存失败，请稍后重试"。

### 6.4 成功状态

- 发布成功：Toast "发布成功"，历史版本列表刷新。

## 7. 业务规则引用

| 规则 | 来源 | 在本页的体现 |
|------|------|-------------|
| 管理员编辑、发布、更新《用户须知》 | PRD §5.5.4 | 编辑器与发布按钮 |

| 用户首次购买前必须同意当前版本 | PRD §5.5.4 / §6.9 | 强制重新签署开关 |
| 版本变更后向所有注册用户推送提醒 | PRD §5.5.4 | 发布成功后的提示文案 |
| 后台可查看用户签署记录及版本号 | PRD §5.5.4 | 签署记录查询入口 |
