## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客（未登录教练） | ✅ | 当前页面目标用户；展示完整授权引导与一键登录按钮 |
| 注册用户（无教练资质） | ✅ | 同游客处理，登录后按无 coach 记录跳转入驻资料页 |
| 已入驻教练 | ❌ | 已登录教练不应进入此页；若通过旧链接/分享进入，自动跳转 `C-教练端首页` |
| 学员 | ❌ | 学员使用用户端小程序登录流程 |
| 管理员 | ❌ | 管理端使用 Web 后台登录流程 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| **未发起授权** | 教练刚进入页面，尚未点击登录 | 展示品牌区 + 底部登录按钮，无 loading |
| **授权中** | 教练已点击「微信一键登录」，正在调用 `wx.login()` 或后端 `code2session` | 按钮进入 loading，显示「登录中…」文案，防止重复点击 |
| **首次登录（无 coach 记录）** | 微信返回新用户或仅有 user 记录，无 coach 记录 | 登录成功后跳转 `C-入驻资料页`（US-010） |
| **待审核（coach.status=0）** | 已提交入驻资料，等待管理员审核 | 登录成功后跳转 `C-等待审核页` |
| **已通过（coach.status=1）** | 入驻审核通过 | 登录成功后跳转 `C-教练端首页` |
| **已驳回（coach.status=2）** | 审核被拒绝，需重新提交 | 登录成功后跳转 `C-入驻资料页`（US-040，重新入驻状态），显示驳回原因 |
| **已离职（coach.status=3）** | 离职审批通过 | 登录成功后跳转 `C-入驻资料页`（US-040，重新入驻状态） |
| **申请离职中（coach.status=4）** | 已提交离职申请，待管理员审批 | 登录成功后跳转 `C-教练端首页`；「我的」页面提供「查看离职申请」入口，教练可主动进入 `C-离职处理中页` |
| **教练拒绝授权** | 教练在授权弹窗中点击「拒绝」 | 停留在本页，展示错误提示「需要微信授权才能登录」+ 「重新授权」按钮 |
| **微信接口失败** | `wx.login()` 失败或后端调用微信 `code2session` 失败 | 停留在本页，展示错误提示「微信服务暂时不可用，请稍后重试」 |
| **登录凭证失效** | 用户提交的 `code` 已过期或已被使用 | 停留在本页，展示错误提示「登录凭证已失效，请重新点击登录」 |
| **未同意隐私协议** | 教练完成微信授权但未同意当前隐私协议 | 跳转 `U-隐私协议页`（US-009），同意后再按 redirect_page 跳转 |

## 5. 跳转动线矩阵

> 本页所有跳转由用户主动点击或登录成功后自动触发。教练端登录后的分流以 `coach_status` 为核心。

| 触发条件 | 目标页面 | 条件/说明 |
|---------|---------|----------|
| 点击「微信一键登录」且成功 + 无 coach 记录 | → `C-入驻资料页` | US-010 |
| 点击「微信一键登录」且成功 + `coach_status=0` | → `C-等待审核页` | 本 Page Spec 定义 |
| 点击「微信一键登录」且成功 + `coach_status=1` | → `C-教练端首页` | US-012 起 |
| 点击「微信一键登录」且成功 + `coach_status=2` | → `C-入驻资料页` | US-040，重新入驻状态，显示驳回原因 |
| 点击「微信一键登录」且成功 + `coach_status=3` | → `C-入驻资料页` | US-040，重新入驻状态 |
| 点击「微信一键登录」且成功 + `coach_status=4` | → `C-教练端首页` | 不强制跳转离职处理中页；「我的」页面提供「查看离职申请」入口，教练主动查看 |
| 点击《隐私协议》/《用户须知》 | → `U-登录页协议浮层` | US-009 |
| 用户拒绝授权后点击「重新授权」 | 调用 `wx.openSetting()` | — |
| 已登录教练通过旧链接进入 | — | 自动 → `C-教练端首页` |

> **登录成功后的回跳逻辑**：若教练从受登录限制的功能被引导至本页，登录成功后应返回原页面并刷新身份状态；若直接打开小程序进入本页，登录成功后按 `coach_status` 跳转对应页面。

### 5.1 跳转参数说明

| 参数 | 类型 | 来源 | 用途 |
|------|------|------|------|
| source_page | string | 拦截来源页 | 记录用户从哪个页面被引导至授权页，用于登录成功后回跳 |
| target_action | string | 拦截来源操作 | 如 `book_slot`，登录成功后继续该操作 |
| code | string | 微信 `wx.login()` | 用于后端换取 openid/session_key |
| coach_status | int/null | 后端返回 | 决定登录后跳转目标页 |
| redirect_page | string | 后端返回 | 枚举：coach_onboarding / coach_pending / coach_home / coach_rejected / coach_resigned；coach_resigning 不再作为登录后自动跳转目标 |

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 页面首次加载，未触发任何操作 | 与成功态视觉一致，展示品牌元素 + 底部登录区；无错误提示 |
| **加载中** | 用户点击「微信一键登录」后，`wx.login()` 或后端接口处理中 | 品牌元素保留；底部登录按钮进入 loading 态，文案变为「登录中…」；隐私协议勾选区保持可见但不可交互 |
| **错误状态** | 用户拒绝授权 / 微信接口失败 / 登录凭证失效 / 网络超时 | 品牌元素保留但整体 opacity 降至 0.85；底部登录区上方显示错误提示区；拒绝授权时额外显示「重新授权」按钮；登录按钮恢复可点击 |
| **成功状态** | 微信授权成功且后端返回登录结果 | 页面保持品牌元素完整显示 300ms 后，以淡出动效（opacity 1→0, ease-out）离开并跳转目标页 |
| **协议未勾选状态** | 用户点击登录按钮但未勾选隐私协议 | 底部登录区上方显示「请先阅读并同意协议」提示，按钮不进入 loading |
