# 页面规格：U-套餐详情页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-017（游客购买体验课套餐）/ US-019（学员浏览正价套餐）/ US-020（学员购买正价套餐，含自定义套餐）/ US-021（学员查看我的套餐详情）/ US-045（套餐模板上下架与字段扩展）
> **对应 PRD**：§3.2 身份状态机、§3.5 单教练约束、§4.1 套餐类型、§4.4 关键不变量、§4.5 体验课特殊规则、§4.6 套餐过期与续期、§5.1 游客功能、§5.3.1 教练与套餐浏览、§5.5.3 套餐与订单、§13.3 MVP 页面 10

## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | ✅ | 可查看套餐全部公开信息；点击购买跳转 `U-微信授权页` |
| 注册用户 | ✅ | 可查看并购买体验课/正价套餐；受体验课 1 份限制 |
| 学员（已绑定本教练）| ✅ | 可查看并购买本教练的加课套餐 |
| 学员（已绑定其他教练）| ✅ | 可查看信息，但**不可购买**；顶部显示单教练约束提示，底部购买区隐藏 |
| 教练 | ❌ | 教练端使用教练端小程序 |
| 管理员 | ❌ | 管理端使用 Web 后台 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| **套餐类型 = 体验课** | `package_type = 0` | 页面标题/徽标/主题色使用活力橙；展示"1 节 · 30 天有效"；非退款提示 |
| **套餐类型 = 标准套餐** | `package_type = 1`，固定课时（1/6/8/10 节） | 展示标准套餐详情；按教练参考单价计算总价 |
| **套餐类型 = 自定义课时** | `package_type = 1`，课时由用户选择 | 展示参考单价；购买时进入课时选择流程 |
| **用户无体验套餐** | 未持有 active/exhausted 体验套餐 | 体验课详情页显示"立即购买"按钮 |
| **用户已有体验套餐** | 持有 active/exhausted 体验套餐 | 体验课详情页按钮改为"已购买"禁用态 |
| **未绑定教练** | 游客或注册用户 | 购买按钮正常可用 |
| **已绑定本教练** | 学员持有该教练 active 套餐 | 购买按钮正常可用；可显示"为当前教练加课"提示 |
| **已绑定其他教练** | 学员持有其他教练 active 套餐 | 顶部显示约束提示；底部购买区隐藏或显示"已绑定其他教练"禁用态 |
| **教练 status ≠ 1** | 教练未通过审核或已离职 | 购买按钮置灰/隐藏，提示"暂不可购买" |
| **套餐 template status ≠ 'active'** | 标准套餐模板未上架或已被下架 | 进入空状态，提示"套餐不存在或已下架"；底部购买区隐藏 |
| **已下架/不存在** | 套餐配置被删除、template status ≠ 'active' 或 coach 已离职 | 进入空状态，提示"套餐不存在或已下架" |
| ** coach.status = 4（申请离职中）**| 教练申请离职但尚未完成交接 | 购买按钮置灰，文案"暂不可购买"；不显示特殊标签 |
| ** coach.status = 3（已离职）**| 教练已完成离职交接 | 该教练套餐不应被搜索/列表展示；通过旧链接进入时显示空状态 |
| **入口来源 = 全局套餐列表**| 从 `U-套餐列表页` 进入，未携带 coach_id | 页面底部展示「教练选择区」，必须选中一名教练后才能点击购买；单教练时默认选中 |
| **入口来源 = 教练详情页**| 从 `U-教练详情页` 进入，已携带 coach_id | 教练选择区展示「已选教练自适应卡」，不可更改 |
| **入口来源 = 我的套餐列表**| 从 `U-我的套餐列表页` 进入，查看已购 package 实例 | 页面为只读详情，底部展示「已选教练信息卡」，无购买操作按钮 |
| **入口来源 = 我的订单列表**| 从 `U-我的订单列表页` 进入，查看订单关联 package 实例 | 页面为只读详情，底部展示「已选教练信息卡」，无购买操作按钮 |
| **套餐类型 = 自定义课时**| `package_mode = custom` | 点击「立即购买」→ `U-自定义套餐配置页`（携带 package_id / coach_id），而非 `U-订单确认页` |

> **状态优先级**：当多个状态同时满足时，按「已下架/不存在 > 教练 status ≠ 1 > 已绑定其他教练 > 已购买/已绑定本教练 > 未选择教练 > 正常购买」顺序决定底部按钮形态。

## 5. 跳转动线矩阵

| 起点元素 | 游客 | 注册用户 | 学员（本教练）| 学员（其他教练）|
|---------|------|---------|-------------|-------------|
| 返回按钮 | → 上一页 | → 上一页 | → 上一页 | → 上一页 |
| 教练选择区（选中某教练）| — | — | — | — |

| 已购套餐底部教练信息区 | → `U-教练详情页` | → `U-教练详情页` | → `U-教练详情页` | → `U-教练详情页` |
| "立即购买" 按钮（体验课 / 标准套餐）| → `U-微信授权页` | → `U-订单确认页` | → `U-订单确认页` | — |

> **"引导登录"**：当游客点击「立即购买」时，统一跳转 `U-微信授权页`，登录成功后返回本页面并刷新身份状态。自定义课时在登录成功后进入 `U-自定义套餐配置页`。
>
> **已购套餐详情**：从我的套餐列表 / 我的订单列表进入时，仅保留「返回按钮」与「底部已购套餐教练信息区 → `U-教练详情页`」动线。

### 5.1 跳转参数说明

| 参数 | 类型 | 来源 | 用途 |

| package_type | int | 套餐详情接口 | 0=体验课 / 1=正价课，订单确认页据此渲染不同表单 |
| source_page | string | 当前页面标识 | 用于登录成功后回跳，可选值：`package_detail` |

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 套餐不存在、套餐模板 `status ≠ 'active'` 或 coach 已离职 | 隐藏套餐主信息卡与购买区；居中展示空状态插画 + "套餐不存在或已下架" + "返回首页" 按钮（→ `U-首页`） |
