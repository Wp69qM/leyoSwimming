## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | ✅ | 可查看套餐全部公开信息；点击购买跳转 `U-微信授权页` |
| 注册用户 | ✅ | 可查看并购买体验课/正价套餐；受体验课 1 份限制 |
| 学员（已绑定本教练）| ✅ | 可查看并购买本教练的加课套餐 |
| 学员（已绑定其他教练）| ✅ | 可查看信息，但**不可购买**；顶部显示单教练约束提示，底部购买区隐藏 |
| 教练 | ❌ | 教练端使用教练端小程序 |
| 管理员 | ❌ | 管理端使用 Web 后台 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| **套餐类型 = 体验课** | `package_type = 0` | 页面标题/徽标/主题色使用活力橙；展示"1 节 · 30 天有效"；非退款提示 |
| **套餐类型 = 标准套餐** | `package_type = 1`，固定课时（1/6/8/10 节） | 展示标准套餐详情；按教练参考单价计算总价 |
| **套餐类型 = 自定义课时** | `package_type = 1`，课时由用户选择 | 展示参考单价；购买时进入课时选择流程 |
| **用户无体验套餐** | 未持有 active/exhausted 体验套餐 | 体验课详情页显示"立即购买"按钮 |
| **用户已有体验套餐** | 持有 active/exhausted 体验套餐 | 体验课详情页按钮改为"已购买"禁用态 |
| **未绑定教练** | 游客或注册用户 | 购买按钮正常可用 |
| **已绑定本教练** | 学员持有该教练 active 套餐 | 购买按钮正常可用；可显示"为当前教练加课"提示 |
| **已绑定其他教练** | 学员持有其他教练 active 套餐 | 顶部显示约束提示；底部购买区隐藏或显示"已绑定其他教练"禁用态 |
| **教练 status ≠ 1** | 教练未通过审核或已离职 | 购买按钮置灰/隐藏，提示"暂不可购买" |
| **已下架/不存在** | 套餐配置被删除或 coach 已离职 | 进入错误状态，提示"套餐不存在或已下架" |
| ** coach.status = 4（申请离职中）**| 教练申请离职但尚未完成交接 | 购买按钮置灰，文案"暂不可购买"；不显示特殊标签 |
| ** coach.status = 3（已离职）**| 教练已完成离职交接 | 该教练套餐不应被搜索/列表展示；通过旧链接进入时显示空状态 |

> **状态优先级**：当多个状态同时满足时，按「已下架/不存在 > 教练 status ≠ 1 > 已绑定其他教练 > 已购买/已绑定本教练 > 正常购买」顺序决定底部按钮形态。

## 5. 跳转动线矩阵

| 起点元素 | 游客 | 注册用户 | 学员（本教练）| 学员（其他教练）|
|---------|------|---------|-------------|-------------|
| 返回按钮 | → 上一页 | → 上一页 | → 上一页 | → 上一页 |

| "立即购买" 按钮 | → `U-微信授权页` | → `U-订单确认页` | → `U-订单确认页` | — |
| 空状态 "返回首页" | → `U-首页` | → `U-首页` | → `U-首页` | → `U-首页` |

> **"引导登录"**：当游客点击「立即购买」时，统一跳转 `U-微信授权页`，登录成功后返回本页面并刷新身份状态。

### 5.1 跳转参数说明

| 参数 | 类型 | 来源 | 用途 |
|------|------|------|------|
| package_id | string | 套餐详情接口 | 标识当前套餐，订单确认页据此查询套餐信息 |
| coach_id | string | 套餐详情接口 | 标识套餐所属教练，用于单教练约束校验 |
| package_type | int | 套餐详情接口 | 0=体验课 / 1=正价课，订单确认页据此渲染不同表单 |
| source_page | string | 当前页面标识 | 用于登录成功后回跳，可选值：`package_detail` |

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 套餐不存在或已下架 | 隐藏套餐主信息卡与购买区；居中展示空状态插画 + "套餐不存在或已下架" + "返回首页" 按钮（→ `U-首页`） |
| **加载中** | 首次进入 / 刷新套餐详情 | 显示骨架屏；NavBar 保持可见 |
| **错误状态** | 网络/服务异常 | 隐藏骨架屏；居中展示错误插画 + 文案 + "重新加载" 按钮 |
| **成功状态** | 数据正常返回 | 按 §4 矩阵完整展示；底部购买区按身份/业务状态显示对应按钮 |
