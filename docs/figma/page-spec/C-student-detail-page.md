# 页面规格：C-学员详情编辑页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-037
> **对应 PRD**：§5.4.4 学员管理、§11.1 数据安全
> **版本**：v2.0 | **创建日期**：2026-08-02 | **更新日期**：2026-08-12

## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 已通过（1） | 是 | 完整编辑功能 |
| 申请离职中（4） | 是 | 可查看/编辑 |
| 其他状态 | 否 | 重定向 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| 成人学员 | is_minor = false | 未成年人徽章不展示 |
| 未成年学员 | is_minor = true | 未成年人徽章展示；监护人信息只读展示（来自 US-005） |
| 学员已注销 | user.status = 1 | 姓名/手机号脱敏，编辑功能禁用 |
| 非关联学员 | 无 booking/package | 显示"无权查看"空状态 |
| 无关联套餐 | 当前教练与该学员无 package 记录 | 「关联套餐」卡片区展示空状态 |

## 3. 元素清单（自上而下）

### 3.1 状态栏 + NavBar

| 字段 | 值 |
|------|-----|
| 状态栏 | 375×44，#FFFFFF，y=0 |
| NavBar | 375×44，#FFFFFF，y=44，底部 1px `#F0F0F0` |
| 标题 | "学员详情"，17px Medium `#262626`，居中 |
| 左侧返回 | 24×24 `#262626` 图标，x=16 |
| 右侧保存 | 文字按钮 "保存"，14px Medium `#1890FF` |

### 3.2 学员基础信息区（y=88）

| 字段 | 值 |
|------|-----|
| 容器 | 375×120，`gradient-water` 背景 |
| 头像 | 64×64 圆形，居中，白边 3px |
| 姓名 | 20px Bold 白色，居中 |
| 手机号 | 14px 白色 80%，居中（已注销时脱敏） |
| 未成年人徽章 | 条件显示，pill，`#FF4D4F` 浅色 |

### 3.3 关联数据摘要（y=224）

| 字段 | 值 |
|------|-----|
| 容器 | 343×72，x=16，白底圆角 12，shadow-card |
| 3 列数据 | 累计课时 / 剩余课时 / 最近上课日期 |
| 数字 | 24px Bold `#262626` |
| 标签 | 12px `#8C8C8C` |

> **说明**：累计课时、剩余课时统计当前教练与该学员所有 package 实例的 `total_hours`、`available` 之和；最近上课日期取 booking 表中最近一次已完成的上课时间。

### 3.4 信息切片编辑区（y=312）

| 字段 | 值 |
|------|-----|
| 容器 | 343×动态，x=16，白底圆角 12，shadow-card |
| 学习泳姿 | 单选/输入，如自由泳/蛙泳/仰泳/蝶泳 |
| 游泳等级 | 单选，如初级/进阶/高级 |
| 基础情况 | 多行文本，最多 200 字 |
| 沟通备注 | 多行文本，最多 500 字 |

> **约束**：未成年人及监护人信息统一由学员在 US-005 维护，教练端不可编辑；如需记录未成年人相关教学注意事项，教练可写在「基础情况」或「沟通备注」中。

### 3.5 关联套餐卡片区

> **来源**：US-037 §4.1 / §5 规则 8-10；点击卡片跳转至 US-021 教练视角套餐使用详情页。

| 字段 | 值 |
|------|-----|
| 容器 | 343×动态，x=16，白底圆角 12，shadow-card |
| 区标题 | "关联套餐"，16px Medium `#262626` |
| 卡片列表 | 该学员与当前教练的所有 package 实例，按购买时间倒序排列 |
| 卡片间距 | 12px |
| 单张卡片 | 白底圆角 12，内边距 16px，横向布局 |
| 左侧信息 | 套餐名称（16px Medium `#262626`）、套餐模式标签（正价/体验，12px Regular）、有效期（12px `#8C8C8C`） |
| 右侧信息 | 状态标签（未使用/使用中/已使用/已过期/已退款/已冻结，12px Medium）、"剩余 X 课时"（14px Bold `#262626`） |
| 空状态 | 无关联 package 时展示"暂无关联套餐"插画与文案 |
| 点击行为 | 点击整张卡片跳转 `C-套餐使用详情页`（US-021 教练视角），携带 `package_id` |
| 按压态 | 卡片整体 scale 0.98，过渡 150ms |

### 3.6 底部保存按钮

| 字段 | 值 |
|------|-----|
| 按钮 | 343×48，`gradient-primary` 渐变，圆角 8，白色文字 "保存" |
| 位置 | 底部 32px |
| 禁用态 | 学员已注销或校验不通过时透明度 50% |

## 5. 跳转动线

| 起点 | 行为 |
|------|------|
| 保存成功 | 返回 C-我的学员列表页，Toast "保存成功" |
| 校验失败 | 停留在本页，字段标红 |
| 返回 | → C-我的学员列表页 |
| 套餐卡片点击 | → C-套餐使用详情页（US-021 教练视角），携带 package_id |

## 6. 四态设计

| 状态 | 表现 |
|------|------|
| 空状态 | 非关联学员显示"无权查看该学员"插画 + 返回按钮；无关联套餐时「关联套餐」区显示"暂无关联套餐" |
| 加载中 | 表单区骨架屏 + 套餐卡片区骨架屏 |
| 错误状态 | 字段校验错误 / 网络错误 |
| 成功状态 | 保存成功 Toast |
