# 页面规格：U-首页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-001 / US-002 / US-003 / US-005 / US-017 / US-019 / US-020 / US-021 / US-029
> **对应 PRD**：§2 首页、§3.2 身份状态机、§4.1/§4.4/§4.5 套餐模型、§5.1 游客功能、§5.2.3 转化入口、§5.3.2 预约、§5.5.5 首页运营
> **版本**：v3.0 | **创建日期**：2026-08-02
> **重写原因**：v2.0 错误地把游客推荐教练区隐藏、错误取消套餐入口、错误把倒计时合并进通知栏；v3.0 完全对齐 US 原文

## 2. 用户身份与页面分区

### 2.1 三种身份（PRD §3.1）

| 身份 | 定义 | 首页差异 |
|------|------|---------|
| **游客** | 未登录 | 能浏览公开信息；不能购买；点击购买/预约时引导登录 |
| **注册用户** | 已注册，0 个 active 套餐 | 能购买体验课/正价套餐；无"继续上课"区 |
| **学员** | 已注册，≥1 个 active 套餐 | 首页聚焦"当前教练"的继续上课/加课/预约入口 |

### 2.2 首页四大信息区（US 聚合）

| 分区 | 来源 | 游客 | 注册用户 | 学员 |
|------|------|:---:|:---:|:---:|
| 通知栏（公告/倒计时）| US-002 / US-003 | ✅ | ✅ | ✅ |
| 运营 Banner | US-002 / US-017 | 新人 Banner 隐藏 | 新人 Banner 显示 | 隐藏 |
| 教练区 | US-001 | 热门教练横向卡片 | 热门教练横向卡片 | 当前教练继续上课卡片 |
| 套餐/场馆入口 | US-002 | 查看全部套餐 + 场馆信息 | 同左 | 当前教练加课入口 |

## 3. 元素清单（自上而下）

### 3.1 状态栏 + NavBar

| 字段 | 值 |
|------|-----|
| 状态栏 | 375×44，#0050B3，y=0 |
| NavBar | 375×44，#0050B3，y=44 |
| 标题 | "leyoSwimming"，17px Medium 白色，居中 |
| 右侧消息图标 | 24×24 白色占位 x=335, y=54 |

### 3.2 通知栏 + 倒计时区（y=88 ~ 124）

> **来自 US-002 §4.1 + US-003 §4.1**：首页顶部同时承载公告通知和预约释放倒计时。
> 两者不可合并：通知栏是滚动的轻量公告；倒计时是高亮的独立时间组件。

#### A. 通知栏（y=88, h=36）

| 字段 | 值 |
|------|-----|
| 容器 | 375×36，y=88 |
| 背景 | 按 notice.type 变化：0=开放 #E6F7FF / 1=换水 #FFF2E8 / 2=释放 #F6FFED / 3=紧急 #FFF1F0 |
| 左侧图标 | 16×16 圆形，颜色与类型对应（蓝/橙/绿/红） |
| 文字 | notice.title，12px，颜色与类型对应 |
| 空状态 | 无生效公告时**整栏隐藏**，不展示空状态 |

#### B. 倒计时组件（y=124, h=56）

> **来自 US-003 §14.3**：仅在释放倒计时窗口内显示，非窗口期完全隐藏。

| 字段 | 值 |
|------|-----|
| 容器 | 375×56，y=124 |
| 背景 | #1890FF 主色（高亮吸引） |
| 文案 1 | "距离下周预约开放还有 XX 小时"（释放前 24h ~ 释放当天 10:00 前） |
| 文案 2 | "今日 10:00 开放下周预约"（释放当天 10:00 前） |
| 数字 | 大号 24px Bold 白色，带翻牌动效占位 |
| 空状态 | 不在倒计时窗口时**完全隐藏**，下方模块上移 |

### 3.3 搜索栏（y=140 或 y=88，根据倒计时是否显示动态调整）

> **来自 US-001 §4.1**：游客进入「找教练」入口。搜索栏是最高效的教练入口。

| 字段 | 值 |
|------|-----|
| 容器 | 343×40，x=16，胶囊圆角 20 |
| 背景 | #FFFFFF，1px 边框 #E8E8E8 |
| 左侧图标 | 20×20 圆形 #E6F7FF 占位 |
| placeholder | "搜索教练姓名"（游客/注册用户）/ "搜索你的教练"（学员） |
| 点击 | → `U-教练列表页` 或 `U-搜索结果页` |

### 3.4 运营 Banner「新人体验课」（y=192）

> **来自 US-017 §4.1 + PRD §4.5**：
> - 游客：**不显示**（未登录无法购买）
> - 注册用户：**显示**（前提是名下无 active/exhausted 体验套餐）
> - 学员：**不显示**（已经不是新人）

| 字段 | 值 |
|------|-----|
| 容器 | 343×120，x=16，y=192，圆角 12 |
| 背景 | #1890FF |
| 主标题 | "新人体验课"，20px Bold 白色 |
| 副标题 | "¥99 / 1 节 · 30 天有效"，14px 白色 80% |
| CTA | "立即购买" 90×28 白色胶囊，12px Bold #1890FF |
| 点击 | → `U-套餐详情页`（体验课） |

### 3.5 教练区（y=328）

> **来自 US-001 §4.1**：游客能看到热门教练。学员则看到当前绑定教练。

#### A. 游客 / 注册用户：「热门教练」横向滑动

| 字段 | 值 |
|------|-----|
| 区标题 | "热门教练"，16px Bold #262626，x=16, y=328 |
| 右侧"查看全部" | 12px #1890FF，x=300, y=332 |
| 卡片尺寸 | 160×120，圆角 12，白底，1px #F0F0F0 |
| 卡片内容 | 头像 48×48 圆形 + 姓名 14px Bold + 评分 ⭐4.8 12px + 实时状态徽标 |
| 实时状态徽标 | 与 `U-教练列表页` §3.4.4 对齐：空闲中 `#F6FFED`/#52C41A、上课中 `#FFF1F0`/#FF4D4F、休息中 `#FFFBE6`/#FAAD14、已下班 `#F5F5F5`/#8C8C8C、请假中 `#FFFBE6`/#FAAD14 |
| 横向排列 | 2-3 张可见，可滑动查看更多 |
| 点击 | → `U-教练详情页` |

#### B. 学员：「继续上课」当前教练卡片

### 3.6 套餐/场馆入口区（y=476）

> 对学员来说，因为单教练约束（PRD §4.4），这里变成"当前教练加课"。

## 6. 四态设计

| 状态 | 表现 |
|------|------|
| 空状态 | 通知栏隐藏；Banner 按身份显示；教练区显示"暂无热门教练"/"暂无绑定教练"；套餐/场馆入口仍显示 |
| 加载中 | 各卡片区域显示骨架屏（浅灰 #F5F5F5 占位） |
| 错误状态 | 中央错误插画 + "加载失败，点击重试" + 按钮 |
| 成功状态 | 按 §4 矩阵完整显示 |
