# 页面规格：U-首页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-001 / US-002 / US-003 / US-005 / US-017 / US-019 / US-020 / US-021 / US-029
> **对应 PRD**：§2 首页、§3.2 身份状态机、§4.1/§4.4/§4.5 套餐模型、§5.1 游客功能、§5.2.3 转化入口、§5.3.2 预约、§5.5.5 首页运营
> **版本**：v4.0 | **创建日期**：2026-08-02
> **重写原因**：v2.0 错误地把游客推荐教练区隐藏、错误取消套餐入口、错误把倒计时合并进通知栏；v3.0 完全对齐 US 原文；v4.0 结合管理端运营配置与教练数据，丰富首页展示逻辑

## 2. 用户身份与页面分区

### 2.1 三种身份（PRD §3.1）

| 身份 | 定义 | 首页差异 |
|------|------|---------|
| **游客** | 未登录 | 能浏览公开信息；不能购买；点击购买/预约时引导登录 |
| **注册用户** | 已注册，0 个 active 套餐 | 能购买体验课/正价套餐；无"继续上课"区 |
| **学员** | 已注册，≥1 个 active 套餐 | 首页聚焦"当前教练"的继续上课/加课/预约入口 |

### 2.2 首页八大信息区（管理端 + 教练数据 + US 聚合）

| 分区 | 数据来源 | 游客 | 注册用户 | 学员 |
|------|---------|:---:|:---:|:---:|
| 通知栏（公告/倒计时）| US-002 / US-003 / A-公告运营配置页 | ✅ | ✅ | ✅ |
| 场馆图片轮播 | A-场馆配置页（新增相册） | ✅ | ✅ | ✅ |
| 可配置 Banner 轮播 | A-公告运营配置页 · Banner Tab | 按可见身份 | 按可见身份 | 按可见身份 |
| 我的预约快捷入口 | US-029 / 教练排班数据 | 引导登录 | ✅ | ✅ |
| 首页卡片网格 | A-公告运营配置页 · 首页卡片 Tab | 按可见身份 | 按可见身份 | 按可见身份 |
| 教练区 | US-001 / C-教练实时状态 | 热门教练横向卡片 | 热门教练横向卡片 | 当前教练继续上课卡片 |
| 场馆状态/信息卡 | A-场馆配置页 | ✅ | ✅ | ✅ |
| 套餐/课程入口 | US-002 / US-017 | 查看全部套餐 + 场馆信息 | 同左 | 当前教练加课入口 |

## 3. 元素清单（自上而下）

### 3.1 状态栏 + NavBar

### 3.2 通知栏 + 倒计时区（y=88 ~ 124）

> **来自 US-002 §4.1 + US-003 §4.1 + A-公告运营配置页**：首页顶部同时承载公告通知和预约释放倒计时。
> 两者不可合并：通知栏是滚动的轻量公告；倒计时是高亮的独立时间组件。

#### A. 通知栏（y=88, h=36）

| 字段 | 值 |
|------|-----|
| 容器 | 375×36，y=88 |
| 背景 | 按 notice.type 变化：0=开放 #E6F7FF / 1=换水 #FFF2E8 / 2=释放 #F6FFED / 3=紧急 #FFF1F0 |
| 左侧图标 | 16×16 圆形，颜色与类型对应（蓝/橙/绿/红） |
| 文字 | notice.title，12px，颜色与类型对应 |
| 数据源 | A-公告运营配置页 · 通知栏公告 Tab |
| 空状态 | 无生效公告时**整栏隐藏**，不展示空状态 |

#### B. 倒计时组件（y=124, h=56）

> **来自 US-003 §14.3**：仅在释放倒计时窗口内显示，非窗口期完全隐藏。

| 字段 | 值 |
|------|-----|
| 容器 | 375×56，y=124 |
| 背景 | #1890FF 主色（高亮吸引） |
| 文案 1 | "距离下周预约开放还有 XX 小时"（释放前 24h ~ 释放当天 10:00 前） |
| 文案 2 | "今日 10:00 开放下周预约"（释放当天 10:00 前） |
| 数字 | 大号 24px Bold 白色，带翻牌动效占位 |
| 空状态 | 不在倒计时窗口时**完全隐藏**，下方模块上移 |

### 3.3 场馆图片轮播区（y=140 或 y=88，根据倒计时是否显示动态调整）

> **来自 A-场馆配置页（新增相册）**：展示场馆环境、泳池、设施图片，增强首页氛围感。

| 字段 | 值 |
|------|-----|
| 容器 | 375×180，白底 |
| 图片 | 3-5 张场馆/泳池/设施图，16:9 比例，圆角 12（首张 x=16，左右可滑动） |
| 指示器 | 底部圆点，当前点 #1890FF，其他 #D9D9D9 |
| 点击 | 整图放大预览 |
| 空状态 | 未配置图片时**整区隐藏**，下方模块上移 |
| 数据源 | `venue.images`（由管理端 A-场馆配置页上传） |

### 3.4 可配置 Banner 轮播区（y=328 或 y=140，动态调整）

> **来自 A-公告运营配置页 · Banner Tab**：运营位不再只放固定新人体验课 Banner，而是管理端可配置的多张轮播 Banner。

| 字段 | 值 |
|------|-----|
| 容器 | 343×120，x=16，圆角 12 |
| 图片 | 1-N 张 Banner 图，横向滑动轮播，自动播放 5s |
| 指示器 | 底部圆点或进度条 |
| 点击 | 按 Banner.link 跳转：外部链接 / 内部套餐页 / 教练详情页 |
| 可见身份 | 每张 Banner 可单独配置可见范围：全部 / 游客 / 注册用户 / 学员 |
| 空状态 | 无生效 Banner 时**整区隐藏** |
| 数据源 | A-公告运营配置页 · Banner Tab |

> **特别说明**：原「新人体验课」Banner 仍可通过管理端配置为其中一张 Banner， targeting 注册用户；不再作为首页固定组件硬编码。

### 3.5 我的预约快捷入口（y=456，仅注册用户/学员）

> **来自 US-029 / C-教练排班数据**：把「我的预约」中最近一节课提到首页，缩短操作路径。

| 字段 | 值 |
|------|-----|
| 容器 | 343×80，x=16，白底圆角 12，1px #F0F0F0 |
| 左侧时间区 | 80×80，#E6F7FF，圆角 12 0 0 12，居中大号时间 |
| 内容 | 课程类型标签 + 教练名 + "周三 09:00-10:00" |

### 3.6 首页卡片网格（y=548 或动态）

| 字段 | 值 |

## 6. 四态设计

| 状态 | 表现 |
|------|------|
| 空状态 | 通知栏/场馆图片/Banner/卡片网格按配置显隐；教练区显示"暂无热门教练"/"暂无绑定教练"；我的预约快捷入口显示引导文案；套餐/场馆入口仍显示 |
| 加载中 | 各卡片区域显示骨架屏（浅灰 #F5F5F5 占位）；轮播区显示渐变占位 |
| 错误状态 | 中央错误插画 + "加载失败，点击重试" + 按钮；局部错误可仅刷新该区域 |
| 成功状态 | 按 §4 矩阵完整显示；管理端配置内容实时生效 |
