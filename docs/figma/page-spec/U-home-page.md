# 页面规格：U-首页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-001 / US-002 / US-003 / US-005 / US-017 / US-019 / US-020 / US-021 / US-029
> **对应 PRD**：§2 首页、§3.2 身份状态机、§4.1/§4.4/§4.5 套餐模型、§5.1 游客功能、§5.2.3 转化入口、§5.3.2 预约、§5.5.5 首页运营
> **版本**：v4.0 | **创建日期**：2026-08-02
> **重写原因**：v2.0 错误地把游客推荐教练区隐藏、错误取消套餐入口、错误把倒计时合并进通知栏；v3.0 完全对齐 US 原文；v4.0 结合管理端运营配置与教练数据，丰富首页展示逻辑

## 2. 用户身份与页面分区

### 2.1 三种身份（PRD §3.1）

| 身份 | 定义 | 首页差异 |
|------|------|---------|
| **游客** | 未登录 | 能浏览公开信息；不能购买；点击购买/预约时引导登录 |
| **注册用户** | 已注册，0 个 active 套餐 | 能购买体验课/正价套餐；无"继续上课"区 |
| **学员** | 已注册，≥1 个 active 套餐 | 首页聚焦"当前教练"的继续上课/加课/预约入口 |

### 2.2 首页八大信息区（管理端 + 教练数据 + US 聚合）

| 分区 | 数据来源 | 游客 | 注册用户 | 学员 |
|------|---------|:---:|:---:|:---:|
| 通知栏（公告/倒计时）| US-002 / US-003 / A-公告运营配置页 | ✅ | ✅ | ✅ |
| 场馆图片轮播 | A-场馆配置页（新增相册） | ✅ | ✅ | ✅ |
| 可配置 Banner 轮播 | A-公告运营配置页 · Banner Tab | 按可见身份 | 按可见身份 | 按可见身份 |
| 我的预约快捷入口 | US-029 / 教练排班数据 | 引导登录 | ✅ | ✅ |
| 首页卡片网格 | A-公告运营配置页 · 首页卡片 Tab | 按可见身份 | 按可见身份 | 按可见身份 |
| 教练区 | US-001 / C-教练实时状态 | 热门教练横向卡片 | 热门教练横向卡片 | 当前教练继续上课卡片 |
| 场馆状态/信息卡 | A-场馆配置页 | ✅ | ✅ | ✅ |
| 套餐/课程入口 | US-002 / US-017 | 查看全部套餐 + 场馆信息 | 同左 | 当前教练加课入口 |

### 3.2 通知栏 + 倒计时区

> 两者不可合并：通知栏是滚动的轻量公告；倒计时是高亮的独立时间组件。

## 6. 四态设计

| 状态 | 表现 |
|------|------|
| 空状态 | 通知栏/场馆图片/Banner/卡片网格按配置显隐；教练区显示"暂无热门教练"/"暂无绑定教练"；我的预约快捷入口显示引导文案；套餐/场馆入口仍显示 |
| 加载中 | 各卡片区域显示骨架屏占位；轮播区显示渐变占位 |
| 错误状态 | 中央错误插画 + "加载失败，点击重试" + 按钮；局部错误可仅刷新该区域 |
| 成功状态 | 按 §4 矩阵完整显示；管理端配置内容实时生效 |
