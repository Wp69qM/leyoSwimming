## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 业务含义 | 页面表现 |
| ------ | --------- | ---------- |
| -1 未提交 | 尚未提交 | **不可进入本页**；重定向至 C-教练端入驻资料填写页 |
| 0 待审核 | 已正式提交 | 本页默认场景；展示审核中状态、资料摘要、查看资料入口 |
| 1 已通过 | 已入驻 | **不可进入本页**；重定向至 C-教练端首页 |
| 2 已驳回 | 审核未通过 | **不可进入本页**；重定向至 C-教练端入驻资料填写页（带驳回原因） |
| 3 已离职 | 已离职 | **不可进入本页** |
| 4 申请离职中 | 功能仍可用 | **不可进入本页** |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
| ------ | ------ | ----------- |
| 草稿态 | coach.status = 0 且 submitted_at IS NULL | **不可进入本页**；应回到入驻资料页继续编辑 |
| 正式提交态 | coach.status = 0 且 submitted_at IS NOT NULL | 展示等待审核内容 |

## 5. 跳转动线

| 起点 | 行为 | 条件/说明 |
| ------ | ------ | ---------- |
| 进入本页 | → C-教练端入驻资料填写页 | status = -1 或草稿态 |
| 进入本页 | → C-教练端首页 | status = 1（已通过） |
| 进入本页 | → C-教练端入驻资料填写页 | status = 2（已驳回，带驳回原因） |
| 查看完整入驻资料 | 弹出资料详情浮层 | status = 0 正式提交态 |
| 客服/帮助入口 | 打开客服会话 / 帮助页面 | — |
| 审核通过（后续 US-011） | → C-教练端首页 | 状态由 0 → 1 时自动跳转 |

## 6. 四态设计

| 状态 | 表现 |
| ------ | ------ |
| 空状态 | 无数据摘要时展示"暂无入驻资料"提示，并提供"去填写"按钮（实际不会出现在 status=0 场景） |
| 加载中 | 审核状态区与摘要卡显示骨架屏；资料详情浮层打开时显示 loading |
| 错误状态 | 网络异常时中央错误插画 + "加载失败，点击重试" |
| 成功状态 | 按 §3 完整展示审核中状态、摘要卡、按钮与客服入口 |

## 7. 业务规则引用

| 规则 | 来源 | 在本页的体现 |
| ------ | ------ | ------------- |
| 提交审核后 status=0 且 submitted_at 写入 | US-010 §4.1 / §7.3 | 本页仅对正式提交态展示 |
| 草稿态 submitted_at = NULL 不进入审核队列 | US-010 §4.1 | status=0 草稿态重定向至填写页 |
| 已驳回 coach.status=2 需重新提交 | US-010 §4.2 | 重定向至填写页并展示驳回原因 |
| 等待审核页展示已提交资料摘要 | 字段设计 / US-010 §4.1 | §3.3 摘要卡 |
| 等待审核页可查看完整入驻资料 | 字段设计 / US-010 §6.9 | §3.5 资料详情浮层 |
| 客服/帮助入口 | 字段设计 / US-010 §4.1 | §3.4 客服入口 |
