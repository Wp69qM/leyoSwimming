## 3. 元素清单（自上而下）

### 3.1 TopBar / 侧边栏 / 面包屑

同 A-用户管理页，当前菜单为 "场馆配置"，面包屑为 "首页 / 场馆运营 / 场馆配置"。

### 3.2 场馆基础信息卡

| 字段 | 值 |
|------|-----|
| 容器 | 卡片 |
| 标题 | "场馆基础信息" |
| 场馆名称 | 输入框，中输入 |
| 场馆地址 | 输入框，长输入 |
| 导航坐标 | 经纬度输入 + 地图选点按钮 |
| 开业年限 | 数字输入框，单位 "年" |
| 泳池状态 | 下拉：开放中 / 维护中 / 换水中 |
| 场馆电话 | 输入框 |
| 营业时间 | 时间范围选择器 |
| 场馆相册 | 图片上传组件，建议 3-5 张，支持拖拽排序 / 删除 / 替换；单图限制 5MB，格式 jpg/png/webp |

## 6. 四态设计

### 6.1 空状态

- 表单初始为空，placeholder 提示输入。

### 6.2 加载中

- 表单区显示骨架屏，保存按钮显示 Loading。

### 6.3 错误状态

- 保存失败：顶部 `el-message` "保存失败，请稍后重试"。

### 6.4 成功状态

- 保存成功：Toast "保存成功"，表单显示最新配置。

## 7. 业务规则引用

| 规则 | 来源 | 在本页的体现 |
