## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
| ------ | :-------: | --------- |
| 待审核（0） | 否 | 重定向至 `C-入驻提交成功页` |
| 已通过（1） | 是 | 完整代约功能 |
| 已驳回（2） | 否 | 重定向至 `C-入驻资料填写页` |
| 已离职（3） | 否 | 功能锁定，重定向至 `C-教练中心页` |
| 申请离职中（4） | 是 | 可代约，但需遵守 <24h 学员确认规则 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
| ------ | ------ | ----------- |
| 学员有 active 套餐 | 存在可消耗课时 | 允许代约 |
| 学员无 active 套餐 | 无可消耗课时 | 提示先购买套餐，不可代约 |
| 目标时段可约 | 教练开放且无冲突 | 可选中 |
| 目标时段已约/请假/过去 | 不可选择 | 对应格子禁用 |
| ≥24h 代约 | 小时 | 教练直接创建预约 |
| <24h 代约 | 小时 | 需学员在系统内确认 |

## 6. 四态设计

| 状态 | 触发 | 表现 |
| ------ | ------ | ------ |
| 空状态 | 选中日期无可约时段 | 网格区显示「当日暂无可约时段」插画 |
| 加载中 | 拉取学员/排班数据 | 学员卡 + 日期栏 + 网格骨架屏 |
| 错误状态 | 网络/服务异常 | 中央错误插画 + 「加载失败，点击重试」 |
| 成功状态 | 代约成功 | Toast「代约成功」并跳转 `C-预约管理页` |
