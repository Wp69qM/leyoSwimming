# 页面规格：C-个人主页编辑页

> **性质**：Figma 设计交付的唯一指令源。
> **归属 US**：US-012 / US-038
> **对应 PRD**：§5.4.1 入驻与资料、§5.4.8 重新入驻
> **版本**：v1.0 | **创建日期**：2026-08-02

---

## 1. 页面基础

| 字段 | 值 |
|------|-----|
| 页面名（中文） | 个人主页编辑页 |
| 页面名（Frame） | `C-个人主页编辑页` |
| 平台 | 微信小程序 - 教练端 |
| 画板尺寸 | 375 × 812 px |
| 页面背景 | `#F5F7FA` |
| 是否含 TabBar | 否 |
| 是否含 NavBar | **是**（白色背景，标题 "个人主页"，右侧「分享」icon） |
| 返回按钮 | 是 |

---

## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 已通过（1） | 是 | 完整编辑功能 |
| 申请离职中（4） | 是 | 可编辑，但隐藏「分享主页」入口 |
| 其他状态 | 否 | 重定向至对应状态页 |

---

## 3. 元素清单（自上而下）

### 3.1 预览头图区

| 字段 | 值 |
|------|-----|
| 容器 | 375×180，背景 `gradient-water` |
| 头像 | 80×80 圆形，居中，白边 3px |
| 姓名 | 20px Bold 白色，居中 |
| 任教年限 | 14px 白色 80%，居中 |
| 实时状态标签 | pill，居中下方，按状态色 |

### 3.2 可编辑资料区

| 字段 | 值 |
|------|-----|
| 任教年限 | 数字输入，1-50 年 |
| 个人简介 | 多行文本，500 字，实时字数 |
| 证书照片 | 横向滑动，最多 5 张，可删除/排序 |
| 微信二维码 | 上传区，1 张 |
| 手机号 | 可编辑，带格式校验 |
| 总学员数/总课时数 | 只读展示（系统统计） |

### 3.3 参考单价入口

| 字段 | 值 |
|------|-----|
| 容器 | 343×56，白底圆角 12，shadow-card |
| 左侧 | "参考单价" 14px Bold |
| 右侧 | 当前价格 + "元/节" + 箭头 |
| 点击 | → C-参考单价设置页 |

### 3.4 底部保存按钮

| 字段 | 值 |
|------|-----|
| 按钮 | 343×48，#1890FF 渐变，圆角 8，白色文字 "保存" |
| 位置 | 底部 32px |

---

## 4. 显示规则总表

| 元素 | 已通过（1） | 申请离职中（4） |
|------|:-----------:|:----------------:|
| 预览头图 | ✅ | ✅ |
| 可编辑资料 | ✅ | ✅ |
| 参考单价入口 | ✅ | ✅ |
| 右上角分享 | ✅ | ❌ |
| 保存按钮 | ✅ | ✅ |

---

## 5. 跳转动线

| 起点 | 行为 |
|------|------|
| 参考单价入口 | → C-参考单价设置页 |
| 右上角分享 | → C-教练主页分享页 / 生成海报 |
| 保存成功 | 返回 C-教练中心页 |

---

## 6. 四态设计

| 状态 | 表现 |
|------|------|
| 空状态 | 证书区显示占位 |
| 加载中 | 表单骨架屏 |
| 错误状态 | 字段校验错误 |
| 成功状态 | 保存成功 Toast |
