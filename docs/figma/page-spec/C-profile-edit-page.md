## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
| ------ | :-------: | --------- |
| 已通过（1） | 是 | 完整编辑功能 |
| 申请离职中（4） | 是 | 可编辑，但隐藏「分享主页」入口 |
| 其他状态 | 否 | 重定向至对应状态页 |

## 3. 元素清单（自上而下）

### 3.1 预览头图区

| 字段 | 值 |
| ------ | ----- |
| 容器 | — |
| 个人形象照 | — |
| 姓名 | — |
| 任教年限 | — |
| 实时状态标签 | 按 |

### 3.2 资料分组

#### 3.2.1 形象展示

| 字段 | 组件/规则 | 可编辑 |
| ------ | ---------- | -------- |
| 个人形象照 | 预览；点击上传区替换，JPG/PNG ≤5MB，1 张 | 是 |
| 姓名/昵称 | 输入框，1-32 字符 | 是 |
| 任教年限 | 数字输入，0-60 年 | 是 |
| 实时状态标签 | 标签，按 | 否（只读） |

#### 3.2.2 基础信息

| 字段 | 组件/规则 | 可编辑 |
| ------ | ---------- | -------- |
| 性别 | 单选，男 / 女 | 是 |
| 年龄 | 数字输入，18-80 岁整数 | 是 |
| 邮箱 | 输入框，有效邮箱格式，≤128 字符 | 是 |
| 手机号 | 只读文本，微信授权手机号脱敏展示 | 否 |
| 微信二维码 | 上传区 ，JPG/PNG ≤5MB，1 张；点击可预览/替换 | 是 |

#### 3.2.3 实名与资质（仅展示）

| 字段 | 组件/规则 | 可编辑 |
| ------ | ---------- | -------- |
| 身份证号 | 脱敏只读文本 | 否 |
| 身份证正面照 | 预览，点击放大 | 否 |
| 身份证反面照 | 预览，点击放大 | 否 |
| 教练资格证 | 横向排列，点击放大 | 否 |
| 健康证 | 预览，点击放大 | 否 |
| 重新提交入口 | 文字链「修改实名与资质需重新提交审核」→ US-010 入驻资料页 | — |

#### 3.2.4 教学履历

| 字段 | 组件/规则 | 可编辑 |
| ------ | ---------- | -------- |
| 总学员数 | 只读数字，系统统计 | 否 |
| 总课时数 | 只读数字，系统统计 | 否 |
| 擅长泳姿 | 多选标签，蛙泳/自由泳/仰泳/蝶泳 | 是 |
| 个人简介 | 多行文本，10-500 字符，实时字数 | 是 |

#### 3.2.5 服务设置

| 字段 | 组件/规则 | 可编辑 |
| ------ | ---------- | -------- |
| 参考单价 | 入口行，显示当前价格 + "元/节"；点击 → C-参考单价设置页 | 是（在独立页编辑） |

### 3.3 底部保存按钮

| 字段 | 值 |
| ------ | ----- |
| 按钮 | "保存" |

## 5. 跳转动线

| 起点 | 行为 |
| ------ | ------ |
| 参考单价入口 | → C-参考单价设置页 |
