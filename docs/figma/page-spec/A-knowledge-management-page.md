## 6. 四态设计

### 6.1 空状态

- 表格空：空插画 + "暂无知识库文档" + 「新增文档」按钮

### 6.2 加载中

- 表格骨架屏

### 6.3 错误状态

- 错误提示 Message
- 或错误占位页：插画 + 错误信息 + 重试按钮

### 6.4 成功状态

- 操作成功 Message / Toast
- 禁用/启用/删除后列表状态更新
