## 2. 状态维度

| 维度 | 状态枚举 | 弹窗影响 |
|------|---------|---------|
| 当前登录管理员角色 | `super_admin` / `admin` | 底部「编辑」按钮显隐 |
| 目标管理员角色 | `super_admin` / `admin` | 角色 Tag 颜色 |
| 目标账号状态 | 启用 / 禁用 | 状态 Tag 颜色 |
| 最近登录时间 | 有 / 无 | 显示具体时间或「从未登录」 |

***

## 3. 元素清单（自上而下）

### 3.1 标题栏

| 字段 | 值 |
|------|-----|
| 容器 | 顶部固定，高度 56 px，白底，底部 1px #E4E7ED |
| 标题 | 18px Medium #262626，文字「管理员详情」 |
| 关闭按钮 | 右上角 24×24 px 关闭 icon，#8C8C8C |

### 3.2 信息卡

| 字段 | 值 |
|------|-----|
| 容器 | 白底，内边距 24 px，底部 margin 16 px |
| 管理员姓名 | 20px Medium #262626 |
| 管理员 ID | 12px Regular #8C8C8C |
| 角色标签 | Tag：超级管理员 #1890FF / 普通管理员 #52C41A |
| 状态标签 | Tag：启用 #52C41A / 禁用 #FF4D4F |

### 3.3 基础信息分组

| 字段 | 说明 |
|------|------|
| 管理员 ID | 系统分配 |
| 姓名 | `name` |
| 登录账号 | `username` |
| 角色 | 超级管理员 / 普通管理员 |
| 状态 | 启用 / 禁用 |
| 最近登录时间 | YYYY-MM-DD HH:mm:ss 或「从未登录」 |
| 创建时间 | YYYY-MM-DD HH:mm:ss |
| 更新时间 | YYYY-MM-DD HH:mm:ss |

### 3.4 操作日志分组（最近 5 条）

| 字段 | 说明 |
|------|------|
| 操作时间 | YYYY-MM-DD HH:mm:ss |
| 操作人 | 操作者姓名 / 系统 |
| 操作类型 | 创建 / 编辑 / 禁用 / 启用 / 删除 / 重置密码 |
| 变更摘要 | 简短描述，如「角色由 admin 变更为 super_admin」 |

### 3.5 底部操作栏

| 字段 | 值 |
|------|-----|
| 容器 | 弹窗底部固定，高度 56 px，白底，顶部 1px #E4E7ED，内边距 0 24 px |
| 左侧按钮 | 关闭（默认按钮） |
| 右侧按钮 | 编辑资料（主按钮），仅 `super_admin` 查看他人账号时显示；查看自身账号或 `admin` 登录时不显示 |

***

## 4. 显示规则总表

| 元素/分组 | super_admin 登录 | admin 登录 |
|----------|:----------------:|:----------:|
| 基础信息分组 | ✅ | ✅ |
| 操作日志分组 | ✅ | ✅（仅展示与自身相关的日志） |
| 编辑资料按钮 | ✅ | ❌ |

> 具体以接口返回的 `allowed_actions` 为准。
