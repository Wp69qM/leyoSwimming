## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
| ------ | :-------: | --------- |
| 待审核（0） | 否 | 重定向至 `C-入驻提交成功页` |
| 已通过（1） | 是 | 完整记录列表 |
| 已驳回（2） | 否 | 重定向至 `C-入驻资料填写页` |
| 已离职（3） | 否 | 功能锁定，重定向至 `C-教练中心页` |
| 申请离职中（4） | 是 | 可查看与新建请假 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
| ------ | ------ | ----------- |
| 有待审批请假 | 已提交未审批 | 显示待审批提示卡 |
| 无请假记录 | 从未提交过请假 | 显示空状态 |
| 有历史记录 | 存在已通过/已驳回记录 | 按筛选展示列表 |
| 请假审批通过 | 管理员已批准 | 卡片显示已通过标签，并展示受影响课程数 |

## 6. 四态设计

| 状态 | 触发 | 表现 |
| ------ | ------ | ------ |
| 空状态 | 无请假记录 | 中央游泳主题插画 + 「暂无请假记录」+ 「去请假」按钮 |
| 加载中 | 拉取请假记录 | 列表卡片骨架屏 |
| 错误状态 | 网络/服务异常 | 中央错误插画 + 「加载失败，点击重试」 |
| 成功状态 | 数据正常返回 | 按 §4 矩阵完整显示 |
