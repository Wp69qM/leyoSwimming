# 页面规格：A-请假审批页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时必须按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-036 / US-044
> **对应 PRD**：§5.5.2 教练排班与预约释放管理、§6.6 请假处理
> **版本**：v1.0 | **创建日期**：2026-08-02

## 3. 元素清单（自上而下）

### 3.1 TopBar / 侧边栏 / 面包屑

同 A-排班管理页，当前菜单为 "请假审批"，面包屑为 "首页 / 课程预约 / 请假审批"。

### 3.2 待办摘要条

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 16 px，margin-bottom 16 px，背景 `#E6F7FF` |
| 内容 | "待审批：{N} 条 · 今日请假：{M} 条"，14px Regular |

### 3.3 筛选区

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 16 px，margin-bottom 16 px |
| 请假状态下拉 | 宽度 160 px：全部 / 待审批 / 已通过 / 已驳回 |
| 请假类型下拉 | 宽度 160 px：全部 / 事假 / 病假 / 其他 |
| 请假时间段 | 双日期选择器 |
| 关键词搜索 | 宽度 240 px，placeholder "教练姓名" |
| 查询按钮 | 主按钮 #1890FF |
| 重置按钮 | 默认按钮 |

### 3.4 表格区

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px |
| 表头 | 14px Medium #262626，背景 #F5F7FA，高 48 px |
| 行高 | 56 px |
| 行分隔 | 1 px #F0F2F5 |
| 分页 | 底部居中，默认 20 条/页 |

表格列：

| 列名 | 宽度 | 对齐 | 说明 |
|------|------|------|------|
| 请假单号 | 120 px | 左对齐 | — |
| 教练 | 120 px | 左对齐 | 姓名，可跳转 |
| 请假时间段 | 200 px | 左对齐 | YYYY-MM-DD HH:mm ~ HH:mm |
| 类型 | 100 px | 居中 | 事假/病假/其他 Tag |
| 原因 | 200 px | 左对齐 | 原因摘要 |
| 状态 | 100 px | 居中 | 待审批 #1890FF / 已通过 #52C41A / 已驳回 #FF4D4F |
| 操作 | ≥160 px | 居中 | 查看 / 同意 / 拒绝 |

### 3.5 操作按钮

| 字段 | 值 |
|------|-----|
| 查看 | 蓝色文字按钮，所有状态显示 |
| 同意 | 蓝色文字按钮，仅待审批显示 |
| 拒绝 | 红色文字按钮，仅待审批显示 |

## 6. 四态设计

### 6.1 空状态

- 表格空：空插画 + "暂无请假申请" + 「刷新」按钮。

### 6.2 加载中

- 表格骨架屏 3 行。

### 6.3 错误状态

- 表格区域 `el-empty` "加载失败" + 「重试」按钮。

### 6.4 成功状态

- 审批操作后 Toast "操作成功" 并刷新列表。
