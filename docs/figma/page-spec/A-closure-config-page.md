## 6. 四态设计

### 6.1 空状态

- 列表为空时显示 "暂无闭馆/换水安排"。

### 6.2 加载中

- 列表显示骨架屏。

### 6.3 错误状态

- 保存失败：顶部 `el-message` "保存失败，请稍后重试"。

### 6.4 成功状态

- 新增/编辑/删除成功后 Toast "操作成功" 并刷新列表。
