## 2. 状态维度

| 维度 | 状态枚举 | 页面影响 |

## 3. 元素清单（自上而下）

### 3.1 TopBar / 侧边栏 / 面包屑

同 A-退款审批页，面包屑当前页为 "审批详情"。

### 3.2 订单信息卡

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 24 px，margin-bottom 16 px |
| 订单号 | 20px Medium #262626 |
| 退款类型 Tag | 正常退款 / 争议申诉 |
| 审批状态 Tag | 待审批 / 处理中 / 已批准 / 已驳回 |

| 金额信息 | 实付金额、申请退款金额、可退金额 |

### 3.3 退款金额计算卡

| 字段 | 值 |
|------|-----|

| 标题 | "退款金额计算"，16px Medium #262626 |
| 计算明细 | 单价/课时 × (reserved + available) |
| 已消耗课时 | 不参与退款，灰色标注 |
| 退费比例 | 教练离职 100% / 其他按规则 |
| 最终可退金额 | 28px Bold #262626 |

### 3.4 申请原因与证明材料

| 字段 | 值 |
|------|-----|

### 3.6 底部固定审批操作栏

| 字段 | 值 |
|------|-----|
| 位置 | 固定页面底部 |

| 右侧 | 审批意见输入框（宽度 400 px，必填）+ 驳回按钮（危险）+ 批准按钮（主按钮） |

## 6. 四态设计

### 6.1 空状态

- 证明材料缺失时显示 "未上传证明材料"。

### 6.2 加载中

- 页面级 `el-loading` 遮罩。

### 6.3 错误状态

- 错误占位页：插画 + "退款申请不存在" + 「返回列表」按钮。

### 6.4 成功状态

- 批准后 Toast "已批准，进入退款处理中"；驳回后 Toast "已驳回"；均返回列表。
