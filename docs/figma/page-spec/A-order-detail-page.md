# 页面规格：A-订单详情弹窗

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时必须按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-026 / US-043 / US-046 / US-028
> **对应 PRD**：§5.5.3 套餐与订单、§6.2 订单状态机
> **版本**：v1.3 | **创建日期**：2026-08-02

***

## 3. 元素清单（自上而下）

### 3.1 弹窗标题栏

| 字段 | 值 |
|------|-----|
| 标题 | "订单详情" |
| 关闭按钮 | `×`，点击关闭弹窗 |
| 底部分隔线 | — |

### 3.2 订单基本信息组

> 来源：US-026 / US-046；按信息项自然分组展示，不再拆分为多个卡片。

| 字段 | 值 |
|------|-----|
| 容器 | 纵向分组，无额外卡片，标题 "订单信息" |
| 订单号 | — |
| 类型标签 | Tag：购买订单 / 退款订单 |
| 状态标签 | Tag：订单状态，位于类型标签右侧 |
| 用户 | 用户昵称（可跳转 → A-用户详情页） |
| 教练 | 教练姓名（可跳转 → A-教练详情页） |
| 课程类型 | 教学类型 |
| 课时数 | 关联套餐总课时 |
| 创建时间 | 订单创建时间 |

### 3.3 金额信息组

> 来源：US-046；购买订单与退款订单字段不同。

| 字段 | 值 |
|------|-----|
| 容器 | 纵向分组，标题 "金额信息" |
| 购买订单字段 | 应付金额、实付金额、优惠金额 |
| 退款订单字段 | 可退金额、申请退款金额、调整后退款金额（审批中可编辑） |

### 3.4 支付/退款信息组

> 来源：US-026 / US-046 / US-028；按订单类型展示不同字段。

| 字段 | 值 |
|------|-----|
| 容器 | 纵向分组，标题 "支付信息" / "退款信息" |
| 购买订单字段 | 支付方式、支付时间、第三方流水号、支付状态 |
| 退款订单字段 | 原购买订单号（可跳转 → A-订单详情弹窗）、退款原因、驳回原因（如有）、Mock 渠道流水号、退款阶段 Tag |

### 3.5 关联套餐组

> 来源：US-043 / US-046；展示订单对应的 package 实例快照。

| 字段 | 值 |
|------|-----|
| 容器 | 纵向分组，标题 "关联套餐" |
| 套餐编号 | package.package_no |
| 状态 | package.status 中文标签 |
| 总课时 | total_hours |
| 剩余课时 | available |
| 到期时间 | expire_at |
| 操作 | 「查看套餐」→ A-套餐详情页 |

### 3.6 底部操作区

| 字段 | 值 |
|------|-----|
| 容器 | 弹窗 |
| 左侧按钮 | 「返回」（默认按钮），点击关闭弹窗 |
| 购买订单右侧按钮 | 「取消」（仅 status = 待支付 时展示，危险按钮） |
| 退款订单右侧按钮 | 「通过」/「驳回」（仅 status = 退款审批中 时展示） |

## 6. 四态设计

### 6.1 空状态

- 支付信息/退款信息/关联套餐缺失时显示 "暂无数据"。

### 6.2 加载中

- 弹窗内局部 `el-loading` 遮罩，不影响底层列表页。

### 6.3 错误状态

- 订单不存在：弹窗内展示错误占位（插画 + "订单不存在" + 「关闭」按钮）。

### 6.4 成功状态

- 订单基本信息、金额信息、支付/退款信息、关联套餐分组正常展示。

## 7. 业务规则引用

| 规则 | 来源 | 在本页的体现 |
|------|------|-------------|
| 订单状态机 | PRD §6.2 / 全局原则 §3.3 | 状态标签 |
| 订单与退款订单为独立记录 | US-046 | 类型标签、退款信息组 |
| 两阶段退款时序 | PRD §6.2.1 / US-028 | 退款阶段 Tag |
| 订单支付成功后立即生效 | PRD §5.5.3 | 关联套餐组 |
| 退款金额计算与管理员修改 | US-046 / US-028 | 可退金额展示与金额输入框 |
| 驳回退款后 package 自动恢复 active | US-028 | 驳回操作反馈 |
| 退款订单可由套餐管理发起 | US-043 | 退款信息组展示来源与关联套餐 |
