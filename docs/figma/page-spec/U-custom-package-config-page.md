## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | 否 | 购买入口前置引导登录，不会直接进入本页 |
| 注册用户 | 是 | 未绑定其他教练且同意协议时可正常配置与提交 |
| 学员 | 是 | 同注册用户；若已持有其他教练 active 套餐，则显示单教练冲突提示并禁用提交 |
| 教练 | 否 | — |
| 管理员 | 否 | — |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| 已选教练入口 | 从 `U-套餐详情页`（自定义课时）点击「立即购买」进入，已携带选中的 coach_id | 顶部展示已选教练横向自适应卡，仅作展示与跳转，不可切换教练 |
| 已绑定其他教练 | 用户名下已有其他教练的 active 套餐 | 展示单教练冲突提示条，底部提交按钮禁用 |
| 教练不可用 | coach.status ≠ 1 | 展示教练不可用提示条，底部提交按钮禁用 |
| 自定义规则未配置/模板下架 | `custom_package_config` 不存在或对应模板 status ≠ 'active' | 展示异常提示条，禁用提交 |

## 3. 元素清单（自上而下）

> **设计原则**：
> 1. **元素清单只描述「有什么元素」以及「元素之间的交互与状态」，不描述具体样式细节。** 颜色、宽度、高度、边距、背景、圆角、字体、字号、阴影等视觉参数**禁止**出现在 page-spec 中，避免对后续 Figma 渲染和 Calicat 设计稿还原造成干扰。
> 2. 视觉样式以 Calicat 设计稿为唯一最高优先级来源；page-spec 仅对交互逻辑、业务规则、状态流转负责。
> 3. 每个元素必须说明：名称、作用、显示条件、交互行为、关联业务规则。

### 3.1 状态栏 + NavBar

| 字段 | 值 |
|------|-----|
| 名称 | 状态栏 + NavBar |
| 作用 | 系统状态栏与页面导航；显示页面标题「自定义套餐」及返回入口 |
| 显示条件 | 所有身份统一显示 |
| 点击行为 | 返回按钮 → 上一页（套餐详情页 / 套餐列表页 / 教练详情页） |
| 关联业务规则 | PRD §13.3 页面导航；US-020 §6 购买流程 |

### 3.2 已选教练区

| 字段 | 值 |
|------|-----|
| 名称 | 已选教练区 |
| 作用 | 展示从 `U-套餐详情页`（自定义课时）带入的已选教练快照，不可在本页切换教练 |
| 显示条件 | 始终显示；由上一页携带 `coach_id`，展示横向自适应卡（头像、姓名、评分、擅长泳姿、教龄、总学员数、参考单价） |
| 点击行为 | 点击横向自适应卡 → `U-教练详情页`（携带 coach_id） |
| 关联业务规则 | US-020 §5 / §6.3 / §6.4；US-019 §4.1；PRD §5.3.1 教练资料展示；PRD §3.5 单教练约束 |

### 3.3 课时选择区

| 字段 | 值 |
|------|-----|
| 名称 | 课时选择区 |
| 作用 | 选择购买课时数量 |
| 显示条件 | 始终显示 |
| 点击行为 | 快捷选项 4 / 8 / 12 / 20 单选；选中后更新价格明细；<br>「自定义」选项支持输入任意整数，需在 `custom_package_config.min_hours` ~ `max_hours` 范围内；越界时输入框异常反馈、禁用提交并提示允许范围。 |
| 关联业务规则 | US-020 §6.3 / §6.4 / §6.5；US-045 §4.2 / §6.3 |

### 3.4 有效期选择区

| 字段 | 值 |
|------|-----|
| 名称 | 有效期选择区 |
| 作用 | 选择套餐有效期 |
| 显示条件 | 始终显示 |
| 点击行为 | 选项 30 / 60 / 90 / 180 天单选；默认选中项由 `custom_package_config.default_valid_days` 决定；若默认值不在四档中，按最接近档位默认或提供自定义输入。 |
| 关联业务规则 | US-020 §6.3 / §6.4；US-045 §4.2 |

### 3.5 泳姿多选区

| 字段 | 值 |
|------|-----|
| 名称 | 泳姿多选区 |
| 作用 | 选择本次购买的泳姿 |
| 显示条件 | 始终显示；选项默认取教练/模板支持的全部泳姿 |
| 点击行为 | 多选切换；至少保留 1 项选中，全部取消时提示「至少选择 1 项泳姿」并禁用提交。 |
| 关联业务规则 | US-020 §6.3 / §6.4；US-045 §14.3 泳姿字段说明 |

### 3.6 价格明细区

| 字段 | 值 |
|------|-----|
| 名称 | 价格明细区 |
| 作用 | 实时展示所选课时与教练参考单价计算出的应付金额 |
| 显示条件 | 教练已选且课时在有效范围内时完整显示；教练未选或课时越界时显示占位或提示 |
| 点击行为 | 无需点击，随教练/课时选择实时计算：商品总价 = 课时数 × 教练参考单价；应付总额 = 商品总价（无优惠时）。 |
| 关联业务规则 | PRD §5.5.3；US-020 §6.3 / §6.4；US-045 §4.2 |

### 3.7 购买须知与协议勾选区

| 字段 | 值 |
|------|-----|
| 名称 | 购买须知与协议勾选区 |
| 作用 | 展示购买须知与协议，要求用户勾选同意后方可提交 |
| 显示条件 | 登录用户始终显示 |
| 点击行为 | 默认未勾选；点击协议名称展开协议全文弹窗/WebView；<br>未勾选全部协议时点击提交，toast 提示「请先阅读并同意协议」并滚动定位到勾选区；<br>正价课需同时勾选《用户须知》《健康承诺书》《免责协议》。 |
| 关联业务规则 | PRD §6.9；US-020 §4.1 / §6.6；US-045 §6 |

### 3.8 未成年人监护人区

| 字段 | 值 |
|------|-----|
| 名称 | 未成年人监护人区 |
| 作用 | 未成年用户购买正价课时收集监护人手机号（MVP 阶段不触发短信验证） |
| 显示条件 | 仅用户年龄 < 18 岁且购买正价课时显示；已填写监护人手机号后隐藏 |
| 点击行为 | 输入监护人手机号；未填写时点击提交，提示「请填写监护人手机号」。 |
| 关联业务规则 | PRD §6.9；US-020 §6.7 |

> **MVP 范围**：仅需填写监护人手机号，不触发短信验证；短信验证为 MVP 后增强项。

### 3.9 业务警告条

| 字段 | 值 |
|------|-----|
| 名称 | 业务警告条 |
| 作用 | 展示阻断购买的业务异常 |
| 显示条件 | **单教练冲突提示条**：用户已持有其他教练 active 套餐时显示；<br>**教练不可用提示条**：coach.status ≠ 1 时显示；<br>**模板未上架/规则未配置提示条**：对应 `package_template` status ≠ 'active' 或 `custom_package_config` 不存在时显示。 |
| 点击行为 | 「更换教练」→ `U-换教练流程页`（US-022）；提示条出现时底部提交按钮禁用。 |
| 关联业务规则 | PRD §3.5 / §4.4；US-020 §6.8 / §6.9 / §6.10；US-045 §4.2 / §5.2 |

### 3.10 底部固定提交栏

| 字段 | 值 |
|------|-----|
| 名称 | 底部固定提交栏 |
| 作用 | 展示应付总额并提交订单 |
| 显示条件 | 正常状态显示；课时越界 / 未签协议 / 未成年未填写监护人手机号 / 单教练冲突 / 教练不可用 / 模板下架时按钮禁用 |
| 点击行为 | 点击「提交订单」→ 前端校验协议、课时范围、泳姿、教练状态、单教练约束 → 调用 `/api/orders/formal`（携带 coach_id、hours、valid_days、stroke_ids、agreement_version 等）→ 创建 order.status = 待支付，course_type = 1 → 跳转 `U-支付页`（携带 order_id）。 |
| 关联业务规则 | PRD §6.2；US-020 §4.1 / §6.3 / §6.4 / §6.5 / §6.6 / §6.7 / §6.8；US-045 |

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| 空状态 | 无教练/无规则数据传入（如 deep link 缺少参数） | 中央 Empty 组件：插画 + 「暂无配置信息」+ 「返回首页」按钮（→ `U-首页`） |
| 加载中 | 首次进入 / 拉取教练列表或配置规则 / 提交订单中 | 内容区显示骨架屏；提交按钮显示 loading 态 |
| 错误状态 | 网络断开 / 接口 5xx / 业务 4xx（如模板下架、课时越界） | 中央错误插画 + 「加载失败，点击重试」+ Primary「重新加载」按钮；模板下架时显示「该套餐已下架，请重新选择」 |
| 成功状态 | 数据正常返回 | 按 §4 显示规则矩阵完整展示；提交成功后跳转支付页 |

## 14. 页面级设计决策

### 14.1 教练选择区按入口区分形态

- **背景**：自定义套餐可从套餐列表、套餐详情页或教练详情页进入。不同入口下教练是否已确定、是否支持切换对页面布局与交互影响较大。
- **选项**：
  - A. 所有入口统一使用横向滚动竖向教练卡片，已选教练也需高亮显示；优点：形态统一；缺点：从教练详情进入时仍让用户重复选择，增加操作成本。
  - B. 全局入口使用竖向卡片列表供选择，单教练/教练详情入口使用横向自适应卡锁定展示；优点：减少已确定场景下的选择成本；缺点：需前端根据 source 参数切换布局。
- **结论**：选择 B。全局入口展示可切换的竖向卡片列表；单教练入口与教练详情入口展示锁定的横向自适应卡，点击仅可进入教练详情。
- **影响范围**：自定义套餐配置页（US-020）、套餐详情页教练卡片区（US-019）。

### 14.2 自定义课时采用快捷选项 + 自定义输入

- **背景**：US-045 允许后台配置自定义课时范围（min_hours / max_hours），学员购买的课时数差异大；全部用步进器效率低，全部用输入框又缺少常用推荐。
- **选项**：
  - A. 仅展示输入框，提交时校验范围；错误后置，体验差。
  - B. 提供 4/8/12/20 快捷选项 + 自定义输入，越界时实时禁用提交并提示；兼顾效率与灵活性。
  - C. 仅提供 4/8/12/20 固定选项；无法覆盖所有业务允许范围。
- **结论**：选择 B。快捷选项满足常见需求，自定义输入覆盖剩余合法范围，越界实时阻断提交。
- **影响范围**：自定义套餐配置页（US-020）、自定义课时输入组件。
