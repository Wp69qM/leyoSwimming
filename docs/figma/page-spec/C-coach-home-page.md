## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 未提交入驻资料（-1） | 否 | 重定向至 C-教练端入驻资料填写页 |
| 待审核（0） | 否 | 重定向至 C-教练端等待审核页 |
| 已通过（1） | 是 | 完整功能首页 |
| 已驳回（2） | 否 | 重定向至 C-教练端入驻资料填写页（带驳回原因，即重新提交入驻页） |
| 已离职（3） | 否 | 重定向至 C-教练中心页 |
| 申请离职中（4） | 是 | 功能完整，顶部增加「离职申请中」隐私提示条（仅自己可见） |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| 实时状态 | 空闲中/上课中/休息中/已下班/请假中 | 顶部状态区展示，请假中锁定切换入口 |
| 今日有课/无课 | 今日是否存在 booking | 今日课程区展示内容不同 |
| 请假中 | 审批通过的请假时段 | 快捷操作区「请假申请」置灰或隐藏 |

### 3.3 数据概览卡（y=168）

### 3.4 快捷操作区（y=272）

| 字段 | 值 |
|------|-----|
| 区标题 | "快捷操作"，16px Bold `#262626`，x=16 |
| 4 个图标按钮 | 排班管理 / 代约 / 请假申请 / 分享主页 |
| 按钮尺寸 | 每个 72×72，圆角 12，白底，shadow-card |

### 3.5 今日课程时间轴（y=384）

> **来自 US-031 / US-033**：按时间顺序展示今日课程卡片。

| 字段 | 值 |
|------|-----|
| 区标题 | "今日课程"，16px Bold `#262626`，x=16，右侧"查看全部" → C-预约管理页 |
| 时间轴 | 左侧 2px 竖线 `#E8E8E8`，右侧卡片 |

## 4. 显示规则总表

| 元素 | 已通过（1） | 申请离职中（4） | 未提交/待审核/已驳回/已离职 |
|------|:-----------:|:----------------:|:----------------------------:|

| 数据概览卡 | ✅ | ✅ | 按 §2.1 重定向 |

| 今日课程 | ✅ | ✅ | 按 §2.1 重定向 |
| 请假通知区 | ✅ | ✅ | 按 §2.1 重定向 |
| 顶部离职提示条 | ❌ | ✅ 仅自己可见 | — |
