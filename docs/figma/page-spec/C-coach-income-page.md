## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
| ------ | :-------: | --------- |
| 待审核（0） | 否 | 无收入入口，重定向至 `C-入驻提交成功页` |
| 已通过（1） | 是 | 完整收入概览与明细 |
| 已驳回（2） | 否 | 重定向至 `C-入驻资料填写页` |
| 已离职（3） | 否 | 功能锁定，重定向至 `C-教练中心页` |
| 申请离职中（4） | 是 | 可查看收入，但隐藏提现操作 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
| ------ | ------ | ----------- |
| 有收入数据 | 存在结算/待结算/提现记录 | 展示明细列表 |
| 无收入数据 | 无任何收入记录 | 显示空状态 |
| 可提现金额 > 0 | 账户余额可提现 | 提现按钮可用 |
| 可提现金额 = 0 | 无可提现余额 | 提现按钮禁用 |

## 6. 四态设计

| 状态 | 触发 | 表现 |
| ------ | ------ | ------ |
| 空状态 | 无收入明细记录 | 中央游泳插画 + 「暂无收入明细」+ 「收入将在课程确认后结算」 |
| 加载中 | 进入页面拉取收入数据 | 概览卡、统计行、列表显示骨架屏 |
| 错误状态 | 网络/服务异常 | 中央错误插画 + 「加载失败，点击重试」 |
| 成功状态 | 数据正常返回 | 按 §4 矩阵完整显示 |

## 7. 业务规则引用

| 规则 | PRD / US 引用 | 在本页面应用 |
| ------ | -------------- | ------------- |
| 教练可在个人中心查看收入明细、提现申请 | PRD §5.4.6 | §3.2 / §3.5 / §3.6 |
| 收入结算模式由平台配置 | PRD §5.4.6 第 1 条 | §3.3 已结算/待结算拆分 |
| 教练可管理个人主页与资料 | US-012 §3 | §1 入口归属 |
| 申请离职中功能仍可用但限制资金操作 | `CROSS-BATCH-PRINCIPLES-COACH.md` §1.2 | §2.1 / §3.6 |
