## 2. 状态维度

| 维度 | 状态枚举 | 页面影响 |
|------|---------|---------|
| 上传方式 | 手动输入 / 文件上传 | 内容区显隐 |
| 内容类型 | text / markdown | 是否显示 Markdown 提示 |
| 表单校验 | 合法 / 非法 | 保存按钮是否可点击、错误提示 |

## 3. 元素清单（自上而下）

### 3.1 弹窗头部

| 元素 | 说明 |
|------|------|
| 标题 | "新增知识库文档" |

### 3.2 上传方式切换

| 元素 | 说明 |
|------|------|
| 手动输入 Tab | 默认选中 |
| 文件上传 Tab | 切换后显示文件上传区 |

### 3.3 表单区（手动输入）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 标题 | 文本输入 | 是 | 最多 200 字符 |
| 分类 | 下拉选择 | 是 | 安全 / 技巧 / 急救 / 其他 |
| 内容类型 | 单选 | 是 | text / markdown |
| 内容 | 多行文本域 | 是 | 无字数上限 |

### 3.4 表单区（文件上传）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|

| 分类 | 下拉选择 | 是 | 安全 / 技巧 / 急救 / 其他 |
| 文件上传 | 上传组件 | 是 | 仅支持 .txt / .md |

### 3.5 底部操作区

| 元素 | 说明 |
|------|------|

## 6. 四态设计

### 6.1 空状态

- 表单初始为空

### 6.2 加载中

- 保存按钮显示 loading

### 6.3 错误状态

- 必填项未填：字段下方红色提示
- 标题重复：全局错误提示
- 文件格式错误：上传组件错误提示

### 6.4 成功状态

- 弹窗关闭
- 父页面列表刷新
- 父页面显示"上传成功" Toast
