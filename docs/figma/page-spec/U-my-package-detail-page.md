## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | 否 | 未登录用户被拦截，引导至 `U-微信授权页` |
| 注册用户 | 是 | 登录后仅可查看自己名下的 package |
| 学员 | 是 | 登录后仅可查看自己名下的 package |
| 教练 | 否 | 用户端页面，教练不可见 |
| 管理员 | 否 | 用户端页面，管理员不可见 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| `active` | 套餐生效中，可预约/可申请退款 | 展示使用状态卡与退款入口（满足退款条件时） |
| `exhausted` | 课时已耗尽 | 展示使用状态卡；**不展示**退款入口 |
| `expired` | 套餐已过期 | 展示过期提示条；满足条件时展示退款入口 |
| `frozen(coach_resigned)` | 因教练离职被冻结 | 展示冻结提示条与"教练离职 100% 退款"提示；满足条件时展示退款入口 |
| `frozen(refund_pending)` | 退款审批中 | 展示冻结提示条；**不展示**再次申请退款入口 |
| `refunded` | 已退款完成 | 展示退款完成状态；**不展示**退款入口 |

## 3. 元素清单（自上而下）

> **设计原则**：
> 1. **元素清单只描述「有什么元素」以及「元素之间的交互与状态」，不描述具体样式细节。** 颜色、宽度、高度、边距、背景、圆角、字体、字号、阴影等视觉参数**禁止**出现在 page-spec 中，避免对后续 Figma 渲染和 Calicat 设计稿还原造成干扰。
> 2. 视觉样式以 Calicat 设计稿为唯一最高优先级来源；page-spec 仅对交互逻辑、业务规则、状态流转负责。
> 3. 每个元素必须说明：名称、作用、显示条件、交互行为、关联业务规则。
> 4. 快捷入口 ≠ TabBar 重复。
> 5. 同一业务入口在不同身份下形态可能不同，必须分身份定义。

### 3.1 状态栏 + NavBar

| 字段 | 值 |
|------|-----|
| 名称 | 状态栏 + NavBar |
| 作用 | 顶部系统状态栏与页面导航，承载页面标题与返回能力 |
| 显示条件 | 登录用户进入本页时始终显示；游客被整页拦截 |
| 点击行为 | 返回按钮 → `U-我的套餐页`（上一页） |
| 关联业务规则 | 全局设计规范 §2.5.6 NavBar |

### 3.2 套餐快照信息卡

| 字段 | 值 |
|------|-----|
| 名称 | 套餐快照信息卡 |
| 作用 | 展示 package 购买时快照字段，确保原 `package_template` 后续下架或修改不影响已购套餐展示 |
| 显示条件 | package 存在且属于当前登录用户时显示 |
| 点击行为 | 无 |
| 关联业务规则 | US-021 §4.1 / §5 #6 / §12；US-045 §5 #5 / §8.6 |

> **快照字段清单**：套餐名称、套餐模式（`standard` 正价套餐 / `experience` 体验课）、教练姓名、教学类型（一对一 / 一对二 / 一对三）、泳姿（`stroke_ids` 具体值，未配置时显示"全部泳姿"）、课时数、每节课时长、有效期、原价、实付价、退款规则、购买时间、到期时间。

### 3.3 套餐使用状态卡

| 字段 | 值 |
|------|-----|
| 名称 | 套餐使用状态卡 |
| 作用 | 展示套餐使用进度、有效期及状态提示条 |
| 显示条件 | package 存在且属于当前登录用户时显示 |
| 点击行为 | 无 |
| 关联业务规则 | US-021 §4.1 / §5 #1 / §6.1 / §6.4；PRD §3.4 / §4.4 |

> **内容项**：总课时、剩余课时、已用课时、有效期至；当 `package.status = expired` 时显示过期提示条；当 `package.status = frozen` 时显示冻结提示条。

### 3.4 申请退款入口

| 字段 | 值 |
|------|-----|
| 名称 | 申请退款入口 |
| 作用 | 满足退款条件时，引导学员进入退款申请流程 |
| 显示条件 | 同时满足：<br>1. `package.status ∈ {active, expired}` 或 (`package.status = frozen` 且 `frozen_reason = 'coach_resigned'`)；<br>2. package 快照 `refund_enabled = true`；<br>3. 未超过 package 快照 `refund_valid_days`；<br>4. `package.status ≠ exhausted` 且 `package.status ≠ refunded` 且不存在待处理退款订单。 |
| 点击行为 | → `U-退款申请页`（携带 `package_id`） |
| 关联业务规则 | US-021 §4.1 / §5 #4 / §5 #6 / §6.6 / §6.7；US-027 §2 / §3 / §4.2 / §6.4 / §12 |

### 3.5 教练离职全额退款提示

| 字段 | 值 |
|------|-----|
| 名称 | 教练离职全额退款提示 |
| 作用 | 当套餐因教练离职被冻结时，提示用户可申请 100% 全额退款 |
| 显示条件 | `package.status = frozen` 且 `frozen_reason = 'coach_resigned'` |
| 点击行为 | 无（纯提示，退款操作通过「申请退款入口」完成） |
| 关联业务规则 | US-027 §6.4 / §12；PRD §3.7 / §6.4.5 |

### 3.6 不存在 / 越权提示

| 字段 | 值 |
|------|-----|
| 名称 | 不存在 / 越权提示 |
| 作用 | 当用户请求不属于自己的 package_id 或 package 不存在时给出明确反馈 |
| 显示条件 | 接口返回 package 不存在或越权时 |
| 点击行为 | 「返回我的套餐」→ `U-我的套餐页` |
| 关联业务规则 | US-021 §4.3 / US-026 §8.1 |

## 5. 跳转动线矩阵

| 起点元素 | 游客 | 注册用户 | 学员 | 教练 | 管理员 |
|---------|------|---------|------|------|--------|
| 整页访问 | → `U-微信授权页` | 正常进入（校验所有权） | 正常进入（校验所有权） | — | — |
| 返回按钮 | — | → `U-我的套餐页` | → `U-我的套餐页` | — | — |
| 申请退款入口 | — | → `U-退款申请页`（携带 `package_id`） | → `U-退款申请页`（携带 `package_id`） | — | — |
| 不存在 / 越权提示「返回我的套餐」 | — | → `U-我的套餐页` | → `U-我的套餐页` | — | — |

> **"引导登录"**：游客访问本页时直接跳转 `U-微信授权页`，不在当前页弹登录框；登录成功后返回本页并刷新数据。

### 5.1 跳转参数说明

| 参数 | 类型 | 来源 | 用途 |
|------|------|------|------|
| package_id | string | 当前页面路由参数 / 接口返回 | 标识当前套餐，退款申请页据此查询 package 快照与可退金额 |
| source_page | string | 当前页面标识 | 用于登录成功后回跳，可选值：`my_package_detail` |

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 当前用户无任何 package 或请求的 package 不存在 | 隐藏套餐信息卡；居中展示空状态插画 + "暂无套餐" / "套餐不存在" 文案 + 返回按钮 |
| **加载中** | 首次进入 / 下拉刷新 | 显示骨架屏；NavBar 保持可见 |
| **错误状态** | 网络断开 / 接口 5xx / 越权访问 | 隐藏骨架屏；居中展示错误插画 + 文案 + "重新加载" / "返回我的套餐" 按钮 |
| **成功状态** | 数据正常返回 | 按 §4 显示规则矩阵完整展示套餐快照信息卡、使用状态卡、退款入口及状态提示条 |

## 7. 业务规则引用

| 规则 | PRD / US 引用 | 在本页面应用 |
|------|--------------|-------------|
| 学员查看自己的套餐详情与完整快照字段 | US-021 §4.1 / §5 #6 / §6.6 / §12 | §3.2 套餐快照信息卡 |
| 已购 package 保存模板快照，模板后续变更不影响历史展示 | US-045 §5 #5 / §8.6；US-021 §12 | §3.2 字段全部读取 package 实例快照 |
| 套餐状态机：active / exhausted / expired / refunded / frozen | PRD §3.4 / §4.4；US-021 §5 #2 | §2.2 关键业务状态、§3.3 提示条 |
| 教练离职后 package 冻结且学员端可见 | PRD §3.7；US-021 §5 #3 / §6.3 | §2.2 / §3.5 教练离职提示 |
| 退款触发场景：active / expired 或 frozen(coach_resigned)；exhausted 不可退款 | PRD §6.4.1；US-021 §5 #4 / §6.4 / §6.5 / §6.7；US-027 §2 / §4.2 | §3.4 申请退款入口显示条件 |
| 退款金额 = paid_amount × (total_hours - consumed_count) / total_hours × refund_ratio；教练离职 frozen 按 100% 退 | PRD §6.4.2 / §6.4.5；US-021 §5 #5；US-027 §6.4 / §12 | §3.5 教练离职提示文案；退款金额计算在 `U-退款申请页` 完成 |
| 退款资格受 package 快照 refund_enabled、refund_valid_days 控制 | PRD §6.4.1；US-021 §5 #6；US-027 §3 / §4.2 | §3.4 申请退款入口显示条件 |
| 退款申请由 US-027 承接，点击后跳转 | US-021 §4.1 / §5 #7；US-027 §4.1 | §3.4 点击行为、§5 跳转动线矩阵 |
| 用户只能查看自己的 package | US-021 §4.3 | §4 显示矩阵、§3.6 越权提示 |
