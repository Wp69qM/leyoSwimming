## 3. 元素清单（自上而下）

### 3.1 TopBar / 侧边栏 / 面包屑

同 A-场馆配置页，当前菜单为 "公告/Banner/卡片"，面包屑为 "首页 / 场馆运营 / 公告/Banner/卡片"。

### 3.2 Tab 切换区

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片顶部，圆角 4 px 4 px 0 0 |
| Tab 项 | 通知栏公告 / Banner / 首页卡片 |
| 选中态 | 底部 2px #1890FF |

| 字段 | 值 |
|------|-----|

| 新增/编辑弹窗 | 内容输入、排序、有效期、是否启用 |

### 3.4 Banner Tab

| 字段 | 值 |
|------|-----|
| 列表 | 图片 / 标题 / 链接 / 排序 / 有效期 / 状态 / 操作 |
| 操作 | 上传图片、编辑、删除、排序 |
| 新增/编辑弹窗 | 图片上传、标题、链接、排序、有效期 |

### 3.5 首页卡片 Tab

| 字段 | 值 |
|------|-----|
| 列表 | 标题 / 图标 / 链接 / 可见身份 / 排序 / 有效期 / 状态 / 操作 |
| 操作 | 新增 / 编辑 / 删除 / 排序 |
| 新增/编辑弹窗 | 标题、图标上传、链接、可见身份多选、排序、有效期 |

### 3.6 实时预览区

| 字段 | 值 |
|------|-----|

### 3.7 底部固定操作栏

| 字段 | 值 |
|------|-----|

## 6. 四态设计

### 6.1 空状态

- 各 Tab 列表为空时显示 "暂无配置"。

### 6.2 加载中

- 列表显示骨架屏，预览区显示占位。

### 6.3 错误状态

- 保存失败：顶部 `el-message` "保存失败，请稍后重试"。

### 6.4 成功状态

- 保存成功：Toast "发布成功"，预览区实时更新。
