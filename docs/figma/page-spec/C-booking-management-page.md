## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
| ------ | :-------: | --------- |
| 已通过（1） | 是 | 完整功能 |
| 申请离职中（4） | 是 | 可查看/确认课程，代约仍可操作 |
| 其他状态 | 否 | 重定向 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
| ------ | ------ | ----------- |
| 课程状态 | 已预约/待上课/上课中/已完成/已取消/旷课 | 卡片/操作按钮不同 |
| 时间筛选 | 今日/本周/本月 | Tab 切换 |
| 请假取消 | 学员课程被请假取消 | 卡片显示「因请假取消」标签 |

> **来自 US-031 / US-033**：卡片通过标签区分课程类型和状态。

| 字段 | 值 |
| ------ | ----- |
| 课程类型标签 | 体验课 / 正价课 |
