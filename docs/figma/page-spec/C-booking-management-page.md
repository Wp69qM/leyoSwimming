# 页面规格：C-预约管理页

> **性质**：Figma 设计交付的唯一指令源。
> **归属 US**：US-031 / US-033 / US-036
> **对应 PRD**：§5.4.2 预约管理、§5.4.3 上课记录、§5.4.5 请假处理
> **版本**：v1.0 | **创建日期**：2026-08-02

---

---

## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 已通过（1） | 是 | 完整功能 |
| 申请离职中（4） | 是 | 可查看/确认课程，代约仍可操作 |
| 其他状态 | 否 | 重定向 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| 课程状态 | 已预约/待上课/上课中/已完成/已取消/旷课 | 卡片颜色/操作按钮不同 |
| 时间筛选 | 今日/本周/本月 | 顶部 Tab 切换 |
| 请假取消 | 学员课程被请假取消 | 卡片显示「因请假取消」标签 |

## 3. 元素清单（自上而下）

### 3.1 顶部时间筛选

| 字段 | 值 |
|------|-----|
| 容器 | 375×44，y=88，白底 |
| 选项 | 今日 / 本周 / 本月 |
| 选中态 | `#1890FF` 下划线 2px |
| 右侧 | 日历图标 → 选择具体日期 |

### 3.2 数据摘要条

| 字段 | 值 |
|------|-----|
| 容器 | 343×48，x=16，y=140，#E6F7FF 背景，圆角 8 |
| 内容 | "共 X 节课 · 待确认 Y 节 · 已取消 Z 节" 12px |

### 3.3 预约卡片列表

> **来自 US-031 / US-033**：卡片通过颜色/图标/标签区分课程类型和状态。

| 字段 | 值 |
|------|-----|
| 卡片尺寸 | 343×108，x=16，白底圆角 12，shadow-card |
| 左侧时间区 | 80×108，#F5F7FA，圆角 12 0 0 12，居中大号时间 |
| 课程类型标签 | 体验课 `#52C41A` / 正价课 `#1890FF`，pill |
| 学员姓名 | 16px Bold `#262626` |
| 状态徽标 | 已预约/待上课/上课中/已完成/已取消/旷课 |
| 额外信息 | 年龄/泳姿/剩余课时 |
| 操作按钮 | 已结束未确认显示「确认上课」；待上课显示「提醒学员」 |
| 候补/关注提示 | 卡片右上角显示候补人数/关注人数 |
| 点击 | 整卡 → C-上课记录确认页 |

### 3.4 底部 TabBar

| 字段 | 值 |
|------|-----|
| 尺寸 | 375×83，y=729 |
| 4 Tab | 首页 / 预约 / 学员 / 我的 |

## 6. 四态设计

| 状态 | 表现 |
|------|------|
| 空状态 | "暂无预约" 插画 + "去排班" 按钮 |
