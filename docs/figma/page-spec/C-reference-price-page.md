## 6. 四态设计

| 状态 | 表现 |
|------|------|
| 空状态 | 输入框 placeholder |
| 加载中 | 骨架屏 |
| 错误状态 | 价格超限/格式错误提示 |
| 成功状态 | Toast "保存成功" |
