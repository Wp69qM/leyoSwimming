### 3.5 操作按钮

| 字段 | 值 |
|------|-----|
| 查看 | 按钮，所有状态显示；点击 → A-教练入驻审核详情页 |
| 通过 | 按钮，仅待审核显示；点击后弹出二次确认弹窗，确认后直接调用通过接口并刷新列表，无需跳转详情页 |
| 驳回 | 按钮，仅待审核显示；点击后弹出轻量输入框 / Popconfirm，管理员填写驳回原因后确认执行；驳回原因必填 |

### 3.6 列表页通过确认弹窗

| 字段 | 值 |
|------|-----|
| 容器 | Popconfirm / 小型 Dialog |
| 标题 | "确认通过" |
| 文案 | "确认通过该教练入驻申请？通过后将立即生效且不可撤销" |
| 确认按钮 | 主按钮 "确认通过" |
| 取消按钮 | 默认按钮 "取消" |
| 结果反馈 | Toast "操作成功"，列表刷新，该行状态变为「已通过」 |

### 3.7 列表页驳回弹窗

| 字段 | 值 |
|------|-----|
| 容器 | 小型 Dialog / Popconfirm with Input |
| 标题 | "驳回入驻申请" |
| 原因输入 | 多行文本，placeholder "请输入驳回原因，教练将收到该原因"，必填 |
| 快捷原因 | 单选标签："资料不全" / "证书不清晰" / "信息不一致" / "单价不合理"；选择后自动填充输入框 |
| 确认按钮 | 危险按钮 "确认驳回"，原因未填时禁用 |
| 取消按钮 | 默认按钮 "取消" |

### 3.8 批量操作栏

| 字段 | 值 |
|------|-----|
| 容器 | 卡片 |
| 触发条件 | 至少选中一条待审核记录时显示 |
| 左侧 | 已选 {N} 条 文案 + 「取消选择」按钮 |
| 右侧 | 批量通过按钮（主按钮） |
| 点击批量通过 | 二次确认弹窗：标题「批量通过确认」，文案「确认通过已选 N 条入驻申请？通过后将立即生效且不可撤销」；确认后逐条调用批量通过接口 |
| 结果反馈 | Toast：「成功通过 N 条，失败 M 条」；失败项在表格中保持选中并展示具体错误原因 |

> 批量驳回暂不支持，如需驳回请进入详情页或单行操作。

## 6. 四态设计

### 6.1 空状态

- 表格空：空插画 + "暂无入驻申请" + 「刷新」按钮。

### 6.2 加载中

- 表格骨架屏 3 行。

### 6.3 错误状态

- 表格区域 `el-empty` "加载失败" + 「重试」按钮。

### 6.4 成功状态

- 列表正常展示，审核操作后 Toast "操作成功" 并刷新列表。
