## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 待审核（0） | 否 | 重定向至 `C-入驻提交成功页` |
| 已通过（1） | 是（只读预览） | 从「学员套餐处理入口」进入，可查看但不可提交工单 |
| 已驳回（2） | 否 | 重定向至 `C-入驻资料填写页` |
| 已离职（3） | 否 | 功能锁定，重定向至 `C-教练中心页` |
| 申请离职中（4） | 是（可编辑） | 处理套餐并提交审批 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| 有 active 套餐 | 名下存在未完结学员套餐 | 列出每份套餐并要求选择处理方式 |
| 无 active 套餐 | 名下无未完结套餐 | 显示空状态提示，可直接返回 |
| 工单已提交 | 处理完成并提交管理员 | 底部提交按钮隐藏，显示审批中状态 |
| 部分套餐未处理 | 还有套餐未选择处理方式 | 「提交审批」按钮禁用 |

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| 空状态 | 无 active 套餐 | 显示 3.6 无套餐提示卡片 |
| 加载中 | 拉取套餐列表 | 进度指示器 + 卡片骨架屏 |
| 错误状态 | 网络/服务异常 | 中央错误插画 + 「加载失败，点击重试」 |
| 成功状态 | 数据返回且已处理 | 显示审批中状态或允许提交 |
