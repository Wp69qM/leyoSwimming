## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
| ------ | :-------: | --------- |
| 待审核（0） | 否 | 重定向至 `C-入驻提交成功页` |
| 已通过（1） | 是（只读预览） | 从「学员套餐处理入口」进入，可查看但不可提交工单 |
| 已驳回（2） | 否 | 重定向至 `C-入驻资料填写页` |
| 已离职（3） | 否 | 功能锁定，重定向至 `C-教练中心页` |
| 申请离职中（4） | 是（可编辑） | 处理套餐并提交审批 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
| ------ | ------ | ----------- |
| 有 active 套餐 | 名下存在未完结学员套餐 | 列出每份套餐并要求选择处理方式 |
| 无 active 套餐 | 名下无未完结套餐 | 显示空状态提示，可直接返回 |
| 工单已提交 | 处理完成并提交管理员 | 提交按钮隐藏，显示审批中状态 |
| 部分套餐未处理 | 还有套餐未选择处理方式 | 「提交审批」按钮禁用 |

## 3. 元素清单（自上而下）

### 3.1 状态栏 + NavBar

| 字段 | 值 |
| ------ | ----- |
| 名称 | 状态栏 + 导航栏 |
| 显示条件 | 全部可见状态 |
| 点击行为 | 返回 → `C-离职申请页` |

### 3.2 离职进度指示器

| 字段 | 值 |
| ------ | ----- |
| 名称 | 离职进度指示器 |
| 显示条件 | status=1 预览 / status=4 编辑 |
| 点击行为 | 无 |

#### 3.2.1 步骤定义

| 步骤 | 文案 | 状态 |
| ------ | ------ | ------ |
| 1 | 提交申请 | 已完成 |
| 2 | 处理套餐 | 当前（ 高亮） |
| 3 | 提交工单 | 待进行 |
| 4 | 审批结果 | 待进行 |

### 3.3 套餐清单区标题

| 字段 | 值 |
| ------ | ----- |
| 名称 | 套餐清单区标题 |
| 显示条件 | 存在 active 套餐时 |
| 点击行为 | 无 |

### 3.4 学员套餐处理卡片

| 字段 | 值 |
| ------ | ----- |
| 名称 | 学员套餐处理卡片 |
| 显示条件 | 存在 active 套餐 |
| 点击行为 | 卡片本身无跳转，内部选择器操作 |

#### 3.4.1 套餐状态标签

| 字段 | 值 |
| ------ | ----- |
| 名称 | 套餐状态标签 |
| 显示条件 | 每张卡片 |
| 点击行为 | 无 |

#### 3.4.2 处理方式选择器

| 字段 | 值 |
| ------ | ----- |
| 名称 | 处理方式选择器 |
| 显示条件 | status=4 可编辑；status=1 只读展示 |
| 点击行为 | 点击弹出 ActionSheet：「转新教练 / 全额退款 / 继续上完」 |

#### 3.4.3 转新教练搜索区

| 字段 | 值 |
| ------ | ----- |
| 名称 | 转新教练搜索区 |
| 显示条件 | 该套餐选择「转新教练」时显示 |
| 点击行为 | 点击输入区打开教练选择器（本 MVP 内联搜索，不跳转独立页面） |

### 3.5 底部提交栏

| 字段 | 值 |
| ------ | ----- |
| 名称 | 提交栏 |
| 显示条件 | status=4 且未提交工单时 |
| 点击行为 | 无 |

#### 3.5.1 提交审批按钮

| 字段 | 值 |
| ------ | ----- |
| 名称 | 提交审批按钮 |
| 显示条件 | status=4 且所有套餐已选择处理方式 |
| 点击行为 | 二次确认 → 提交离职工单 → 成功后返回 `C-教练中心页` |

### 3.6 无 active 套餐提示

| 字段 | 值 |
| ------ | ----- |
| 名称 | 无 active 套餐提示 |
| 显示条件 | 无 active 套餐 |
| 点击行为 | 提示内「返回」按钮 → `C-离职申请页` |

## 6. 四态设计

| 状态 | 触发 | 表现 |
| ------ | ------ | ------ |
| 空状态 | 无 active 套餐 | 显示 3.6 无套餐提示卡片 |
| 加载中 | 拉取套餐列表 | 进度指示器 + 卡片骨架屏 |
| 错误状态 | 网络/服务异常 | 中央错误插画 + 「加载失败，点击重试」 |
| 成功状态 | 数据返回且已处理 | 显示审批中状态或允许提交 |

## 7. 业务规则引用

| 规则 | PRD / US 引用 | 在本页面应用 |
| ------ | -------------- | ------------- |
| 教练提交离职申请后需处理 active 学员套餐 | US-039 §4.1 / `CROSS-BATCH-PRINCIPLES-COACH.md` §6.1 | §2 / §3.4 |
| 处理方式为转新教练 / 全额退款 / 继续上完 | `CROSS-BATCH-PRINCIPLES-COACH.md` §6.1 步骤 3 | §3.4.2 |
| 所有套餐处理完毕后提交管理员审批 | `CROSS-BATCH-PRINCIPLES-COACH.md` §6.1 步骤 4 | §3.5.1 |
| 管理员审批通过后 status 4 → 3 | US-041 §4.1 / PRD §6.4.5 | §2.1 |
| 离职审批通过后 active package 冻结 | PRD §4.2.1 / US-041 | §3.4.1 标签 |
