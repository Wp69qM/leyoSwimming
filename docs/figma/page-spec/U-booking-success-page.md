# 页面规格：U-预约成功页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-018 / US-029
> **对应 PRD**：§5.3.2 预约功能、§6.1 预约状态机、§6.3.1 预占规则、§7.2 通知场景、§13.3 MVP 页面清单第 14 项
> **版本**：v1.0 | **创建日期**：2026-08-02
> **特别说明**：预约成功页是约课闭环的终点，必须明确告知用户预约结果、展示预约卡片、提供日历同步入口，并以「完成」按钮结束流程；本页无返回按钮。

## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。
> 身份定义来源：[PRD §3.2](../../../docs/prd/prd.md) 与 [US-018](../../../docs/stories/US-018-体验课学员-预约与取消/user-story.md) / [US-029](../../../docs/stories/US-029-学员-预约正价课程/user-story.md)。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| **游客** | 否 | 预约成功后不会进入本页；游客前置被拦截 |
| **注册用户（无套餐）** | 否 | 无套餐无法完成预约，不会进入本页 |
| **体验课学员** | 是 | 展示体验课预约成功信息 |
| **正价课学员（已绑定本教练）** | 是 | 展示正价课预约成功信息 |
| **教练/管理员（以用户身份进入）** | 是 | 按其实际用户身份处理，不显示管理态 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| `booking.status = 2` 已预约 | 预约提交成功 | 正常展示成功页 |
| `booking.course_type = 0` | 体验课 | 预约卡片显示「体验课」标签 |
| `booking.course_type = 1` | 正价课 | 预约卡片显示「正价课」标签 |
| `calendar_sync = true` | 用户已授权日历同步 | 「添加到日历」按钮显示为「已添加」或隐藏 |
| `calendar_sync = false` | 未同步日历 | 显示「添加到日历」按钮 |
| `first_booking` | 用户首次预约 | 展示额外欢迎文案 "恭喜您完成首次预约" |
| `release_countdown` | 处于释放倒计时窗口 | 显示"距离上课还有 X 天"提示 |

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 无 booking_id 传入或预约不存在 | 中央 Empty 组件：插画 + "暂无预约信息" + "返回首页" 按钮（→ `U-首页`） |
| **加载中** | 查询预约详情 / 等待预约创建回调 | 成功区显示渐变占位；卡片区域显示骨架屏（浅灰 #F5F5F5 矩形占位） |
| **错误状态** | 网络断开 / 接口 5xx / 预约不存在 | 中央错误插画 + "加载失败，点击重试" + Primary「重新加载」按钮 |
| **成功状态** | 预约创建成功且数据正常返回 | 按 §4 显示规则矩阵完整展示成功页；底部固定「完成」按钮 |
