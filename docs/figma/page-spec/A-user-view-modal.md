> **对应 PRD**：§5.5.1 用户管理

## 1. 页面基础

| 字段 | 值 |
|------|-----|
| 页面名（中文） | 用户查看弹窗 |
| 页面名（Frame） | `A-用户查看弹窗` |
| 平台 | Web 后台管理系统 |
| 页面类型 | 弹窗（Modal） |
| 弹窗宽度 | 640 px |
| 弹窗最大高度 | 80vh，内容超出时内部滚动 |
| 遮罩层 | rgba(0, 0, 0, 0.45) |
| 圆角 | 8 px |
| 顶部标题栏 | 64 px，左侧标题「用户详情」，右侧关闭 icon |

***

## 2. 状态维度

| 维度 | 状态枚举 | 弹窗影响 |
|------|---------|---------|
| 用户身份 | 游客 / 注册用户 / 学员 | 身份标签颜色、游泳档案/订单入口显隐 |
| 账号状态 | 正常 / 注销 / 封禁 | 底部操作栏「封禁/解禁」按钮 |
| 资料完善状态 | 未完善 / 已完善 | 基本信息区字段是否展示占位文本 |
| 是否为未成年人 | 是 / 否 | 监护人信息分组显隐 |
| 有无游泳基础 | 有 / 无 | 泳姿、年限字段显隐 |

***

## 3. 元素清单（自上而下）

### 3.1 标题栏

| 字段 | 值 |
|------|-----|
| 容器 | 顶部固定，高度 64 px，白底，底部 1px #E4E7ED |
| 标题 | 18px Medium #262626，文字「用户详情」 |
| 关闭按钮 | 右上角 24×24 px 关闭 icon，#8C8C8C |

### 3.2 用户信息卡

| 字段 | 值 |
|------|-----|
| 容器 | 白底，内边距 24 px，底部 margin 16 px |
| 头像 | 80×80 px 圆形，无头像时显示默认头像 |
| 昵称/姓名 | 20px Medium #262626 |
| 用户 ID | 12px Regular #8C8C8C |
| 身份标签 | Tag：游客 / 注册用户 / 学员 |
| 账号状态标签 | Tag：正常 / 注销 / 封禁 |
| 资料完善标签 | Tag：已完善 / 未完善 |
| 信息行 | 手机号（脱敏，点击显示）、性别、年龄、注册来源、注册时间、最后登录时间 |

### 3.3 信息分组区

| 字段 | 值 |
|------|-----|
| 容器 | 白底，内边距 24 px |
| 布局 | 2 列只读信息表，标签左、值右 |
| 分组标题 | 14px Medium #262626，margin-bottom 16 px |

#### 3.3.1 基础信息分组

| 字段 | 说明 |
|------|------|
| 用户 ID | 系统分配 |
| 昵称/姓名 | 用户填写的 `name`，未填写显示「未设置」 |
| 手机号 | 脱敏显示，点击显示完整 |
| 性别 | 男 / 女 |
| 年龄 | 数字或「未知」 |
| 注册来源 | 微信授权 / 手机号登录 |
| 注册时间 | YYYY-MM-DD HH:mm:ss |
| 最后登录时间 | YYYY-MM-DD HH:mm:ss |
| 账号状态 | 正常 / 注销 / 封禁 |
| 资料完善状态 | 已完善 / 未完善 |

#### 3.3.2 游泳档案分组

| 字段 | 说明 |
|------|------|
| 有无游泳基础 | 有 / 无 |
| 会什么泳姿 | 当「有基础」时显示，多选：蛙泳/自由泳/仰泳/蝶泳 |
| 游泳年限 | 当「有基础」时显示，数字年 |
| 个人描述 | 用户填写的个人描述文本，未填写显示「未填写」 |

#### 3.3.3 监护人信息分组（未成年人 age < 18 时显示）

| 字段 | 说明 |
|------|------|
| 监护人姓名 | `guardian_name` |
| 监护人手机号 | 脱敏显示，点击显示完整 |

### 3.4 底部操作栏

| 字段 | 值 |
|------|-----|
| 容器 | 弹窗底部固定，高度 64 px，白底，顶部 1px #E4E7ED，内边距 0 24 px |
| 左侧按钮 | 关闭（默认按钮） |
| 右侧按钮组 | 封禁或解禁 / 编辑资料（主按钮） |

## 6. 四态设计

### 6.1 空状态

- 各分组字段未填写时显示「未填写」占位文本。
- 游泳档案无基础时，泳姿/年限显示「—」。

### 6.2 加载中

- 弹窗内容区骨架屏，头像与信息行占位。

### 6.3 错误状态

- 弹窗顶部红色提示条：「用户不存在或已删除」。
- 关闭弹窗后回到列表页。

### 6.4 成功状态

- 用户信息正常展示，底部操作按钮按权限与状态正常显隐。
