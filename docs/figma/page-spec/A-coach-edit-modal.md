## 2. 模式维度

| 维度 | 状态枚举 | 页面影响 |
|------|---------|---------|
| 弹窗模式 | 新建 / 编辑 | 编辑模式回显 coach_id 与当前资料；新建模式所有字段为空 |
| 表单分组 | 基础信息 / 实名与资质 / 教学履历 / 服务设置 | 与教练端入驻资料分组一致 |
| 保存状态 | 可保存 / 校验中 / 保存中 | 保存按钮 loading / disabled 状态 |

## 6. 四态设计

### 6.1 空状态

- 新建模式：所有表单字段为空，图片上传区显示占位图。

### 6.2 加载中

- 编辑模式打开时：表单字段 skeleton 加载，图片上传区显示 loading 占位。

### 6.3 错误状态

- 字段校验失败：对应字段下方显示红色错误文案。
- 手机号/身份证号重复：字段下方显示"已被其他教练使用"。
- 接口失败：弹窗顶部显示全局错误提示。

### 6.4 成功状态

- 保存成功后关闭弹窗，A-教练管理页列表刷新，toast 提示"教练已创建"/"教练资料已更新"。
