> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-018（体验课学员预约与取消）/ US-029（学员预约正价课程）/ US-030（学员取消正价课程）/ US-031（教练代约/改约正价课程）/ US-032（学员签到课程）/ US-033（教练确认上课记录）/ US-049（管理员处理客服工单）

> **版本**：v1.0 | **创建日期**：2026-08-02
> **特别说明**：本页为二级详情页，承载单条 booking 的完整信息、取消/改约/申诉操作与流程状态展示。

## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。
> 身份定义来源：[PRD §3.2](../../../docs/prd/prd.md) 与 [CROSS-BATCH-PRINCIPLES.md](../CROSS-BATCH-PRINCIPLES.md) §1。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | 否 | 需从「我的预约」进入；直接访问时跳转微信授权页 |
| 注册用户 | 否 | 无 active 套餐，无预约数据；直接访问时跳转套餐列表页 |
| 学员 | 是 | 本人预约详情查看与操作入口；非本人 booking 跳转 403 提示页 |
| 教练 | 否 | 教练端查看对应预约使用教练端页面 |
| 管理员 | 否 | 管理端使用 Web 后台 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| `booking.status = 已预约` | 预约成功且未开课 | 展示取消/改约入口；按时间窗显示不同操作 |
| `booking.status = 待上课` | 距开课 ≤ 10 分钟 | 展示「一键签到」入口；取消入口受时间窗约束 |
| `booking.status = 上课中` | 课程进行中 | 展示签到状态；底部操作区隐藏 |
| `booking.status = 已完成` | 教练已确认扣课时 | 展示上课记录与课后总结入口 |
| `booking.status = 已取消` | 用户/教练/平台取消 | 展示取消原因、取消时间；底部仅保留「再次预约」 |
| `booking.status = 旷课` | 学员未到场且教练标记 | 展示旷课状态、教练备注；底部仅保留客服申诉入口 |
| `booking.status = 候补中` | 加入候补队列 | 展示候补序号与预计转正提示；支持取消候补 |
| `time_to_start ≥ 24h` | 距离开课 ≥ 24 小时 | 底部显示「直接取消」主按钮 |
| `2h ≤ time_to_start < 24h` | 距离开课 < 24 小时且 ≥ 2 小时 | 底部显示「申请取消（需教练审批）」主按钮 |
| `time_to_start < 2h` | 距离开课 < 2 小时 | 底部显示「特殊原因申诉」入口；需填写原因+上传证明 |
| `cancellation.status = 待审批` | 已提交 24h 内取消申请 | 展示审批进度条与剩余时间 |
| `cancellation.status = 已拒绝` | 教练拒绝取消 | 展示拒绝原因；若仍在 2h 阈值内显示「特殊原因申诉」 |
| `appeal.status = 争议退款处理中` | 已提交特殊原因申诉 | 展示申诉单号、提交时间、处理进度 |

## 3. 元素清单（自上而下）

> **设计原则**：
> 1. **元素清单只描述「有什么元素」以及「元素之间的交互与状态」，不描述具体样式细节。** 颜色、宽度、高度、边距、背景、圆角、字体、字号、阴影等视觉参数**禁止**出现在 page-spec 中。
> 2. 视觉样式以 Calicat 设计稿为唯一最高优先级来源；page-spec 仅对交互逻辑、业务规则、状态流转负责。
> 3. 每个元素必须说明：名称、作用、显示条件、交互行为、关联业务规则。
> 4. 开发使用 rpx 适配设计稿基准宽度（仅作为工程说明，不作为视觉规格）。

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | booking 不存在 / 已删除 / 无权限 | 中央插画 + "预约不存在或已被取消" + Primary「返回我的预约」按钮 |
| **加载中** | 首次进入 / 刷新 / 提交后重新加载 | 页面内容区显示骨架屏占位，底部栏显示默认占位 |
| **错误状态** | 网络断开 / 接口 5xx / 业务 4xx | 中央错误插画 + "网络异常，请重试" 或 "服务繁忙，请稍后重试" + Primary「重新加载」按钮 |
| **成功状态** | 数据正常返回 | 按 §4 显示规则矩阵完整展示头部卡、信息卡、流程卡、操作栏；提交操作后 Toast 提示 |
