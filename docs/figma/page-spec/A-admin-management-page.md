## 2. 状态维度

| 维度 | 状态枚举 | 页面影响 |
|------|---------|---------|
| 当前登录管理员角色 | `super_admin` / `admin` | 是否显示「新建管理员」按钮、操作列入口 |
| 目标管理员角色 | `super_admin` / `admin` | 操作按钮显隐（super_admin 不可被 admin 操作） |
| 目标管理员状态 | 启用 / 禁用 | 禁用/启用按钮切换、状态标签颜色 |
| 操作权限 | `allowed_actions` 返回数组 | 后端控制前端只渲染有权限的入口 |

| 字段 | 值 |

表格列：

| 列名 | 宽度 | 对齐 | 说明 |
|------|------|------|------|
| 管理员 ID | 80 px | 左对齐 | — |

| 创建时间 | 160 px | 左对齐 | YYYY-MM-DD HH:mm |
| 操作 | ≥220 px | 居中 | 查看 / 编辑 / 更多 |

### 3.6 操作按钮

| 字段 | 值 |
|------|-----|
| 查看 | 蓝色文字按钮，打开 [A-管理员账号查看弹窗](./A-admin-view-modal.md) |
| 编辑 | 蓝色文字按钮，打开 [A-编辑管理员弹窗](./A-admin-edit-modal.md)；仅 `super_admin` 对他人可见（不可编辑自身） |
| 更多 | 下拉菜单：禁用 / 启用 / 删除 / 重置密码 |

#### 更多菜单项

| 菜单项 | 显示条件 | 说明 |
|--------|---------|------|
| 禁用 | 状态为启用时；仅 `super_admin` 且非自身 | 红色文字，二次确认后禁用 |
| 启用 | 状态为禁用时；仅 `super_admin` 且非自身 | 蓝色文字 |
| 删除 | 仅 `super_admin` 且非自身 | 红色文字，二次确认后删除 |
| 重置密码 | 仅 `super_admin` 且非自身 | 蓝色文字，打开重置密码结果弹窗 |

## 6. 四态设计

### 6.1 空状态

- 表格空：空插画 120×120 + "暂无管理员账号" + 「重置筛选」按钮。

### 6.2 加载中

- 表格骨架屏 3 行，表头保留；筛选区按钮 disabled。

### 6.3 错误状态

- 表格区域 `el-empty` "加载失败" + 「重试」按钮。

### 6.4 成功状态

- 列表正常展示，分页可用，操作按钮按权限渲染。

***

## 7. 业务规则引用

| 规则 | 来源 | 在本页的体现 |
|------|------|-------------|
| 管理员账号由系统预置或超级管理员创建 | PRD §10.1 | 仅 super_admin 显示「新建管理员」按钮 |
| super_admin 拥有最高权限 | PRD §10.1 | super_admin 可操作他人账号；admin 只读 |
| 敏感操作需记录审计日志 | PRD §11.1 | 禁用/删除/重置密码等操作需二次确认 |
| 管理员状态 0=启用 / 1=禁用 | US-057 §4.1 | 状态 Tag 与禁用/启用按钮切换 |
