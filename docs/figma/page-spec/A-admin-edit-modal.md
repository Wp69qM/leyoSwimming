## 2. 状态维度

| 维度 | 状态枚举 | 弹窗影响 |
|------|---------|---------|
| 当前登录管理员角色 | `super_admin` | 仅 `super_admin` 可打开本弹窗 |
| 目标管理员角色 | `super_admin` / `admin` | `super_admin` 可修改任何可编辑字段 |
| 表单校验 | 合法 / 非法 | 保存按钮可用态与字段错误提示 |
| 提交状态 | 空闲 / 提交中 | 保存按钮 loading 态 |

| 字段 | 值 |

#### 3.2.1 表单字段

| 字段 | 组件 | 规则 |

| 字段 | 值 |

| 右侧按钮 | 保存（主按钮），表单无变更或校验不通过时 disabled |

## 5. 跳转动线

| 触发元素 | 目标 | 条件/说明 |
|---------|------|----------|
| 关闭按钮 / 遮罩层 / 取消按钮 | 关闭弹窗，不保存 | 有未保存改动时提示「是否放弃修改」 |
| 保存按钮 | 校验通过 → 调用 POST /api/admin/admin/update | 成功后关闭弹窗并刷新列表，toast 提示「管理员资料已更新」 |

***

## 6. 四态设计

### 6.1 空状态

- 弹窗打开时自动回显目标管理员当前信息，不存在空状态。

### 6.2 加载中

- 打开弹窗时回显数据 loading；保存时保存按钮 loading，表单 disabled。

### 6.3 错误状态

- 字段级错误：红色文字提示在字段下方。
- 提交失败：弹窗顶部红色 alert 提示错误信息。

### 6.4 成功状态

- 关闭弹窗，列表刷新，toast 提示成功。
