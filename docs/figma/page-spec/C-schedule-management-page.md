## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
| ------ | :-------: | --------- |
| 已通过（1） | 是 | 完整功能 |
| 申请离职中（4） | 是 | 功能完整，但提示"离职申请中，排班仍会继续生成" |
| 其他状态 | 否 | 重定向 |

## 3. 元素清单（自上而下）

### 3.1 周历选择栏

| 字段 | 值 |
| ------ | ----- |
| 容器 | — |
| 左右切换 | 上周 / 下周 箭头按钮 |
| 当前周标题 | "8月1日 - 8月7日" |
| 7 天日期 | 每个日期，选中态 |
| 今天标识 | 未选中日期显示今天标识 |

### 3.2 二维时段网格

> **来自 US-014**：上方是周历，下方是周+时间段的二维网格，教练可预览全部时段。

| 字段 | 值 |
| ------ | ----- |
| 容器 | — |
| 时段格 | 每个时段格按状态区分 |
| 时段状态 | 可约 / 已预约 / 已请假 / 过去 |
| 格内文案 | 已预约显示学员姓名首字；可约显示 "+" |
| 长按/点击 | 可约格 → 编辑/删除弹窗；空白格 → 添加时段弹窗 |

### 3.3 底部操作栏

| 字段 | 值 |
| ------ | ----- |
| 容器 | （除 TabBar 外） |
| 添加时段按钮 | — |
| 批量发布按钮 | — |
| 提示文案 | "时段不可编辑" |

### 3.4 添加/编辑时段弹窗

| 字段 | 值 |
| ------ | ----- |
| 容器 | 弹出 |
| 日期选择 | 当前选中日期，可修改 |
| 开始时间 | 时间选择器，1 小时粒度 |
| 结束时间 | 时间选择器，默认开始+1 小时 |
| 重复规则 | 仅本周 / 每周重复（模板） |
| 操作按钮 | 删除 / 取消 / 保存 |

## 5. 跳转动线

| 起点 | 行为 |
| ------ | ------ |
| 可约格点击 | 弹窗：编辑/删除 |
| 空白格点击 | 弹窗：添加时段 |
| 复制上周 | 二次确认 → 生成本周排班 |
| 批量发布 | Toast "已发布 X 个时段" |

---

## 6. 四态设计

| 状态 | 表现 |
| ------ | ------ |
| 空状态 | 整周无时段时显示"本周暂无排班"插画 + "添加时段" |
| 加载中 | 周历/网格骨架屏 |
| 错误状态 | 网络错误提示 + 重试 |
| 成功状态 | 添加/删除/发布后 Toast |
