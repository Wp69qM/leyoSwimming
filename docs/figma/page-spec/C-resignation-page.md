## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 已通过（1） | 是 | 完整功能 |
| 申请离职中（4） | 否 | 进入 C-离职工单处理页 |
| 其他状态 | 否 | 隐藏入口或提示"当前状态不可申请离职" |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| 有 active 套餐 | 名下存在未完结套餐 | 需处理学员套餐清单 |
| 无 active 套餐 | 名下无未完结套餐 | 可直接提交 |
| 已提交 | coach.status 1 → 4 | 跳转至工单处理页 |

## 5. 跳转动线

| 起点 | 行为 |
|------|------|
| 提交申请 | 二次确认弹窗 → 成功后 → C-离职工单处理页 |
| 学员套餐入口 | → C-离职工单处理页 |
| 返回 | → C-教练中心页 |

## 6. 四态设计

| 状态 | 表现 |
|------|------|
| 空状态 | 无（本页主态为表单） |
| 加载中 | 提交按钮 loading |
| 错误状态 | 状态不满足提示 / 重复提交提示 |
| 成功状态 | 跳转至工单处理页 |
