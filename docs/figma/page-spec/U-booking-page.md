## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。
> 身份定义来源：[PRD §3.2](../../../docs/prd/prd.md) 与 [US-018](../../../docs/stories/US-018-体验课学员-预约与取消/user-story.md) / [US-029](../../../docs/stories/US-029-学员-预约正价课程/user-story.md)。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| **游客** | 否 | 预约必须先登录并拥有有效套餐；游客点击预约入口前置跳转 `U-微信授权页` |
| **注册用户（无套餐）** | 否 | 无 active 套餐不可预约；进入本页时提示"请先购买套餐"并跳转 `U-套餐列表页` |
| **体验课学员** | 是 | 仅可预约标记为「体验课」的可约时段（`slot.course_type = 0`） |
| **正价课学员（已绑定本教练）** | 是 | 可预约本教练正价时段（`slot.course_type = 1`），是主预约路径 |
| **正价课学员（绑定其他教练）** | 否 | 单教练约束下不可预约其他教练；进入本页时跳转 `U-换教练流程页` 或 `U-我的套餐页` |
| **教练/管理员（以用户身份进入）** | 是 | 按其实际用户身份处理，不显示管理态 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| `slot_status = available` | 教练已释放且无人预约 | 格子显示「可约」态，可点击 |
| `slot_status = booked_by_me` | 当前用户已预约该时段 | 格子显示「我的」态，高亮 |
| `slot_status = full` | 已被他人预约或锁定 | 格子显示「已满」态；若允许候补则叠加「候补」入口 |
| `slot_status = closed` | 教练请假 / 闭馆 / 未释放 | 格子显示「休息」态，不可点击 |
| `slot.course_type = 0` | 体验课时段 | 仅体验课学员可点击；正价课学员点击提示"请购买体验课套餐" |
| `slot.course_type = 1` | 正价课时段 | 正价课学员可点击；体验课学员不可约 |
| `waitlist_open = true` | 满员但可排队候补 | 满员格显示「候补 N」而非纯灰「已满」 |
| `release_countdown` | 处于释放倒计时窗口 | 顶部显示倒计时条 |
| `package.available_count = 0` | 可用课时不足 | 底部按钮禁用，提示"课时不足，请购买加课套餐" |

## 3. 元素清单（自上而下）

> **设计原则**：
> 1. **元素清单只描述「有什么元素」以及「元素之间的交互与状态」，不描述具体样式细节。** 颜色、宽度、高度、边距、背景、圆角、字体、字号、阴影等视觉参数**禁止**出现在 page-spec 中。
> 2. 视觉样式以 Calicat 设计稿为唯一最高优先级来源；page-spec 仅对交互逻辑、业务规则、状态流转负责。
> 3. 每个元素必须说明：名称、作用、显示条件、交互行为、关联业务规则。
> 4. 开发使用 rpx 适配设计稿基准宽度（仅作为工程说明，不作为视觉规格）。

### 3.5 二维预约网格（2D Booking Grid）

> **来源**：[PRD §5.3.2 第 8 条](../../../docs/prd/prd.md) 学员端预约卡片展示规则 / [US-029 §14.2](../../../docs/stories/US-029-学员-预约正价课程/user-story.md)。
> **硬性约束**：必须使用二维表格，禁止做成「日期 Tab + 纵向时段卡片列表」。
> 复用 `U-教练排班页` §3.5 网格结构，但本页课程类型由套餐决定。

#### E. 单元格状态定义（7 种状态）

> 在 `U-教练排班页` 6 种状态基础上，增加「体验课可约」与「正价课可约」的区分，以支持体验课规则。

| 状态 | 视觉语义 | 点击行为 | 来源 |
|------|----------|---------|------|
| **正价可约 available-regular** | 显示 "可约" | 正价学员点击选中；体验课学员点击提示"请购买正价套餐" | PRD §5.3.2 第 8 条 |
| **体验可约 available-trial** | 显示 "体验" | 体验课学员可点击；正价学员点击提示"请购买体验课套餐" | US-018 §4.1 |
| **我的 my-booking** | 显示 "我的" | 点击可查看预约详情 / 取消入口 | US-029 §4.1 |
| **已满 full** | 显示 "已满" | 不可预约 | PRD §5.3.2 第 8 条 |
| **休息 closed** | 显示 "休息" | 不可点击 | US-014 / PRD §5.4.5 |
| **候补 waitlist-available** | 显示 "候补 N" | 点击选中，底部栏出现「加入候补」 | US-023 §4.1 |
| **不可约 disabled-for-me** | 显示 "—" 或锁图标 | 不可点击；toast 说明原因（课程类型不匹配/课时不足） | 本页新增 |

> **状态优先级**：当多个状态可能同时存在时，按以下优先级显示：
> 1. 我的预约（my-booking）
> 2. 休息（closed）
> 3. 候补（waitlist-available）
> 4. 已满（full）
> 5. 不可约（disabled-for-me）
> 6. 体验可约（available-trial）
> 7. 正价可约（available-regular）

#### F. 课程类型不匹配处理

| 场景 | 处理策略 |
|------|----------|
| 体验课学员看到正价可约格 | 显示为「不可约」态或保持「可约」但点击后 toast "请购买正价套餐" |
| 正价课学员看到体验可约格 | 显示为「不可约」态或保持「体验」但点击后 toast "请购买体验课套餐" |
| 决策 | 为减少误点，本页采用「显示为不可约态」策略，与课时不足格统一视觉 |

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 该教练当前周无可约时段（未释放或全部关闭） | 网格区域替换为 Empty 组件：游泳主题插画 + "暂无可约时段" + 释放倒计时提示（若处于窗口期） |
| **加载中** | 首次进入 / 切换周 / 下拉刷新 | 网格区域显示骨架屏占位，底部栏显示默认占位文字 |
| **错误状态** | 网络断开 / 接口 5xx / 业务 4xx | 中央错误插画 + "网络异常，请重试" 或 "服务繁忙，请稍后重试" + Primary「重新加载」按钮 |
| **成功状态** | 数据正常返回 | 按 §4 显示规则矩阵完整展示 2D 网格、图例、底部栏；选中态按用户操作实时更新 |
