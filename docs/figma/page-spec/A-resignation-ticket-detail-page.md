## 2. 状态维度

| 维度 | 状态枚举 | 页面影响 |
|------|---------|---------|
| 工单状态 | 待审批 / 已通过 / 已驳回 | 底部审批栏显隐 |
| 学员处理结果 | 转新教练 / 全额退款 / 继续上完 | 处理清单列显示 |

| 审批意见 | 未填写 / 已填写 | 通过/驳回按钮启用态 |

## 3. 元素清单（自上而下）

### 3.1 TopBar / 侧边栏 / 面包屑

同 A-离职审批队列页，面包屑当前页为 "工单详情"。

### 3.2 教练信息卡

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 24 px，margin-bottom 16 px |
| 头像 | 80×80 px 圆形 |
| 姓名 | 20px Medium #262626 |

### 3.3 学员处理清单

| 字段 | 值 |

### 3.4 四项检查清单

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 24 px，margin-bottom 16 px |
| 标题 | "管理员检查清单（全部通过才可批准）"，16px Medium #262626 |
| 检查项 | ① active 学员数 = 0 / ② 所有学员处理结果已登记 / ③ 教练费已结算 / ④ 排班未来时段已清空 |
| 状态 | 自动勾选或管理员手动确认 |

### 3.5 状态时间轴

### 3.6 底部固定审批操作栏

| 字段 | 值 |
|------|-----|
| 位置 | 固定页面底部 |
| 背景 | #FFFFFF，顶部阴影 `shadow-float` |
| 左侧 | 返回按钮（默认） |
| 右侧 | 审批意见输入框（宽度 400 px，必填）+ 驳回按钮（危险）+ 通过按钮（主按钮） |

| 已审批态 | 仅显示返回按钮和状态标签 |

## 6. 四态设计

### 6.1 空状态

- 学员处理清单为空时显示 "无 active 学员"。

### 6.2 加载中

- 页面级 `el-loading` 遮罩。

### 6.3 错误状态

- 错误占位页：插画 + "工单不存在" + 「返回列表」按钮。

### 6.4 成功状态

- 审批通过后 Toast "审批通过，教练已离职"；驳回后 Toast "已驳回"；均返回队列页。

## 7. 业务规则引用

| 规则 | 来源 | 在本页的体现 |
|------|------|-------------|
| 管理员查看离职工单详情 | PRD §5.5.1.1 | 教练信息卡 |
| 4 项检查清单全部通过才可批准 | PRD §5.5.1.1 | 检查清单卡及通过按钮禁用逻辑 |
