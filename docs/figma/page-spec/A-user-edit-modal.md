## 2. 状态维度

| 维度 | 状态枚举 | 弹窗影响 |
|------|---------|---------|
| 当前用户 age | < 18 / ≥ 18 | 监护人字段显隐与必填校验 |
| 有无游泳基础 | 有 / 无 | 泳姿、游泳年限字段显隐与必填校验 |
| 表单校验 | 合法 / 非法 | 保存按钮可用态与字段错误提示 |
| 提交状态 | 空闲 / 提交中 | 保存按钮 loading 态 |

## 3. 元素清单（自上而下）

### 3.1 标题栏

| 字段 | 值 |
|------|-----|
| 容器 | 顶部固定，高度 64 px，白底，底部 1px #E4E7ED |
| 标题 | 18px Medium #262626，文字「编辑用户资料」 |
| 关闭按钮 | 右上角 24×24 px 关闭 icon，#8C8C8C |

### 3.2 表单区

| 字段 | 值 |
|------|-----|
| 容器 | 白底，内边距 24 px |
| 布局 | 单列表单，label 在上，输入框在下 |
| 分组标题 | 14px Medium #262626，margin 24 px 0 16 px 0 |

#### 3.2.1 基础信息分组

| 字段 | 组件 | 规则 |
|------|------|------|
| 头像 | 头像上传组件 | 80×80 px 圆形，支持上传/删除，未上传显示默认头像 |
| 手机号 | 文本输入框 | **只读**，展示当前绑定手机号，不可编辑 |
| 昵称/姓名 | 文本输入框 | 必填，长度 1-64 字符 |
| 性别 | 单选组 | 男 / 女 |
| 年龄 | 数字输入框 | 整数，0-150，必填 |

#### 3.2.2 游泳档案分组

| 字段 | 组件 | 规则 |
|------|------|------|
| 有无游泳基础 | 开关 / 单选 | 必填 |
| 会什么泳姿 | 多选组 | 当「有基础」时显示并必填；选项：蛙泳 / 自由泳 / 仰泳 / 蝶泳 |
| 游泳年限 | 数字输入框 | 当「有基础」时显示并必填；整数 ≥ 0 |
| 个人描述 | 多行文本域 | 可选，长度 0-512 字符 |

#### 3.2.3 监护人信息分组（age < 18 时显示）

| 字段 | 组件 | 规则 |
|------|------|------|
| 监护人姓名 | 文本输入框 | 未成年人必填，长度 1-64 字符 |
| 监护人手机号 | 文本输入框 | 未成年人必填，中国大陆手机号格式 |

### 3.3 底部操作栏

| 字段 | 值 |
|------|-----|
| 容器 | 弹窗底部固定，高度 64 px，白底，顶部 1px #E4E7ED，内边距 0 24 px |
| 左侧按钮 | 取消（默认按钮） |
| 右侧按钮 | 保存（主按钮），表单校验不通过时 disabled |

## 5. 跳转动线

| 触发元素 | 目标 | 条件/说明 |
|---------|------|----------|
| 关闭按钮 / 遮罩层 / 取消按钮 | 关闭弹窗，不保存 | 有未保存改动时提示「是否放弃修改」 |
| 保存按钮 | 校验通过 → 调用 POST /api/admin/user/update（请求体 `{ userId, profile, version }`） | 成功后关闭弹窗并刷新列表 |

## 6. 四态设计

### 6.1 空状态

- 表单初始化时，从用户当前数据回填；不存在空表单。

### 6.2 加载中

- 弹窗内容区骨架屏或表单 disabled 态，保存按钮显示 loading。

### 6.3 错误状态

- 字段级校验错误：输入框下方红色提示文本。
- 提交失败：弹窗顶部红色提示条显示后端错误信息（如 `INVALID_GUARDIAN_INFO`、`USER_CONCURRENTLY_UPDATED`）。

### 6.4 成功状态

- 保存成功后关闭弹窗，列表页 toast 提示「用户资料已更新」。
