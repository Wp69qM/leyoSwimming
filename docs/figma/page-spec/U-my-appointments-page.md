# 页面规格：U-我的预约页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-018（体验课学员预约与取消）/ US-029（学员预约正价课程）/ US-030（学员取消正价课程）/ US-032（学员签到课程）/ US-033（教练确认上课记录）
> **对应 PRD**：§5.3.2 预约功能、§5.3.3 课时与上课记录、§6.1 预约状态机、§6.5 取消与改约、§14 C1 取消规则澄清、§13.3 MVP 核心页面清单（页面 18）
> **版本**：v1.0 | **创建日期**：2026-08-02
> **特别说明**：本页为 Tab 页第 3 项「预约」，是学员查看全部预约（含体验课/正价课、已完成/待上课/已取消）的统一入口。

## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。
> 身份定义来源：[PRD §3.2](../../../docs/prd/prd.md) 与 [CROSS-BATCH-PRINCIPLES.md](../CROSS-BATCH-PRINCIPLES.md) §1。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | 否 | 点击 TabBar「预约」→ 跳转微信授权页（`U-微信授权页`），不显示本页内容 |
| 注册用户 | 否 | 无 active 套餐，点击 TabBar「预约」→ 跳转 `U-套餐列表页` 提示购买套餐 |
| 学员 | 是 | 持有 active 套餐，是本页唯一目标用户；展示全部预约卡片 |
| 教练 | 否 | 教练端使用教练端页面；以用户身份登录后若同时为学员则按学员身份显示 |
| 管理员 | 否 | 管理端使用 Web 后台 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| `booking.status = 已预约` | 预约成功且未开课 | 显示在「 upcoming 」列表；可取消/改约 |
| `booking.status = 待上课` | 距开课 ≤ 10 分钟 | 显示在「 upcoming 」列表；展示「一键签到」入口 |
| `booking.status = 上课中` | 课程进行中 | 显示在「 upcoming 」列表；展示「一键签到」入口（若未签到） |
| `booking.status = 已完成` | 教练已确认扣课时 | 显示在「 past 」列表；可查看上课记录 |
| `booking.status = 已取消` | 用户/教练/平台取消 | 显示在「 past 」列表；展示取消原因 |
| `booking.status = 旷课` | 学员未到场且教练标记 | 显示在「 past 」列表；展示旷课状态与教练备注 |
| `booking.status = 候补中` | 加入候补队列 | 显示在「 upcoming 」列表；展示候补序号 |
| `time_to_start ≥ 24h` | 距离开课 ≥ 24 小时 | 卡片徽标「可取消」，点击直接取消 |
| `2h ≤ time_to_start < 24h` | 距离开课 < 24 小时且 ≥ 2 小时 | 卡片徽标「需审批」，取消需教练审批 |
| `time_to_start < 2h` | 距离开课 < 2 小时 | 卡片徽标「不可取消」，仅可走特殊原因申诉 |

#### G. 状态徽标计算规则

> **来源**：PRD §6.5.1 / CROSS-BATCH-PRINCIPLES §4.2。

| 优先级 | 判定条件 | 徽标文案 |
|--------|---------|----------|
| 1 | booking.status = 候补中 | 候补中 |
| 2 | booking.status = 已完成 | 已完成 |
| 3 | booking.status = 已取消 | 已取消 |
| 4 | booking.status = 旷课 | 旷课 |
| 5 | booking.status ∈ {已预约, 待上课, 上课中} 且 time_to_start ≥ 24h | 可取消 |
| 6 | booking.status ∈ {已预约, 待上课, 上课中} 且 2h ≤ time_to_start < 24h | 需审批 |
| 7 | booking.status ∈ {已预约, 待上课, 上课中} 且 time_to_start < 2h | 不可取消 |

> **计算基准**：`time_to_start = 课程开始时间 - 当前时间`；精确到分钟，不考虑秒级。

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 学员无历史预约 / 当前分类下无预约 | 列表区替换为 Empty 组件：游泳主题插画 + "暂无预约" + "去预约一节课程吧" + Primary「去预约」按钮 |
| **加载中** | 首次进入 / 切换分类 / 下拉刷新 | 列表区显示骨架屏（卡片占位），TabBar 保持可见 |
| **错误状态** | 网络断开 / 接口 5xx / 业务 4xx | 中央错误插画 + "网络异常，请重试" 或 "服务繁忙，请稍后重试" + Primary「重新加载」按钮 |
