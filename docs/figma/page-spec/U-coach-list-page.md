> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-001（游客浏览教练列表与详情）
> **对应 PRD**：§3.1 身份体系、§5.1 游客功能、§5.3.1 教练与套餐浏览、§5.4.7 教练离职/可见性、§13.3 MVP 页面 6

## 2. 用户身份与业务状态维度

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | 是 | 可浏览教练列表、查看详情；不能购买/预约，点击"立即预约"需引导登录 |
| 注册用户 | 是 | 可浏览、查看详情；购课后才能成为学员 |
| 学员 | 是 | 可浏览、查看详情；详情页可直接预约（受实时状态约束） |
| 教练 | 否 | 本页为用户端，教练通过教练端小程序操作 |
| 管理员 | 否 | 本页为用户端，管理员通过 Web 后台操作 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| 有公开教练 | `coach.status IN (1, 4)` 的教练存在 | 正常展示卡片列表 |
| 无公开教练 | 系统没有 `status IN (1, 4)` 的教练 | 展示空状态 |
| 筛选/排序生效 | 用户点击排序项或输入搜索词 | 列表按新条件重新拉取 |
| 分页未结束 | 当前页 < 总页数 | 底部展示加载更多提示 |
| 分页已结束 | 当前页 = 总页数 | 底部展示"没有更多了" |

### 3.3 筛选/排序栏

> **来自 PRD §13.3 页面 6 / US-001 §5 规则 6**：教练列表页支持筛选/排序。

| 字段 | 值 |
|------|-----|
| 容器 | 375×48，y=140，背景 `#FFFFFF`，底部 1px `color-divider` #F0F0F0 |
| 排序项 | 横向等分 3 项："综合评分" / "价格" / "可约时间" |
| 排序项文字 | 14px Regular；未选中 `#262626`；选中 `#1890FF` Medium |

| 价格切换 | 首次点击"价格"按价格升序；再次点击切换为降序，文字后显示 ▲/▼ 图标（12px） |
| 可约时间 | 按最近可约时段从早到晚排序 |

### 3.4 教练卡片列表

> **来自 US-001 §4.1 / §14.1 / PRD §5.3.1**：列表按综合评分默认降序展示；卡片展示头像、姓名、实时状态、评分、教龄、参考单价、标签。

#### 3.4.1 列表容器

| 字段 | 值 |
|------|-----|
| 容器 | x=16，宽度 343，顶部 y=196，底部预留 83px（避开 TabBar） |
| 卡片间距 | 垂直 12px |
| 卡片尺寸 | 343×120，圆角 `radius-lg` 12px，背景 `#FFFFFF`，阴影 `shadow-card` |
| 卡片内边距 | 16px |
| 可点击态 | hover/按下阴影变为 `shadow-raised`，过渡 200ms |

#### 3.4.2 卡片内部布局

| 元素 | 规格 | 位置 |
|------|------|------|
| 头像 | 48×48 圆形，默认背景 `#E6F7FF`；如加载失败显示首字符白色 16px Medium | 卡片左侧，垂直居中 |
| 姓名 | 16px Bold `#262626`，最多 8 字，超出省略 | 头像右侧，距左 12px，顶部与头像顶部对齐 |
| 实时状态标签 | 使用全局徽标 Tag 样式（§3.1），12px，距姓名右侧 8px | 姓名同一行右侧 |
| 评分 | ⭐ 图标 12×12（`color-warning` #FAAD14）+ 数字 14px Bold `#FF6B35`（`color-accent`），如 4.8 | 姓名下方 8px |
| 教龄 | "X 年教龄"，12px Regular `#8C8C8C`，距评分右侧 12px | 与评分同行 |
| 参考单价 | "¥XXX/节"，14px Bold `#262626`，右对齐 | 卡片右侧，垂直居中 |
| 标签行 | 最多 2 个标签 + "..."，标签使用 Neutral Tag 样式（#F5F5F5 / `#8C8C8C`） | 评分行下方 8px |

#### 3.4.3 评分星级显示规则

> **来自 US-001 §14.2**：星级比精确小数更直观。

| 评分区间 | 展示 |
|---------|------|
| ≥ 4.5 | 5 个实心星 + 数字 |
| 4.0 ~ 4.5 | 4 实心星 + 1 半星 + 数字 |
| 3.0 ~ 4.0 | 4 实心星 + 1 空星 + 数字 |
| < 3.0 | 4 实心星 + 1 空星 + 数字，末尾加 "评价较少" 标签 |

#### 3.4.4 实时状态徽标

> **来自 PRD §5.3.1 / §5.4.7 / 全局规范 §3.1**：列表展示教练实时状态，不展示入职审核/离职申请等内部状态。

| 实时状态 | 文案 | 背景色 | 文字色 |
|---------|------|--------|--------|
| 空闲中 | 空闲中 | `#F6FFED` | `#52C41A`（Success） |
| 上课中 | 上课中 | `#FFF1F0` | `#FF4D4F`（Error） |
| 休息中 | 休息中 | `#FFFBE6` | `#FAAD14`（Warning） |
| 已下班 | 已下班 | `#F5F5F5` | `#8C8C8C`（Neutral） |
| 请假中 | 请假中 | `#FFFBE6` | `#FAAD14`（Warning） |

> **注意**：`coach.status = 4`（申请离职中）的教练仍正常展示，**不得**出现"申请离职中"等内部状态标签（PRD §5.4.7）。

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| 空状态 | 系统无公开教练 / 搜索/筛选结果为空 | 隐藏卡片列表与加载更多；居中展示空状态插画 + "暂无教练入驻，敬请期待" |
| 加载中 | 首次进入、下拉刷新、切换排序、输入搜索 | 显示骨架屏；NavBar / 搜索栏 / 排序栏保持可见 |
| 错误状态 | 网络/服务异常 | 隐藏骨架屏；居中展示错误插画 + 文案 + "重新加载" 按钮；下拉仍可触发重试 |
| 成功状态 | 数据正常返回 | 按 §3 元素清单完整展示；默认按综合评分降序 |

## 7. 业务规则引用

| 规则 | PRD / US 引用 | 在本页面应用 |
|------|--------------|-------------|
| 游客可浏览教练列表与详情 | PRD §5.1 / US-001 §4.1 | 页面不拦截游客访问，列表正常展示 |
| 教练列表展示字段：姓名、证书、任教年限、评分、评价、可约时间、实时状态 | PRD §5.3.1 / US-001 §5 规则 3 | 卡片展示姓名、教龄、评分、参考单价、实时状态、标签 |
| 教练实时状态：空闲中/上课中/休息中/已下班/请假中 | PRD §5.3.1 / US-001 §5 规则 2 | 卡片状态徽标按 §3.4.4 展示 |
| 公开可见的教练为 `status IN (1, 4)`；status=0/2/3 不公开 | PRD §5.4.7 / US-001 §5 规则 4 | 列表仅展示已入驻（status=1）或申请离职中（status=4）的教练 |
| status=4 的教练不得展示"申请离职中"标签 | PRD §5.4.7 / US-001 §5 规则 5 | 状态徽标仅显示实时状态，不显示入职流程状态 |
| 教练列表支持筛选/排序 | PRD §13.3 页面 6 / US-001 §5 规则 6 | 顶部提供"综合评分/价格/可约时间"排序栏 |
| 空状态文案 | US-001 §6.2 / 全局规范 §5.2 | "暂无教练入驻，敬请期待" |
| 列表分页 | US-001 §8 边界场景 5 | 滚动到底部自动加载下一页，size=10 |
| 评分可视化规则 | US-001 §14.2 | 星级 + 数字，按评分区间展示 |
