## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 业务含义 | 是否可见 | 差异说明 |
|------|---------|:--------:|---------|
| -1 未提交 | 尚未提交 | 否 | 不会进入本页 |
| 0 待审核 | 提交成功 | 是 | 本页默认场景 |
| 1 已通过 | 已入驻 | 否 | 正常不会进入 |
| 2 已驳回 | 重新提交后 | 是 | 重新提交成功后可能短暂展示，随后进入待审核态 |
| 3 已离职 | 重新入驻提交 | 是 | 标题文案强调"重新入驻" |
| 4 申请离职中 | 功能仍可用 | 否 | 不可进入 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| 首次提交成功 | coach.status 由 -1 → 0 | 主标题"提交成功"，副标题"提交成功，等待审核" |
| 重新入驻成功 | coach.status 由 3 → 0 | 主标题"重新入驻申请已提交"，增加历史数据说明 |

## 6. 四态设计

| 状态 | 表现 |
|------|------|
| 空状态 | 无（结果页主态即成功态） |
| 加载中 | 提交过程中在入驻资料页显示 loading 遮罩，进入本页后停止 loading |
| 错误状态 | 提交失败时不进入本页，留在入驻资料页显示错误提示 |
| 成功状态 | 本页完整内容展示，2 秒后自动跳转 |
