| 维度 | 状态枚举 | 页面影响 |
|------|---------|---------|
| 工单状态 | 待处理 / 处理中 / 待反馈 / 已关闭 | 筛选条件、操作按钮 |
| 工单类型 | 投诉 / 建议 / 换教练申请 / 其他 | 筛选条件、标签 |

## 3. 元素清单（自上而下）

### 3.1 TopBar / 侧边栏 / 面包屑

同 A-用户管理页，当前菜单为 "工单列表"，面包屑为 "首页 / 客服工单 / 工单列表"。

### 3.2 待办摘要条

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 16 px，margin-bottom 16 px，背景 `#E6F7FF` |
| 内容 | "待处理：{N} 条 · 处理中：{M} 条 · 今日新增：{K} 条"，14px Regular |

### 3.3 筛选区

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 16 px，margin-bottom 16 px |
| 工单状态下拉 | 宽度 160 px：全部 / 待处理 / 处理中 / 待反馈 / 已关闭 |
| 工单类型下拉 | 宽度 160 px：全部 / 投诉 / 建议 / 换教练申请 / 其他 |
| 提交时间 | 双日期选择器 |
| 关键词搜索 | 宽度 240 px，placeholder "工单号 / 用户 / 处理人" |
| 查询按钮 | 主按钮 #1890FF |
| 重置按钮 | 默认按钮 |

### 3.4 表格区

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px |
| 表头 | 14px Medium #262626，背景 #F5F7FA，高 48 px |
| 行高 | 56 px |
| 行分隔 | 1 px #F0F2F5 |
| 分页 | 底部居中，默认 20 条/页 |

表格列：

| 列名 | 宽度 | 对齐 | 说明 |
|------|------|------|------|
| 工单号 | 120 px | 左对齐 | — |
| 用户 | 120 px | 左对齐 | 昵称，可跳转 |
| 类型 | 100 px | 居中 | Tag |
| 状态 | 100 px | 居中 | 待处理 #1890FF / 处理中 #FAAD14 / 待反馈 #722ED1 / 已关闭 #8C8C8C |
| 提交时间 | 160 px | 左对齐 | — |
| 处理人 | 120 px | 左对齐 | 未分配时显示 "—" |
| 操作 | ≥160 px | 居中 | 查看 / 处理 / 关闭 |

### 3.5 操作按钮

| 字段 | 值 |
|------|-----|
| 查看 | 蓝色文字按钮，所有状态显示 |
| 处理 | 蓝色文字按钮，待处理/处理中显示 |
| 关闭 | 红色文字按钮，处理中/待反馈显示 |
| 分配 | 蓝色文字按钮，待处理显示 |

## 6. 四态设计

### 6.1 空状态

- 表格空：空插画 + "暂无工单" + 「刷新」按钮。

### 6.2 加载中

- 表格骨架屏 3 行。

### 6.3 错误状态

- 表格区域 `el-empty` "加载失败" + 「重试」按钮。

### 6.4 成功状态

- 列表正常展示，操作后刷新。
