# 页面规格：A-退款审批页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时必须按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-027 / US-028
> **对应 PRD**：§6.4 退款规则、§6.10 争议退款/申诉
> **版本**：v1.0 | **创建日期**：2026-08-02

***

## 2. 状态维度

| 维度 | 状态枚举 | 页面影响 |
|------|---------|---------|
| 退款类型 | 正常退款申请 / 争议申诉 | 筛选条件、标签 |
| 审批状态 | 待审批 / 已批准 / 已驳回 / 处理中 | 筛选条件、操作按钮 |
| 冻结原因 | coach_resigned / refund_pending / admin_frozen | 退款金额计算依据 |

***

## 3. 元素清单（自上而下）

### 3.1 TopBar / 侧边栏 / 面包屑

同 A-订单管理页，当前菜单为 "退款审批"，面包屑为 "首页 / 套餐订单 / 退款审批"。

### 3.2 待办摘要条

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 16 px，margin-bottom 16 px，背景 `#E6F7FF` |
| 内容 | "待审批：{N} 条 · 争议申诉：{M} 条"，14px Regular |

### 3.3 筛选区

| 字段 | 值 |
|------|-----|

| 审批状态下拉 | 宽度 160 px：全部 / 待审批 / 处理中 / 已批准 / 已驳回 |
| 退款类型下拉 | 宽度 160 px：全部 / 正常退款 / 争议申诉 |
| 申请时间 | 双日期选择器 |
| 关键词搜索 | 宽度 240 px，placeholder "订单号 / 用户 / 教练" |
| 查询按钮 | 主按钮 #1890FF |
| 重置按钮 | 默认按钮 |

### 3.4 表格区

| 字段 | 值 |

| 字段 | 值 |

| 驳回 | 红色文字按钮，仅待审批/争议处理中显示 |

## 6. 四态设计

### 6.1 空状态

- 表格空：空插画 + "暂无退款申请" + 「刷新」按钮。

### 6.2 加载中

- 表格骨架屏 3 行。

### 6.3 错误状态

- 表格区域 `el-empty` "加载失败" + 「重试」按钮。

### 6.4 成功状态

- 列表正常展示，审批操作后刷新。

***

## 7. 业务规则引用

| 规则 | 来源 | 在本页的体现 |
|------|------|-------------|
| 管理员处理退款申请 | PRD §6.4 | 审批操作 |
| 争议申诉由管理员 3 工作日内决定 | PRD §6.10 | 争议申诉标签与待办摘要 |
| 退款两阶段：批准 → 处理中 → 已退款 | PRD §6.2.1 | 状态列 |
| 平台原因真实性审核 | PRD §6.4.5 | 详情页处理 |
