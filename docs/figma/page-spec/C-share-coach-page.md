# 页面规格：C-教练主页分享页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-038
> **对应 PRD**：§5.4.1 入驻与资料、§5.4.2 预约管理
> **版本**：v1.0 | **创建日期**：2026-08-02

---

## 1. 页面基础

| 字段 | 值 |
|------|-----|
| 页面名（中文） | 教练主页分享页 |

---

## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 已通过（1） | 是 | 完整功能 |
| 申请离职中（4） | 是 | 允许分享，但顶部增加隐私提示 |
| 其他状态 | 否 | 隐藏入口或提示"入驻审核通过后可分享" |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| 有可约时段 | 未来 7 天存在 schedule_slot | 分享卡片展示最近 3 个时段 |
| 无可约时段 | 未来 7 天无时段 | 卡片展示兜底文案 |
| 海报生成中 | 后端生成图片 | 按钮显示 loading |

|------|-----|

## 5. 跳转动线

| 起点 | 行为 |
|------|------|
| 分享给好友 | 调用微信小程序原生分享菜单 |
| 生成海报 | 底部弹出海报预览弹窗 |
| 保存相册 | 调起相册授权，保存图片 |
| 返回 | → 上一页（C-个人主页编辑页 或 C-教练端首页） |

---

## 6. 四态设计

| 状态 | 表现 |
|------|------|
| 空状态 | 无可约时段时卡片显示兜底文案 |
| 加载中 | 海报生成中显示 loading 占位 |
| 错误状态 | 海报生成失败提示"生成失败，请重试" |
| 成功状态 | 完整卡片预览 + 分享方式选择 |

## 7. 业务规则引用

| 规则 | 来源 | 本页应用 |
|------|------|---------|
| 教练可分享个人主页 | US-038 §4.1 / §5 规则 1 | §3.3 分享卡片 |
| 分享卡片包含个人形象照/姓名/任教年限/评分/可约时段 | US-038 §6.1 | §3.3 卡片内容 |
| 游客落地页隐藏手机号与微信二维码 | US-038 §5 规则 3 / §14.1 | §3.3 卡片不含联系方式 |
| 申请离职中仍可使用分享功能 | US-039 / CROSS-BATCH §1.2 | §2.1 / §4 |
