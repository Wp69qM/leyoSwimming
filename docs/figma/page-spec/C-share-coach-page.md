## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
| ------ | :-------: | --------- |
| 已通过（1） | 是 | 完整功能 |
| 申请离职中（4） | 是 | 允许分享，但增加隐私提示 |
| 其他状态 | 否 | 隐藏入口或提示"入驻审核通过后可分享" |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
| ------ | ------ | ----------- |
| 有可约时段 | 未来 7 天存在 schedule_slot | 分享卡片展示最近 3 个时段 |
| 无可约时段 | 未来 7 天无时段 | 卡片展示兜底文案 |
| 海报生成中 | 后端生成图片 | 按钮显示 loading |

## 5. 跳转动线

| 起点 | 行为 |
| ------ | ------ |
| 分享给好友 | 调用微信小程序原生分享菜单 |
| 生成海报 | 弹出海报预览弹窗 |
| 保存相册 | 调起相册授权，保存图片 |
| 返回 | → 上一页（C-个人主页编辑页 或 C-教练端首页） |

## 6. 四态设计

| 状态 | 表现 |
| ------ | ------ |
| 空状态 | 无可约时段时卡片显示兜底文案 |
| 加载中 | 海报生成中显示 loading 占位 |
| 错误状态 | 海报生成失败提示"生成失败，请重试" |
| 成功状态 | 完整卡片预览 + 分享方式选择 |
