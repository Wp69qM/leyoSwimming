## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 业务含义 | 是否可见 | 差异说明 |
|------|---------|:--------:|---------|
| -1 未提交 | 尚未提交入驻资料 | 否 | 重定向至 C-教练端入驻资料填写页 |
| 0 待审核 | 入驻审核中 | 否 | 重定向至 C-教练端等待审核页 |
| 1 已通过 | 已入驻 | 否 | 可申请离职，申请后进入本页 |
| 2 已驳回 | 入驻被驳回 | 否 | 重定向至 C-教练端入驻资料填写页 |
| 3 已离职 | 已审批通过离职 | 否 | 重定向至 `C-入驻资料页`（重新入驻状态） |
| 4 申请离职中 | 离职申请已提交 | 是 | 本页默认场景；教练从「我的」页面主动点击「查看离职申请」进入，展示当前工单进度 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| 教练刚提交申请 | ticket.status = processing | 进度文案"等待教练处理学员套餐"，"查看离职工单"按钮高亮 |
| 教练已提交至管理员 | ticket.status = pending_audit | 进度文案"已提交管理员审批"，预计处理时间展示 |
| 管理员审批通过 | coach.status = 3 | 本页不可见，自动重定向至 `C-入驻资料页`（重新入驻状态） |
| 管理员拒绝审批 | coach.status = 1 | 本页不可见，自动重定向至教练首页 |

## 5. 跳转动线

| 起点 | 行为 | 条件/说明 |
|------|------|----------|
| 提交离职申请成功 | → C-离职处理中页 | US-039 主路径 |
| 「我的」页面点击「查看离职申请」 | → C-离职处理中页 | coach.status = 4 时显示入口，教练主动查看 |
| 查看离职工单按钮 | → C-离职工单处理页 | 进入工单详情进行学员套餐处理 |
| 客服/帮助入口 | 打开客服会话 / 帮助页面 | — |
| 管理员审批通过（US-041） | → `C-入驻资料页`（重新入驻状态） | coach.status 4 → 3 |
| 管理员拒绝审批（US-041） | → C-教练端首页 | coach.status 4 → 1 |

## 6. 四态设计

| 状态 | 表现 |
|------|------|
| 空状态 | 无（状态页主态即处理中态） |
| 加载中 | 状态图标区与进度卡显示骨架屏 |
| 错误状态 | 网络异常时中央错误插画 + "加载失败，点击重试" |
| 成功状态 | 按 §3 完整展示处理中状态、进度卡、提示说明与操作按钮 |

## 7. 业务规则引用

| 规则 | 来源 | 在本页的体现 |
|------|------|-------------|
| 提交离职申请后 coach.status = 4 | US-039 §4.1 | 本页仅对 status=4 展示；教练主动从「我的」页面进入 |
| 离职工单 ticket.status 初始为 processing | US-039 §7.3 | §3.3 进度文案 |
| 教练提交工单后 ticket.status 变为 pending_audit | US-039 §4.1 | §3.3 进度文案更新 |
| 审批通过后 coach.status 4 → 3 | US-041 §7.3 | §5 跳转至 `C-入驻资料页`（重新入驻状态） |
| 审批拒绝后 coach.status 4 → 1 | US-041 §7.3 | §5 跳转至教练首页 |
| 状态 4 期间不通知学员，不展示「申请中」标签 | US-039 §5 | 本页为隐私状态页，列表/搜索不暴露；不拦截教练正常登录/上课 |
