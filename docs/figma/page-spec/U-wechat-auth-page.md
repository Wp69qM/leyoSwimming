## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | ✅ | 当前页面目标用户；展示完整授权引导与一键登录按钮 |
| 注册用户 | ❌ | 已登录用户不应进入此页；若通过旧链接/分享进入，自动跳转 `U-首页` |
| 学员 | ❌ | 已登录用户不应进入此页；若通过旧链接/分享进入，自动跳转 `U-首页` |
| 教练 | ❌ | 教练端使用教练端小程序登录流程 |
| 管理员 | ❌ | 管理端使用 Web 后台登录流程 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| **未发起授权** | 用户刚进入页面，尚未点击登录 | 展示品牌区 + 底部登录按钮，无 loading |
| **授权中** | 用户已点击「微信一键登录」，正在调用 `wx.login()` 或后端 `code2session` | 按钮进入 loading，显示「登录中…」文案，防止重复点击 |
| **新用户首次登录** | 微信返回新用户，后端 `is_new_user=true` | 登录成功后自动跳转 `U-补充手机号页`（US-005） |
| **老用户已完善资料** | 微信返回老用户，`profile_completed=true` | 登录成功后自动跳转 `U-首页` |
| **老用户资料不完整** | 微信返回老用户，但 `profile_completed=false` | 登录成功后自动跳转 `U-补充手机号页` |
| **用户拒绝授权** | 用户在授权弹窗中点击「拒绝」 | 停留在本页，展示错误提示「需要微信授权才能登录」+ 「重新授权」按钮 |
| **微信接口失败** | `wx.login()` 失败或后端调用微信 `code2session` 失败 | 停留在本页，展示错误提示「微信服务暂时不可用，请稍后重试」 |
| **登录凭证失效** | 用户提交的 `code` 已过期或已被使用 | 停留在本页，展示错误提示「登录凭证已失效，请重新点击登录」 |

## 5. 跳转动线矩阵

> 本页所有跳转由用户主动点击或登录成功后自动触发。以下矩阵按「触发元素/状态」组织。

| 触发条件 | 游客 | 注册用户 | 学员 |
|---------|------|---------|------|
| 点击「微信一键登录」且成功 + `is_new_user=true` | → `U-补充手机号页` | — | — |
| 点击「微信一键登录」且成功 + `profile_completed=true` | → `U-首页` | — | — |
| 点击「微信一键登录」且成功 + `profile_completed=false` | → `U-补充手机号页` | — | — |
| 点击「使用手机号登录」 | → `U-登录页` | — | — |
| 点击《隐私协议》/《用户须知》 | → `U-隐私协议页` | — | — |
| 用户拒绝授权后点击「重新授权」 | 调用 `wx.openSetting()` | — | — |
| 已登录用户通过旧链接进入 | — | 自动 → `U-首页` | 自动 → `U-首页` |

> **登录成功后的回跳逻辑**：若用户从受登录限制的功能（如购买套餐、预约）被引导至本页，登录成功后应返回原页面并刷新身份状态；若直接打开小程序进入本页，登录成功后按 `profile_completed` 跳转首页或补充资料页。

### 5.1 跳转参数说明

| 参数 | 类型 | 来源 | 用途 |
|------|------|------|------|
| source_page | string | 拦截来源页 | 记录用户从哪个页面被引导至授权页，用于登录成功后回跳 |
| target_action | string | 拦截来源操作 | 如 `purchase_package` / `book_slot`，登录成功后继续该操作 |
| code | string | 微信 `wx.login()` | 用于后端换取 openid/session_key |
| is_new_user | boolean | 后端返回 | 判断新/老用户，决定跳转补充资料页或首页 |
| profile_completed | boolean | 后端返回 | 判断资料是否完善，决定跳转首页或补充资料页 |

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 页面首次加载，未触发任何操作 | 与成功态视觉一致，展示品牌元素 + 底部登录区；无错误提示 |
| **加载中** | 用户点击「微信一键登录」后，`wx.login()` 或后端接口处理中 | 品牌元素保留；底部登录按钮进入 loading 态，文案变为「登录中…」；隐私协议勾选区和手机号入口保持可见但不可交互 |
| **错误状态** | 用户拒绝授权 / 微信接口失败 / 登录凭证失效 / 网络超时 | 品牌元素保留但整体 opacity 降至 0.85；底部登录区上方显示错误提示区；拒绝授权时额外显示「重新授权」按钮；登录按钮恢复可点击 |
| **成功状态** | 微信授权成功且后端返回登录结果 | 页面保持品牌元素完整显示 300ms 后，以淡出动效（opacity 1→0, ease-out）离开并跳转目标页 |
| **协议未勾选状态** | 用户点击登录按钮但未勾选隐私协议 | 底部登录区上方显示「请先阅读并同意协议」提示，按钮不进入 loading |
