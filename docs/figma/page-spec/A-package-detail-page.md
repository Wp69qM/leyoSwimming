# 页面规格：A-套餐详情页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时必须按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-021 / US-043 / US-045 / US-050
> **对应 PRD**：§5.5.1.2 手动冻结/解冻 package、§4.2 套餐状态机
> **说明**：本规格描述一个弹窗（Modal），用于在 A-套餐管理页中查看用户购买后生成的 package 实例详情。套餐名称、模式、班级规模、泳姿、课时、有效期、价格、退款规则等信息均取自 package 购买时快照，不随 package_template 后续变更而改变。
> **版本**：v1.0 | **创建日期**：2026-08-02

### 3.2 弹窗主体：套餐信息卡

| 字段 | 值 |
|------|-----|
| 容器 | 卡片 |
| 标题 | "套餐信息" |

| 状态标签 | Tag：active / exhausted / expired / frozen / refunded |
| 套餐名称 | 可点击文字链接，点击弹出「套餐模板详情弹窗」，展示购买时对应的模板配置信息 |

| 到期时间 | package.expire_at |
| 已消耗 | 可点击跳转「上课记录」Tab |
| 已预约 | — |
| 剩余 | — |
| 金额信息 | 实付金额、单价/课时 |
| 冻结信息 | frozen 状态时显示 frozen_reason 与冻结时间 |

> **自定义套餐差异**：
> - 不展示「套餐模式」Tag；可用 Tag「自定义套餐」替代或不展示
> - 展示班级规模、课时数、每节课时长、有效期、单价/课时、实付总价
> - 实付总价 = 购买时教练参考单价 × 课时数

### 3.5 子弹窗：套餐模板详情弹窗

| 字段 | 值 |
|------|-----|
| 触发 | 点击套餐信息卡中的「套餐名称」 |
| 标题 | "套餐模板详情" |
| 说明文字 | "以下信息为购买时快照，不随套餐模板后续变更而改变" |
| 内容 | 与「模板配置新建页」元素一致，展示购买时的模板完整信息 |
| 字段清单 | 套餐名称、套餐模式、班级规模、泳姿、课时数、每节课时长、有效期、原价、售价、退款规则、套餐介绍、套餐图片、标签等 |
| 自定义套餐差异 | 不展示营销字段（介绍、图片、标签）；展示教练、班级规模、课时数、每节课时长、有效期、单价/课时、实付总价 |
| 操作按钮 | 「关闭」 |

> **备注**：若原模板已删除或不存在，弹窗顶部提示「原模板已失效」，但仍展示购买时快照内容。

### 3.6 子弹窗：冻结确认弹窗

| 字段 | 值 |
|------|-----|
| 触发 | 点击底部「冻结」按钮 |
| 标题 | "冻结套餐" |
| 套餐信息摘要 | 套餐名称、当前剩余课时、到期时间 |
| 提示文案 | "冻结后该套餐将无法继续预约课程，已有的未上课预约将被取消。" |
| 冻结原因单选 | 投诉处理中 / 异常订单 / 司法冻结 |
| 备注输入框（可选） | 管理员补充说明，最多 500 字符 |
| 操作按钮 | 「取消」/「确认冻结」 |
| 二次确认 | 点击「确认冻结」后再次弹窗提示「确认冻结后不可撤销，是否继续？」（或采用二次确认弹窗/Checkbox 形式） |
| 提交后反馈 | 关闭弹窗，Toast「套餐已冻结」，详情弹窗状态更新为 frozen，套餐信息卡展示冻结原因与冻结时间 |

### 3.7 子弹窗：解冻确认弹窗

| 字段 | 值 |
|------|-----|
| 触发 | 点击底部「解冻」按钮 |
| 标题 | "解冻套餐" |
| 套餐信息摘要 | 套餐名称、当前剩余课时、到期时间 |
| 提示文案 | "解冻后该套餐恢复为可预约状态，学员可继续预约课程。" |
| 当前冻结原因展示 | 只读展示当前 frozen_reason 及细分原因 |
| 操作按钮 | 「取消」/「确认解冻」 |
| 提交后反馈 | 关闭弹窗，Toast「套餐已解冻」，详情弹窗状态更新为 active，冻结原因清空 |

### 3.8 子弹窗：延期弹窗

| 字段 | 值 |
|------|-----|
| 触发 | 点击底部「延期」按钮 |
| 标题 | "延期套餐" |
| 套餐信息摘要 | 套餐名称、当前剩余课时、当前到期时间 |
| 新到期时间选择 | 日期时间选择器，必须晚于当前时间 |
| 延期原因 | 多行文本输入框，必填，最多 200 字 |
| 提示文案 | "延期后套餐有效期将更新，已消耗的课时不受影响。" |
| 操作按钮 | 「取消」/「确认延期」 |
| 校验失败 | 新到期时间早于等于当前时间，提示"新到期时间必须晚于当前时间"；延期原因为空或超过 200 字，提示"请输入延期原因，最多 200 字" |
| 提交后反馈 | 关闭弹窗，Toast"套餐已延期"，详情弹窗状态从 expired 更新为 active（如适用），到期时间更新 |

### 3.9 子弹窗：退款原因弹窗

| 字段 | 值 |
|------|-----|
| 触发 | 点击底部「退款」按钮 |
| 标题 | "发起退款" |
| 套餐信息摘要 | 套餐名称、总课时、已消耗课时、剩余课时、到期时间、退款比例 |
| 可退金额 | 输入框，默认展示系统计算的 refund_amount；管理员可修改，但不得超过计算金额且不能小于 0 |
| 金额调整原因 | 当管理员修改金额时必填，最多 500 字符 |
| 退款原因输入框 | 必填，最多 500 字符 |
| 提示文案 | "发起退款后将生成一笔退款订单，请前往订单管理页进行审批。原购买订单状态保持不变。" |
| 操作按钮 | 「取消」/「确认发起退款」 |
| 校验失败 | 1. 退款原因未填写时，提示"退款原因不能为空"；2. 可退金额小于 0 或超过系统计算金额时，提示"退款金额必须在 0 ~ {计算金额} 元之间"；3. 金额被修改且未填写调整原因时，提示"请填写金额调整原因" |
| 提交后反馈 | 关闭弹窗，Toast"退款订单已生成，请前往订单管理审批"，详情弹窗状态更新为 frozen，frozen_reason 展示为 refund_pending；生成的退款订单以填写的金额为准 |

## 6. 四态设计

### 6.1 空状态

- Tab 无数据时显示 `el-empty` "暂无数据"。

### 6.2 加载中

- 弹窗内容区 `el-loading` 遮罩。

### 6.3 错误状态

- 弹窗内错误占位：插画 + "套餐不存在" + 「关闭」按钮。

### 6.4 成功状态

- 套餐信息与状态标签正常展示。

## 7. 业务规则引用

| 规则 | 来源 | 在本弹窗的体现 |
|------|------|---------------|
| package 状态机 | PRD §4.2 / 全局原则 §3.4 | 状态标签与操作按钮显隐 |
| 冻结原因 3 值枚举 | PRD §5.5.1.2 | 冻结信息说明 |
| 管理员手动冻结/解冻 | PRD §5.5.1.2 | 底部操作按钮 |
| 手动延期条件 | PRD §4.6 | 延期按钮显隐 |
| 管理员对 active package 发起退款 | US-028 | 退款按钮；发起后生成退款订单并在订单管理页审批 |
| 退款资格受 package 快照 refund_enabled / refund_valid_days 控制 | US-027 / US-045 | 退款按钮置灰/隐藏条件 |
| 已购 package 保存模板快照 | US-045 | 套餐信息卡字段取自快照；套餐模板详情弹窗展示购买时模板信息 |
| 模板上下架与 package 实例状态分离 | US-045 | 本弹窗不展示 package_template 的 active/inactive 上下架状态 |
| 套餐管理与订单管理职责边界 | US-043 / US-046 | 本弹窗仅发起退款，审批/驳回/金额调整在 A-订单管理页 |
