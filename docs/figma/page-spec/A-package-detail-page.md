# 页面规格：A-套餐详情页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时必须按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-021 / US-050 / US-045
> **对应 PRD**：§5.5.1.2 手动冻结/解冻 package、§4.2 套餐状态机
> **说明**：本页面展示的是用户购买后生成的 package 实例详情。套餐名称、模式、教学类型、泳姿、课时、有效期、价格、退款规则等信息均取自 package 购买时快照，不随 package_template 后续变更而改变。
> **版本**：v1.0 | **创建日期**：2026-08-02

## 2. 状态维度

| 维度 | 状态枚举 | 页面影响 |
|------|---------|---------|
| 套餐状态 | active / exhausted / expired / frozen / refunded | 操作按钮显隐 |
| 冻结原因 | coach_resigned / refund_pending / admin_frozen | 冻结信息卡显示 |

## 3. 元素清单（自上而下）

### 3.1 TopBar / 侧边栏 / 面包屑

同 A-套餐管理页，面包屑当前页为 "套餐详情"。

### 3.2 购买时快照信息卡

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 24 px，margin-bottom 16 px |
| 标题 | "购买时快照"，16px Medium #262626 |
| 说明文字 | 12px Regular #8C8C8C："以下信息为购买时快照，不随套餐模板变更而改变" |
| 套餐名称 | 16px Medium #262626 |
| 套餐模式 | Tag：正价套餐 / 体验课 |
| 教练 | 姓名，可跳转 |
| 教学类型 | 私教 / 小班 / 大班等 |
| 泳姿 | 蛙泳 / 自由泳 / 仰泳 / 蝶泳等，可多选 |
| 课时数 | 总课时数 |
| 每节课时长 | duration_minutes，单位：分钟 |
| 有效期 | valid_days，单位：天 |
| 原价 | original_price |
| 实付价 | price |
| 退款规则 | 是否可退款、退款比例、退款有效天数 |
| 查看当前模板 | 文字链接（可选），跳转至模板配置页查看当前模板最新信息 |

> **备注**：「查看当前模板」为可选入口，用于管理员在购买后仍想查看当前模板最新信息时使用。若当前模板已删除或不存在，则链接置灰并提示「模板已失效」。

### 3.3 套餐信息卡

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 24 px，margin-bottom 16 px |
| 标题 | "套餐信息"，16px Medium #262626 |
| 套餐编号 | 20px Medium #262626 |
| 状态标签 | Tag：套餐状态 |
| 信息行 | 用户（可跳转）、购买时间、到期时间、总课时、已消耗、已预约、剩余 |
| 金额信息 | 实付金额、单价/课时 |
| 冻结信息 | frozen 状态时显示 frozen_reason 与冻结时间 |

### 3.4 状态机说明卡

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 24 px，margin-bottom 16 px |
| 标题 | "状态流转"，16px Medium #262626 |
| 内容 | 状态机图：active → exhausted / expired / frozen → refunded / active |
| 当前状态高亮 | 当前状态节点使用 `#1890FF` 描边 |

### 3.5 操作按钮区

## 6. 四态设计

### 6.1 空状态

- Tab 无数据时显示 `el-empty` "暂无数据"。

### 6.2 加载中

- 页面级 `el-loading` 遮罩。

### 6.3 错误状态

- 错误占位页：插画 + "套餐不存在" + 「返回列表」按钮。

### 6.4 成功状态

- 套餐信息与状态机正常展示。
