> **对应 PRD**：§3.5 单教练约束、§4.1 套餐类型、§4.4 关键不变量、§4.5 体验课特殊规则、§5.1 游客功能、§5.2.3 转化入口、§5.3.1 教练与套餐浏览、§5.5.3 套餐与订单、§13.3 MVP 页面 9

## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | ✅ | 可浏览全部公开套餐；点击购买跳转 `U-微信授权页` |
| 注册用户 | ✅ | 可浏览并购买体验课/正价套餐；无单教练限制 |
| 学员 | ✅ | 已绑定教练 A 时，仅教练 A 的套餐可购买；其他教练套餐置灰并提示"已绑定其他教练" |
| 教练 | ❌ | 教练端使用教练端小程序 |
| 管理员 | ❌ | 管理端使用 Web 后台 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| **无体验套餐** | 用户名下无 active/exhausted 体验套餐 | 体验课套餐显示「购买」按钮 |
| **已有体验套餐** | 用户持有 active/exhausted 体验套餐 | 体验课卡片显示「已购买」徽标，按钮禁用或隐藏 |
| **未绑定教练** | 用户为游客或注册用户，无 active 正价套餐 | 所有正价套餐正常显示购买入口 |
| **已绑定教练 A** | 学员持有教练 A 的 active 套餐 | 教练 A 的套餐正常显示；其他教练套餐置灰并提示 |
| **教练 status ≠ 1** | 教练未通过审核或已离职 | 该教练所有套餐不展示或展示为空 |
| **无标准套餐配置** | 管理员未配置标准套餐 | 标准套餐区显示空状态，仅展示自定义课时入口 |
| **教练未设参考单价** | 教练未设置参考单价 | 自定义课时入口置灰，提示"教练尚未开放自定义课时" |
| ** coach.status = 4（申请离职中）**| 教练申请离职但尚未完成交接 | 该教练套餐卡片 opacity 0.5，CTA 置灰，提示"暂不可购买" |
| ** coach.status = 3（已离职）**| 教练已完成离职交接 | 该教练套餐不在列表中展示 |
| **筛选结果为空** | 当前筛选条件下无匹配套餐 | 按套餐类型显示对应空状态提示 |

> **列表排序默认规则**：体验课卡片固定置顶（仅 1 张或无）；正价套餐按「教练 status=1 优先 + 综合排序」展示；学员已绑定教练时，该教练套餐置顶显示。

| 体验课"立即购买" | → `U-微信授权页` | → `U-订单确认页`（体验课） | → `U-订单确认页`（体验课，限本教练/无教练） |
| 标准套餐卡片 | → `U-微信授权页` | → `U-套餐详情页` | → `U-套餐详情页`（本教练）；冲突态无操作 |
| 自定义课时入口 | → `U-微信授权页` | → `U-套餐详情页`（自定义） | → `U-套餐详情页`（本教练）；冲突态无操作 |
| 筛选"全部" / "体验课" / "正价课" | 刷新列表过滤 | 同左 | 同左 |

> **"引导登录"**：当游客点击受登录限制的功能时，应跳转登录页，而不是直接提示错误。登录成功后返回原页面并刷新身份状态。

### 5.1 跳转参数说明

| 参数 | 类型 | 来源 | 用途 |
|------|------|------|------|
| package_id | string | 卡片数据 | 标准套餐/自定义课时进入详情页时标识套餐 |
| coach_id | string | 卡片数据 | 体验课进入订单确认页时标识教练 |
| package_type | int | 卡片数据 | 0=体验课 / 1=正价课，订单确认页据此渲染 |
| filter_type | string | 当前筛选状态 | "all" / "experience" / "standard"，用于登录回跳后恢复筛选 |

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 系统无可用套餐 / 当前筛选结果为空 | 隐藏套餐卡片列表；居中展示空状态插画 + "暂无套餐，敬请期待" |
| **加载中** | 首次进入 / 切换筛选 / 下拉刷新 | 显示骨架屏；NavBar / 筛选栏保持可见 |
| **错误状态** | 网络/服务异常 | 隐藏骨架屏；居中展示错误插画 + 文案 + "重新加载" 按钮 |
| **成功状态** | 数据正常返回 | 按 §4 矩阵完整展示；默认按「体验课优先 + 正价套餐综合排序」 |
| **筛选切换状态** | 用户切换筛选条件 | 列表区域显示骨架屏或 loading 指示器，NavBar/筛选栏保持可见，切换完成后按新条件展示 |
