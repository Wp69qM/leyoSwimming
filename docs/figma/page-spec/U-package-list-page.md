# 页面规格：U-套餐列表页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-002（游客查看套餐、公告与场馆信息）/ US-017（游客购买体验课套餐）/ US-019（学员浏览正价套餐）/ US-045（套餐模板上下架与字段扩展）
> **对应 PRD**：§3.5 单教练约束、§4.1 套餐类型、§4.4 关键不变量、§4.5 体验课特殊规则、§5.1 游客功能、§5.2.3 转化入口、§5.3.1 教练与套餐浏览、§5.5.3 套餐与订单、§13.3 MVP 页面 9

## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | ✅ | 可浏览全部公开套餐；点击购买跳转 `U-微信授权页` |
| 注册用户 | ✅ | 可浏览并购买体验课/正价套餐；无单教练限制 |
| 学员 | ✅ | 已绑定教练 A 时，仅教练 A 的套餐可购买；其他教练套餐置灰并提示"已绑定其他教练" |
| 教练 | ❌ | 教练端使用教练端小程序 |
| 管理员 | ❌ | 管理端使用 Web 后台 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| **无体验套餐** | 用户名下无 active/exhausted 体验套餐 | 体验课套餐显示「购买」按钮 |
| **已有体验套餐** | 用户持有 active/exhausted 体验套餐 | 体验课卡片显示「已购买」徽标，按钮禁用或隐藏 |
| **未绑定教练** | 用户为游客或注册用户，无 active 正价套餐 | 所有正价套餐正常显示购买入口 |
| **已绑定教练 A** | 学员持有教练 A 的 active 套餐 | 教练 A 的套餐正常显示；其他教练套餐置灰并提示 |
| **教练 status ≠ 1** | 教练未通过审核或已离职 | 该教练所有套餐不展示或展示为空 |
| **套餐 template status ≠ 'active'** | 标准套餐模板未上架 | 该套餐不在列表中展示 |
| **无在售标准套餐** | 管理员未配置标准套餐，或所有标准套餐均已下架 | 标准套餐区显示空状态，文案"暂无在售正价套餐" |
| **教练未设参考单价** | 教练未设置参考单价 | 自定义课时入口置灰，提示"教练尚未开放自定义课时" |
| ** coach.status = 4（申请离职中）**| 教练申请离职但尚未完成交接 | 该教练套餐卡片置灰，CTA 置灰，提示"暂不可购买" |
| ** coach.status = 3（已离职）**| 教练已完成离职交接 | 该教练套餐不在列表中展示 |

> **列表排序默认规则**：体验课卡片固定置顶（仅 1 张或无）；正价套餐按「教练 status=1 优先 + 综合排序」展示；学员已绑定教练时，该教练套餐置顶显示。

## 5. 跳转动线矩阵

| 起点元素 | 游客 | 注册用户 | 学员 |
|---------|------|---------|------|
| 返回按钮 | → 上一页 | → 上一页 | → 上一页 |
| 体验课"立即购买" | → `U-微信授权页` | → `U-套餐详情页`（体验课） | → `U-套餐详情页`（体验课，限本教练/无教练） |
| 标准套餐卡片 | → `U-微信授权页` | → `U-套餐详情页` | → `U-套餐详情页`（本教练）；冲突态无操作 |
| 自定义课时入口 | → `U-微信授权页` | → `U-套餐详情页`（自定义） | → `U-套餐详情页`（本教练）；冲突态无操作 |

> **"引导登录"**：当游客点击受登录限制的功能时，应跳转登录页，而不是直接提示错误。登录成功后返回原页面并刷新身份状态。

### 5.1 跳转参数说明

| 参数 | 类型 | 来源 | 用途 |
|------|------|------|------|
| package_id | string | 卡片数据 | 标准套餐/自定义课时进入详情页时标识套餐 |
| coach_id | string | 卡片数据 | 体验课进入详情页时标识教练 |
| package_type | int | 卡片数据 | 0=体验课 / 1=正价课，详情页/订单确认页据此渲染 |

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 系统无可用套餐 | 隐藏套餐卡片列表；居中展示空状态插画 + "暂无套餐，敬请期待" |
| **加载中** | 首次进入 / 下拉刷新 | 显示骨架屏；NavBar 保持可见 |
| **错误状态** | 网络/服务异常 | 隐藏骨架屏；居中展示错误插画 + 文案 + "重新加载" 按钮 |
| **成功状态** | 数据正常返回 | 按 §4 矩阵完整展示；默认按「体验课优先 + 正价套餐综合排序」 |

> **AI 生成备注**：本页为购买转化漏斗中间页，AI 生成时应重点保证体验课卡片视觉突出、正价套餐列表信息层级清晰、列表滚动与空状态切换自然。
>
> **设计重点**：列表页的核心目标是帮助用户快速定位可购买套餐，因此体验课卡片与正价套餐卡片必须在色彩、尺寸、CTA 上形成明确区分，同时单教练约束提示需足够醒目但不遮挡主要内容。
>
> **验收红线**：若 AI 生成的列表页出现体验课卡片与正价卡片样式混淆、或学员绑定其他教练时仍可点击购买，视为不合格。
>
