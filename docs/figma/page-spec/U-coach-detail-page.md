## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | 是 | 可浏览全部公开资料、可约时间、套餐、评价；点击购买/预约/联系时引导登录 |
| 注册用户 | 是 | 可购买体验课/正价套餐；无"继续上课"入口 |
| 学员（已绑定本教练）| 是 | 展示"预约正课"与"购买加课套餐"入口；展示完整联系方式 |
| 学员（已绑定其他教练）| 是 | 隐藏本教练购买套餐入口，顶部提示单教练约束；不可购买 |
| 教练 | 否 | 教练端查看自己主页使用教练端页面 |
| 管理员 | 否 | 管理端使用 Web 后台 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| `coach.status = 1` | 教练已通过审核 | 正常展示购买/预约入口 |
| `coach.status = 4` | 教练申请离职中 | 页面仍正常展示，但**不显示**"申请离职中"标签；购买按钮置灰/隐藏，提示"暂不可购买" |
| `coach.real_time_status = 请假中` | 教练请假 | 隐藏"立即预约"类 CTA，顶部显示提示条 |
| 用户无体验套餐 | 未持有 active/exhausted 体验套餐 | 展示"购买体验课"入口 |
| 用户已有体验套餐 | 持有 active/exhausted 体验套餐 | 隐藏"购买体验课"入口 |
| 用户持有本教练 active 套餐 | 学员且单教练约束满足 | 展示"预约正课" + "购买加课套餐" |
| 用户持有其他教练 active 套餐 | 学员但教练冲突 | 隐藏购买入口，显示冲突提示 |

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| 空状态 | 教练无简介/无证书/无评价/无可约时段/无套餐配置 | 对应卡片内显示空状态文案（如"暂无简介""暂无可约时段"），整体页面其他可展示模块仍保留；教练不存在时整页显示"教练信息不存在" |
