## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | 是 | 可浏览全部公开资料、可约时间、套餐、评价；点击购买/预约/联系时引导登录 |
| 注册用户 | 是 | 可购买体验课/正价套餐；无"继续上课"入口 |
| 学员（已绑定本教练）| 是 | 展示"预约正课"与"购买加课套餐"入口；展示完整联系方式 |
| 学员（已绑定其他教练）| 是 | 隐藏本教练购买套餐入口，顶部提示单教练约束；不可购买 |
| 教练 | 否 | 教练端查看自己主页使用教练端页面 |
| 管理员 | 否 | 管理端使用 Web 后台 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| `coach.status = 1` | 教练已通过审核 | 正常展示购买/预约入口 |
| `coach.status = 4` | 教练申请离职中 | 页面仍正常展示，但**不显示**"申请离职中"标签；购买按钮置灰/隐藏，提示"暂不可购买" |
| `coach.real_time_status = 请假中` | 教练请假 | 隐藏"立即预约"类 CTA，顶部显示提示条 |
| 用户无体验套餐 | 未持有 active/exhausted 体验套餐 | 展示"购买体验课"入口 |
| 用户已有体验套餐 | 持有 active/exhausted 体验套餐 | 隐藏"购买体验课"入口 |
| 用户持有本教练 active 套餐 | 学员且单教练约束满足 | 展示"预约正课" + "购买加课套餐" |
| 用户持有其他教练 active 套餐 | 学员但教练冲突 | 隐藏购买入口，显示冲突提示 |

## 3. 元素清单（自上而下）

> **设计原则**：
> 1. 每个元素必须说明：名称、作用、显示条件、交互行为、关联业务规则。
> 2. 快捷入口 ≠ TabBar 重复。
> 3. 同一业务入口在不同身份下形态可能不同，必须分身份定义。

| 元素名称 | 作用 | 显示条件 | 交互行为 | 关联业务规则 |
|----------|------|----------|----------|--------------|
| 状态栏 + NavBar | 为系统状态栏预留区域并展示页面标题「教练详情」与返回入口 | 所有身份 | 点击返回按钮 → 返回上一页；右侧分享图标为 P3 预留 | 全局设计规范 §2.5.6；PRD §5.3.1 |
| 教练头部信息区 | 展示教练个人形象照、姓名、性别、实时状态、评分、教龄/年龄、累计课时、带过学员数、证书标签等核心信息 | 所有身份 | 无 | US-001 §4.1；US-012 §4.1；PRD §5.4.1 |
| 教练简介区 | 展示教练简介、擅长泳姿、证书列表 | 所有身份 | 简介超出时显示「展开」文字按钮；证书列表横向滚动 | US-001 §4.1；US-012 §4.1；PRD §5.4.1 |
| 参考单价区 | 展示教练参考单价，作为套餐定价基准 | 所有身份 | 无 | US-012 §4.1；PRD §5.4.1 / §5.5.3 |
| 联系方式区 | 展示电话、微信二维码、聊天入口（P3 禁用） | 游客隐藏具体号码/二维码，显示登录引导；注册用户/学员显示完整入口 | 点击电话 → 调起系统拨号；点击微信 → 二维码弹窗；聊天入口 P3 禁用 | PRD §5.3.1；US-001 |
| 可约时间预览区 | 预览本周（周一至周日）每天可约时段 | 所有身份 | 点击「查看全部」→ `U-教练排班页`（US-029） | US-001 §4.1 / §6.8；PRD §5.3.1 |
| 可选套餐区 | 展示体验课套餐、标准套餐、自定义课时入口 | 按用户身份与套餐资格显隐 | 点击套餐卡片 → 套餐详情页；点击「更多」→ 完整套餐列表；点击自定义课时 → 订单确认页 | US-001 §4.1 / §6.7；US-017；US-019 / US-020；PRD §4.1 / §4.5 / §5.5.3 |
| 评价区 | 展示评分汇总、评价标签与最多 3 条评价 | 所有身份 | 点击「查看全部评价」→ `U-评价列表页` | US-001 §4.1；PRD §5.3.1 |
| 底部固定 CTA 栏 | 根据身份与教练状态展示主要操作按钮 | 按 §3.1 CTA 状态矩阵显隐 | 点击对应按钮 → 登录引导 / 订单确认页 / 套餐列表页 / 教练排班页 | US-001；US-017；US-020；PRD §3.5 单教练约束 |

### 3.1 教练头部信息区字段

| 字段 | 说明 |
|------|------|
| 个人形象照 | 教练头像 |
| 教练姓名 | 教练姓名 |
| 性别 | "男" / "女" |
| 实时状态徽标 | 按教练实时状态显示（空闲中 / 上课中 / 休息中 / 已下班 / 请假中） |
| 评分行 | 星形图标 + 评分数字 + "分" |
| 任教年限 / 年龄 | 如「教龄 X 年 · 32 岁」 |
| 数据标签组 | 如「累计 X 课时」「带过 X 学员」 |
| 证书标签 | 最多 2 个胶囊标签 + "+N" 省略 |

**状态徽标显隐规则**：
- 实时状态 = 空闲中 / 上课中 / 休息中 / 已下班 / 请假中 均显示对应徽标。
- coach.status = 4（申请离职中）**不展示任何特殊标签**，页面看起来与正常教练一致。

### 3.2 参考单价区状态

| 状态 | 表现 |
|------|------|
| 已设置参考单价 | 展示「参考单价 ¥XXX/节」与说明文案 |
| 未设置参考单价 | 展示「教练尚未设置参考单价」，说明「暂不可购买自定义课时」 |

### 3.3 联系方式区显隐规则

| 身份 | 表现 |
|------|------|
| 游客 | 隐藏具体号码/二维码，显示「登录后查看联系方式」文字按钮 |
| 注册用户/学员 | 显示电话与微信二维码入口 |
| 全部身份 | 聊天入口始终置灰（P3） |

### 3.4 可约时间预览区字段

| 字段 | 说明 |
|------|------|
| 日期行 | 纵向列表，每天一行：左侧「周一」~「周日」，右侧展示当天可约时段标签（如 "09:00-10:00"），每天最多 3 个；无时段显示 "暂无可约" |
| 时段标签 | 可约时段与已满/已锁定时段使用不同语义样式 |
| 空状态 | 本周均无可约时段时显示 "本周暂无可约时段" |

### 3.5 可选套餐区字段与规则

| 字段 | 说明 |
|------|------|
| 分组标题 | 左侧 "可选套餐"，右侧展示 "更多套餐" 文字按钮 |
| 查看更多 | 套餐数量 > 3 时标题行右侧展示 "更多套餐" 文字按钮，点击跳转完整套餐列表 |
| 套餐卡片 | 默认最多展示 3 个卡片；用户具备购买体验课资格时，第 1 张为体验课套餐，其余为标准套餐；不具备资格时 3 张均为标准套餐 |
| 体验课卡 | 主标题 "新人体验课"，副标题 "1 节 · 30 天有效"，价格 "¥99 起"，右侧 "立即购买" 按钮 |
| 标准套餐卡 | 展示套餐名、课时数、价格、单价；右侧箭头 |
| 卡片点击 | 点击任意套餐卡片进入套餐详情页，游客需登录后购买，学员可直接购买 |
| 自定义课时入口 | 标题 "自定义课时"，描述 "按参考单价灵活选择"，右侧箭头 |
| 空状态 | 管理员未配置标准套餐且教练未设置参考单价、且用户不具备体验课购买资格时，显示 "暂无可选套餐" |
| 购买条件 | 游客点击引导登录；学员绑定其他教练时隐藏本区购买入口或显示冲突提示；体验课卡仅在用户未持有 active/exhausted 体验套餐时展示 |

### 3.6 评价区字段

| 字段 | 说明 |
|------|------|
| 评分汇总 | 左侧大评分 + 星级 + "X 条评价" |
| 评价标签 | 横向滚动标签：如 "专业耐心" "进步明显" 等 |
| 评价列表 | 最多 3 条，每条包含头像、昵称、星级、内容（最多 2 行）、时间 |
| 查看更多 | 底部 "查看全部评价" 文字按钮 |
| 空状态 | 无评价时显示 "暂无评价" |

### 3.7 底部固定 CTA 栏

> **来源**：US-001（立即预约）、US-017（购买体验课）、US-020（购买正价套餐 / 预约正课）、PRD §3.5 单教练约束。
> CTA 文案与显隐由用户身份 + 套餐状态共同决定。

#### CTA 状态矩阵

| 用户身份/状态 | 主按钮 | 次按钮 | 说明 |
|--------------|--------|--------|------|
| 游客 | "预约体验课" | "购买正价套餐" | 点击均引导登录 |
| 注册用户（无体验套餐）| "购买体验课" | "购买正价套餐" | — |
| 注册用户（已有体验套餐）| "购买正价套餐" | 无 | 隐藏体验课入口 |
| 学员（绑定本教练）| "预约正课" | "购买加课套餐" | 加课套餐已过滤本教练 |
| 学员（绑定其他教练）| 无购买按钮 | 无 | 显示顶部冲突提示条，CTA 栏仅保留返回/客服入口 |

**教练状态影响**：
- coach.status = 4 或 coach.real_time_status = 请假中：所有"预约"类按钮置灰/隐藏。
- coach.status ≠ 1：所有购买按钮置灰/隐藏，提示"暂不可购买"。

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| 空状态 | 教练无简介/无证书/无评价/无可约时段/无套餐配置 | 对应卡片内显示空状态文案（如"暂无简介""暂无可约时段"），整体页面其他可展示模块仍保留；教练不存在时整页显示"教练信息不存在" |
| 加载中 | API 请求中 | 头部显示渐变占位；各卡片区域显示骨架屏占位 |
| 错误状态 | 网络/服务错误 / 教练 status=0/2/3 | 中央错误插画 + "加载失败，点击重试" + 按钮；教练未公开时提示"教练信息不存在" |
| 成功状态 | 数据正常返回 | 按 §4 矩阵完整显示 |
