# 页面规格：C-套餐使用详情页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时**必须**按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-021（教练视角承接）/ US-037（入口来源）
> **对应 PRD**：§4.1 套餐类型、§4.4 关键不变量、§4.5 体验课特殊规则、§4.6 套餐过期与续期、§5.3.3 我的套餐、§5.4.4 学员管理
> **版本**：v1.0 | **创建日期**：2026-08-12

---

## 1. 页面基础

| 字段 | 值 |
| ------ | ----- |
| 页面名（中文） | 套餐使用详情页 |
| 页面名（Frame） | `C-套餐使用详情页` |
| 平台 | 微信小程序 - 教练端 |
| 是否含 TabBar | 否 |
| 是否含 NavBar | **是**（标题 "套餐使用详情"） |
| 返回按钮 | 是 |

> **特别说明**：本页为 US-021 教练视角套餐详情页，由 US-037 学员详情页「关联套餐」卡片点击跳转进入。页面 focus 在「已购 package 实例的使用情况」，不提供购买/加课入口。

## 2. 教练与套餐状态维度

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
| ------ | :-------: | --------- |
| 教练（已通过/申请离职中） | ✅ | 查看与当前教练关联的 package 使用详情 |
| 其他身份 | ❌ | 重定向 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
| ------ | ------ | ----------- |
| **package 属于当前教练** | `package.coach_id = 当前 coach_id` | 正常展示 |
| **package 不属于当前教练** | 越权访问 | 展示"无权查看"空状态 |
| **status = active** | 套餐可用 | 展示「剩余课时」与「预约」入口（若业务需要） |
| **status = exhausted** | 课时已用完 | 展示「已使用」标签，使用记录完整展示 |
| **status = expired** | 已过期 | 展示「已过期」标签与过期日期，剩余课时若 >0 提示可申请延期 |
| **status = refunded** | 已退款 | 展示「已退款」标签，使用记录展示至退款前 |
| **status = frozen** | 冻结中 | 展示「已冻结」标签与冻结原因（如教练离职） |
| **package_mode = standard** | 正价套餐 | 展示标准套餐快照信息 |
| **package_mode = experience** | 体验课 | 展示体验课快照信息 |

> **状态优先级**：当多个状态同时满足时，以 package.status 标签为最高优先级展示。

## 5. 跳转动线

| 起点元素 | 行为 |
| --------- | ------ |
| 返回按钮 | → 上一页（通常为 C-学员详情编辑页） |
| 学员迷你卡 | → `C-学员详情编辑页`（携带 student_user_id） |
| 空状态 "返回" | → 上一页 |
| 错误状态 "重新加载" | 刷新当前页面 |

### 5.1 跳转参数说明

| 参数 | 类型 | 来源 | 用途 |
| ------ | ------ | ------ | ------ |
| package_id | string | C-学员详情编辑页套餐卡片 | 标识当前套餐，详情页据此查询 package 信息 |
| student_user_id | string | package 详情接口 | 标识套餐所属学员，用于返回学员详情页 |
| source_page | string | 当前页面标识 | 用于返回跳转，可选值：`student_detail` |

## 6. 四态设计

| 状态 | 触发 | 表现 |
| ------ | ------ | ------ |
| **空状态** | package 不存在 / 越权 | 隐藏套餐信息；展示空状态插画 + 文案 + "返回" 按钮 |
| **加载中** | 首次进入 / 刷新 | 显示骨架屏；NavBar 保持可见 |
| **错误状态** | 网络/服务异常 | 隐藏骨架屏；展示错误插画 + 文案 + "重新加载" 按钮 |
| **成功状态** | 数据正常返回 | 按 §4 矩阵完整展示套餐信息、统计摘要、学员卡、使用记录 |

## 7. 业务规则引用

| 规则 | PRD / US 引用 | 在本页面应用 |
| ------ | -------------- | ------------- |
| 教练仅可查看自己关联学员的 package 详情 | US-037 §4.1 / §5 规则 1 | §2.2 / §3.7 / §4 |
| package 实例保存模板快照，不受后续模板变更影响 | US-045 §6 / US-021 §12 | §3.2 字段均来自 package 快照 |
| 套餐状态机 active / exhausted / expired / refunded / frozen | PRD §3.4 / §4.2；US-021 §5 | §2.2 / §3.2 状态标签 |
| active → exhausted 由 available=0 且 reserved=0 自动触发 | PRD §4.4；US-050 §3 | §3.3 统计摘要 |
| 体验课优先于正价课扣减 | PRD §4.1 / §4.5 | §3.5 使用记录 |
| 教练离职后 package 冻结且学员/教练端可见 | PRD §3.7；US-041 | §2.2 frozen 状态 |
| 套餐详情页由 US-021 教练视角统一承接 | US-037 §5 规则 10 / §14.5 | 本页整体定义 |
