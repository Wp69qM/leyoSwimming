# 跨批次全局设计原则（Web 后台管理端）

> **用途**：确保 Web 后台管理端全部 MVP 页面在布局、组件、状态、权限、动线上保持全局一致。
> **适用范围**：Web 后台管理系统（管理员使用），基于 Element Plus 组件库。
> **版本**：v1.0
> **最后更新**：2026-08-02

***

## 1. 平台与画布基础

### 1.1 目标平台

- **框架**：Vue 3 + Element Plus
- **设计宽度**：1440 px（最小 1280 px，最大 1920 px）
- **内容区宽度**：自适应，左侧固定 220 px 侧边栏，右侧内容区最小 1060 px
- **网格**：8 px 基准网格
- **字体**：系统默认无衬线字体（PingFang SC / Microsoft YaHei / -apple-system）

### 1.2 全局布局

```
┌─────────────────────────────────────────────────────────────┐
│ 顶部导航栏（TopBar）64 px，背景 #FFFFFF，底部边框 #E4E7ED       │
├──────────┬──────────────────────────────────────────────────┤
│          │ 面包屑导航（Breadcrumb）48 px                      │
│ 侧边栏    ├──────────────────────────────────────────────────┤
│ 220 px   │                                                  │
│ 背景     │  内容区（Content）                                │
│ #001529  │  内边距 24 px                                     │
│          │  背景 #F0F2F5                                     │
│          │                                                  │
└──────────┴──────────────────────────────────────────────────┘
```

### 1.3 页面类型

| 类型 | 说明 | 典型页面 |
|------|------|---------|
| Dashboard | 数据看板 + 快捷入口 | 首页 |
| 管理列表 | 表格 + 筛选 + 分页 + 操作 | 用户管理、教练管理、订单管理 |
| 审核队列 | 待办列表 + 审批操作 | 教练入驻审核、离职审批、退款审批 |
| 详情页 | 信息展示 + 状态流 + 操作日志 | 用户详情、订单详情、工单详情 |
| 配置页 | 表单 + 开关 + 保存 | 场馆配置、预约释放配置、公告配置 |

## 3. 状态机与颜色规范

### 3.1 通用状态色

| 状态 | 颜色 | 用途 |
|------|------|------|
| 默认/处理中 | `#1890FF` | 待审核、处理中、待上课 |
| 成功/通过 | `#52C41A` | 已通过、已完成、已签到 |
| 警告/待处理 | `#FAAD14` | 待处理、待确认、请假中 |
| 错误/拒绝 | `#FF4D4F` | 已驳回、已取消、旷课 |
| 失效/离职 | `#8C8C8C` | 已离职、已过期、已封禁 |
| 冻结 | `#722ED1` | 冻结（package frozen） |

### 3.2 教练状态机

```
0（待审核） → 1（已通过） / 2（已驳回）
1（已通过） → 4（申请离职中）
4（申请离职中） → 3（已离职） / 1（审批拒绝）
```

| 状态 | 颜色 | 管理员可见操作 |
|------|------|---------------|
| 0 待审核 | `#1890FF` | 查看资料、通过、驳回 |
| 1 已通过 | `#52C41A` | 查看详情、取消入驻 |
| 2 已驳回 | `#FF4D4F` | 查看原因、重新审核（教练重新提交后） |
| 3 已离职 | `#8C8C8C` | 查看历史、不允许恢复 |
| 4 申请离职中 | `#FAAD14` | 查看工单、审批通过/拒绝 |

### 3.3 订单状态机

| 状态 | 颜色 | 管理员操作 |
|------|------|-----------|
| 待支付 | `#8C8C8C` | 查看、取消 |
| 已支付 | `#1890FF` | 查看、冻结/解冻 package |
| 退款审批中 | `#FAAD14` | 查看、批准/驳回 |
| 退款处理中 | `#FAAD14` | 查看、等待渠道回调 |
| 已退款 | `#52C41A` | 查看 |
| 退款被拒 | `#FF4D4F` | 查看 |
| 已取消 | `#8C8C8C` | 查看 |
| 争议处理中 | `#FF4D4F` | 查看、裁决 |

### 3.4 Package 状态机

| 状态 | 颜色 | 管理员操作 |
|------|------|-----------|
| active | `#52C41A` | 冻结、手动延期 |
| exhausted | `#8C8C8C` | 查看 |
| expired | `#FF4D4F` | 手动延期（条件见 PRD §4.6） |
| frozen | `#722ED1` | 解冻 |
| refunded | `#8C8C8C` | 查看 |

### 3.5 Booking 状态机

| 状态 | 颜色 |
|------|------|
| 已预约 | `#1890FF` |
| 待上课 | `#1890FF` |
| 上课中 | `#1890FF` |
| 已完成 | `#52C41A` |
| 已取消 | `#8C8C8C` |

## 4. 表格与列表规范

### 4.1 表格列宽规则

| 列类型 | 最小宽度 | 对齐 |
|--------|---------|------|
| 序号/ID | 80 px | 左对齐 |
| 姓名/名称 | 120 px | 左对齐 |
| 手机号 | 120 px | 左对齐 |
| 状态 | 100 px | 居中 |
| 金额 | 120 px | 右对齐 |
| 时间 | 160 px | 左对齐 |
| 操作 | ≥160 px | 居中或左对齐 |

### 4.2 操作按钮优先级

| 优先级 | 展示方式 | 示例 |
|--------|---------|------|
| P0 主操作 | 蓝色文字按钮/主按钮 | 审核、通过、驳回 |
| P1 次要 | 默认文字按钮 | 查看、编辑 |
| P2 危险 | 红色文字按钮 | 删除、取消、封禁 |
| P3 更多 | 下拉菜单（…） | 重置密码、查看日志 |

### 4.3 分页规范

- 默认每页 20 条
- 提供 10/20/50/100 选项
- 显示总条数
- 跳转页码输入框

### 4.4 筛选区规范

- 位于表格上方，白色卡片内
- 常用筛选：状态下拉、时间范围、关键词搜索
- 高级筛选：点击展开更多条件
- 筛选按钮：查询（主色）、重置（默认）

***

## 5. 表单与详情页规范

### 5.1 表单布局

- 标签右对齐，宽度 120 px
- 输入区宽度：短输入 200 px，中输入 400 px，长输入 600 px
- 多行文本最小高度 80 px
- 操作按钮左对齐于标签右侧，主按钮在前

### 5.2 详情页布局

- 左侧/上方：基础信息卡片（只读为主）
- 中部：状态时间轴/操作日志
- 右侧/下方：关联列表（如订单的套餐信息、退款记录）
- 底部固定操作栏：通过/驳回/取消/返回

### 5.3 审批操作组件

- 审批按钮区使用 `el-affix` 固定在页面底部或顶部
- 通过/驳回并排，通过用主按钮，驳回用危险按钮
- 必须填写审批意见（必填）
- 二次确认弹窗提示影响范围

***

## 6. 弹窗与抽屉规范

### 6.1 弹窗（Modal）

- 用于表单提交、二次确认、轻量详情
- 宽度：小 480 px / 中 640 px / 大 800 px
- 表单弹窗底部：取消 + 确定

### 6.2 抽屉（Drawer）

- 用于详情展示、复杂表单
- 宽度：默认 600 px，复杂详情 800 px
- 详情抽屉底部：关闭 + 主要操作

***

## 7. 数据看板规范

### 7.1 指标卡

- 4 列布局，卡间距 24 px
- 卡内：指标名称、数值、环比、趋势图标
- 数值使用 28px Bold

### 7.2 图表

- 折线图/柱状图展示趋势
- 饼图展示占比
- 表格展示 Top N 列表

***

## 8. 权限与可见性

### 8.1 管理员角色

MVP 阶段默认单一管理员角色，所有菜单可见。

### 8.2 数据权限

- 管理员可查看全部用户/教练/订单数据
- 敏感字段（完整手机号、身份证号）默认脱敏，点击可查看

***

## 9. 四态设计强制要求

每个管理列表/详情/配置页必须考虑：

| 状态 | 处理方式 |
|------|---------|
| 空状态 | 表格空数据展示空插画 + 引导文案 |
| 加载中 | 表格骨架屏 / 页面 Loading 遮罩 |
| 错误 | 错误提示 + 重试按钮 |
| 成功 | 操作成功 Toast / Message 提示 |
