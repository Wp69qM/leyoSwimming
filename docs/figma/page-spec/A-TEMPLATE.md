## 6. 四态设计

### 6.1 空状态

- 表格空：空插画 + "暂无数据" + 可选「新建」按钮
- 画布居中，插画 120×120

### 6.2 加载中

- 表格骨架屏（3 行）
- 或整页 `el-loading` 遮罩

### 6.3 错误状态

- 错误提示 Message
- 或错误占位页：插画 + 错误信息 + 重试按钮

### 6.4 成功状态

- 操作成功 Message / Toast
- 保存后自动返回列表页
