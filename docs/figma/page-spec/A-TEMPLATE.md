## 2. 状态维度

> 说明本页面需要处理的状态维度。Web 后台管理端通常关注：目标对象状态、审批状态、订单/套餐/booking 状态等。

| 维度 | 状态枚举 | 页面影响 |
|------|---------|---------|
| 示例：教练状态 | 0 待审核 / 1 已通过 / 2 已驳回 / 3 已离职 / 4 申请离职中 | 审核操作按钮显隐 |

***

## 3. 元素清单（自上而下）

> **设计原则**：
> 1. **元素清单只描述「有什么元素」以及「元素之间的交互与状态」，不描述具体样式细节。** 颜色、字体、字号、背景、阴影、圆角等视觉参数**禁止**出现在 page-spec 中，避免对后续 Figma 渲染和 Calicat 设计稿还原造成干扰。
> 2. 视觉样式以 Calicat 设计稿为唯一最高优先级来源；page-spec 仅对交互逻辑、业务规则、状态流转负责。
> 3. 页面骨架尺寸（如侧边栏宽度、TopBar 高度）属于布局约束，可保留；但颜色、字体、阴影等视觉细节必须删除。
> 4. 每个元素必须说明：名称、作用、显示条件、交互行为、关联业务规则。

## 6. 四态设计

### 6.1 空状态

- 表格空：空插画 + "暂无数据" + 可选「新建」按钮

### 6.2 加载中

- 表格骨架屏
- 或整页加载遮罩

### 6.3 错误状态

- 错误提示 Message
- 或错误占位页：插画 + 错误信息 + 重试按钮

### 6.4 成功状态

- 操作成功 Message / Toast
- 保存后自动返回列表页
