## 2. 用户身份与业务状态维度

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | ✅ | 可进入，顶部显示登录/注册入口；底部「退出登录」按钮隐藏 |
| 注册用户 | ✅ | 完整入口与信息展示；底部显示「退出登录」按钮 |
| 学员 | ✅ | 与注册用户一致 |
| 教练 | ❌ | 用户端不展示教练身份；教练使用教练端小程序 |
| 管理员 | ❌ | 管理端使用 Web 后台 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| **已登录** | 本地存在有效 access_token / refresh_token | 展示用户头像、昵称、身份状态与完整功能入口；底部显示「退出登录」按钮 |
| **未登录（游客）** | 无有效 token | 顶部区域显示默认头像与「请登录/注册」提示；功能入口点击后引导登录；隐藏「退出登录」按钮 |
| **退出登录中** | 用户点击「退出登录」并确认后 | 按钮进入 loading，调用 `/api/user/auth/logout` |
| **退出登录成功** | 后端/前端清除 token 后 | 页面刷新为游客态，不跳转其他页面 |

## 5. 跳转动线矩阵

| 触发元素 | 游客 | 注册用户 | 学员 |
|---------|:----:|:-------:|:----:|
| 用户信息头图 | → `U-微信授权页` / `U-手机号登录页` | → `U-完善个人资料页` | → `U-完善个人资料页` |
| 我的套餐 | 引导登录 | → `U-我的套餐页` | → `U-我的套餐页` |
| 我的订单 | 引导登录 | → `U-订单列表页` | → `U-订单列表页` |
| 我的预约 | 引导登录 | → `U-我的预约页` | → `U-我的预约页` |
| 隐私协议 | 引导登录 | → `U-隐私协议页` | → `U-隐私协议页` |
| 设置 | 引导登录 | → `U-设置页` | → `U-设置页` |
| 退出登录 | 隐藏 | 二次确认 → 退出登录 → 刷新本页为游客态 | 二次确认 → 退出登录 → 刷新本页为游客态 |

> **登录引导**：当游客点击受登录限制的功能入口时，优先唤起登录页（`U-微信授权页` 或 `U-手机号登录页`），而不是直接提示错误。

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 页面首次加载，数据尚未返回 | 展示占位头像与默认昵称；功能入口正常显示 |
| **加载中** | 请求用户信息或提交退出登录 | 头像/昵称区域显示骨架屏；退出登录按钮显示「退出中…」 |
| **错误状态** | 网络/服务错误 | 顶部展示错误提示条，支持重试 |
| **成功状态** | 数据正常或退出成功 | 按身份展示完整内容；退出成功后切换为游客态 |
