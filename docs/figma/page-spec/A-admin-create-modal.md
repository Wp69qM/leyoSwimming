## 2. 状态维度

## 3. 元素清单（自上而下）

### 3.1 标题栏

| 字段 | 值 |
|------|-----|
| 容器 | 顶部固定，高度 56 px，白底，底部 1px #E4E7ED |
| 标题 | 18px Medium #262626，文字「新建管理员」 |
| 关闭按钮 | 右上角 24×24 px 关闭 icon，#8C8C8C |

### 3.2 表单区

| 字段 | 值 |
|------|-----|
| 容器 | 白底，内边距 24 px |
| 布局 | 单列表单，label 宽 120 px 右对齐，输入区宽 280 px |

#### 3.2.1 表单字段

| 字段 | 组件 | 规则 |
|------|------|------|
| 姓名 | 文本输入框 | **必填**，长度 2-32 字符 |
| 登录账号 | 文本输入框 | **必填**，3-32 位，字母/数字/下划线，唯一 |
| 初始密码 | 密码输入框 | **必填**，8-32 位，需包含字母+数字+特殊字符；右侧含「显示/隐藏」icon |
| 确认密码 | 密码输入框 | **必填**，必须与初始密码一致 |
| 角色 | 单选组 | **必填**，选项：超级管理员 / 普通管理员 |

### 3.3 底部操作栏

| 字段 | 值 |
|------|-----|
| 容器 | 弹窗底部固定，高度 56 px，白底，顶部 1px #E4E7ED，内边距 0 24 px |
| 左侧按钮 | 取消（默认按钮） |
| 右侧按钮 | 保存（主按钮），表单校验不通过时 disabled |

## 5. 跳转动线

| 触发元素 | 目标 | 条件/说明 |
|---------|------|----------|
| 关闭按钮 / 遮罩层 / 取消按钮 | 关闭弹窗，不保存 | 有未保存改动时提示「是否放弃创建」 |
| 保存按钮 | 校验通过 → 调用 POST /api/admin/admin/add | 成功后关闭弹窗并刷新列表，toast 提示「管理员账号创建成功」 |
| 登录账号已占用 | 字段提示「该登录账号已存在」 | 后端返回 `ADMIN_USERNAME_ALREADY_EXISTS` |

***

## 6. 四态设计

### 6.1 空状态

- 弹窗首次打开时所有字段为空，角色默认未选择。

### 6.2 加载中

- 保存按钮显示 loading，表单输入框 disabled。

### 6.3 错误状态

- 字段级错误：红色文字提示在字段下方。
- 提交失败：弹窗顶部红色 alert 提示错误信息。

### 6.4 成功状态

- 关闭弹窗，列表刷新，toast 提示成功。
