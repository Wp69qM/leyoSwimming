## 3. 元素清单（自上而下）

### 3.1 TopBar / 侧边栏 / 面包屑

同 A-用户管理页，当前菜单为 "套餐管理"，面包屑为 "首页 / 套餐订单 / 套餐管理"。

### 3.2 筛选区

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 16 px，margin-bottom 16 px |
| 套餐状态下拉 | 宽度 160 px：全部 / active / exhausted / expired / frozen / refunded |
| 课程类型下拉 | 宽度 160 px：全部 / 体验课 / 正价课 |
| 到期时间 | 双日期选择器 |
| 关键词搜索 | 宽度 240 px，placeholder "套餐编号 / 用户 / 教练" |
| 查询按钮 | 主按钮 #1890FF |
| 重置按钮 | 默认按钮 |

### 3.3 表格区

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px |

| 行高 | 56 px |
| 行分隔 | 1 px #F0F2F5 |
| 分页 | 底部居中，默认 20 条/页 |

表格列：

| 列名 | 宽度 | 对齐 | 说明 |
|------|------|------|------|
| 套餐编号 | 120 px | 左对齐 | — |
| 用户 | 120 px | 左对齐 | 昵称，可跳转 |
| 教练 | 120 px | 左对齐 | 姓名，可跳转 |

| 字段 | 值 |
|------|-----|
| 查看 | 蓝色文字按钮，所有状态显示 |

| 解冻 | 蓝色文字按钮，frozen 状态显示 |

## 6. 四态设计

### 6.1 空状态

- 表格空：空插画 + "暂无套餐数据" + 「重置筛选」按钮。

### 6.2 加载中

- 表格骨架屏 3 行。

### 6.3 错误状态

- 表格区域 `el-empty` "加载失败" + 「重试」按钮。

### 6.4 成功状态

- 列表正常展示，操作后刷新。
