# 页面规格：A-套餐管理页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时必须按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-021 / US-043 / US-045 / US-050
> **对应 PRD**：§5.5.1.2 手动冻结/解冻 package、§4.2 套餐状态机
> **说明**：本页面管理的是用户购买后生成的 package 实例，列表中展示的套餐名称、模式、教学类型、课时等信息均为购买时的快照字段，不受后续 package_template 变更影响。
> **版本**：v1.0 | **创建日期**：2026-08-02

## 2. 状态维度

| 维度 | 状态枚举 | 页面影响 |
|------|---------|---------|
| 套餐状态 | active / exhausted / expired / frozen / refunded | 筛选条件、操作按钮 |
| 套餐模式 | standard / experience | 列表标签，对应正价套餐 / 体验课 |
| 班级规模 | 一对一 / 一对二 / 一对三 | 筛选条件、标签 |
| 冻结原因 | coach_resigned / refund_pending / admin_frozen | 详情与操作提示 |

> **注意**：本页「套餐状态」是 package 实例的生命周期状态；package_template 的「上下架状态」（active / inactive）是模板配置层面的概念，二者不可混淆。package_template 的上下架管理不在本页进行。

### 3.4 操作按钮

| 字段 | 值 |
|------|-----|
| 查看 | 按钮，所有状态显示 |
| 冻结 | 按钮，active 状态显示 |
| 解冻 | 按钮，frozen 状态显示 |
| 延期 | 按钮，active / expired 状态显示 |
| 退款 | 按钮，active 状态显示；需 package 快照 refund_enabled = true 且在 refund_valid_days 内，否则置灰并提示不可退款 |

### 3.5 退款弹窗

| 字段 | 值 |
|------|-----|
| 触发 | 点击列表行「退款」按钮 |
| 标题 | "发起退款" |
| 套餐信息摘要 | 套餐名称、总课时、已消耗课时、剩余课时、到期时间、退款比例 |
| 可退金额 | 输入框，默认展示系统计算的 refund_amount；管理员可修改，但不得超过计算金额且不能小于 0 |
| 金额调整原因 | 当管理员修改金额时必填，最多 500 字符 |
| 退款原因输入框 | 必填，最多 500 字符 |
| 提示文案 | "发起退款后将生成一笔退款订单，请前往订单管理页进行审批。原购买订单状态保持不变。" |
| 操作按钮 | 「取消」/「确认发起退款」 |
| 校验失败 | 1. 退款原因未填写时，提示"退款原因不能为空"；2. 可退金额小于 0 或超过系统计算金额时，提示"退款金额必须在 0 ~ {计算金额} 元之间"；3. 金额被修改且未填写调整原因时，提示"请填写金额调整原因" |
| 提交后反馈 | 关闭弹窗，Toast"退款订单已生成，请前往订单管理审批"，列表行状态更新为 frozen，frozen_reason 展示为 refund_pending；生成的退款订单以填写的金额为准 |

## 6. 四态设计

### 6.1 空状态

- 表格空：空插画 + "暂无套餐数据" + 「重置筛选」按钮。

### 6.2 加载中

- 表格骨架屏 3 行。

### 6.3 错误状态

- 表格区域 `el-empty` "加载失败" + 「重试」按钮。

### 6.4 成功状态

- 列表正常展示，操作后刷新。

## 7. 业务规则引用

| 规则 | 来源 | 在本页的体现 |
|------|------|-------------|
| 管理员手动冻结/解冻 package | PRD §5.5.1.2 | 冻结/解冻按钮 |
| 冻结原因 3 值枚举 | PRD §5.5.1.2 | 冻结弹窗原因选择 |
| package 状态机 | PRD §4.2 / 全局原则 §3.4 | 状态筛选与标签 |
| 管理员手动延期 | PRD §4.6 | 延期按钮 |
| 管理员对 active package 发起退款 | US-028 / US-043 | 退款按钮；发起后生成退款订单并在订单管理页审批 |
| 退款资格受 package 快照 refund_enabled / refund_valid_days 控制 | US-027 / US-045 | 退款按钮置灰/隐藏条件 |
| 已购 package 保存模板快照 | US-045 | 列表字段展示购买时快照，不受后续模板变更影响 |
| 套餐管理与订单管理职责边界 | US-043 / US-046 | 本页仅发起退款，审批/驳回/金额调整在 A-订单管理页 |
