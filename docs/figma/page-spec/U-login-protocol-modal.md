# 页面规格：U-登录页协议浮层

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时必须按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../../docs/prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-009（隐私协议与用户须知授权）/ US-004 / US-006 / US-051 / US-054
> **对应 PRD**：§11.2 隐私合规、§5.2.2 账号安全
> **版本**：v1.0 | **创建日期**：2026-08-08

---

## 1. 页面基础

| 字段 | 值 |
|------|-----|
| 页面名（中文） | 登录页协议浮层 |
| 页面名（Frame） | `U-登录页协议浮层` |
| 平台 | 微信小程序 - 用户端 / 教练端 |
| 页面类型 | 底部弹层（Bottom Sheet） |
| 弹层高度 | 屏幕高度的 80%（最小 600 px），顶部圆角 16 px |
| 遮罩层 | `rgba(0, 0, 0, 0.45)` |
| 背景 | `#FFFFFF` |
| 是否含 NavBar | **否** |
| 是否含 TabBar | **否** |

> **特别说明**：本浮层由用户端/教练端登录页点击《用户须知》或《隐私协议》协议名唤起；浮层内两个 Tab 分别展示对应协议内容；点击「同意」后关闭浮层并勾选登录页协议勾选框，点击「不同意」仅关闭浮层。

## 2. 用户身份与业务状态维度

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | ✅ | 登录流程中的游客可唤起本浮层 |
| 注册用户 | ❌ | 已登录用户不进入登录页 |
| 学员 | ❌ | 已登录用户不进入登录页 |
| 教练 | ✅ | 教练端登录流程中可唤起本浮层，内容与用户端一致 |
| 管理员 | ❌ | 管理端使用 Web 后台登录流程 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本浮层影响 |
|------|------|-----------|
| **默认进入** | 浮层被唤起，未指定协议名 | 默认展示《用户须知》Tab |
| **从《用户须知》唤起** | 用户点击登录页「《用户须知》」协议名 | 浮层展示《用户须知》Tab 并高亮 |
| **从《隐私协议》唤起** | 用户点击登录页「《隐私协议》」协议名 | 浮层展示《隐私协议》Tab 并高亮 |
| **协议内容加载中** | 调用 `/api/terms-policy/current` 或 `/api/privacy-policy/current` 未返回 | 内容区展示骨架屏或 loading 指示器 |
| **协议内容加载失败** | 网络异常或接口报错 | 内容区展示错误提示与「重试」按钮 |
| **点击同意** | 用户点击底部「同意」按钮 | 浮层关闭，登录页勾选框变为已勾选 |
| **点击不同意** | 用户点击底部「不同意」按钮 | 浮层关闭，登录页勾选框保持唤起前状态 |
| **点击蒙层外部** | 用户点击黑色遮罩区域 | 浮层关闭，登录页勾选框保持唤起前状态 |

## 3. 元素清单（自上而下）

> **设计原则**：
> 1. 每个元素必须说明：名称、尺寸、位置、颜色、圆角、字体、显示条件、交互行为
> 2. 浮层顶部有拖拽指示条，提示可下滑关闭
> 3. Tab 切换时内容区平滑滚动或切换，Tab 栏始终固定

### 3.1 顶部指示条

| 字段 | 值 |
|------|-----|
| 名称 | 顶部指示条 |
| 尺寸 | 36 × 4 px |
| 位置 | 浮层顶部居中，距上边 8 px |
| 背景/颜色 | `#D9D9D9` |
| 圆角 | 2 px |
| 显示条件 | 始终显示 |
| 点击行为 | 无 |

### 3.2 浮层标题栏

| 字段 | 值 |
|------|-----|
| 名称 | 浮层标题栏 |
| 尺寸 | 宽度填满，高度 56 px |
| 位置 | 指示条下方，顶部固定 |
| 背景 | `#FFFFFF` |
| 标题 | 18px Medium `color-text-primary` #262626，文字「协议详情」 |
| 关闭按钮 | 右侧 24×24 px 关闭 icon，#8C8C8C，距右 16 px |
| 显示条件 | 始终显示 |
| 点击行为 | 点击关闭按钮 → 浮层关闭 |

### 3.3 Tab 切换栏

| 字段 | 值 |
|------|-----|
| 名称 | Tab 切换栏 |
| 尺寸 | 宽度填满，高度 48 px |
| 位置 | 标题栏下方，顶部固定 |
| 背景 | `#FFFFFF` |
| 下划线 | 当前选中 Tab 底部 2px `color-primary` #1890FF 指示线 |
| Tab 文案 | 16px Medium；选中 `#1890FF`，未选中 `#8C8C8C` |
| Tab 项 | 「用户须知」「隐私协议」 |
| 显示条件 | 始终显示 |
| 点击行为 | 切换 Tab，内容区更新为对应协议内容 |

### 3.4 协议内容区

| 字段 | 值 |
|------|-----|
| 名称 | 协议内容区 |
| 尺寸 | 宽度填满，顶部距 Tab 栏 0，底部距按钮区 80 px |
| 位置 | Tab 栏下方，可垂直滚动 |
| 背景 | `#FFFFFF` |
| 内边距 | 16 px（左右）/ 20 px（上下） |
| 标题样式 | 18px Bold `color-text-primary` #262626，段前间距 24 px |
| 正文样式 | 14px Regular `color-text-secondary` #595959，行高 1.6 |
| 列表样式 | 14px Regular `color-text-secondary`，项目符号圆点 6px #595959 |
| 显示条件 | 协议加载成功后显示 |
| 滚动行为 | 内容超出时内部滚动 |

### 3.5 底部按钮区

| 字段 | 值 |
|------|-----|
| 名称 | 底部按钮区 |
| 尺寸 | 宽度填满，高度 80 px，带顶部 1px #E8E8E8 分割线 |
| 位置 | 浮层底部固定 |
| 背景 | `#FFFFFF` |

### 3.6 加载状态

| 字段 | 值 |
|------|-----|
| 名称 | 协议内容加载中 |

| 位置 | 内容区居中 |
| 显示条件 | 协议内容 API 请求中 |

| 字段 | 值 |
|------|-----|
| 名称 | 协议内容加载失败 |

| 位置 | 内容区居中 |
| 显示条件 | 协议内容 API 失败 |
| 表现 | 48×48 px 错误图标占位 + 14px #8C8C8C 文案「协议内容加载失败，请重试」+ 下方「重试」文字按钮（`color-primary`） |
| 点击行为 | 点击「重试」重新请求当前 Tab 协议内容 |

## 5. 跳转动线矩阵

| 触发条件 | 游客 | 教练 |
|---------|------|------|
| 点击登录页「《用户须知》」 | 浮层打开，默认《用户须知》Tab | 浮层打开，默认《用户须知》Tab |
| 点击登录页「《隐私协议》」 | 浮层打开，默认《隐私协议》Tab | 浮层打开，默认《隐私协议》Tab |
| 点击「同意」 | 浮层关闭，登录页勾选框变为已勾选 | 浮层关闭，登录页勾选框变为已勾选 |
| 点击「不同意」 | 浮层关闭，勾选框状态保持 | 浮层关闭，勾选框状态保持 |
| 点击蒙层/关闭按钮 | 浮层关闭，勾选框状态保持 | 浮层关闭，勾选框状态保持 |

> **说明**：浮层本身不直接触发页面跳转；关闭后用户仍停留在登录页。

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 浮层刚打开，协议内容尚未请求 | 内容区展示加载骨架屏 |
| **加载中** | 切换 Tab 或首次打开 | 内容区展示 loading 指示器 |
| **错误状态** | 协议内容加载失败 | 内容区展示错误图标 + 文案 + 重试按钮 |
| **成功状态** | 协议内容加载完成 | 内容区完整展示协议标题与正文 |

## 7. 业务规则引用

| 规则 | PRD / US 引用 | 在本浮层应用 |
|------|--------------|-------------|
| 首次注册/登录需用户同意隐私协议与用户须知 | PRD §11.2；US-009 §4.1 | §3.5 底部按钮区：提供「同意」入口 |
| 登录页点击协议名唤起浮层 | US-009 §4.1 步骤 4 | §5 跳转动线矩阵 |
| 浮层内可切换《用户须知》与《隐私协议》 | US-009 §4.1 步骤 5 | §3.3 Tab 切换栏 |
| 不同意协议则关闭浮层且不勾选 | US-009 §4.2 | §3.5.1 「不同意」按钮 |
| 协议内容加载失败支持重试 | US-009 §8.2 | §3.7 错误状态 |
| 点击浮层外部关闭浮层 | US-009 §4.4 分支 1 | §5 跳转动线矩阵 |
