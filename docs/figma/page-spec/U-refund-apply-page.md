## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | 否 | 前置跳转 `U-微信授权页`，不会到达本页 |
| 注册用户 | 否 | 未购买套餐的用户无入口；已购买用户以学员身份进入 |
| 学员 | 是 | 仅可查看自己购买的 package 对应的退款申请页 |
| 教练 | 否 | 不进入用户端退款流程 |
| 管理员 | 否 | 不进入用户端退款流程 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| `package.status = active` | 套餐生效中 | 可申请退款，按剩余课时比例计算可退金额 |
| `package.status = expired` | 套餐已过期但仍有剩余课时 | 可申请退款，按剩余课时比例计算可退金额 |
| `package.status = frozen(frozen_reason=coach_resigned)` | 教练离职导致套餐冻结 | 可申请退款，按 100% 全额计算可退金额 |
| `package.status = exhausted` | 课时已用完 | 不展示退款入口，不可进入本页 |
| `package.status = frozen(frozen_reason=refund_pending)` | 已存在待处理退款 | 不展示退款入口，不可重复申请 |
| `refund_enabled = false` | 套餐不支持退款 | 不展示退款入口，不可进入本页 |
| 超出 `refund_valid_days` | 已过退款有效期 | 不展示退款入口或进入后提示不可退款 |

## 3. 元素清单（自上而下）

> **设计原则**：
> 1. **元素清单只描述「有什么元素」以及「元素之间的交互与状态」，不描述具体样式细节。** 颜色、宽度、高度、边距、背景、圆角、字体、字号、阴影等视觉参数**禁止**出现在 page-spec 中，避免对后续 Figma 渲染和 Calicat 设计稿还原造成干扰。
> 2. 视觉样式以 Calicat 设计稿为唯一最高优先级来源；page-spec 仅对交互逻辑、业务规则、状态流转负责。
> 3. 每个元素必须说明：名称、作用、显示条件、交互行为、关联业务规则。

### 3.1 状态栏 + NavBar

| 字段 | 值 |
|------|-----|
| 名称 | 状态栏 + NavBar |
| 作用 | 页面顶部导航，提供返回入口与页面标题 |
| 显示条件 | 学员进入本页时统一显示 |
| 点击行为 | 返回按钮 → 返回 `U-我的套餐详情页`；标题为"申请退款" |
| 关联业务规则 | PRD §13.3 页面导航规范 |

### 3.2 套餐快照信息卡

| 字段 | 值 |
|------|-----|
| 名称 | 套餐快照信息卡 |
| 作用 | 展示购买时 package 快照，让用户确认退款对象 |
| 显示条件 | 成功状态始终显示 |
| 点击行为 | 无点击跳转，仅展示 |
| 关联业务规则 | US-045 §5 #5：购买时保存模板快照；退款计算基于快照字段，不受后续模板变更影响 |

### 3.3 退款规则与可退金额区

| 字段 | 值 |
|------|-----|
| 名称 | 退款规则与可退金额区 |
| 作用 | 展示退款规则说明、可退金额计算公式与计算示例 |
| 显示条件 | 成功状态始终显示；教练离职 frozen 时显示 100% 退款说明 |
| 点击行为 | 无点击跳转，仅展示 |
| 关联业务规则 | US-027 §4.1 / §5 #2：退款金额 = 快照 `paid_amount × (total_hours - consumed_count) / total_hours × refund_ratio`；教练离职 frozen 时按 `paid_amount × refund_ratio` 全额退款 |

### 3.4 退款原因选择器

| 字段 | 值 |
|------|-----|
| 名称 | 退款原因选择器 |
| 作用 | 让用户选择退款原因，必填 |
| 显示条件 | 成功状态始终显示 |
| 点击行为 | 点击展开选项：1 教练原因 / 2 个人原因 / 3 平台原因；选择后收起并回填选中项 |
| 关联业务规则 | US-027 §4.1：退款原因分类 |

### 3.5 退款原因说明输入框

| 字段 | 值 |
|------|-----|
| 名称 | 退款原因说明输入框 |
| 作用 | 用户补充退款说明，多行文本，可选填 |
| 显示条件 | 成功状态始终显示 |
| 点击行为 | 获取焦点，调起多行键盘；限制最大输入长度 |
| 关联业务规则 | US-027 §4.1：原因说明为可选字段 |

### 3.6 底部固定提交栏

| 字段 | 值 |
|------|-----|
| 名称 | 底部固定提交栏 |
| 作用 | 展示可退金额并提供提交申请入口 |
| 显示条件 | 成功状态始终显示；退款资格校验不通过时禁用提交按钮 |
| 点击行为 | 点击"提交申请" → 二次确认弹窗 → 调用 POST `/api/packages/{package_id}/refund` → 成功跳转 `U-订单详情页`（退款订单 order_id）或 `U-我的套餐页`；失败按错误码提示 |
| 关联业务规则 | US-027 §4.1：提交后创建退款订单（order.type='refund'，status=退款审批中），package.status → frozen（frozen_reason='refund_pending'），释放 reserved_count 并取消已预约课程 |

### 3.7 不可退款提示区

| 字段 | 值 |
|------|-----|
| 名称 | 不可退款提示区 |
| 作用 | 当 package 不具备退款资格时，展示具体原因并引导返回 |
| 显示条件 | 进入本页时校验失败：exhausted / refund_enabled=false / 超出 refund_valid_days / 已存在待处理退款 / 非教练离职的 frozen |
| 点击行为 | 提示"返回"按钮 → 返回 `U-我的套餐详情页` |
| 关联业务规则 | US-027 §4.2 异常分支：PACKAGE_EXHAUSTED_NOT_REFUNDABLE、REFUND_NOT_SUPPORTED、REFUND_EXPIRED、REFUND_IN_PROGRESS、PACKAGE_FROZEN |

## 5. 跳转动线矩阵

| 起点元素 | 游客 | 注册用户 | 学员 | 教练 | 管理员 |
|---------|------|---------|------|------|--------|
| 整页访问 | → `U-微信授权页` | 无入口或被拦截 | 正常进入本页（校验 package 归属与退款资格） | — | — |
| 返回按钮 | — | — | → `U-我的套餐详情页` | — | — |
| 提交申请成功 | — | — | → `U-订单详情页`（退款订单 order_id）或 `U-我的套餐页` | — | — |
| 提交申请失败 | — | — | 留在本页，按错误码 toast / 弹窗提示 | — | — |
| 不可退款提示区返回 | — | — | → `U-我的套餐详情页` | — | — |

> **"引导登录"**：游客访问本页时直接跳转 `U-微信授权页`，不在当前页弹登录框；登录成功后返回 `U-我的套餐详情页`。

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 无 package 数据传入（如缺少参数直接 deeplink） | 中央 Empty 组件：插画 + "暂无套餐信息" + "返回我的套餐" 按钮（→ `U-我的套餐页`） |
| **加载中** | 进入页面时调用 GET `/api/packages/{package_id}/refund/check` 校验资格并获取可退金额 | 页面主体显示骨架屏占位；底部提交栏显示默认占位 |
| **错误状态** | 网络断开 / 接口 5xx / package 不存在 / 越权访问 | 隐藏骨架屏，中央展示错误插画 + 文案 + Primary「重新加载」/「返回我的套餐」按钮 |
| **成功状态** | 数据正常返回且具备退款资格 | 按 §4 显示规则矩阵完整展示套餐快照、退款规则、原因选择、说明输入与底部提交栏 |
