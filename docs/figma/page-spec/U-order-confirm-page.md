## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。
> 身份定义来源：[PRD §3.2](../../../docs/prd/prd.md) 与 [US-017](../../../docs/stories/US-017-游客-购买体验课套餐/user-story.md) / [US-020](../../../docs/stories/US-020-学员-购买正价套餐/user-story.md)。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| **游客** | 否 | 购买套餐必须先登录；从套餐详情/教练详情点击购买时统一跳转 `U-微信授权页`，不会直接进入本页 |
| **注册用户** | 是 | 可购买体验课/正价套餐；无当前绑定教练时按正常流程确认 |
| **学员（已绑定本教练）** | 是 | 为当前教练加课；顶部显示"为 教练A 加课"提示 |
| **学员（已绑定其他教练）** | 是 | 进入本页即触发单教练约束阻断；顶部显示冲突提示条，提交按钮禁用 |
| **教练/管理员（以用户身份进入）** | 是 | 按其实际用户身份处理，不显示管理态 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| `package_type = 0` | 体验套餐 | 标题显示"体验课订单"，数量固定为 1 节，不可调整 |
| `package_type = 1` | 正价套餐 | 标题显示"正价课订单"，数量按标准套餐固定课时展示 |
| `order_source = standard` | 标准套餐（1/6/8/10 节）| 数量锁定为套餐固定课时，显示单价/总价 |
| `coach.status ≠ 1` | 教练未在职/离职审批中 | 顶部显示警告条，提交按钮置灰 |
| `user_has_other_coach_active` | 用户已绑定其他教练 active 套餐 | 顶部显示单教练冲突提示条，提交按钮禁用 |
| `agreements_signed = false` | 未勾选协议 | 提交按钮禁用，点击时提示"请先同意协议" |
| `minor_guardian_missing` | 未成年用户未填写监护人手机号 | 显示监护人输入区，未完成时提交按钮禁用 |

> **自定义套餐说明**：`order_source = custom`（自定义课时）不在本页处理。用户在 `U-自定义套餐配置页` 完成课时选择与价格确认后，直接创建订单并跳转 `U-支付页`，**不经过订单确认页**。

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 无套餐信息传入（如直接 deep link 进入缺少参数） | 中央 Empty 组件：插画 + "暂无订单信息" + "返回首页" 按钮（→ `U-首页`） |
| **加载中** | 首次进入 / 拉取教练/套餐详情 / 提交订单中 | 卡片区域显示骨架屏占位；提交按钮显示 loading 态 |
| **错误状态** | 网络断开 / 接口 5xx / 业务 4xx（如套餐已下架） | 中央错误插画 + "加载失败，点击重试" + Primary「重新加载」按钮；套餐模板下架或不存在时显示 "该套餐已下架，请重新选择" |
| **成功状态** | 数据正常返回 | 按 §4 显示规则矩阵完整展示；提交成功后跳转支付页 |
