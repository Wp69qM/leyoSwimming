## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | 是 | 仅展示 `visible_scope = all` 的公告 |
| 注册用户 | 是 | 展示 `visible_scope ∈ {all, student}` 的公告 |
| 学员 | 是 | 同注册用户：展示 `visible_scope ∈ {all, student}` 的公告 |
| 教练 | 是（若访问用户端） | 按用户端身份判定；`visible_scope = coach` 的公告不在用户端展示，由教练端承接 |
| 管理员 | 是（若访问用户端） | 按登录的用户身份判定；管理端有独立公告配置入口 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| 有生效公告 | 当前时间在 `notice.start_at` 与 `notice.end_at` 之间，且 `visible_scope` 命中当前身份 | 按 type 分类展示列表 |
| 无生效公告 | 时间窗未命中或全部公告已下线 | 展示空状态，不展示空分类标签 |
| 筛选中 | 用户点击某一分类标签 | 列表仅展示该 type 的公告 |
| 网络/服务异常 | 接口失败或超时 | 展示错误状态 + 重试按钮 |

## 3. 元素清单（自上而下）

> **设计原则**：
> 1. 每个元素必须说明：名称、尺寸、位置、颜色、圆角、字体、显示条件、交互行为
> 2. 快捷入口 ≠ TabBar 重复
> 3. 同一业务入口在不同身份下形态可能不同，必须分身份定义

### 3.1 状态栏 + NavBar

> **来自 PRD §5.1 / US-002 §4.1**：场馆公告页为二级页面，由首页公告摘要卡或首页通知栏点击进入。

| 字段 | 值 |
|------|-----|
| 状态栏 | 375×44，与 NavBar 同色（白色） |
| NavBar | 375×44，y=44，背景 `#FFFFFF`，底部 1px `#F0F0F0` |
| 标题 | "场馆公告"，17px Medium `#262626`，居中 |
| 左侧返回按钮 | 24×24 `#262626`，左 padding 16px，点击返回上一页 |
| 右侧操作 | 无 |

### 3.2 分类标签栏（Tabs）

> **来自 PRD §9.2.13**：公告 type 枚举为 0=开放 / 1=换水 / 2=释放 / 3=紧急。标签栏提供按 type 快速筛选。

| 字段 | 值 |
|------|-----|
| 容器 | 375×44，y=88，背景 `#FFFFFF`，底部 1px `#F0F0F0` |
| 标签项 | 全部 / 开放 / 换水 / 释放 / 紧急，共 5 个 |
| 标签尺寸 | 高度 28px，水平 padding 12px，项间距 8px |
| 未选中态 | 背景透明，文字 14px Regular `#8C8C8C` |
| 选中态 | 背景 `#E6F7FF`，文字 14px Medium `#1890FF`，圆角 `radius-pill`（999px） |
| 交互 | 点击切换选中态，列表按 type 过滤；"全部" 展示所有当前身份可见公告 |
| 显示条件 | 始终显示 5 个标签；若某分类下无公告，标签仍可点击，列表为空状态 |

### 3.3 公告列表

> **来自 US-002 §4.1 / §5 业务规则 / §8 边界场景**：列表展示当前身份可见的生效公告，按 `priority` 降序 + `start_at` 降序排列。

#### A. 列表容器

| 字段 | 值 |
|------|-----|
| 容器 | 375×自适应，y=132，背景 `#F5F7FA` |
| 列表项间距 | 12px（卡片之间） |
| 左右边距 | 16px |
| 列表项宽度 | 343px |
| 底部留白 | 24px（二级页面无 TabBar） |

#### B. 公告列表项

| 字段 | 值 |
|------|-----|
| 容器 | 343×88，背景 `#FFFFFF`，圆角 `radius-lg`（12px），阴影 `shadow-card` |
| 内边距 | 16px |
| 左侧类型图标区 | 40×40 圆形，按 type 着色 |
| type 颜色映射 | 开放 `#E6F7FF` 背景 + `#1890FF` 图标；换水 `#FFF2E8` + `#FAAD14`；释放 `#F6FFED` + `#52C41A`；紧急 `#FFF1F0` + `#FF4D4F` |
| 图标 | 20×20 线性图标，居中于圆形内；无法提供 SVG 时用 20×20 圆角矩形占位，标注 `Icon: notice-type` |
| 中间内容区 | 距左侧图标 12px，宽度约 227px |
| 标题 | `notice.title`，14px Medium `#262626`，单行，溢出省略 |
| 摘要 | `notice.content` 前 24 字，12px Regular `#8C8C8C`，单行，溢出省略 |
| 右侧时间 | 12px Regular `#8C8C8C`，距右侧 16px，垂直居中于标题行 |
| 时间格式 | 当天 → "HH:mm"；7 天内 → "X 天前"；更早 → "YYYY-MM-DD" |
| 整行点击 | 切换该条公告的展开/收起状态（手风琴） |

#### C. 展开详情区（手风琴）

> **来自 PRD §9.2.13 `notice.content` 字段**：详情区承载完整公告正文，无需跳转新页面。

| 字段 | 值 |
|------|-----|
| 容器 | 343×自适应，紧邻列表项下方，背景 `#FAFAFA`，无阴影 |
| 顶部间距 | 与列表项无间距（手风琴一体感） |
| 内边距 | 16px |
| type 标签 | 胶囊 Tag，文案按 type（开放/换水/释放/紧急），使用 §3 状态徽标对应颜色 |
| 完整标题 | `notice.title`，16px Medium `#262626`，距标签 12px |
| 完整内容 | `notice.content`，14px Regular `#595959`，行高 1.6，距标题 8px |
| 发布时间 | "发布时间：YYYY-MM-DD HH:mm"，12px Regular `#8C8C8C`，距内容 16px |
| 收起交互 | 点击列表项任意区域或详情区底部 "收起" 文字按钮收起 |
| 显示条件 | 仅当前被点击项展开；同时最多展开 1 项 |

## 4. 显示规则总表

| 元素 | 游客 | 注册用户 | 学员 | 教练 | 管理员 |
|------|:---:|:---:|:---:|:---:|:---:|
| NavBar 返回按钮 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 分类标签栏 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 公告项（`visible_scope = all`） | ✅ | ✅ | ✅ | ✅ | ✅ |
| 公告项（`visible_scope = student`） | ❌ | ✅ | ✅ | ❌ | ❌ |
| 公告项（`visible_scope = coach`） | ❌ | ❌ | ❌ | ❌ | ❌ |
| 展开详情区 | ✅（按身份可见项） | ✅ | ✅ | ✅ | ✅ |
| TabBar | ❌ | ❌ | ❌ | ❌ | ❌ |

> **说明**：
> - `visible_scope = coach` 的公告在用户端任何身份下均不展示，由教练端页面承接。
> - 教练/管理员访问用户端时，按其在用户端的登录身份判定 `student` 范围是否可见；未登录则按游客处理。

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| 空状态 | 无生效公告 或 当前分类下无公告 | 居中 Empty 组件：120×120 扁平运动主题插画 + "暂无公告" 14px `#8C8C8C`；分类标签仍展示 |
| 加载中 | 页面首次加载 / 下拉刷新 | 列表区域显示骨架屏：3 行 343×88 灰色矩形 `#F0F0F0`（无阴影），圆角 12px，行间距 12px；标签栏置灰不可点 |
| 错误状态 | 网络断开 / 接口 5xx / 超时 | 中央错误插画 + "网络异常，请重试" + Primary 按钮 "重新加载" |
| 成功状态 | 默认 | 按 §4 矩阵完整显示：NavBar + 分类标签 + 公告列表（含可展开详情） |

## 7. 业务规则引用

| 规则 | PRD / US 引用 | 在本页面应用 |
|------|--------------|-------------|
| 游客可查看场馆公告 | PRD §5.1 / US-002 §5 | 游客可见 `visible_scope = all` 的公告 |
| 公告 type 枚举与颜色 | PRD §9.2.13 | §3.2 分类标签、§3.3 类型图标与 Tag 颜色 |
| 公告可见范围 | PRD §9.2.13 `visible_scope` / US-002 §8 边界场景 4 | §4 显示规则矩阵 |
| 公告排序与有效期 | US-002 §4.1 | 列表按 `priority` 降序 + `start_at` 降序；过滤 `NOW()` 在 `start_at`/`end_at` 之间的记录 |
| 无公告时隐藏而非报错 | US-002 §4.2 分支 2 / §8 边界场景 2 | §6 空状态不展示错误插画，使用 Empty 组件 |
| 首页通知栏点击跳转公告页 | US-002 §4.1 / U-home-page.md §3.7 | 本页作为首页通知栏/公告摘要卡的下游页面 |
