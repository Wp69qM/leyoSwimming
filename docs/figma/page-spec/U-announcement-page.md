## 2. 用户身份与业务状态维度

> **本节是 Page Spec 根基**。先定义"谁可能看到这个页面"以及"以什么业务状态看到"。

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | 是 | 仅展示 `visible_scope = all` 的公告 |
| 注册用户 | 是 | 展示 `visible_scope ∈ {all, student}` 的公告 |
| 学员 | 是 | 同注册用户：展示 `visible_scope ∈ {all, student}` 的公告 |
| 教练 | 是（若访问用户端） | 按用户端身份判定；`visible_scope = coach` 的公告不在用户端展示，由教练端承接 |
| 管理员 | 是（若访问用户端） | 按登录的用户身份判定；管理端有独立公告配置入口 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| 有生效公告 | 当前时间在 `notice.start_at` 与 `notice.end_at` 之间，且 `visible_scope` 命中当前身份 | 按 type 分类展示列表 |
| 无生效公告 | 时间窗未命中或全部公告已下线 | 展示空状态，不展示空分类标签 |
| 筛选中 | 用户点击某一分类标签 | 列表仅展示该 type 的公告 |
| 网络/服务异常 | 接口失败或超时 | 展示错误状态 + 重试按钮 |

## 3. 元素清单（自上而下）

> **设计原则**：
> 1. **元素清单只描述「有什么元素」以及「元素之间的交互与状态」，不描述具体样式细节。** 颜色、宽度、高度、边距、背景、圆角、字体、字号、阴影等视觉参数**禁止**出现在 page-spec 中。
> 2. 视觉样式以 Calicat 设计稿为唯一最高优先级来源；page-spec 仅对交互逻辑、业务规则、状态流转负责。
> 3. 每个元素必须说明：名称、作用、显示条件、交互行为、关联业务规则。
> 4. 快捷入口 ≠ TabBar 重复。
> 5. 同一业务入口在不同身份下形态可能不同，必须分身份定义。

### 3.1 状态栏 + NavBar

> **来自 PRD §5.1 / US-002 §4.1**：场馆公告页为二级页面，由首页公告摘要卡或首页通知栏点击进入。

| 元素名称 | 作用 | 显示条件 | 交互行为 | 关联业务规则 |
|----------|------|----------|----------|--------------|
| 状态栏占位 | 为系统状态栏预留区域 | 始终显示 | 无 | 全局设计规范 |
| 导航栏 | 展示页面标题与返回入口 | 始终显示 | 点击返回按钮 → 上一页 | PRD §5.1 / US-002 §4.1 |
| 页面标题 | 标识当前页面为“场馆公告” | 始终显示 | 无 | — |
| 返回按钮 | 返回上一页 | 始终显示 | 点击返回上一页 | — |
| 右侧操作 | 无操作入口 | 始终显示 | 无 | — |

### 3.2 分类标签栏（Tabs）

> **来自 PRD §9.2.13**：公告 type 枚举为 0=开放 / 1=换水 / 2=释放 / 3=紧急。标签栏提供按 type 快速筛选。

| 元素名称 | 作用 | 显示条件 | 交互行为 | 关联业务规则 |
|----------|------|----------|----------|--------------|
| 标签栏容器 | 承载分类筛选标签 | 始终显示 | 横向滚动或等分展示 | PRD §9.2.13 |
| 标签项 | 切换公告分类筛选 | 始终显示 5 个标签：全部 / 开放 / 换水 / 释放 / 紧急 | 点击切换选中态，列表按 type 过滤；“全部” 展示所有当前身份可见公告 | PRD §9.2.13 |
| 选中态指示 | 标识当前选中分类 | 随用户点击切换 | 无 | — |

> **说明**：若某分类下无公告，标签仍可点击，列表进入对应空状态。

### 3.3 公告列表

> **来自 US-002 §4.1 / §5 业务规则 / §8 边界场景**：列表展示当前身份可见的生效公告，按 `priority` 降序 + `start_at` 降序排列。

#### A. 列表容器

| 元素名称 | 作用 | 显示条件 | 交互行为 | 关联业务规则 |
|----------|------|----------|----------|--------------|
| 列表容器 | 承载公告列表项 | 有生效公告时显示 | 垂直滚动 | US-002 §4.1 |
| 列表项 | 展示单条公告摘要 | 有生效公告时显示 | 点击切换该条公告的展开/收起状态（手风琴） | US-002 §4.1 |

#### B. 公告列表项

| 元素名称 | 作用 | 显示条件 | 交互行为 | 关联业务规则/数据 |
|----------|------|----------|----------|-------------------|
| 类型图标区 | 按公告 type 展示语义图标 | 每条公告均显示 | 无 | PRD §9.2.13 `notice.type` |
| 公告标题 | 展示 `notice.title` | 每条公告均显示 | 无 | PRD §9.2.13 |
| 摘要 | 展示 `notice.content` 前若干字 | 每条公告均显示 | 无 | PRD §9.2.13 |
| 发布时间 | 展示公告相对/绝对时间 | 每条公告均显示 | 无 | 时间格式：当天 → "HH:mm"；7 天内 → "X 天前"；更早 → "YYYY-MM-DD" |
| 整行点击区 | 切换展开/收起详情 | 每条公告均显示 | 点击展开/收起该条详情 | US-002 §4.1 |

#### C. 展开详情区（手风琴）

> **来自 PRD §9.2.13 `notice.content` 字段**：详情区承载完整公告正文，无需跳转新页面。

| 元素名称 | 作用 | 显示条件 | 交互行为 | 关联业务规则/数据 |
|----------|------|----------|----------|-------------------|
| 详情区容器 | 展示完整公告内容 | 仅当前被点击项展开；同时最多展开 1 项 | 点击列表项任意区域或详情区底部“收起”按钮收起 | US-002 §4.1 |
| type 标签 | 按 type 展示公告分类标签 | 展开时显示 | 无 | PRD §9.2.13 `notice.type` |
| 完整标题 | 展示 `notice.title` | 展开时显示 | 无 | PRD §9.2.13 |
| 完整内容 | 展示 `notice.content` | 展开时显示 | 无 | PRD §9.2.13 |
| 发布时间 | "发布时间：YYYY-MM-DD HH:mm" | 展开时显示 | 无 | PRD §9.2.13 |
| 收起按钮 | 收起当前展开详情 | 展开时显示 | 点击收起详情区 | — |

## 4. 显示规则总表

| 元素 | 游客 | 注册用户 | 学员 | 教练 | 管理员 |
|------|:---:|:---:|:---:|:---:|:---:|
| NavBar 返回按钮 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 分类标签栏 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 公告项（`visible_scope = all`） | ✅ | ✅ | ✅ | ✅ | ✅ |
| 公告项（`visible_scope = student`） | ❌ | ✅ | ✅ | ❌ | ❌ |
| 公告项（`visible_scope = coach`） | ❌ | ❌ | ❌ | ❌ | ❌ |
| 展开详情区 | ✅（按身份可见项） | ✅ | ✅ | ✅ | ✅ |
| TabBar | ❌ | ❌ | ❌ | ❌ | ❌ |

> **说明**：
> - `visible_scope = coach` 的公告在用户端任何身份下均不展示，由教练端页面承接。
> - 教练/管理员访问用户端时，按其在用户端的登录身份判定 `student` 范围是否可见；未登录则按游客处理。

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| 空状态 | 无生效公告 或 当前分类下无公告 | 中央 Empty 组件：游泳主题插画 + "暂无公告"；分类标签仍展示 |
| 加载中 | 页面首次加载 / 下拉刷新 | 列表区域显示骨架屏占位；标签栏置灰不可点 |
| 错误状态 | 网络断开 / 接口 5xx / 超时 | 中央错误插画 + "网络异常，请重试" + Primary「重新加载」按钮 |
| 成功状态 | 默认 | 按 §4 矩阵完整显示：NavBar + 分类标签 + 公告列表（含可展开详情） |

## 7. 业务规则引用

| 规则 | PRD / US 引用 | 在本页面应用 |
|------|--------------|-------------|
| 游客可查看场馆公告 | PRD §5.1 / US-002 §5 | 游客可见 `visible_scope = all` 的公告 |
| 公告 type 枚举 | PRD §9.2.13 | §3.2 分类标签、§3.3 类型图标与 Tag |
| 公告可见范围 | PRD §9.2.13 `visible_scope` / US-002 §8 边界场景 4 | §4 显示规则矩阵 |
| 公告排序与有效期 | US-002 §4.1 | 列表按 `priority` 降序 + `start_at` 降序；过滤 `NOW()` 在 `start_at`/`end_at` 之间的记录 |
| 无公告时隐藏而非报错 | US-002 §4.2 分支 2 / §8 边界场景 2 | §6 空状态不展示错误插画，使用 Empty 组件 |
| 首页通知栏点击跳转公告页 | US-002 §4.1 / U-home-page.md §3.7 | 本页作为首页通知栏/公告摘要卡的下游页面 |
