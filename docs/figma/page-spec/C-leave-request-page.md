## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 已通过（1） | 是 | 完整功能 |
| 申请离职中（4） | 是 | 允许提交请假 |
| 其他状态 | 否 | 重定向或提示"当前状态不可请假" |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| 请假时段冲突 | 与已批准请假重叠 | 提交时提示冲突 |
| 时间已过期 | 开始时间早于当前 | 禁用提交并提示 |
| 存在待审批请假 | 已提交未审批 | 列表顶部展示待审批卡片 |

## 5. 跳转动线

| 起点 | 行为 |
|------|------|
| 提交成功 | → C-请假申请页（顶部显示待审批提示）或独立成功提示 |
| 时间冲突 | 停留在本页，字段下方红色提示 |
| 返回 | → 上一页（通常为 C-教练端首页或 C-排班管理页） |

## 6. 四态设计

| 状态 | 表现 |
|------|------|
| 空状态 | 表单区显示默认值，影响预览区隐藏 |
| 加载中 | 表单区骨架屏 |
| 错误状态 | 时间冲突/已过/结束早于开始字段标红 + 提示 |
| 成功状态 | 顶部显示"提交成功，等待审批"Toast/横幅 |
