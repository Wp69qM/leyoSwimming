# 页面规格：U-用户须知页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时必须按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../../docs/prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-009（隐私协议与用户须知授权）
> **对应 PRD**：§11.3.3《用户须知》、§5.2.2 账号安全
> **版本**：v1.0 | **创建日期**：2026-08-08

---

## 1. 页面基础

| 字段 | 值 |
|------|-----|
| 页面名（中文） | 用户须知页 |
| 页面名（Frame） | `U-用户须知页` |
| 平台 | 微信小程序 - 用户端 / 教练端 |
| 画板尺寸 | 标准小程序页面尺寸 |
| 页面背景 | 按全局规范页面背景色 |
| 是否含 TabBar | **否**（设置二级页） |
| 是否含 NavBar | **是**，标题「用户须知」 |
| 返回按钮 | 是（返回「我的 → 设置」） |

> **特别说明**：本页为纯内容查看页，展示当前生效的《用户须知》版本内容；页面不提供「撤回授权」按钮，也不提供编辑能力。

## 2. 用户身份与业务状态维度

### 2.1 适用身份

| 身份 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 游客 | ❌ | 必须登录后通过「我的 → 设置」进入 |
| 注册用户 | ✅ | 可从「我的 → 设置 → 用户须知」进入 |
| 学员 | ✅ | 与注册用户一致 |
| 教练 | ✅ | 从教练端「我的 → 设置 → 用户须知」进入，内容一致 |
| 管理员 | ❌ | 管理端通过 Web 后台管理协议内容 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| **内容加载中** | 调用 `/api/terms-policy/current` 未返回 | 内容区展示骨架屏或 loading 指示器 |
| **内容加载成功** | 返回当前生效《用户须知》 | 展示版本号与完整内容 |
| **内容加载失败** | 网络异常或接口报错 | 展示错误提示与「重试」按钮 |
| **内容为空** | 系统未配置当前生效版本 | 展示空态提示「暂无内容」 |

## 3. 元素清单（自上而下）

| 元素名称 | 作用 | 显示条件 | 交互行为 | 关联业务规则 |
|----------|------|----------|----------|--------------|
| 状态栏占位 | 为系统状态栏预留区域 | 始终显示 | 无 | 全局设计规范 |
| 顶部导航栏 | 展示页面标题「用户须知」与返回入口 | 始终显示 | 点击返回按钮 → 返回「我的 → 设置」页 | 全局设计规范 §2.5.6 |
| 版本号标签 | 展示当前协议版本号（如「版本：v2.0」） | 内容加载成功后显示 | 无 | 协议版本管理（US-047 后台管理） |
| 协议内容区 | 展示《用户须知》完整内容，包括主标题、章节标题、正文与列表 | 内容加载成功后显示 | 页面整体垂直滚动 | PRD §11.3.3；US-009 §4.3 |
| 加载状态 | 提示协议内容正在加载 | 协议内容 API 请求中 | 无 | US-009 §8.2 |
| 错误状态 | 提示协议内容加载失败，并提供重试入口 | 协议内容 API 失败 | 点击「重试」→ 重新请求 `/api/terms-policy/current` | US-009 §8.2 |
| 空状态 | 提示系统未配置当前生效版本 | 系统未配置当前生效《用户须知》 | 无 | US-009 §3 前置条件 |

| 点击返回按钮 | → 「我的 → 设置」页 | → 「我的 → 设置」页 | → 教练端「我的 → 设置」页 |

## 6. 四态设计

| 状态 | 触发 | 表现 |
|------|------|------|
| **空状态** | 系统未配置当前生效版本 | 展示空状态插画 + 「暂无用户须知内容」 |
| **加载中** | 页面首次进入或点击重试 | 内容区展示骨架屏或 loading 指示器 |
| **错误状态** | 网络异常或接口报错 | 展示错误插画 + 文案 + 「重试」按钮 |
| **成功状态** | 协议内容加载完成 | 展示版本号标签与完整协议内容 |

---

## 7. 业务规则引用

| 规则 | PRD / US 引用 | 在本页面应用 |
|------|--------------|-------------|
| 用户可在个人中心随时查看最新版《用户须知》 | PRD §11.3.3；US-009 §4.3 | §2.1 适用身份、§5 跳转动线矩阵 |
| 页面仅支持查看，不提供撤回授权 | US-009 §4.3 步骤 3 | 页面不含「撤回授权」按钮 |
| 协议内容由 US-047 后台管理 | US-009 §3 前置条件 | 本页只读，调用 `/api/terms-policy/current` |
| 协议内容加载失败支持重试 | US-009 §8.2 | §3 错误状态 |
