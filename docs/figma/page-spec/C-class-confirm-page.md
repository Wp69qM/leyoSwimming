## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 已通过（1） | 是 | 完整功能 |
| 申请离职中（4） | 是 | 可确认/标记旷课 |
| 其他状态 | 否 | 重定向 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| 课程未开始 | 当前时间 < 开课时间 | 确认/旷课按钮禁用 |
| 课程进行中 | 开课时间 ≤ 当前 < 结束时间 | 确认/旷课按钮禁用 |
| 课程已结束 ≤24h | 结束时间 ≤ 当前 < 结束+24h | 确认/旷课按钮可用 |
| 课程已结束 >24h | 当前 ≥ 结束+24h | 按钮隐藏，显示"已自动确认" |
| 已确认 | booking.status = 已完成 | 按钮隐藏，展示课程记录 |
| 已旷课 | booking.status = 旷课 | 按钮隐藏，展示旷课备注 |
| 已取消 | booking.status = 已取消 | 隐藏操作区，显示取消原因 |

## 5. 跳转动线

| 起点 | 行为 |
|------|------|
| 确认上课 | 二次确认弹窗 → 成功后 Toast "确认成功" → 返回 C-预约管理页 |
| 标记旷课 | 二次确认弹窗（强提示）→ 成功后 Toast "已标记旷课" → 返回 C-预约管理页 |
| 改约入口 | → C-改约页（课程未开始时） |
| 返回 | → C-预约管理页 |

## 6. 四态设计

| 状态 | 表现 |
|------|------|
| 空状态 | 无（本页基于 booking_id 加载） |
| 加载中 | 课程信息卡与操作区骨架屏 |
| 错误状态 | 网络错误 / 非本课程教练 403 提示 |
| 成功状态 | 按 §4 矩阵完整显示 |
