# 页面规格：A-订单管理页

> **性质**：Figma 设计交付的唯一指令源。AI 生成 Figma 时必须按本规格严格执行。
> **核心约束**：本规格的每一条元素显隐规则必须可追溯到 [PRD](../../prd/prd.md) 或具体 US 的某条业务规则。
> **归属 US**：US-026 / US-046
> **对应 PRD**：§5.5.3 套餐与订单
> **版本**：v1.0 | **创建日期**：2026-08-02

***

## 3. 元素清单（自上而下）

### 3.1 TopBar / 侧边栏 / 面包屑

## 6. 四态设计

### 6.1 空状态

- 表格空：空插画 + "暂无订单数据" + 「重置筛选」按钮。

### 6.2 加载中

- 表格骨架屏 3 行。

### 6.3 错误状态

- 表格区域 `el-empty` "加载失败" + 「重试」按钮。

### 6.4 成功状态

- 列表正常展示，操作后刷新。
