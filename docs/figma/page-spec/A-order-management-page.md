## 6. 四态设计

### 6.1 空状态

- 表格空：空插画 + "暂无订单数据" + 「重置筛选」按钮。

### 6.2 加载中

- 表格骨架屏 3 行。

### 6.3 错误状态

- 表格区域 `el-empty` "加载失败" + 「重试」按钮。

### 6.4 成功状态

- 列表正常展示，操作后刷新。

***

## 7. 业务规则引用

| 规则 | 来源 | 在本页的体现 |
|------|------|-------------|
| 管理员查看所有订单 | PRD §5.5.3 | 列表展示 |
| 订单与退款订单为独立记录 | US-046 | 订单类型列与筛选 |
| 订单状态机 | PRD §6.2 / 全局原则 §3.3 | 状态筛选与标签 |
| 待支付购买订单可取消 | PRD §6.2 | 取消按钮 |
| 退款订单在退款审批中可通过/驳回 | US-046 / US-028 | 通过/驳回按钮 |
| 驳回退款后 package 自动恢复 active | US-028 | 驳回操作的业务结果 |
| 退款金额允许管理员修改 | US-046 | 通过弹窗中的金额输入 |
| 退款订单可由套餐管理发起 | US-043 | 退款订单在列表中展示，来源为管理员或学员发起 |
