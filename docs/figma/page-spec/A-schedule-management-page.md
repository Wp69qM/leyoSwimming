## 3. 元素清单（自上而下）

### 3.1 TopBar / 侧边栏 / 面包屑

同 A-用户管理页，当前菜单为 "排班管理"，面包屑为 "首页 / 课程预约 / 排班管理"。

### 3.2 工具栏

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 4 px，内边距 16 px，margin-bottom 16 px |
| 教练选择器 | 下拉选择教练，支持多选/全部 |
| 周历切换 | 上一周 / 本周 / 下一周 按钮 + 日期范围显示 |
| 快速操作 | 「添加时段」/「批量隐藏」/「显示全部」 |
| 图例 | available 可约 / booked 已约 / hidden 隐藏 / leave 请假 |

### 3.3 周历头部

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片顶部，圆角 4 px 4 px 0 0 |
| 布局 | 7 列等宽（周一~周日），每列宽度 = (内容区宽 - 48px 时段列) / 7 |
| 单元格 | 日期 + 星期，选中日期蓝色背景 |
| 高度 | 60 px |

### 3.4 2D 时段网格

| 字段 | 值 |
|------|-----|
| 容器 | 白底卡片，圆角 0 0 4 px 4 px |
| 左侧时段列 | 宽 48 px，显示 8:00 / 9:00 / ... / 22:00 |
| 右侧 7 列 | 每天时段格 |
| 单元格 | 48×48 px（或按设计高度），圆角 4 px |
| 可约 | 白底 + 蓝色边框 + 蓝色文字 |
| 已约 | 灰底 #F5F5F5 + 灰字，Hover 显示预约信息 |
| 隐藏 | 浅灰底 #F0F0F0 + 虚线边框 |
| 请假 | 橙底 #FFFBE6 + 橙色文字 "请假" |
| 选中态 | 渐变蓝背景 + 白字 |

### 3.5 时段操作弹窗

| 字段 | 值 |
|------|-----|
| 触发 | 点击可约/隐藏单元格 |
| 宽度 | 480 px |
| 内容 | 日期、时段、状态切换（可约/隐藏）、重复规则 |
| 底部 | 取消 + 确定 |

### 3.6 底部操作栏（可选）

| 字段 | 值 |
|------|-----|
| 位置 | 页面底部固定 |
| 背景 | #FFFFFF，顶部阴影 `shadow-float` |
| 按钮 | 返回今日 / 保存修改（主按钮） |

## 6. 四态设计

### 6.1 空状态

- 无教练数据时显示 "暂无教练，请先审核教练入驻"。

### 6.2 加载中

- 网格显示骨架屏占位。

### 6.3 错误状态

- 顶部 `el-alert` "排班数据加载失败" + 「重试」按钮。

### 6.4 成功状态

- 网格正常展示，操作后 Toast "保存成功"。
