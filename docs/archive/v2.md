# 【乐游】游泳约课系统 - 产品需求文档（增强版）

## 1. 项目概述

### 1.1 产品定位
打造一个面向游泳场馆的约课与运营管理平台，覆盖教练、学员、自由游泳者、系统管理员四类角色，支持小程序端与后台管理系统，未来可扩展为移动端 App。

### 1.2 核心价值
- 对学员：降低预约门槛，透明化教练与套餐信息，记录成长轨迹。
- 对教练：数字化管理学员与课时，通过数据优化教学策略。
- 对场馆：提升运营效率，沉淀数据资产，辅助经营决策。

### 1.3 目标平台
1. 微信小程序（学员端、教练端、自由游泳者端）
2. Web 后台管理系统（管理员、教练部分复杂操作）
3. 未来可扩展：iOS / Android App（与小程序数据互通）

---

## 2. 版本规划

### 2.1 MVP（第一阶段）：核心约课闭环
目标：让学员能约课、教练能上课、管理员能管理。

- 用户注册登录与角色选择
- 教练信息维护与可约时间配置
- 学员查看教练、预约、取消预约
- 一对一 / 一对二基础套餐配置与购买
- 微信支付 / 支付宝支付
- 上课记录与课时消耗
- 基础消息通知（预约、取消、课前提醒）
- 管理员：用户管理、订单确认、基础数据看板

### 2.2 第二阶段：体验优化与运营提效
- 排队候补与自动转正
- 周期性预约 / 固定课程
- 退款 / 退课流程
- 发票 / 收据管理
- 教练绩效与收入结算
- 评价与反馈闭环
- 学员等级与能力评估体系
- AI 数据查询助手（教练 / 学员）

### 2.3 第三阶段：智能化与增长
- AI 视频动作分析
- 学员画像与教练推荐
- 营销裂变（老带新、拼团、优惠券）
- 社区 / 打卡 / 内容库
- 物联网硬件联动（闸机、手环、智能柜）
- 多场馆支持

## 3. 角色定义

### 3.1 游泳教练
- 可查看自己的预约、学员、上课记录
- 可记录每节课内容与学员表现
- 可管理自己关联的学员信息切片
- 可通过 AI 助手查询数据、生成图表
- 可上传上课视频供学员查看

### 3.2 游泳学员
- 已购课学员：预约教练、查看课时、查看上课记录、评价教练
- 新学员：浏览教练与套餐、购买体验课、购买套餐
- 可维护固定搭档信息（一对多套餐）
- 可查看教练上传的视频并做课后总结

### 3.3 自由游泳者
- 购买次卡 / 月卡
- 记录游泳时长、距离、消耗
- 查看泳池拥挤情况
- 入场签到

### 3.4 系统管理员
- 管理用户、角色、权限
- 管理教练排班、请假、审批
- 配置套餐、价格、折扣活动
- 处理订单、退款、投诉
- 查看数据报表与经营分析
- 配置公告、泳池信息、AI 参数

## 4. 功能模块详细设计

### 4.1 用户与账号体系

#### 4.1.1 注册登录
1. 支持微信授权登录，首次登录后需补充手机号、用户名、密码、邮箱。
2. 注册时需选择角色：学员 / 教练 / 自由游泳者。
3. 教练首次注册需上传：证书、任教时间、总学员数、总课时数、个人简介。
4. 支持账号密码登录、手机号验证码登录。
5. 系统管理员使用默认账号 `admin / admin123` 登录后台。

#### 4.1.2 账号安全
1. 支持手机号换绑、密码修改、邮箱绑定。
2. 支持登录设备管理。
3. 支持账号注销与数据删除申请（符合隐私合规）。

#### 4.1.3 家庭账号
1. 家长账号可绑定未成年学员子账号。
2. 家长可代为预约、查看课时、接收通知。
3. 学员成年后可将账号迁移为独立账号。

---

### 4.2 教练端功能

#### 4.2.1 预约管理
1. 以日 / 周 / 月 / 年维度查看预约卡片。
2. 点击卡片查看预约详情：学员姓名、年龄、手机号、游泳等级、学习泳姿、基础情况、已上课时、剩余课时。
3. 确认预约、拒绝预约、协商时间。
4. 上课前 10 分钟查看学员入场状态，未入场可一键提醒。
5. 教练可帮学员代约或锁课。

#### 4.2.2 上课记录
1. 记录每节课时间、内容、学员学习情况。
2. 记录课时消耗：总课时、已用课时、剩余课时。
3. 支持结构化标签：今日重点、掌握程度、课后作业。
4. 支持语音输入快速记录。
5. 上传照片 / 视频作为本节课记录。

#### 4.2.3 学员信息维护
1. 教练可维护自己关联学员的信息切片。
2. 默认从学员自填信息带入，教练可根据沟通情况更新。
3. 仅影响该教练视角，不影响其他教练或学员本人信息。
4. 可查看学员评价、反馈、历史总结。

#### 4.2.4 AI 助理
1. 查询自己的预约情况、学员信息、上课记录、评价反馈。
2. 生成图表：课时统计、学员增长、收入趋势。
3. 生成经营分析：淡季 / 旺季判断、学员画像、高转化人群特征。
4. 生成学员评价报告：学习进度、动作标准度、对水恐惧程度等。

#### 4.2.5 个人主页
1. 展示任教时间、专业证书、总课时、带过的学生总量。
2. 展示学员评价与评分。
3. 展示微信二维码与手机号，方便学员联系。

---

### 4.3 学员端功能

#### 4.3.1 教练与套餐浏览
1. 查看所有教练列表，点击进入教练详情页。
2. 教练详情展示：姓名、年龄、证书、任教时间、学员数、总课时、评分、评价、可约时间。
3. 查看系统套餐：一对一、一对二、一对多，以及自定义套餐。
4. 查看折扣活动与优惠信息。

#### 4.3.2 预约功能
1. 查看教练可约时间段，提前预约未来 7 天课程。
2. 预约成功后生成预约卡片，显示时间、教练、状态。
3. 24 小时外可随时取消；24 小时内取消需教练审批。
4. 满员时段可排队或关注，有空位时自动通知。
5. 支持周期性预约固定时间。

#### 4.3.3 一对多套餐与搭档
1. 一对多套餐学员可维护固定搭档信息：姓名、手机号、游泳等级。
2. 固定搭档入场后互相通知。
3. 不固定搭档模式：预约界面显示已预约人数、还差几人拼课成功,教练可以在系统中查看所有拼课成功的学员列表，如果拼课未成功，教练可以帮助拼课，如果开课前24小时未拼课成功，则自动取消该预约。
4. 不同套餐类型不可混约。

#### 4.3.4 课时与上课记录
1. 查看总课时、已上课时、剩余课时。
2. 查看历史上课记录：时间、教练、内容、视频。
3. 每节课后填写自我总结：身体感受、学习效果、问题反馈。
4. 对教练进行评价：教学清晰度、速度、效果。

#### 4.3.5 购买与支付
1. 购买套餐生成订单，支持微信支付、支付宝支付。
2. 查看订单列表与支付状态。
3. 申请退款 / 退课（按比例计算）。
4. 申请电子发票。

#### 4.3.6 视频与学习
1. 查看教练上传的本节课视频。
2. 上传自己的游泳视频（可选）。
3. AI 分析游泳动作，给出改进建议（第三阶段）。

#### 4.3.7 AI 助理
1. 查询泳池拥挤情况、教练空闲时间。
2. 查询自己的游泳记录、上课记录、剩余课时。
3. 推荐教练、泳姿、训练时间。
4. 根据画像推荐合适的套餐。

---

### 4.4 自由游泳者功能

#### 4.4.1 游泳记录
1. 入场签到，记录游泳时长、距离、消耗。
2. 查看历史游泳记录统计。
3. 今年游了多少次、总共多长时间。

#### 4.4.2 场馆信息
1. 查看泳池拥挤情况、开放时间、换水时间。
2. 查看场馆名称、地址、导航。

#### 4.4.3 次卡 / 月卡
1. 购买普通游泳次卡或月卡。
2. 查看卡内剩余次数或有效期。
3. 到期前 3 天自动推送续费提醒。

#### 4.4.4 转化入口
1. 查看教练列表，预约 30 分钟或 60 分钟体验课。
2. 通过 AI 助理分析游泳习惯并推荐课程。

---

### 4.5 系统管理员后台

#### 4.5.1 用户与角色管理
1. 查看所有学员、教练、自由游泳者账号。
2. 重置密码、手机号、邮箱。
3. 配置角色权限。
4. 教练入驻资质审核。

#### 4.5.2 教练排班与请假
1. 查看所有教练排班表。
2. 添加、删除、修改排班时间。
3. 查看请假申请，同意或拒绝。
4. 配置下周可约时间并一键发布到小程序。

#### 4.5.3 套餐与订单
1. 配置一对一、一对二、一对多套餐及自定义套餐。
2. 配置折扣活动、优惠券。
3. 查看所有订单，确认或拒绝订单。
4. 处理退款、价格调整、套餐次数调整。
5. 订单需经教练与学员双方确认后生效。

#### 4.5.4 场馆与公告
1. 配置场馆名称、地址、导航、开业年限、泳池状态。
2. 发布开放时间、换水时间、拥挤情况公告。
3. 配置免责声明、健康申报模板。

#### 4.5.5 数据看板
1. 游泳高峰期（按小时 / 天 / 周 / 月）。
2. 学习游泳高峰期。
3. 每月总课时、各教练课时。
4. 教练评分、投诉情况。
5. 学员画像：性别、年龄、泳姿分布、消费情况。
6. 每天各时段人数分布。
7. 转化率、续费率、退课率、坪效等经营指标。

#### 4.5.6 客服与工单
1. 接收学员投诉、建议、换教练申请。
2. 工单流转：提交 → 处理 → 反馈 → 关闭。

#### 4.5.7 AI 配置
1. 选择 AI 模型（OpenAI、DeepSeek、通义千问等）。
2. 配置温度、最大 Tokens、提示词。
3. 配置 AI 可访问的数据范围。

---

### 4.6 消息通知体系

#### 4.6.1 通知渠道
1. 小程序内消息中心。
2. 微信订阅消息 / 服务通知。

#### 4.6.2 通知场景
1. 预约成功 / 失败 / 取消 / 协商。
2. 排队转正通知。
3. 课前提醒（学员与教练可自定义提前时间）。
4. 入场通知（学员入场提醒教练）。
5. 教练提醒学员入场。
6. 订单状态变更。
7. 场馆闭馆 / 开放时间变更。
8. 次卡 / 月卡到期提醒。

---

### 4.7 支付与财务

#### 4.7.1 支付流程
1. 学员下单 → 选择支付方式 → 完成支付 → 系统确认订单。
2. 支持微信支付、支付宝支付。
3. 支持定金 / 尾款模式（体验课场景）。

#### 4.7.2 退款流程
1. 学员发起退款申请。
2. 系统按已消耗课时计算可退金额。
3. 教练确认 → 管理员审批 → 原路退款。

#### 4.7.3 财务对账
1. 学员账单记录。
2. 教练收入明细与提现申请。
3. 平台流水与对账报表。
4. 电子发票开具记录。

## 5. 核心流程图

### 5.1 预约流程
```
学员选择教练 / 时间
    ↓
提交预约
    ↓
教练确认 / 拒绝 / 协商
    ↓
预约成功 → 发送通知
    ↓
上课前提醒
    ↓
学员入场签到 → 教练收到通知
    ↓
上课 → 教练记录上课内容 → 消耗课时
    ↓
学员课后总结与评价
```

### 5.2 购买套餐流程
```
学员浏览套餐
    ↓
选择套餐 / 自定义套餐
    ↓
生成订单
    ↓
教练二次确认（可修改价格 / 次数）
    ↓
学员确认
    ↓
支付
    ↓
管理员确认订单 → 订单生效
```

### 5.3 退款流程
```
学员发起退款
    ↓
系统计算可退金额
    ↓
教练确认
    ↓
管理员审批
    ↓
原路退款 → 通知学员
```

## 6. 数据与合规

### 6.1 数据安全
1. 用户手机号、邮箱、支付信息加密存储。
2. 敏感操作（支付、退款、修改价格）需二次确认。
3. 操作日志记录，支持审计。
4. 数据库定期备份。

### 6.2 隐私合规
1. 首次注册需用户同意隐私协议。
2. 明确告知数据用途，支持撤回授权。
3. 符合 GDPR、CCPA、国内《个人信息保护法》要求。
4. 未成年人信息需监护人授权。

### 6.3 健康与免责
1. 下水前勾选健康承诺（无心脏病、皮肤病等）。
2. 新学员首次购课或入场前电子签署免责协议。

## 7. 非功能性需求

### 7.1 性能
1. 小程序首页加载时间 < 2 秒。
2. 预约高峰期并发支持 1000 QPS。
3. 视频上传支持断点续传。

### 7.2 可用性
1. 系统可用性 99.9%。
2. 支付链路具备重试与对账机制。
3. 关键操作支持降级方案。

### 7.3 扩展性
1. 预留多场馆、多城市扩展能力。
2. 预留物联网硬件接入接口。
3. AI 模型可配置切换。

### 7.4 多端一致性
1. 小程序与 App 数据互通。
2. 教练复杂操作建议在 Web 后台完成。
