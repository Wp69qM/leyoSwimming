# 【乐游】游泳约课系统 - 产品需求文档（v5 已确认版）

## 1. 项目概述

### 1.1 产品定位
打造一个面向游泳场馆的约课与运营管理平台，支持多类用户身份，覆盖小程序端与后台管理系统，未来可扩展为移动端 App。

### 1.2 核心价值
- 对潜在用户：透明化教练、套餐、场馆信息，降低决策门槛。
- 对学员：数字化管理课时、记录成长轨迹、获取教学反馈。
- 对自由游泳者：便捷购卡、记录游泳数据、查看场馆状态。
- 对教练：数字化管理学员与课时，通过数据优化教学策略。
- 对场馆：提升运营效率，沉淀数据资产，辅助经营决策。

### 1.3 目标平台
1. 微信小程序（用户端）
2. Web 后台管理系统（管理员、教练复杂操作）
3. 未来可扩展：iOS / Android App（与小程序数据互通）

## 2. 版本规划

### 2.1 MVP（第一阶段）：核心约课闭环
目标：让注册用户能变成学员或自由游泳者，教练能上课，管理员能管理。

- 游客浏览公开信息
- 用户注册登录
- 实名认证后方可预约与购课
- 教练信息维护与可约时间配置
- 学员购买套餐、预约教练、取消预约
- 每周固定时间释放下周可约时段（默认周三 10:00，后台可配置）
- 满员时段支持排队候补
- 自由游泳者购买次卡 / 月卡、入场签到
- 微信支付 / 支付宝支付
- 上课记录与课时消耗
- 基础消息通知（预约、取消、课前提醒、候补转正）
- 管理员：用户管理、订单确认、基础数据看板

### 2.2 第二阶段：体验优化与运营提效
- 周期性预约 / 固定课程
- 退款 / 退课流程
- 发票 / 收据管理
- 教练绩效与收入结算
- 评价与反馈闭环
- 学员等级与能力评估体系
- AI 数据查询助手

### 2.3 第三阶段：智能化与增长
- AI 视频动作分析（可能使用云端服务，按使用量计费）
- 学员画像与教练推荐
- 营销裂变（老带新、拼团、优惠券）
- 社区 / 打卡 / 内容库
- 物联网硬件联动（闸机、手环、智能柜）
- 多场馆支持

## 3. 用户身份与角色

### 3.1 身份状态定义

系统中用户身份是**动态、可叠加**的，不是互斥角色。

| 身份 | 定义 | 获得条件 | 可访问功能 |
|------|------|----------|-----------|
| **游客** | 未登录或未注册的访问者 | 打开小程序但未登录 | 浏览教练列表、套餐、场馆公告、教练详情 |
| **注册用户** | 已完成注册登录，但尚未购买任何服务 | 完成微信授权 + 补充手机号等基本信息 | 预约体验课、购买套餐、购买次卡 / 月卡、查看个人中心 |
| **学员** | 已购买教练课程套餐 | 购买正课套餐 / 体验课 / 自定义套餐后生效 | 预约教练上课、查看课时记录、查看上课视频、评价教练 |
| **自由游泳者** | 已购买游泳次卡 / 月卡 | 购买次卡 / 月卡 / 储值卡后生效 | 入场签到、记录游泳数据、查看卡内余额或有效期 |

### 3.2 身份叠加规则

1. 一个用户可以同时拥有多个身份。
2. 常见组合示例：
   - 用户 A 买了 10 节私教课 + 20 次游泳卡 → **学员 + 自由游泳者**
   - 用户 B 只买了次卡，没买课 → **自由游泳者**，不是学员
   - 用户 C 注册完什么都没买 → **注册用户**，处于游客状态
   - 用户 D 课时用完、月卡过期 → 身份失效，变回**注册用户**
3. 身份过期后，历史数据保留，用户可继续查看历史记录。

### 3.3 身份转换流程

```
游客
  ↓ 微信授权 + 补充信息
注册用户
  ├─ 购买教练课程套餐 ──→ 学员
  └─ 购买次卡 / 月卡 ───→ 自由游泳者

学员 + 自由游泳者（可同时具备）
  ↓ 课时用完
自由游泳者
  ↓ 月卡 / 次卡过期
注册用户
```

### 3.4 角色定义（与身份状态区分）

| 角色 | 定义 | 说明 |
|------|------|------|
| **教练** | 在平台提供教学服务的人员 | 可管理自己的预约、学员、上课记录；教练账号为独立角色，不与学员 / 自由游泳者身份重叠 |
| **系统管理员** | 平台运营管理人员 | 管理用户、订单、套餐、数据、公告、AI 配置 |

说明：教练账号是独立角色，不叠加学员或自由游泳者身份。教练本人若需购课或购卡，需使用另外的注册用户账号。

## 4. 各身份 / 角色功能模块

### 4.1 游客功能

1. 浏览教练列表与教练详情（姓名、证书、任教时间、评分、评价）。
2. 查看系统套餐及价格。
3. 查看场馆公告：开放时间、换水时间、拥挤情况。
4. 查看场馆信息：名称、地址、导航。
5. 查看下周预约释放时间公告与倒计时。
6. 触发注册：预约体验课、购买套餐、购买次卡 / 月卡时需先注册登录。

---

### 4.2 注册用户功能

#### 4.2.1 注册登录
1. 支持微信授权登录，首次登录后补充手机号、用户名、密码、邮箱。
2. 支持手机号验证码登录。
3. 支持账号密码登录。
4. 支持账号注销与数据删除申请。
5. **实名认证**：预约体验课、购买正课套餐、购买次卡 / 月卡前必须完成实名认证。

#### 4.2.2 账号安全
1. 手机号换绑、密码修改、邮箱绑定。
2. 登录设备管理。
3. 隐私协议授权与撤回。

#### 4.2.3 家庭账号
1. 家长账号可绑定未成年学员子账号。
2. 家长可代为预约、查看课时、接收通知。
3. 学员成年后可将账号迁移为独立账号。

#### 4.2.4 转化入口
1. 预约体验课（30 分钟或 60 分钟）。
2. 购买正课套餐。
3. 购买次卡 / 月卡成为自由游泳者。

---

### 4.3 学员功能

获得条件：购买教练课程套餐（含体验课、自定义套餐）。

#### 4.3.1 教练与套餐浏览
1. 查看所有教练列表与详情（姓名、证书、任教时间、评分、评价、可约时间、实时状态）。
2. 教练实时状态包括：空闲中、上课中、休息中、已下班、请假中；在教练列表卡片和详情页以圆点 / 标签形式展示。
3. 教练详情页展示微信二维码与手机号，学员可直接扫码加微信或拨打电话联系。
4. 教练详情页提供「发起聊天」按钮；若教练处于上课中 / 已下班 / 休息中，系统提示「教练当前较忙，可能延迟回复」。
5. 查看系统套餐：一对一、一对二、一对多、自定义套餐。
6. 查看折扣活动与优惠信息。

#### 4.3.2 预约功能
1. 正价套餐学员进入预约页面时，默认显示已绑定教练的可约时间段，无需再次选择教练。
2. 体验课学员可在所有教练中自由选择教练和可约时间。
3. 查看教练可约时间段，可预约未来 7 天内的课程。
4. **预约释放规则**：每周三上午 10:00 统一释放下周（周一至周日）的可约时段；具体释放时间、释放范围由管理员在后台配置。
5. 首页显示释放倒计时：释放前 24 小时显示「距离下周预约开放还有 XX 小时」；释放当天显示「今日 10:00 开放下周预约」。
6. **预约锁单机制**：用户点击「提交预约」后，系统立即锁定该时段，其他用户看到该时段为「已锁定」或「已约满」；同一时段多人并发提交时，仅第一个成功，其余用户收到「已被他人预约」提示。
7. **正价套餐学员**：提交预约即预约成功，系统自动从课时包中预占 1 节课时；课程结束后由教练确认并手动点击「扣除课时」，系统才正式扣减课时；课前 24 小时外取消则释放预占课时。
8. **体验课学员**：锁单后需在 15 分钟内完成支付（时长后台可配置），超时未支付则自动释放该时段，候补用户按顺序获得通知。
9. 预约成功后生成预约卡片，显示时间、教练、状态。
10. 24 小时外可随时取消；24 小时内取消需教练审批。
11. 满员时段可排队候补；有人取消或超时释放时按候补顺序自动转正并通知。
12. **候补规则**：用户可同时加入多个时段的候补队列；若其中一个时段候补成功，其他候补订单自动取消。
13. 用户可关注心仪时段，释放前或有人取消时收到提醒。
14. **周期性预约固定时间**：
    - 学员可选择固定教练、固定星期、固定时间段，预约未来 N 周（如 4 周 / 8 周 / 12 周）。
    - 系统生成一系列预约记录，这些时段在教练排班表中显示为「周期性预约」卡片，默认置灰不可再开放给其他用户。
    - 教练可在排班表中查看每张周期性预约卡片内的学员信息。
    - 若遇场馆闭馆、换水、教练请假，系统自动跳过该次预约，不扣除学员课时，并同时通知学员与教练。
    - 学员可在通知中一键将该次课程改约到其他可用时段，或保留课时后续使用。

#### 4.3.3 一对多套餐与搭档
1. 一对多套餐最多支持 3 人（后台可配置，默认上限 3 人）。
2. 一对多套餐学员可维护固定搭档信息：姓名、手机号、游泳等级。
3. 固定搭档入场后互相通知。
4. 不固定搭档模式：预约界面显示已预约人数、还差几人拼课成功。
5. 教练可查看所有拼课成功的学员列表；若开课前 24 小时未拼课成功，系统自动取消该预约，释放该时段，并通知关注该时段的用户和候补队列，其他用户可继续预约。
6. **预约卡片分享**：
    - 所有预约卡片均支持分享，包括可约时段、一对多拼课中、已预约成功等状态。
    - 学员和教练均可将一对多预约卡片分享到微信聊天或朋友圈，便于快速找到搭档或帮学员拼课。
    - 教练还可分享自己空闲的可约时段到朋友圈，吸引新用户预约。
    - 分享页展示：时间、教练、当前状态（可约 / 已满 / 拼课中）、已预约人数、还差几人、套餐类型。
    - 不同身份查看权限：
      - 游客：可查看基础信息，点击预约时引导注册登录。
      - 注册用户：可预约体验课、加入候补、关注时段。
      - 学员：如套餐类型匹配，可直接预约正课或加入拼课。
      - 卡片分享者本人：可查看完整预约详情。
7. **套餐类型与选项规则**：
    - **人数类型**：一对一、一对二、一对三（后台可配置上限，默认一对一 / 一对二 / 一对三）。
    - **教学泳姿**：蛙泳、自由泳、蝶泳、仰泳；用户购买时选择主要练习泳姿。
    - **搭档模式**（仅一对二 / 一对三可选）：
      - 固定搭档：用户维护固定搭档信息，预约时自动带入选项。
      - 不固定搭档：系统根据条件自动撮合，预约界面显示已预约人数与还差人数。
    - **搭档性别要求**（非强制）：男、女、不限；仅作为撮合参考，不强制限制。
    - 不同套餐类型不可混约，例如买一对二的用户不能加入一对一的预约。
8. 临时沟通群：拼课成功后，系统自动创建一个临时聊天窗口（类似美团订单的临时会话），参与该节课的所有学员与教练可在群内沟通预约时间、到场时间、集合地点、装备准备等事项；课程结束后聊天窗口自动关闭或归档。

#### 4.3.4 课时与上课记录
1. 查看总课时、已上课时、剩余课时。
2. 查看历史上课记录：时间、教练、内容、视频。
3. 每节课后填写自我总结：身体感受、学习效果、问题反馈。
4. 对教练进行评价：教学清晰度、速度、效果。

#### 4.3.5 购买与支付
1. 购买套餐生成订单，支持微信支付、支付宝支付。
2. 查看订单列表与支付状态。
3. 申请退款 / 退课（按比例计算）。
4. **退款手续费**：退款时若涉及手续费，系统需明确提示用户，用户确认后再进入退款流程。
5. 申请电子发票。

#### 4.3.6 视频与学习
1. 查看教练上传的本节课视频。
2. 上传自己的游泳视频（可选）。
3. AI 分析游泳动作，给出改进建议（第三阶段）。

#### 4.3.7 AI 助理
1. 查询泳池拥挤情况、教练空闲时间。
2. 查询自己的上课记录、剩余课时。
3. 推荐教练、泳姿、训练时间。
4. 根据画像推荐合适的套餐。

### 4.4 自由游泳者功能

获得条件：购买游泳次卡 / 月卡 / 储值卡。

#### 4.4.1 游泳记录
1. 入场签到，记录游泳时长、距离、消耗。
2. 查看历史游泳记录统计。
3. 今年游了多少次、总共多长时间。

#### 4.4.2 场馆信息
1. 查看泳池拥挤情况、开放时间、换水时间。
2. 查看场馆名称、地址、导航。

#### 4.4.3 次卡 / 月卡
1. 购买普通游泳次卡或月卡。
2. 查看卡内剩余次数或有效期。
3. 到期前 3 天自动推送续费提醒。

#### 4.4.4 转化入口
1. 查看教练列表，预约体验课。
2. 通过 AI 助理分析游泳习惯并推荐课程。

---

### 4.5 教练功能

#### 4.5.1 入驻与资料
1. 首次注册需上传：证书、任教时间、总学员数、总课时数、个人简介。
2. 入驻资质需管理员审核。
3. 个人主页展示任教时间、证书、总课时、带过的学生总量、评分、评价、微信二维码、手机号。
4. 教练可设置自己的实时状态：空闲中、上课中、休息中、已下班、请假中。
5. 系统根据教练当前课程安排自动切换状态：课程开始前 15 分钟自动变为「上课中」，课程结束后 15 分钟自动恢复为「空闲中」或「已下班」（根据当日排班）。
6. 教练手动设置的状态优先级高于自动状态，但请假状态由请假审批自动同步。

#### 4.5.2 预约管理
1. 以日 / 周 / 月 / 年维度查看预约卡片。
2. 点击卡片查看预约详情：学员姓名、年龄、手机号、游泳等级、学习泳姿、基础情况、已上课时、剩余课时；学员信息页展示学员微信二维码与手机号，教练可直接扫码加微信或拨打电话联系。
3. 学员信息页提供「发起聊天」按钮，教练可直接在小程序内与学员建立一对一临时会话，沟通上课时间、注意事项、到馆安排等。
4. 确认预约、拒绝预约、协商时间。
5. 上课前 10 分钟查看学员入场状态，未入场可一键提醒。
6. 教练可帮学员代约或锁课。
7. 教练可将一对多预约卡片分享到微信，帮助学员快速找到搭档拼课。
8. 教练可将自己的空闲可约时段分享到朋友圈，吸引新用户预约体验课或正课。

#### 4.5.3 上课记录
1. 记录每节课时间、内容、学员学习情况。
2. 记录课时消耗：总课时、已用课时、剩余课时；课程结束后教练手动点击「确认上课并扣除课时」，系统才正式从学员课时包中扣减。
3. 支持结构化标签：今日重点、掌握程度、课后作业。
4. 支持语音输入快速记录。
5. 上传照片 / 视频作为本节课记录。

#### 4.5.4 学员信息维护
1. 教练可维护自己关联学员的信息切片。
2. 默认从学员自填信息带入，教练可根据沟通情况更新。
3. 仅影响该教练视角，不影响其他教练或学员本人信息。
4. 可查看学员评价、反馈、历史总结。

#### 4.5.5 AI 助理
1. 查询自己的预约情况、学员信息、上课记录、评价反馈。
2. 生成图表：课时统计、学员增长、收入趋势。
3. 生成经营分析：淡季 / 旺季判断、学员画像、高转化人群特征。
4. 生成学员评价报告：学习进度、动作标准度、对水恐惧程度等。

#### 4.5.6 收入结算
1. 教练收入模式支持按场馆 / 按教练配置：平台抽成、固定课时费、或混合模式。
2. 具体计费规则需在上线前结合市场调研确定。
3. 教练可在个人中心查看收入明细、提现申请。

### 4.6 系统管理员功能

#### 4.6.1 用户与身份管理
1. 查看所有游客、注册用户、学员、自由游泳者账号。
2. 重置密码、手机号、邮箱。
3. 配置角色权限。
4. 教练入驻资质审核。
5. 管理实名认证信息。

#### 4.6.2 教练排班与预约释放管理
1. 查看所有教练排班表。
2. 添加、删除、修改排班时间。
3. 查看请假申请，同意或拒绝。
4. 配置下周可约时间并一键发布到小程序。
5. **预约释放规则配置**：
   - 设置每周固定释放时间（默认周三 10:00）。
   - 设置释放范围（如下周整周或未来 7 天）。
   - 设置锁单时长（默认 15 分钟），超时未支付自动释放。
   - 设置是否启用候补队列、候补有效期。
   - 设置关注提醒提前时间。
   - 特殊情况下可手动提前或延迟释放。
   - **节假日处理**：若节假日不营业，管理员可提前释放下一周可约时段，并通过公告通知用户。
6. **预约规则说明**：单个课程预约采用先抢先得机制，无需教练二次确认；教练确认 / 协商环节仅在购买套餐时触发。

#### 4.6.3 套餐与订单
1. 配置一对一、一对二、一对三及自定义套餐；每个套餐可设置是否需教练审批。
2. 配置套餐选项：教学泳姿（蛙泳 / 自由泳 / 蝶泳 / 仰泳）、搭档模式（固定 / 不固定）、搭档性别要求（男 / 女 / 不限）；选项可作为非强制条件由用户选择。
3. 配置一对多套餐的人数上限（默认 3 人）。
4. 配置折扣活动、优惠券。
5. 查看所有订单，确认或拒绝订单。
6. 处理退款、价格调整、套餐次数调整。
7. 订单需经教练与学员双方确认后生效。

#### 4.6.4 场馆与公告
1. 配置场馆名称、地址、导航、开业年限、泳池状态。
2. 场馆闭馆 / 换水设置：管理员设置闭馆日期后，系统自动检测受影响的周期性预约，自动跳过并通知相关学员与教练。
3. 配置免责声明、健康申报模板。

#### 4.6.5 通知栏与首页运营
1. **首页通知栏（Notice Bar）**：
   - 用于展示轻量、时效性强的公告，无需设计卡片。
   - 支持的内容类型：
     - 泳池状态（开放 / 换水 / 闭馆）
     - 开放时间 / 换水时间提醒
     - 下周预约释放倒计时
     - 节假日提前释放通知
     - 临时紧急公告
   - 展示形式：固定置顶条或横向滚动轮播，支持多条公告按优先级排序。
   - 样式类型：普通（蓝色）、提醒（黄色）、紧急（红色）。
   - 可设置可见范围（全部 / 仅学员 / 仅教练等）。

2. **首页 Banner 配置**：上传游泳馆照片、活动海报，支持设置跳转链接（如套餐详情页、活动页、教练详情页）。

3. **首页卡片配置**：用于运营活动和功能入口，如：
   - 折扣活动卡片（如 618 大促、新用户专享）
   - 热门教练推荐卡片
   - 自由游泳者购卡入口卡片
   - 邀请好友得奖励卡片

4. **卡片可见范围配置**：每张卡片可设置对哪些身份 / 角色可见：
   - 全部可见
   - 仅游客 / 注册用户可见（拉新转化）
   - 仅学员可见
   - 仅自由游泳者可见
   - 仅教练可见

5. **排序与有效期**：支持配置通知栏公告顺序、卡片展示顺序、上线时间、下线时间。

#### 4.6.6 数据看板
1. 游泳高峰期（按小时 / 天 / 周 / 月）。
2. 学习游泳高峰期。
3. 每月总课时、各教练课时。
4. 教练评分、投诉情况。
5. 学员画像：性别、年龄、泳姿分布、消费情况。
6. 每天各时段人数分布。
7. 转化率、续费率、退课率、坪效等经营指标。
8. 预约释放数据：释放时段点击率、候补转化率、热门教练 / 时段分布。
9. 教练实时状态监控：当前空闲、上课中、休息、下班、请假的教练数量分布。

#### 4.6.7 客服与工单
1. 接收学员投诉、建议、换教练申请。
2. 工单流转：提交 → 处理 → 反馈 → 关闭。

#### 4.6.8 AI 配置
1. 选择 AI 模型（OpenAI、DeepSeek、通义千问等）。
2. 配置温度、最大 Tokens、提示词。
3. 配置 AI 可访问的数据范围。
4. AI 视频分析服务可选本地或云端，云端按使用量计费。

## 5. 消息通知体系

### 5.1 通知渠道
1. 小程序内消息中心。
2. 微信订阅消息 / 服务通知。
3. 短信通知（重要事件）。

### 5.2 通知场景
1. 预约成功 / 失败 / 取消 / 协商。
2. 排队候补转正通知。
3. 预约释放前提醒（释放前 24 小时、释放前 1 小时）。
4. 节假日提前释放公告通知。
5. 关注时段空出提醒。
6. 课前提醒（学员与教练可自定义提前时间）。
7. 入场通知（学员入场提醒教练）。
8. 教练提醒学员入场。
9. 订单状态变更。
10. 场馆闭馆 / 开放时间变更。
11. 次卡 / 月卡到期提醒。
12. 身份状态变更通知（如购买成功后成为学员）。
13. 应用内即时通讯新消息提醒。
14. 周期性预约因场馆闭馆 / 换水 / 教练请假自动跳过的通知。
15. 一对多拼课失败，时段释放后可继续预约的通知。

### 5.3 应用内即时通讯
1. 支持一对一临时会话：学员与教练可在小程序内直接发起聊天，无需跳转微信或电话。
2. 支持一对多临时群聊：一对多套餐拼课成功后，系统自动创建临时群聊，参与学员与教练可在群内沟通。
3. 聊天场景：预约时间确认、到场时间、集合地点、装备准备、课后反馈、临时请假等。
4. 聊天记录保存至服务端，关联对应订单或预约记录，便于纠纷处理与服务追溯。
5. 课程结束或订单完成后，临时会话可自动归档，不再允许新消息，但历史记录可查看。
6. 支持发送文字、图片、语音消息；未来可扩展发送场馆位置、预约卡片等结构化消息。
7. 消息通知：收到新消息时，通过小程序服务通知 / 订阅消息推送提醒；同时在小程序底部导航或「我的」页面显示未读消息红点 / 数字角标。
8. 未读消息管理：用户可查看所有未读消息列表，支持一键已读；对方已读状态可显示（可选）。

## 6. 核心流程图

### 6.1 用户身份转换流程
```
游客
  ↓ 浏览信息，触发注册
注册用户
  ├─ 完成实名认证 + 购买教练课程套餐 ──→ 学员
  └─ 完成实名认证 + 购买次卡 / 月卡 ───→ 自由游泳者

学员 + 自由游泳者（可同时具备）
  ↓ 课时用完
自由游泳者
  ↓ 月卡 / 次卡过期
注册用户
```

### 6.2 预约释放与候补流程
```
管理员配置下周排班
    ↓
每周三 10:00 系统自动释放下周可约时段（节假日可提前释放并公告）
    ↓
用户查看可约时间
    ├─ 有库存 → 提交预约 → 系统锁定时段 → 预约成功
    └─ 已满员 → 加入候补队列 / 关注该时段
                    ↓
            有人取消预约或超时释放
                    ↓
            按候补顺序自动转正 → 发送通知
```

### 6.3 预约流程

#### 正价套餐学员预约流程
```
选择上课时间（教练已绑定）
    ↓
提交预约 → 系统立即锁定该时段，并预占 1 节课时
    ↓
预约成功 → 发送通知
    ↓
上课前提醒
    ↓
学员到馆签到 → 教练收到通知
    ↓
上课
    ↓
教练记录上课内容 → 点击「确认上课并扣除课时」→ 系统正式扣减课时
    ↓
学员课后总结与评价

注：课前 24 小时外取消，释放预占课时；24 小时内取消需教练审批。
```

#### 体验课学员预约流程
```
选择教练 / 时间
    ↓
提交预约 → 系统立即锁定该时段
    ↓
15 分钟内完成支付
    ├─ 超时未支付 → 释放时段 → 通知候补用户
    └─ 完成支付 → 预约成功 → 发送通知
    ↓
上课前提醒
    ↓
学员到馆签到 → 教练收到通知
    ↓
上课
    ↓
教练记录上课内容 → 点击「确认上课」
    ↓
学员课后总结与评价
```

### 6.4 购买套餐流程
```
用户浏览套餐
    ↓
选择套餐 / 自定义套餐
    ↓
生成订单
    ↓
教练二次确认（可修改价格 / 次数）
    ↓
用户确认
    ↓
支付
    ↓
管理员确认订单 → 身份变更为学员 → 订单生效

注：当套餐或教练设置为「需审批」时，生成订单后需先由教练确认 / 拒绝 / 协商（可修改价格 / 次数），用户确认后再支付；未设置审批时可直接支付。
```

### 6.5 购买次卡 / 月卡流程
```
用户浏览次卡 / 月卡
    ↓
选择卡种
    ↓
完成实名认证
    ↓
支付
    ↓
身份变更为自由游泳者
    ↓
可入场签到、查看余额
```

### 6.6 退款流程
```
用户发起退款
    ↓
系统计算可退金额
    ↓
若涉及手续费，提示用户并需用户确认
    ↓
教练确认
    ↓
管理员审批
    ↓
原路退款 → 通知用户
    ↓
若课时 / 余额清空，身份相应降级
```

## 7. 数据与合规

### 7.1 数据安全
1. 用户手机号、邮箱、支付信息加密存储。
2. 敏感操作（支付、退款、修改价格）需二次确认。
3. 操作日志记录，支持审计。
4. 数据库定期备份。

### 7.2 隐私合规
1. 首次注册需用户同意隐私协议。
2. 明确告知数据用途，支持撤回授权。
3. 符合 GDPR、CCPA、国内《个人信息保护法》要求。
4. 未成年人信息需监护人授权。

### 7.3 健康与免责
1. 下水前勾选健康承诺（无心脏病、皮肤病等）。
2. 新学员首次购课或入场前电子签署免责协议。

## 8. 非功能性需求

### 8.1 性能
1. 小程序首页加载时间 < 2 秒。
2. 预约高峰期并发支持 1000 QPS。
3. 视频上传支持断点续传。

### 8.2 可用性
1. 系统可用性 99.9%。
2. 支付链路具备重试与对账机制。
3. 关键操作支持降级方案。

### 8.3 扩展性
1. 预留多场馆、多城市扩展能力。
2. 预留物联网硬件接入接口。
3. AI 模型可配置切换。
4. 首期只做微信小程序，服务端接口预留 App 复用能力。

### 8.4 多端一致性
1. 小程序与 App 数据互通。
2. 教练复杂操作建议在 Web 后台完成。

## 9. 已确认产品决策

以下问题已由产品方确认，作为后续设计与开发的依据。

| 序号 | 问题 | 决策 |
|------|------|------|
| 1 | 教练是否也可以同时具备学员或自由游泳者身份？ | 否。教练为独立角色，不叠加学员 / 自由游泳者身份。 |
| 2 | 一对多套餐最多支持几人？ | 最多 3 人，后台可配置。 |
| 3 | 教练收入是平台抽成还是固定课时费？ | 支持按场馆 / 按教练配置：平台抽成、固定课时费或混合模式；具体规则需结合市场调研确定。 |
| 4 | 退款时是否扣除手续费？ | 若涉及手续费，系统需明确提示用户，用户确认后再退款。 |
| 5 | 是否必须实名认证才能预约？ | 是。预约体验课、购买正课套餐、购买次卡 / 月卡前必须完成实名认证。 |
| 6 | AI 视频分析是否使用云端服务？ | 可能使用云端服务，按使用量计费；具体方案第三阶段确定。 |
| 7 | 是否首期只做微信小程序，还是同步做 App？ | 首期只做微信小程序，服务端预留 App 接口。 |
| 8 | 用户身份过期后，历史数据是否保留？ | 是。身份过期后历史数据保留。 |
| 9 | 预约释放时间周三 10:00 是否需要区分节假日？ | 后台可配置，节假日不营业时可提前释放下一周时段，并通过公告通知用户。 |
| 10 | 候补队列是否允许同时候补多个时段？ | 允许。但若其中一个候补成功，其他候补订单自动取消。 |
