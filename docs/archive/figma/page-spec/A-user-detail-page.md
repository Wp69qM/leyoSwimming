### 3.1 TopBar / 侧边栏 / 面包屑

|------|-----|

| 头像 | 80×80 px 圆形，无头像时显示默认头像 |
| 昵称/姓名 | 20px Medium #262626 |
| 用户 ID | 12px Regular #8C8C8C |

| 资料完善标签 | Tag：已完善 / 未完善 |
| 信息行 | 手机号（脱敏，点击显示）、性别、年龄、注册时间、最后登录时间 |

### 3.4 基本信息 Tab

| 字段 | 值 |
|------|-----|
| 内容 | 只读信息表，2 列布局 |
| 分组 | 基础信息 / 游泳档案 / 监护人信息（未成年人时显示） |

#### 3.4.1 基础信息分组

| 字段 | 说明 |
|------|------|
| 头像 | 80×80 px 圆形 |
| 用户 ID | 系统分配 |
| 昵称/姓名 | 用户填写的 `name` |
| 手机号 | 脱敏显示，点击显示完整 |
| 性别 | 男 / 女 / 未知 |
| 年龄 | 数字或「未知」 |
| 注册来源 | 微信授权 / 手机号登录 |
| 注册时间 | YYYY-MM-DD HH:mm:ss |
| 最后登录时间 | YYYY-MM-DD HH:mm:ss |
| 账号状态 | 正常 / 注销 / 封禁 |
| 资料完善状态 | 已完善 / 未完善 |

#### 3.4.2 游泳档案分组

| 字段 | 说明 |
|------|------|

| 游泳年限 | 当「有基础」时显示，数字年 |
| 个人描述 | 用户填写的个人描述文本 |

#### 3.4.3 监护人信息分组（未成年人 age < 18 时显示）

| 字段 | 说明 |

## 6. 四态设计

### 6.1 空状态

- 各 Tab 无数据时显示 `el-empty` "暂无数据"。
- 游泳档案未填写时显示「未填写」占位文本。

### 6.2 加载中

- 页面级 `el-loading` 遮罩或各卡片骨架屏。

### 6.3 错误状态

- 错误占位页：插画 + "用户不存在或已删除" + 「返回列表」按钮。

### 6.4 成功状态

- 用户信息与各 Tab 正常展示。

## 7. 业务规则引用

| 规则 | 来源 | 在本页的体现 |
|------|------|-------------|
| 管理员查看用户详情 | PRD §5.5.1 | 用户信息卡 |

| 未成年人需填写监护人信息 | US-005 §4.1 / §6.2 / §14.5 | age < 18 时显示监护人信息分组 |
| 不同身份展示不同业务数据 | PRD §3.1 | Tab 显隐规则（游客无订单/套餐/上课记录） |
| 管理员可封禁/解禁用户 | PRD §3.3 | 底部操作栏 |
| 敏感信息脱敏 | 全局原则 §8.2 | 手机号/监护人手机号脱敏 |
