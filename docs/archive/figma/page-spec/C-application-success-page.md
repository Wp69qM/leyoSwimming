## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 待审核（0） | 是 | 提交成功后默认进入本页 |
| 已通过（1） | 否 | 正常不会进入 |
| 已驳回（2） | 否 | 重新提交后可能短暂展示，随后进入待审核态 |
| 已离职（3） | 是 | 重新入驻提交成功后进入本页，文案强调"重新入驻" |
| 申请离职中（4） | 否 | 不可进入 |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| 首次入驻成功 | coach.status = 0 | 展示"资料审核中"提示 |
| 重新入驻成功 | coach.status 3 → 0 | 展示"重新入驻申请已提交"提示，增加历史数据说明 |

## 6. 四态设计

| 状态 | 表现 |
|------|------|
| 空状态 | 无（结果页主态即成功态） |
| 加载中 | 提交过程中显示 loading 遮罩 |
| 错误状态 | 提交失败时留在填写页显示错误提示，不进入本页 |
| 成功状态 | 本页完整内容 |
