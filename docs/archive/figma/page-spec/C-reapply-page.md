## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 是否可见 | 差异说明 |
|------|:-------:|---------|
| 已离职（3） | 是 | 完整功能，预填旧资料 |
| 待审核（0） | 是 | 重新入驻提交后进入审核状态页 |
| 已通过（1） | 否 | 正常不会进入 |
| 其他状态 | 否 | 隐藏入口或提示"当前状态不可重新入驻" |

### 2.2 关键业务状态

| 状态 | 含义 | 对本页影响 |
|------|------|-----------|
| 首次进入 | status=3 | 展示"重新入驻"说明，预填旧资料 |
| 已提交 | status 3 → 0 | 跳转 C-入驻提交成功页 |
| 审核拒绝 | status 0 → 3 | 显示拒绝原因，允许再次提交 |
