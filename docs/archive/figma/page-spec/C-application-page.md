# 页面规格：C-入驻资料填写页

> **性质**：Figma 设计交付的唯一指令源。
> **归属 US**：US-010 / US-040
> **对应 PRD**：§5.4.1 入驻与资料、§5.4.8 重新入驻
> **版本**：v1.0 | **创建日期**：2026-08-02

---

## 1. 页面基础

| 字段 | 值 |
|------|-----|
| 页面名（中文） | 入驻资料填写页 |
| 页面名（Frame） | `C-入驻资料填写页` |
| 平台 | 微信小程序 - 教练端 |

| 页面背景 | `#F5F7FA` |

---

## 2. 教练状态维度

### 2.1 适用状态

| 状态 | 页面表现 |
|------|----------|
| 待审核（0） | 显示「审核中」状态页，隐藏表单，提供「查看资料」入口 |
| 已通过（1） | 正常情况下不进入本页；从我的-个人主页编辑进入时展示资料只读/编辑 |
| 已驳回（2） | 顶部显示红色驳回原因条，表单可编辑，提交按钮为「重新提交」 |
| 已离职（3） | 通过「重新入驻」进入，标题改为"重新入驻资料"，流程与首次入驻一致 |
| 申请离职中（4） | 不可进入本页；点击入口提示"当前状态不可修改入驻资料" |

---

## 3. 元素清单（自上而下）

### 3.1 状态提示区（仅特定状态显示）

| 字段 | 值 |
|------|-----|
| 待审核提示 | 375×96，#E6F7FF 背景，图标 + "资料审核中，请耐心等待" + 预计时间 |
| 已驳回提示 | 343×72，x=16，#FFF1F0 背景，圆角 12，标题"审核未通过"，内容 rejection_reason |
| 重新入驻提示 | 343×64，x=16，#FFFBE6 背景，提示"请重新提交资料，历史评分仅对老学员可见" |

### 3.2 表单区

| 字段 | 值 |
|------|-----|
| 证书照片 | 上传区 100×100，最多 5 张，单张 ≤5MB，JPG/PNG |
| 任教年限 | 数字输入框，单位"年"，范围 1-50 |
| 总学员数 | 数字输入框，单位"人" |
| 总课时数 | 数字输入框，单位"节" |
| 个人简介 | 多行文本，最多 500 字，带字数统计 |
| 参考单价 | 数字输入框，单位"元/节"，范围 50-2000，带范围提示 |
| 微信二维码 | 上传区 100×100，单张 |
| 手机号 | 只读展示（来自微信授权/手机号） |

### 3.3 底部操作区

| 字段 | 值 |
|------|-----|
| 保存草稿 | 343×44，白底，#1890FF 边框，圆角 8 |
| 提交审核 | 343×48，#1890FF 渐变，白色文字，圆角 8 |
| 两按钮间距 | 12px |
| 底部留白 | ≥32px（避免被键盘遮挡） |

---

## 4. 显示规则总表

| 元素 | 待审核（0） | 已驳回（2） | 已离职重新入驻（3） |
|------|:-----------:|:-----------:|:-------------------:|
| 表单字段 | 只读 | 可编辑 | 可编辑（预填旧资料） |
| 驳回原因条 | ❌ | ✅ | ❌ |
| 审核中提示 | ✅ | ❌ | ❌ |
| 保存草稿按钮 | ❌ | ✅ | ✅ |
| 提交审核按钮 | ❌ | ✅「重新提交」 | ✅「提交审核」 |

---

## 5. 跳转动线

| 起点 | 行为 |
|------|------|
| 提交审核成功 | → C-入驻提交成功页 |
| 保存草稿成功 | 停留在本页，Toast "草稿已保存" |
| 审核中-查看资料 | 弹窗展示已提交资料（只读） |

---

## 6. 四态设计

| 状态 | 表现 |
|------|------|
| 空状态 | 上传区显示默认占位图 |
| 加载中 | 表单区骨架屏 |
| 错误状态 | 字段下方红色错误提示 |
| 成功状态 | 提交成功后跳转审核状态页 |

## 7. 业务规则引用

| 规则 | 来源 | 本页应用 |
|------|------|---------|
| 首次入驻需上传证书、任教年限等 | US-010 §5 | §3.2 表单字段 |
| 保存草稿与提交审核均写入 status=0 | US-010 §4.1 | §3.3 双按钮逻辑 |
| 参考单价范围 50-2000 元 | US-010 / US-012 | §3.2 参考单价输入 |
| 已驳回可重新提交 | US-010 §4.2 | §2.1 / §4 |
| 已离职可重新入驻 | US-040 | §2.1 / §3.1 |
