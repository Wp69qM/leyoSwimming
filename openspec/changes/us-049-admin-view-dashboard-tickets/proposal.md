## Why

管理后台需要同时掌握场馆运营数据与处理用户反馈。缺少数据看板会导致经营决策缺乏数据支撑；缺少客服工单闭环会导致用户投诉/建议/退款申诉无法及时跟进，影响服务质量与平台合规。

## What Changes

- 管理后台新增「数据看板」模块，默认展示今日/本周/本月关键指标与 5 项基础看板
- 管理后台新增「客服工单」模块，展示待处理 / 处理中 / 待反馈 / 已关闭工单列表
- 管理员可查看工单详情、分配处理人、提交回复、更新工单状态
- 工单状态变更后通知提交者
- 所有敏感操作写入审计日志

## Capabilities

### New Capabilities

- `admin-view-dashboard-tickets`: 管理员查看数据看板与处理客服工单

### Modified Capabilities

- 无

## Impact

- 后端：新增 `/api/admin/dashboard/*` 系列接口、`/api/admin/tickets/*` 系列接口
- 管理端 Web：新增「数据看板」页面与「客服工单」页面
- 依赖：US-004 / US-025 / US-032 产生的用户、订单、上课记录数据
- 影响：为 US-027 / US-030 退款/取消纠纷工单处理提供后台入口
