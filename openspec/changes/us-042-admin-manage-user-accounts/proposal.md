## Why

管理后台需要统一的小程序 C 端用户（学员）账号管理能力，以支持客服、运营人员查询用户信息、处理账号异常（如封禁/解封）以及手动创建用户。缺少该能力会导致管理员无法及时响应用户账号问题。

## What Changes

- 管理后台新增「用户管理 → 用户账号」模块
- 管理员可按身份、账号状态、资料完善状态、注册时间筛选并查看用户列表
- 用户列表展示用户档案关键字段：头像、昵称/姓名、手机号、性别、年龄、身份、资料完善状态、账号状态、注册时间
- 用户查看弹窗展示完整档案：基础信息、游泳档案（有无基础、泳姿、年限、个人描述）、监护人信息（未成年人 age < 18 时）
- 用户编辑弹窗支持管理员编辑用户资料（头像、姓名、性别、年龄、游泳基础、泳姿、游泳年限、个人描述、监护人信息等），编辑未成年人时必须填写监护人信息
- 管理员可手动新建用户，设置 source='ADMIN_CREATED'
- 管理员可封禁/解封用户账号，需填写原因并写入审计日志
- 所有敏感操作写入审计日志
- 本 US 仅操作 `user` 表，不操作 `admin_user` 表（管理员账号由 US-057 维护）

## Capabilities

### New Capabilities

- `admin-manage-user-accounts`: 管理员查询、新增、编辑、封禁/解封小程序 C 端用户账号

### Modified Capabilities

- 无

## Impact

- **数据表**：复用并写入 `user` 表；新增 `audit_log` 记录敏感操作
- **API**：新增 6 个端点 `POST /api/admin/user/list`、`POST /api/admin/user/add`、`POST /api/admin/user/detail`、`POST /api/admin/user/update`、`POST /api/admin/user/ban`、`POST /api/admin/user/unban`
- **状态机**：本 US 不涉及业务状态机转换
- **前端**：新增用户账号列表页、用户查看弹窗、用户编辑弹窗、新建用户弹窗、封禁/解封确认弹窗
- **依赖**：US-004 / US-006（产生 user 记录）、US-005（产生用户档案字段）、US-053（管理后台登录认证）
