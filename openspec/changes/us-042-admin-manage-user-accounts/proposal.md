## Why

管理后台需要统一的用户账号管理能力，以支持客服、运营人员查询用户信息、处理账号异常（如重置密码、换绑手机号）以及分配角色权限。缺少该能力会导致管理员无法及时响应用户账号问题。

## What Changes

- 管理后台新增「用户管理 → 用户账号」模块
- 管理员可按身份、账号状态、资料完善状态、注册时间筛选并查看用户列表
- 用户列表展示用户档案关键字段：头像、昵称/姓名、手机号、性别、年龄、身份、资料完善状态、账号状态、注册时间
- 用户查看弹窗展示完整档案：基础信息、游泳档案（有无基础、泳姿、年限、个人描述）、监护人信息（未成年人 age < 18 时）
- 用户编辑弹窗支持管理员编辑用户资料（头像、姓名、性别、年龄、游泳基础、泳姿、游泳年限、个人描述、监护人信息等），编辑未成年人时必须填写监护人信息
- 管理员可修改用户手机号/邮箱；修改手机号时必须验证原手机号所有权（短信验证码）或强制变更并记录原因
- 管理员可配置用户角色权限（`admin` 不可授予 `super_admin`）
- 管理员可封禁/解封用户账号，需填写原因并写入审计日志
- 所有敏感操作写入审计日志
- RBAC 权限细化：`super_admin` 可操作所有账号；`admin` 仅可操作非管理员账号

## Capabilities

### New Capabilities

- `admin-manage-user-accounts`: 管理员查询、修改用户账号及配置角色权限

### Modified Capabilities

- 无

## Impact

- 后端：新增 `/api/admin/v1/users/*` 系列接口（含用户资料编辑接口）、唯一性校验、乐观锁、审计日志
- 管理端 Web：新增用户账号列表页、用户查看弹窗、用户编辑弹窗；列表与弹窗字段与 US-005 用户档案字段对齐
- 依赖：US-004 / US-006（产生 user 记录）、US-005（产生用户档案字段）
- 影响：为所有需要 RBAC 校验的管理后台 US 提供角色基础
