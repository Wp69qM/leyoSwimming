## Why

正价套餐购买是注册用户转化为正式学员的核心交易入口。用户需要选择教练、课时数，确认协议后生成待支付订单。

## What Changes

- 新增 `POST /api/orders/formal` 创建正价套餐订单
- 新增 `POST /api/agreements/status` 查询协议签署状态
- 新增协议签署记录写入
- 新增单教练冲突校验、教练状态校验、自定义课时校验
- 新增订单幂等机制
- 新增未成年人用户信息中监护人手机号存在性校验
- 购买流程明确为：标准套餐为套餐详情页 → 选择/确认教练 → 确认订单页 → 支付页（US-025）；自定义套餐为套餐详情页 → 选择/确认教练 → 自定义配置页 → 支付页（US-025）
- 套餐详情页区分入口：全局列表进入需选择适配教练，教练详情页进入已绑定当前教练；自定义套餐教练卡片额外展示参考单价
- 自定义套餐配置页支持课时数（4/8/12/20 或自定义输入）、有效期（30/60/90/180 天）、学习泳姿多选，价格按课时数 × 参考单价实时计算

## Capabilities

### New Capabilities

- `student-buy-formal-package`: 学员/注册用户购买正价套餐，支持从全局套餐列表或教练详情页进入，在套餐详情页选择/确认教练后提交订单

### Modified Capabilities

（无）

## Impact

- **数据表**：新增 `order`、`agreement_sign` 记录
- **API**：新增 2 个端点，复用 US-019 的 `/api/packages/detail`
- **校验**：单教练约束、教练状态、协议版本、自定义套餐参数范围、教练必选（全局入口）
- **依赖**：依赖 US-004/US-005 / US-011 / US-019 / US-045 / US-025；被 US-021 依赖
