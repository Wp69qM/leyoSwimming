# 【乐游】系统初步想法

我想做一个 【游泳】的约课系统，是一个全栈开发项目，这我需要设计出一个系统,不同的角色可以看到不同的页面,但是他们都需要登录系统,登录后才能使用系统的功能。
基于下面的想法，帮我生成一份提示词，这份文档可以发给AI，让AI根据提示词生成一份系统的prd文档


## 1. 涉及的角色：
### 1.1 游泳教练
1. 教练需要查看学员的预约时间的卡片，点击卡片可以查看预约的学员信息，包括学员的姓名，年龄，手机号，游泳等级，学习的泳姿，有无基础，已上的课时，剩余的课时，以及其他的一些情况。
2. 教练需要记录学员的上课信息，包括每节课的时间，每节课的内容，每节课的学习情况。
3. 教练需要记录学员的课时信息，学员一共买了多少节课时，已经用了多少节课，还剩多少节课
4. 教练平时上课时会和学员聊天，会得到一些基础信息，比如学员的姓名，年龄，手机号，游泳等级，以及其他的一些情况，需要将这些信息记录下来，以免学员过多，导致信息混乱，因为预约成功后，会将学员自己填写的信息拿过来，但是学员可能是没有标准填写的，信息不完整或者不可信，这是将默认信息带过来，教练可以根据自己聊天了解到的情况更新编辑学员信息，只会影响该教练信息下关联的该学员的信息，对其他教练对该学员的信息及该学员自己系统内的信息并不会做出改变，只是维护了一个该教练的学员信息切片。
6. 教练可以查看学员的评价，以及学员的反馈，根据学员的反馈，调整自己的上课策略。
7. 教练可以在学员上课前10分钟，查看学员的入场情况，如果还没入场，点击按钮可以提醒学员去游泳池， swim swim swim！
8. 教练可以切换查看自己不同视图的预约情况，天维度，周维度，月维度，年维度不同维度的视图卡片，点击卡片进去可以查看详情，比如该天/周/月/年的预约列表，以及该天/周/月/年的学员信息。
9. 教练的页面有一个AI助理，点击后可以直接获取自己想要的不同维度的数据列表，比如
  - 自己的预约情况
  - 自己的学员信息
  - 自己的上课信息
  - 自己的学员评价
  - 自己的学员反馈
  - 全天，全周，全月，全年的上课情况
10. 教练可以根据自己的AI助理获取的数据，让AI助理可以生成图表，分析自己的学员情况，以及自己的上课策略，调整自己的上课策略。
11. 教练可以通过自己的AI助理查看图表，告诉自己现在是淡季还是旺季，学员的画像，分析哪类人员最有可能买课，自己的上课风格是哪些。
12. 系统可以对教练上课的总课时，带过的学生总量进行统计，任教时间，专业证书等作为教练的信息，展示在教练的个人信息页面上。
13. 教练可以在岸上给学员拍摄照片或者视频，上传到系统中，作为该节课的记录视频，供学员查看，也可以在系统中查看所有的记录视频。

### 1.2 游泳学员
1. 已经报课的老学员需要去系统中点击时间段进行预约，预约成功后，生成预约卡片，卡片显示简单的预约信息，点击可以查看详情，记录自己的预约时间，以及预约的教练信息
2. 老学员可以查看自己的课时情况，上了几节课，还剩几节课，可以查看自己所有的上课记录，包括每节课的时间，
3. 老学员每节课结束后也可以自己做一个总结，记录每节课的内容，每节课的评价，身体感受，上课的感受，是否有什么问题，是否需要调整自己的训练计划。这个总结可以直接上传到系统中，教练可以在系统中查看所有的总结，根据AI生成用户画像，及时调整自己的上课策略。
4. 老学员可以对每节课教练的教学质量进行评价，比如教学的清晰度，教学的速度，教学的效果等，这个反馈可以直接给到教练，教练可以根据学员的评价，调整自己的教学策略。
5. 老学员如果对教练不满意，可以申请更换教练，提出申请后，系统管理员接到之后，系统会根据学员的评价，判断是否同意更换教练，可以通过或否决审批单。
6. 对于所有学员，登录系统后，可以查看系统的公告信息，比如游泳池的开放时间，游泳池的换水时间，目前游泳池的拥挤情况等。
7. 对于新学员，可以看到目前游泳馆的所有的教练，点击可以查看教练的详细介绍，比如教练的姓名，年龄，手机号，游泳等级，以及其他的一些情况。
8. 新学员可以在系统中查看游泳的套餐，以及套餐的详细信息
9. 新学员可以预约自己感兴趣的教练进行一节体验教程，体验教程的时间一般是1小时，教练会和学员进行一次简单的介绍，学员可以根据教练的介绍，判断是否感兴趣，是否需要购买套餐。
10. 新学员可以在系统中购买自己喜欢的套餐，系统会根据学员的购买信息，生成一个订单，学员需要支付订单的金额，支付完成后，系统会确认订单，学员就可以在系统中预约教练了。
11. 每个教练的信息里都有微信二维码和手机号，学员可以通过扫描教练的微信二维码，或者直接拨打电话，和教练进行联系。
12. 已经购课的上课的学员，每节课进入场馆里，可以点击一个已入场的按钮，提示教练已经入场，教练收到提醒后可以根据这个提示，开始上课。
13. 如果学员选择的套餐是一对二或者一对多的，教练需要和学员确认一下，是否需要协调其他的学员。如果需要协调其他的学员，需要和其他的学员进行沟通，确认是否可以协调。这种情况可以选择固定搭档，也可以选择不固定搭档，根据学员的情况，来确定是否需要协调其他的学员。如果选择不固定搭档，则在预约界面预约后，其他的也是选择一对多的套餐的人，可以看到这节课还缺几个人，已经有几个人预约了，买的一对一套餐的人预约了课时后，当前这个时间段显示的就是已约满，一对二套餐的只能选择未预约的时间段或者未约满的以及和自己套餐相同的时间段，如果只有一个人预约，则其他也是买的一对二套餐的人人可以看到已预约1人，还差1位拼课成功，一对一及一对三套餐的人可以看到这个，但是不能选择，因为套餐不同
14. 如果一对多的有固定的搭档，那么可以维护自己的搭档信息，比如
  - 固定搭档的姓名
  - 固定搭档的手机号
  - 固定搭档的游泳等及
  - 可以添加搭档的微信或者手机号
  - 可以在入场后通知搭档和教练自己已入场，发送通知消息
15. 学员可以查看到该节课教练上传的记录视频，可以通过AI助理，查看视频中的游泳内容，分析自己的游泳技术，看当前自己的游泳技术是否有问题，是否需要调整，可以通通过一些专业的百度的视频技术分析，看动作是否标准，做一个自己的和标准视频的同步分析，让AI记录结论，之后比如上了5节课后，可以通过AI助理结合之前的视频结论，给出自己的一个动作分析和建议，看是否需要增加学习时间以及下一步的规划

### 1.3 自由游泳者，不报课，只是购买了普通的游泳次卡或者月卡，通过该系统查看自己的游泳记录，以及自己的游泳时间
1. 自由游泳者可以在系统中查看自己的游泳记录，包括每次游了多长时间，消耗量，游得距离
2. 自由游泳者可以在系统中查看游泳池的拥挤情况，包括当前游泳池的人数，以及游泳池的开放时间，换水时间
3. 自由游泳者可以在入场后点击一个按钮，提示自己已入场游泳，作为泳池人数的一个判断依据，当前泳池共有多少人
4. 自由游泳者可以通过AI助理，查看自己的游泳记录，以及自己的游泳时间，AI助理可以根据自己的游泳记录，今年游了多少次，总共游了多长时间，上传自己的游泳视频，分析自己的游泳习惯，比如游的时间，游的距离，游的时间分布等，根据这些数据，AI助理可以推荐自己一些游泳的建议，比如是否需要增加游的时间，是否需要增加游的距离等。
5. 自由游泳者是可以在系统中购买普通的游泳次卡或者月卡，系统会根据学员的购买信息，生成一个订单，学员需要支付订单的金额，支付完成后，系统会确认订单，学员就可以在系统中购买普通的游泳次卡或者月卡了。
6. 自由游泳者是买教练课的潜在用户，如果觉得游的不太好，或者需要专业的教练指导一下，可以在系统中联系教练，教练会和学员进行一次简单的介绍，学员可以根据教练的介绍，判断是否感兴趣，是否需要购买套餐。也可以随时查看教练的空闲时间，预约教练的30分钟或者60分钟次卡课程，进行专业的指导


### 1.4 系统管理员
#### 1.4.1 解决的痛点：
1. 系统管理员需要记录所有教练的信息，以及他们的上课信息，请假信息
2. 系统管理员需要记录所有学员的信息，以及他们的上课信息
3. 系统管理员需要记录所有课时的信息，
4. 系统管理员可以查看不同的图表，根据不同维度的数据，以便数据分析，比如
 - 游泳的高峰期
 - 学习游泳的高峰期
 - 每个月的游泳总课时情况
 - 不同教练的课时情况，可以分析教练的受欢迎程度
 - 可以查看教练的评分和投诉情况
 - 根据学员情况做一个学员的分析，比如女性偏多还是男性偏多，是小孩子多还是成年人多，18岁以上的有多少，18岁以下的有多少，
 - 不同游泳姿的学员情况
 - 不同年龄的一个消费情况，比如小孩子一般报多少节课时，成年人一般报多少节课时，
 - 每天游泳的一个高峰期，比如09:00-10:00，15:00-16:00等，
5. 系统管理员可以管理和配置一些公告信息，比如
  - 游泳馆的开放时间
  - 游泳池的信息，比如游泳池的大小，游泳池的位置，游泳池的设施，游泳池的价格等
  - 游泳馆的换水时间，做一个公告处理，告诉大家今天馆内换水，暂不开放，请勿走空
  - 目前游泳馆的拥挤情况，做一个公告处理，告诉大家当前游泳馆的人数，让大家来判定是否在泳池人多的时候来
  - 可以根据上周的游泳情况，做一个数据统计，比如高峰期是什么时候，有多少人，可以让大家来作为判断依据
6. 教练的排班表
  - 可以在后台管理系统中查看所有的排班表，以及排班表的详细信息
  - 可以在后台管理系统中修改排班表，比如添加或删除某个时间的排班
  - 可以在后台管理系统中查看所有的请假信息，以及请假的原因
  - 可以在后台管理系统中处理请假请求，同意或拒绝请假
  - 可以在后台管理系统中配置好下周的每个教练可预约的时间，然后点击更新，这个就可以更新到小程序中让学员看到每个教练的可预约时间，进行下一周的预约
7. 游泳的套餐
  - 系统管理员可以在后台管理系统中配置游泳的套餐，比如
    - 一对一套餐，
    - 一对二套餐，
    - 一对多套餐
  - 系统管理员可以在后台管理系统中配置最近的折扣活动，优惠多少多少等，比如打几折，可以作为公告信息放在小程序首页
  - 系统管理员可以设置不同教练的单节课的标准价格，仅作为参考，具体的价格可商议后再确定
  - 后台收到学员的购买请求后，需要验证学员的信息是否正确，比如姓名，手机号，邮箱等。以及如果学员和教练商量后价格有背后的调整，也可以随时在后台修改记录，但是要通知学员，学员需要重新支付订单金额。
  - 学员可以在小程序中查看所有的套餐，以及套餐的详细信息
  - 学员可以在小程序中点击购买按钮，购买自己喜欢��套餐
  - 系统需要有一个订单队列，当学员购买套餐后，会从队列中取出一个订单进行处理。
  - 系统管理员可以在后台管理系统中查看所有的订单信息，以及订单的详细信息。
  - 系统管理员可以在后台管理系统中确认订单，拒绝订单。


## 2. 系统的功能
### 2.1 系统的定位
1. 小程序
 - 学员角色的小程序
 - 教练角色的小程序
 - 自由游泳者角色的小程序
2. 后台管理系统-给系统管理员和教练使用
3. 同时希望可以作为应用app可以在移动端应用市场下载使用，小程序和移动端app的数据是互通的

### 2.2 登录注册功能
1. 系统需要有一个登录功能，不同的角色登录后，看到的页面是不同的。
2. 登录时需要输入用户名和密码，系统需要验证用户名和密码是否正确。
3. 如果用户名或密码错误，系统需要提示错误信息。
4. 小程序可以通过微信授权登录，学员和教练可以使用自己的微信账号登录系统，初次进入系统后需要先注册，需要补充输入用户名，密码，手机号，邮箱等信息，注册完成后，就可以使用自己的账号登录系统了，并且需要选择自己是教练还是学员，教练的话初次需要上传证书，任教时间，总学员数，上过的总课时。
5. 系统管理员有的后台管理系统的登录功能，就是账号密码登录，系统管理员需要有一个账号，登录后才能进入后台管理系统。系统管理员默认的账号是admin，密码admin123

### 2.3 预约功能
1. 学员可以在小程序中查看所有的教练，以及他们的预约时间。
2. 学员可以在小程序中点击预约按钮，预约自己喜欢的教练。
3. 教练可以查看所有的预约信息，以及预约的学员信息。
4. 教练收到预约消息后，可以确认预约，拒绝预约，以及协商。
5. 可以提前一周进行预约，预约下周7天的课，就像博物馆的门票预约一样，预约成功后可在上课前一天24小时前，可以随时取消预约，24小时内不可取消预约，但是可以协商时间，如果教练在当天想取消的那个时间内可以找到其他人来上课，则点击可取消，这个时候学员则发起取消申请，由教练来批准申请，如果教练在当天不能找到其他人来上课，则拒绝取消申请。
6. 24小时外随时取消预约，预约取消后，系统会给学员发送一条消息，通知学员预约已取消，同时，可给其他关注了该教练或者该时间段的学员发送一条消息，通知他们有课时空闲，可以继续预约
7. 可预约的时间段被约了之后，其他人相约但是约不到，可以点击排队或者关注功能，排队或者关注后，系统会给其他关注了该教练或者该时间段的学员发送一条消息，通知他们有课时空闲，可以继续预约。
8. 

### 2.4 互动功能
1. 学员和教练可以在小程序中进行互动，比如
 - 学员可以在小程序中发送消息给教练
 - 教练可以在小程序中发送消息给学员
 - 学员和教练可以在小程序中进行聊天
 - 学员入场可发送通知消息，自己已入场
 - 教练可在上课前10分钟，发送通知消息，提醒学员去游泳池， swim swim swim！
 - 一对多套餐的人，可以和搭档进行沟通
 - 一对多套餐的人，可以像美团和饿了么一样，有骑手，商家，顾客的临时聊天群，这个也可以临时搭建一个临时的聊天群，方便和搭档进行沟通，交换信息，协商时间

### 2.5 AI助理
1. 系统可以有一个AI助理，学员和教练可以通过AI助理进行互动。
2. 学员可以在小程序中点击AI助理按钮，开始和AI助理进行互动。
3. AI助理可以根据学员的输入，进行回复，比如
 - 学员可以问AI助理，当前游泳池的拥挤情况
 - 学员可以问AI助理，教练的空闲时间
 - 学员可以问AI助理，教练的教学质量
 - 学员可以问AI助理，自己的游泳记录
 - 学员可以问AI助理，自己的游泳时间
4. AI助理可以根据学员的输入，进行推荐，比如
 - 学员可以问AI助理，推荐我一个教练
 - 学员可以问AI助理，推荐我一个游泳姿
 - 学员可以问AI助理，推荐我一个游泳时间
5. 系统管理员可以在后台管理系统中配置AI助理的模型，比如选择使用OpenAI的ChatGPT模型，还是使用其他的模型。
6. 系统管理员可以在后台管理系统中配置AI助理的参数，比如温度，最大Tokens等。
7. 系统管理员可以在后台管理系统中配置AI助理的提示词，比如
 - 学员可以问AI助理，推荐我一个教练
 - 学员可以问AI助理，推荐我一个游泳姿
 - 学员可以问AI助理，推荐我一个游泳时间
8. 学员可以在小程序中让AI分析上传的游泳视频的姿势，动作是否标准，是否需要调整，是否需要增加学习时间等，
9. 学员可以让AI推荐一些目前自己正在上课内容的视频，可以先看看

## 3. 其他由AI补充的场景

### 3.1 退款与客诉流程
退款与客诉流程：你提到了换教练申请，但缺少了“退课/退款流程”。如果学员买了10节课上了2节想退费，系统需要支持按比例退款、计算已消耗课时价值、教练确认、管理员审批的闭环。

### 3.2. 请假与补课机制
请假与补课机制：学员临时生病无法上课，现有的“24小时内不可取消”过于刚性。建议增加“请假转补课”机制，需教练审批，不扣除课时，但转为本月需消费完的“补课券”。

### 3.3. 换教练申请流程
换教练申请流程：学员想换教练，系统需记录换教练申请，教练审批后，系统更新预约记录。

### 3.4. 课程复盘模板化
教练和学员的课后总结，如果纯文本太麻烦，建议提供“结构化标签”（如：今日重点-换气、掌握程度-80%、课后作业-打腿100次）+语音输入，提升记录效率。

### 3.5.  营销与增长功能补充（如果初版的功能太多，可以考虑后续实现）
裂变与分享机制：新学员购买体验课时，可以增加“拼团体验”或“邀请好友各得1节体验课”功能，降低获客成本。
次卡/月卡到期提醒与续费诱饵：自由游泳者的次卡剩余3次或月卡到期前3天，系统自动推送续费优惠券。
教练主页分享：学员对教练满意，可以将教练的个人主页（带二维码）分享到微信群或朋友圈，方便新学员直接扫码预约体验。

### 3.6 硬件与物联网联动（增值功能，需要传感器或者其他设置支持，可考虑后续与健身房集成，预留接口，后续实现）
智能手环/闸机联动：入场点击按钮可以优化为“小程序扫码闸机入场”或“智能手环感应入场”，自动记录时长，更精准统计场内人数。
智能更衣柜：虽然复杂，但属于高端泳池配置，可预留接口。


### 3.7 小程序需要显示当前场馆的名称，地址，点击地址可以打开地图导航，展示当前场馆的位置，场馆的开业年限，以及当前泳池的状态（开/闭）
