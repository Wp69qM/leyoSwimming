# 【乐游】游泳约课系统 - 产品需求文档（角色模型修订版）

## 1. 项目概述

### 1.1 产品定位
打造一个面向游泳场馆的约课与运营管理平台，支持多类用户身份，覆盖小程序端与后台管理系统，未来可扩展为移动端 App。

### 1.2 核心价值
- 对潜在用户：透明化教练、套餐、场馆信息，降低决策门槛。
- 对学员：数字化管理课时、记录成长轨迹、获取教学反馈。
- 对自由游泳者：便捷购卡、记录游泳数据、查看场馆状态。
- 对教练：数字化管理学员与课时，通过数据优化教学策略。
- 对场馆：提升运营效率，沉淀数据资产，辅助经营决策。

### 1.3 目标平台
1. 微信小程序（用户端）
2. Web 后台管理系统（管理员、教练复杂操作）
3. 未来可扩展：iOS / Android App（与小程序数据互通）

---

## 2. 版本规划

### 2.1 MVP（第一阶段）：核心约课闭环
目标：让注册用户能变成学员或自由游泳者，教练能上课，管理员能管理。

- 游客浏览公开信息
- 用户注册登录
- 教练信息维护与可约时间配置
- 学员购买套餐、预约教练、取消预约
- 自由游泳者购买次卡 / 月卡、入场签到
- 微信支付 / 支付宝支付
- 上课记录与课时消耗
- 基础消息通知（预约、取消、课前提醒）
- 管理员：用户管理、订单确认、基础数据看板

### 2.2 第二阶段：体验优化与运营提效
- 排队候补与自动转正
- 周期性预约 / 固定课程
- 退款 / 退课流程
- 发票 / 收据管理
- 教练绩效与收入结算
- 评价与反馈闭环
- 学员等级与能力评估体系
- AI 数据查询助手

### 2.3 第三阶段：智能化与增长
- AI 视频动作分析
- 学员画像与教练推荐
- 营销裂变（老带新、拼团、优惠券）
- 社区 / 打卡 / 内容库
- 物联网硬件联动（闸机、手环、智能柜）
- 多场馆支持

## 3. 用户身份与角色

### 3.1 身份状态定义

系统中用户身份是**动态、可叠加**的，不是互斥角色。

| 身份 | 定义 | 获得条件 | 可访问功能 |
|------|------|----------|-----------|
| **游客** | 未登录或未注册的访问者 | 打开小程序但未登录 | 浏览教练列表、套餐、场馆公告、教练详情 |
| **注册用户** | 已完成注册登录，但尚未购买任何服务 | 完成微信授权 + 补充手机号等基本信息 | 预约体验课、购买套餐、购买次卡 / 月卡、查看个人中心 |
| **学员** | 已购买教练课程套餐 | 购买正课套餐 / 体验课 / 自定义套餐后生效 | 预约教练上课、查看课时记录、查看上课视频、评价教练 |
| **自由游泳者** | 已购买游泳次卡 / 月卡 | 购买次卡 / 月卡 / 储值卡后生效 | 入场签到、记录游泳数据、查看卡内余额或有效期 |

### 3.2 身份叠加规则

1. 一个用户可以同时拥有多个身份。
2. 常见组合示例：
   - 用户 A 买了 10 节私教课 + 20 次游泳卡 → **学员 + 自由游泳者**
   - 用户 B 只买了次卡，没买课 → **自由游泳者**，不是学员
   - 用户 C 注册完什么都没买 → **注册用户**，处于游客状态
   - 用户 D 课时用完、月卡过期 → 身份失效，变回**注册用户**

### 3.3 身份转换流程

```
游客
  ↓ 微信授权 + 补充信息
注册用户
  ├─ 购买教练课程套餐 ──→ 学员
  └─ 购买次卡 / 月卡 ───→ 自由游泳者

学员 + 自由游泳者（可同时具备）
  ↓ 课时用完
自由游泳者
  ↓ 月卡 / 次卡过期
注册用户
```

### 3.4 角色定义（与身份状态区分）

| 角色 | 定义 | 说明 |
|------|------|------|
| **教练** | 在平台提供教学服务的人员 | 可管理自己的预约、学员、上课记录 |
| **系统管理员** | 平台运营管理人员 | 管理用户、订单、套餐、数据、公告、AI 配置 |

说明：教练和自由游泳者 / 学员身份也可能重叠。例如，某教练本人也可以是学员（向其他教练学习）或自由游泳者。

## 4. 各身份 / 角色功能模块

### 4.1 游客功能

1. 浏览教练列表与教练详情（姓名、证书、任教时间、评分、评价）。
2. 查看系统套餐及价格。
3. 查看场馆公告：开放时间、换水时间、拥挤情况。
4. 查看场馆信息：名称、地址、导航。
5. 触发注册：预约体验课、购买套餐、购买次卡 / 月卡时需先注册登录。

---

### 4.2 注册用户功能

#### 4.2.1 注册登录
1. 支持微信授权登录，首次登录后补充手机号、用户名、密码、邮箱。
2. 支持手机号验证码登录。
3. 支持账号密码登录。
4. 支持账号注销与数据删除申请。

#### 4.2.2 账号安全
1. 手机号换绑、密码修改、邮箱绑定。
2. 登录设备管理。
3. 隐私协议授权与撤回。

#### 4.2.3 家庭账号
1. 家长账号可绑定未成年学员子账号。
2. 家长可代为预约、查看课时、接收通知。
3. 学员成年后可将账号迁移为独立账号。

#### 4.2.4 转化入口
1. 预约体验课（30 分钟或 60 分钟）。
2. 购买正课套餐。
3. 购买次卡 / 月卡成为自由游泳者。

---

### 4.3 学员功能

获得条件：购买教练课程套餐（含体验课、自定义套餐）。

#### 4.3.1 教练与套餐浏览
1. 查看所有教练列表与详情（姓名、证书、任教时间、评分、评价、可约时间）。
2. 教练详情页展示微信二维码与手机号，学员可直接扫码加微信或拨打电话联系。
3. 教练详情页提供「发起聊天」按钮，学员可直接在小程序内与教练建立一对一临时会话，沟通预约时间、诉求、基础情况等。
4. 查看系统套餐：一对一、一对二、一对多、自定义套餐。
5. 查看折扣活动与优惠信息。

#### 4.3.2 预约功能
1. 查看教练可约时间段，提前预约未来 7 天课程。
2. 预约成功后生成预约卡片，显示时间、教练、状态。
3. 24 小时外可随时取消；24 小时内取消需教练审批。
4. 满员时段可排队或关注，有空位时自动通知。
5. 支持周期性预约固定时间。

#### 4.3.3 一对多套餐与搭档
1. 一对多套餐学员可维护固定搭档信息：姓名、手机号、游泳等级。
2. 固定搭档入场后互相通知。
3. 不固定搭档模式：预约界面显示已预约人数、还差几人拼课成功。
4. 教练可查看所有拼课成功的学员列表；若开课前 24 小时未拼课成功，系统自动取消该预约。
5. 不同套餐类型不可混约。
6. 临时沟通群：拼课成功后，系统自动创建一个临时聊天窗口（类似美团订单的临时会话），参与该节课的所有学员与教练可在群内沟通预约时间、到场时间、集合地点、装备准备等事项；课程结束后聊天窗口自动关闭或归档。

#### 4.3.4 课时与上课记录
1. 查看总课时、已上课时、剩余课时。
2. 查看历史上课记录：时间、教练、内容、视频。
3. 每节课后填写自我总结：身体感受、学习效果、问题反馈。
4. 对教练进行评价：教学清晰度、速度、效果。

#### 4.3.5 购买与支付
1. 购买套餐生成订单，支持微信支付、支付宝支付。
2. 查看订单列表与支付状态。
3. 申请退款 / 退课（按比例计算）。
4. 申请电子发票。

#### 4.3.6 视频与学习
1. 查看教练上传的本节课视频。
2. 上传自己的游泳视频（可选）。
3. AI 分析游泳动作，给出改进建议（第三阶段）。

#### 4.3.7 AI 助理
1. 查询泳池拥挤情况、教练空闲时间。
2. 查询自己的上课记录、剩余课时。
3. 推荐教练、泳姿、训练时间。
4. 根据画像推荐合适的套餐。

---

### 4.4 自由游泳者功能

获得条件：购买游泳次卡 / 月卡 / 储值卡。

#### 4.4.1 游泳记录
1. 入场签到，记录游泳时长、距离、消耗。
2. 查看历史游泳记录统计。
3. 今年游了多少次、总共多长时间。

#### 4.4.2 场馆信息
1. 查看泳池拥挤情况、开放时间、换水时间。
2. 查看场馆名称、地址、导航。

#### 4.4.3 次卡 / 月卡
1. 购买普通游泳次卡或月卡。
2. 查看卡内剩余次数或有效期。
3. 到期前 3 天自动推送续费提醒。

#### 4.4.4 转化入口
1. 查看教练列表，预约体验课。
2. 通过 AI 助理分析游泳习惯并推荐课程。

---

### 4.5 教练功能

#### 4.5.1 入驻与资料
1. 首次注册需上传：证书、任教时间、总学员数、总课时数、个人简介。
2. 入驻资质需管理员审核。
3. 个人主页展示任教时间、证书、总课时、带过的学生总量、评分、评价、微信二维码、手机号。

#### 4.5.2 预约管理
1. 以日 / 周 / 月 / 年维度查看预约卡片。
2. 点击卡片查看预约详情：学员姓名、年龄、手机号、游泳等级、学习泳姿、基础情况、已上课时、剩余课时；学员信息页展示学员微信二维码与手机号，教练可直接扫码加微信或拨打电话联系。
3. 学员信息页提供「发起聊天」按钮，教练可直接在小程序内与学员建立一对一临时会话，沟通上课时间、注意事项、到馆安排等。
4. 确认预约、拒绝预约、协商时间。
5. 上课前 10 分钟查看学员入场状态，未入场可一键提醒。
6. 教练可帮学员代约或锁课。

#### 4.5.3 上课记录
1. 记录每节课时间、内容、学员学习情况。
2. 记录课时消耗：总课时、已用课时、剩余课时。
3. 支持结构化标签：今日重点、掌握程度、课后作业。
4. 支持语音输入快速记录。
5. 上传照片 / 视频作为本节课记录。

#### 4.5.4 学员信息维护
1. 教练可维护自己关联学员的信息切片。
2. 默认从学员自填信息带入，教练可根据沟通情况更新。
3. 仅影响该教练视角，不影响其他教练或学员本人信息。
4. 可查看学员评价、反馈、历史总结。

#### 4.5.5 AI 助理
1. 查询自己的预约情况、学员信息、上课记录、评价反馈。
2. 生成图表：课时统计、学员增长、收入趋势。
3. 生成经营分析：淡季 / 旺季判断、学员画像、高转化人群特征。
4. 生成学员评价报告：学习进度、动作标准度、对水恐惧程度等。

### 4.6 系统管理员功能

#### 4.6.1 用户与身份管理
1. 查看所有游客、注册用户、学员、自由游泳者账号。
2. 重置密码、手机号、邮箱。
3. 配置角色权限。
4. 教练入驻资质审核。

#### 4.6.2 教练排班与请假
1. 查看所有教练排班表。
2. 添加、删除、修改排班时间。
3. 查看请假申请，同意或拒绝。
4. 配置下周可约时间并一键发布到小程序。

#### 4.6.3 套餐与订单
1. 配置一对一、一对二、一对多套餐及自定义套餐。
2. 配置折扣活动、优惠券。
3. 查看所有订单，确认或拒绝订单。
4. 处理退款、价格调整、套餐次数调整。
5. 订单需经教练与学员双方确认后生效。

#### 4.6.4 场馆与公告
1. 配置场馆名称、地址、导航、开业年限、泳池状态。
2. 发布开放时间、换水时间、拥挤情况公告。
3. 配置免责声明、健康申报模板。

#### 4.6.5 数据看板
1. 游泳高峰期（按小时 / 天 / 周 / 月）。
2. 学习游泳高峰期。
3. 每月总课时、各教练课时。
4. 教练评分、投诉情况。
5. 学员画像：性别、年龄、泳姿分布、消费情况。
6. 每天各时段人数分布。
7. 转化率、续费率、退课率、坪效等经营指标。

#### 4.6.6 客服与工单
1. 接收学员投诉、建议、换教练申请。
2. 工单流转：提交 → 处理 → 反馈 → 关闭。

#### 4.6.7 AI 配置
1. 选择 AI 模型（OpenAI、DeepSeek、通义千问等）。
2. 配置温度、最大 Tokens、提示词。
3. 配置 AI 可访问的数据范围。

## 5. 消息通知体系

### 5.1 通知渠道
1. 小程序内消息中心。
2. 微信订阅消息 / 服务通知。
3. 短信通知（重要事件）。

### 5.2 通知场景
1. 预约成功 / 失败 / 取消 / 协商。
2. 排队转正通知。
3. 课前提醒（学员与教练可自定义提前时间）。
4. 入场通知（学员入场提醒教练）。
5. 教练提醒学员入场。
6. 订单状态变更。
7. 场馆闭馆 / 开放时间变更。
8. 次卡 / 月卡到期提醒。
9. 身份状态变更通知（如购买成功后成为学员）。
10. 应用内即时通讯新消息提醒。

### 5.3 应用内即时通讯
1. 支持一对一临时会话：学员与教练可在小程序内直接发起聊天，无需跳转微信或电话。
2. 支持一对多临时群聊：一对多套餐拼课成功后，系统自动创建临时群聊，参与学员与教练可在群内沟通。
3. 聊天场景：预约时间确认、到场时间、集合地点、装备准备、课后反馈、临时请假等。
4. 聊天记录保存至服务端，关联对应订单或预约记录，便于纠纷处理与服务追溯。
5. 课程结束或订单完成后，临时会话可自动归档，不再允许新消息，但历史记录可查看。
6. 支持发送文字、图片、语音消息；未来可扩展发送场馆位置、预约卡片等结构化消息。
7. 消息通知：收到新消息时，通过小程序服务通知 / 订阅消息推送提醒；同时在小程序底部导航或「我的」页面显示未读消息红点 / 数字角标。
8. 未读消息管理：用户可查看所有未读消息列表，支持一键已读；对方已读状态可显示（可选）。

## 6. 核心流程图

### 6.1 用户身份转换流程
```
游客
  ↓ 浏览信息，触发注册
注册用户
  ├─ 购买教练课程套餐 ──→ 学员
  └─ 购买次卡 / 月卡 ───→ 自由游泳者

学员 + 自由游泳者（可同时具备）
  ↓ 课时用完
自由游泳者
  ↓ 月卡 / 次卡过期
注册用户
```

### 6.2 预约流程
```
学员选择教练 / 时间
    ↓
提交预约
    ↓
教练确认 / 拒绝 / 协商
    ↓
预约成功 → 发送通知
    ↓
上课前提醒
    ↓
学员入场签到 → 教练收到通知
    ↓
上课 → 教练记录上课内容 → 消耗课时
    ↓
学员课后总结与评价
```

### 6.3 购买套餐流程
```
用户浏览套餐
    ↓
选择套餐 / 自定义套餐
    ↓
生成订单
    ↓
教练二次确认（可修改价格 / 次数）
    ↓
用户确认
    ↓
支付
    ↓
管理员确认订单 → 身份变更为学员 → 订单生效
```

### 6.4 购买次卡 / 月卡流程
```
用户浏览次卡 / 月卡
    ↓
选择卡种
    ↓
支付
    ↓
身份变更为自由游泳者
    ↓
可入场签到、查看余额
```

### 6.5 退款流程
```
用户发起退款
    ↓
系统计算可退金额
    ↓
教练确认
    ↓
管理员审批
    ↓
原路退款 → 通知用户
    ↓
若课时 / 余额清空，身份相应降级
```

## 7. 数据与合规

### 7.1 数据安全
1. 用户手机号、邮箱、支付信息加密存储。
2. 敏感操作（支付、退款、修改价格）需二次确认。
3. 操作日志记录，支持审计。
4. 数据库定期备份。

### 7.2 隐私合规
1. 首次注册需用户同意隐私协议。
2. 明确告知数据用途，支持撤回授权。
3. 符合 GDPR、CCPA、国内《个人信息保护法》要求。
4. 未成年人信息需监护人授权。

### 7.3 健康与免责
1. 下水前勾选健康承诺（无心脏病、皮肤病等）。
2. 新学员首次购课或入场前电子签署免责协议。

## 8. 非功能性需求

### 8.1 性能
1. 小程序首页加载时间 < 2 秒。
2. 预约高峰期并发支持 1000 QPS。
3. 视频上传支持断点续传。

### 8.2 可用性
1. 系统可用性 99.9%。
2. 支付链路具备重试与对账机制。
3. 关键操作支持降级方案。

### 8.3 扩展性
1. 预留多场馆、多城市扩展能力。
2. 预留物联网硬件接入接口。
3. AI 模型可配置切换。

### 8.4 多端一致性
1. 小程序与 App 数据互通。
2. 教练复杂操作建议在 Web 后台完成。
